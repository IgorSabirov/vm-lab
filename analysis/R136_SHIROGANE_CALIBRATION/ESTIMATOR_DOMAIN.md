# На каком объекте определён D₁₃₆

D₁₃₆ — контраст двух оценок по ансамблям SU(3) при Nₜ=8. Положение пика восприимчивости даёт β_c(V), совместное чтение рис. 15 и 3 даёт x_V. В каждой оценке β₀(V)=β_c(V)+F(8)−F(8x_V) константа c при замене F→F+c исчезает точно ещё до вычитания объёмов. Общий сдвиг двух уже вычисленных β₀ также сокращается в их разности. Для горизонтального сдвига двух x локальные коэффициенты дают (0.6219823−0.6228593)δx≈−0.0008770δx. Для противоположных сдвигов модуль коэффициента равен 1.2448416. В переборе ±½ единицы EPS максимальное изменение при общем смещении маркеров составило 1.87×10⁻⁹, при восьми локальных сдвигах 3.46×10⁻⁶. [Статистический бюджет](REPORT.md#statistical-budget)

Смена объёма при фиксированном Nₜ сравнивает разные пространственные размеры. Источник остатка остаётся открытым. Для физического вывода нужны точные авторские β-узлы и совместная ковариация. Отдельный межобъёмный контраст метода производных и SFtX при t→0 равен +0.47968±0.24411 в диагональном сценарии. Для двух объёмов у модели c+b/Nₛ² нет остаточной степени свободы. [Сопоставление оценивателей и сценарии корреляций](METHOD_VOLUME.md)

Полевая голономия h, функционал историй 𝔇(A,B) и ансамблевый D₁₃₆ имеют разные области определения. Чтобы вычислять D₁₃₆ на историях, нужна модель парных ансамблей со сканированием по β, процедурой matching и правилом записи результата. Геометрическая история ADD этих входов не определяет. Сравнение с R140 относится к способу задания инварианта. [Общая схема сопоставления](https://github.com/IgorSabirov/vm-lab/blob/research/r140-haar-sorkin/analysis/NOW_PROJECT_INTEGRATION_20261119/INVARIANT_OBSERVABLES.md)

**Уточнение к архивной формулировке R136.1.** Условие J₁₅(x_V)=J₃ объединяет две оси. Высоту задаёт рис. 3, координату x_V даёт горизонтальная ось рис. 15. При поиске этого корня абсолютный аддитивный якорь F не используется. Каноническое значение контраста по неокруглённой реконструкции равно 0.000622844634102. Разность двух отдельно округлённых якорей равна 0.000622900. Точность вычитания и физическая неопределённость исходных измерений описывают разные свойства.
