## 1. Что можно указать авторам уже сейчас

В журнальном тексте §4.5 на с. 18 решёткам с временным размером 8, 12 и 16 приписаны соответственно красный ромб, зелёный круг и синий треугольник. Легенда самого рис. 13 на с. 19 задаёт другую последовательность.

| Временной размер | Описание в §4.5 | Легенда и маркер на рис. 13 |
|---|---|---|
| 8 | Красный ромб | Зелёный треугольник вверх |
| 12 | Зелёный круг | Синий ромб |
| 16 | Синий треугольник | Красный круг |

В правой панели измеряется скачок энтальпии J = Δ(ε+p)/T⁴. Векторная геометрия из препринта даёт для незакрашенных зелёных треугольников 1,51990 ± 0,21008 и 0,96997 ± 0,12005. В таблице VI первичной работы 2016 года для метода производных напечатаны ровно 1,52(21) и 0,97(12). Закрашенные треугольники дают 1,20213 ± 0,02560 и 1,13195 ± 0,01964. Они совпадают с таблицей 2 статьи 2021 года в схеме NNLO, μ₀. По горизонтали авторы намеренно сместили символы, поэтому физические отношения Nₛ/Nₜ здесь 6 и 8. Идентификация проверена одновременно по стилю, положению, значению и величине ошибки. Сохранённый код R136 уже читает правильные маркеры. [Статья 2021, §4.5 и рис. 13](https://doi.org/10.1093/ptep/ptaa184) · [Работа 2016, таблица VI](https://arxiv.org/pdf/1605.02997#page=17)

Для прямого сравнения метода производных и SFtX в рис. 13 авторы используют предел t→0. При сложении нарисованных ошибок в квадратуре получаются следующие разности «метод производных минус SFtX». В столбце t→0 использована отдельно оцифрованная экстраполированная точка рис. 3.

| Объём | При t/a²=1,4 | При t→0 |
|---|---:|---:|
| 48³×8 | +0,3740 ± 0,2113 (+1,77σ) | +0,3177 ± 0,2117 (+1,50σ) |
| 64³×8 | −0,1286 ± 0,1210 (−1,06σ) | −0,1620 ± 0,1216 (−1,33σ) |

Оба сравнения обходятся без температурной оси рис. 15. Ошибки методов могут коррелировать. По центральным значениям и опубликованным полосам отдельного убедительного противоречия между методами здесь не видно.

## 2. Что дала реконструкция шкалы рис. 15

На рис. 3 скачок J дан при объёмной критической связи βc(V). На рис. 15 величину J₁₅(x) получаем вычитанием холодной ветви из горячей при x=T/Tc. Сопоставлены одинаковые t/a²=1,4, NNLO, μ₀. По форме калибровочной кривой F из работы 2016 года восстановлены положения известных βc на опубликованной оси.

| Объём | βc (таблица 1) | Разность J₁₅(1)−J₃ | x, предсказанный по βc | Остаток при этом x | x, при котором J₁₅(x)=J₃ |
|---|---:|---:|---:|---:|---:|
| 48³×8 | 6,06160(18) | +0,13062 | 0,99735381 | +0,02444 | 0,99678487 |
| 64³×8 | 6,06247(14) | +0,05835 | 0,99875164 | −0,02930 | 0,99918332 |

Разности двух восстановленных опорных значений β₀ соответствует D = βc(48) − βc(64) + F(8x₆₄) − F(8x₄₈) = 0,00062284463. Общая добавка к F сокращается точно. Корни x всё ещё считываются по горизонтальным координатам рис. 15, так что локальная деформация шкалы и выбор формы F могут влиять на D. Вариант с табличной опорой и локальным наклоном даёт остатки +0,03656 и −0,01010. Знак остатка на каждом объёме сохраняется при обеих проверенных реконструкциях. [Калибровка, уравнение 42](https://arxiv.org/abs/1605.02997) · [Статья, §§3 и 5](https://arxiv.org/pdf/2011.10292v2)

По §3.1 максимум восприимчивости определяет βc. Согласно §3.2, для рис. 3 авторы классифицируют конфигурации на hot/cold, отбрасывают смешанные и перевзвешивают средние по фазам. В §5 для рис. 15 тоже указано многоузловое перевзвешивание фаз. Толкование рис. 3 как отдельного «пикового оценивателя» амплитуды J лишено основания в тексте. Если условия отбора, веса, нормировка и β совпадают, вычитание двух секторных средних определяет один и тот же скачок. Возможное различие деталей реализации нужно проверить по исходным материалам.

## 3. Что говорят ошибки

Проверены 441 сочетание ρ(h,c) и ρ(15,3) от 0 до 1 с шагом 0,05. Первое число задаёт корреляцию фазовых значений, второе — корреляцию их разности с J₃ того же объёма. Ошибки объёмных βc считались независимыми друг от друга и от скачков, межобъёмная корреляция ошибок скачков задана нулевой. Графические ошибки и линейное распространение использованы в обеих версиях. Эти предположения нельзя считать оценкой корреляций по ансамблям.

| ρ(h,c)=ρ(15,3) | z по соглашению R136.1 | z, если ошибки и наклоны взять в корне |
|---:|---:|---:|
| 0 | 1,104 | 1,103 |
| 0,5 | 1,550 | 1,551 |
| 0,7 | 1,821 | 1,826 |
| 0,9 | 2,112 | 2,129 |

Порог z=1,96 на диагонали равен соответственно 0,7931 и 0,7870. Вне диагонали при ρ(h,c)=0,5 архивный порог по ρ(15,3) равен 0,7865. При ρ(h,c)=0,9 он равен 0,8094. Максимум на всей выбранной сетке получается на границе ρ(15,3)=1 и только описывает предположение о совершенной корреляции. Из этой таблицы нельзя выбрать фактическое p. Необходимо совместно перевзвешивать и оценивать βc и скачки в каждом блоке jackknife. См. covariance_grid.csv.

Точный D и контраст, входящий в подбор общего сдвига методом обобщённых наименьших квадратов (GLS), вычислены двумя способами. В GLS входят остатки r и наклоны s при предсказанных βc. Получается Dₗᵢₙ = r₄₈/s₄₈ − r₆₄/s₆₄ = 0,00062878259. При w=(1/s₄₈,−1/s₆₄) верно χ²min = Dₗᵢₙ²/(wᵀCw). Программа проверяет тождество с допуском 10⁻¹⁰. Отношение квадратов двух центральных контрастов объясняет около 1,9% разницы в опубликованной проверке. При ρ=0 и 0,9 соответственно воспроизводятся χ²min=1,241 и 4,545, p=0,265 и 0,033 для одной степени свободы. В выводе audit_invariant_D.py перепутаны подписи двух вспомогательных величин. Значение 0,00062878 получено из остатков реконструкции по кривой, 0,00062480 — из остатков по табличной опоре. В тексте §2 R136.1 соответствие дано верно.

Если в J₁₅ ввести аддитивные смещения b₄₈ и b₆₄ при фиксированном J₃, линейный отклик D составляет примерно b₄₈/s₄₈ − b₆₄/s₆₄. Оценка масштаба 0,00029–0,00073 в отчёте относится к сдвигу 0,02–0,05 на одном объёме 48³. При одинаковом смещении обеих кривых, s₄₈=68,96 и s₆₄=106,78, масштаб составляет 0,00010–0,00026. Ни одна из этих оценок не измеряет фактическую систематику.

## 4. Остальные проверки из плана R136.1

* **Время потока.** На каждом объёме извлечено 50 точек при t/a² от 0,04 до 2,00 с шагом 0,04 и одна экстраполяция к нулю. Для обоих объёмов табличное окно фита 1,0–1,6. Если менять только J₃, сохраняя опубликованную кривую J₁₅ при t/a²=1,4, получаем D от 0,00058687 до 0,00069423. Знак при этой подстановке сохраняется. Для измерения самого D(t) нужны фазовые ряды рис. 15 при соответствующих t. Разность двух дрейфов J₃(1,4)−J₃(0) составляет −0,02285 ± 0,04215 при независимых ошибках. Данные и признак экстраполяции приведены в fig3_flow.csv.
* **Край холодной ветви 64³, рис. 16.** Независимый разбор координат PDF даёт 0,58406 ± 0,23202 около x=1,00798 и 0,39701 ± 0,35766 при x=1,00878. Они согласуются с исходным EPS. На графике действительно есть снижение на 0,18705. При независимых ошибках это 0,44σ. Для физической интерпретации нужны корреляция соседних точек и статистика метастабильной выборки.
* **Калибровочная кривая.** Все 100 вертикальных координат β в использованной ломаной различны. Предположение о повторяющихся β в этой последовательности не подтвердилось. Остаток от полиномиальной аппроксимации нарисованной линии не оценивает статистическую ошибку решёточных данных.

## 5. Что решит U013

Для каждого из двух объёмов самый короткий контроль — получить использованные пары (β,T/Tc), явное определение Tc и фазовые значения рис. 15, перевзвешенные непосредственно к табличному βc при t/a²=1,4, NNLO, μ₀. Следом нужны согласованные по блокам реплики для J₃, горячей и холодной ветвей и оценки βc, либо ковариация соответствующих величин. В данных должны быть указаны общность ансамблей, маски фаз, обработка смешанных состояний и веса.

1. Если при одинаковой β фазовые значения воспроизводят J₃, можно установить, какая часть исходной разности возникла из-за выбора температурной опоры.
2. Если при одинаковых β, масках, весах и схеме остаётся расхождение за пределами совместной ошибки, появляется численный контрпример для разбора с авторами.
3. Несоответствие маркеров §4.5 и рис. 13 документируется отдельно уже по публикации. Оно не решает пункты 1–2. Статус R136/U013 открыт. Для EOS #167 проверка не поставляет граничных скоростей звука.

В проверенном PR упал test-integrity. Журнал указывает на устаревшие производные реестры INDEX.json, INDEX.md и RESULTS_REGISTER.md. Это техническая причина блокировки слияния. [Журнал Actions](https://github.com/IgorSabirov/vm-lab/actions/runs/44987632872/job/137101696675)

## Воспроизведение пакета

Код опирается на extract.py и verify.py из указанного коммита vm-lab, два исходных архива arXiv и PDF препринта 2021 v2. Сначала сравнивает извлечённые структуры FIGURES.json и CHECKS.json с архивом на точное равенство, затем выполняет дополнительный анализ. Контрольные суммы всех шести EPS проверяются функцией extract.read_figure. Версии среды проверки — Python 3.12.14, NumPy 2.3.5, SciPy 1.17.0, PyMuPDF 1.26.6. Архивы учёных и исходные конфигурации в пакет не включены.

```bash
git clone --filter=blob:none --no-checkout https://github.com/IgorSabirov/vm-lab.git vm-lab
git -C vm-lab fetch origin 6ec62e7bcd218c36f18739036604865fdd9aa2ba
git -C vm-lab checkout --detach FETCH_HEAD
curl -fL https://arxiv.org/e-print/2011.10292v2 -o 2021.tar
curl -fL https://arxiv.org/e-print/1605.02997v1 -o 2016.tar
curl -fL https://arxiv.org/pdf/2011.10292v2 -o source.pdf
python -m pip install numpy==2.3.5 scipy==1.17.0 pymupdf==1.26.6
python audit.py vm-lab/analysis/R136_SHIROGANE_CALIBRATION 2021.tar 2016.tar source.pdf output
```

results.json содержит точные числа, сценарные пороги и SHA-256 входных файлов. covariance_grid.csv содержит обе версии распространения ошибок. fig3_flow.csv позволяет отдельно проверить каждый шаг по времени потока.
