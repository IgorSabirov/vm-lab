# Карта литературы: результаты, цена и предел переноса

3 ноября 2026. 47 работ по связанным направлениям. Это адресный обзор
основных маршрутов, не утверждение об исчерпании мировой литературы.
Поиск велся по исходным вопросам проекта, названиям работ, авторам и текстам
ключевых статей. Приоритет — статьи авторов, издатели, arXiv и авторские копии.
Необоснованные совпадения поисковых запросов не включены.

Степень проверки: **Т** — прочитаны релевантные разделы полного текста;
**А** — проверены аннотация/издательская карточка, не весь ход доказательства;
**В** — проверен первичный вводный фрагмент, полное доказательство не изучено.
Отметка Т не означает построчной проверки всей статьи. URL ведут к источникам;
чужие полные тексты не перепечатаны. Формулировки ниже — краткие пересказы
и наша оценка применимости, а не цитаты.

## Что эта литература не позволяет утверждать

1. «Квантовая теория выводится» всегда означает вывод из определённых аксиом,
   а не из отсутствия всякой структуры.
2. Изометрия, смена часов, представление канала и coarse-graining не выбирают
   автоматически состояние мира или меру порождения.
3. Типичность относительно меры не является выводом самой меры.
4. Равновесие большую часть времени, точный возврат и самоподдержание — разные результаты.
5. Квантовые записи и операциональная объективность не задают ещё Я/Мысль.

Практическая очередь чтения для восстановления: **L46/L45 → L08 → L18 → L13 → L02/L03
→ L09 → L34 → L21 → L47**. Это порядок устранения конкретных долгов проекта,
не рейтинг научной важности и не разрешение нового эксперимента.
