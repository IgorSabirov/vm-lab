## Основной результат

Для ветви соседей с **заменой источников битов и обратными рёбрами** получено
аналитическое тождество **F⁴=id на направленных циклических словах при любом L**.
Оно выполняется для всего четырёхбитного алфавита, а не только для E0.
Следовательно, поиск неограниченного роста в этой ветви закрыт: его нет.
Возможные минимальные периоды слова — 1, 2 и 4. Период имён отсюда не следует.

При этом данная ветвь не проходит Q²=τ на именованных графах. Буквальная ветвь
с обратными рёбрами также не проходит этот контракт. Поэтому утверждение из
сообщения, что сравниваются два корректных квадратных корня одного авторского
транспорта, **не подтверждено и для явно заданных здесь операторов неверно**.
Обратимость каждого Q не означает Q²=τ.

При сохранении направления новых рёбер и переносе битов как на Fig. 2(a)
получается другая, третья система. Для неё Q²=τ выполняется с точными именами;
для E0 доказана дихотомия «вечно тихая орбита / неограниченный рост», хотя
сплиты могут разделяться длинными паузами. Авторское соответствие всей C2-модели
этим не аттестовано; NOW остаётся BLOCKED.

## 2. Четыре оператора вместо смешения двух смыслов

Старые рёбра: `u_i:b -> u_(i+1):a`.
Во всех вариантах `w_i = u_i.r ∨ u_(i+1).l`.
Порядок компонент исходника: **(a1,b1,a2,b2)**.
Ниже формулы применяются поканально; C1 означает a2=b2=0.

| ID | Новое ребро | Биты в w_i | Квадрат на именованном графе |
|---|---|---|---|
| LITERAL_DEF4 | w_i -> w_(i−1) | (a_i,b_(i+1)) | Не τ |
| FIG2A_BITS_ONLY | w_i -> w_(i−1) | (a_(i+1),b_i) | Не τ |
| FIG2A_FULL | w_i -> w_(i+1) | (a_(i+1),b_i) | τ |
| PRESERVE_EDGES_LITERAL_BITS | w_i -> w_(i+1) | (a_i,b_(i+1)) | τ⁻¹ |

FIG2A_BITS_ONLY — именно ветвь нового отчёта соседей: в нём явно оставлено
`w_i -> w_(i−1)`. Рисунок показывает соединение b левой новой вершины с a
следующей справа, поэтому изменение одних битов не воспроизводит весь рисунок.
Зависящего от чётности зеркального правила ни в одном из четырёх вариантов нет.

Для обратных рёбер имя вершины после двух шагов:

`z_i = w_i.r ∨ w_(i−1).l = u_(i+1).l ∨ u_(i−1).r`.

При обоих указанных правилах битов в z_i восстанавливается старое состояние
u_i. Циклическое слово возвращается, но имена не восстанавливаются и частицы
не оказываются у требуемых портовых соседей.

Для прямых рёбер:

`z_i = w_i.r ∨ w_(i+1).l = u_(i+1).l ∨ u_(i+1).r = u_(i+1)`.

С заменой источников битов на исходных именах получается
`a'_i=a_(i+1), b'_i=b_(i−1)`, то есть независимый перенос по соответствующему
порту. Без замены получается обратный перенос. Это алгебраическое вычисление,
а не вывод из числа совпавших случайных тестов.

Проверены 336 графов: все C2 длины 1,2 и все C1 длины 3. На них совпали
самостоятельная динамика слов и графовая реализация Q, I2, QI2; проверены
I2²=id, обе композиции Q и его обратного, сохранение частиц и A1.
Отдельные 16 однокомпонентных мировых линий на четырёх именованных вершинах дали:

| Режим | Q²=τ, точное равенство |
|---|---:|
| LITERAL_DEF4 | 0/16 |
| FIG2A_BITS_ONLY | 0/16 |
| FIG2A_FULL | 16/16 |
| PRESERVE_EDGES_LITERAL_BITS | 0/16 |

Если сравнивать только однокомпонентное слово с точностью до вращения, все
четыре режима дают 16/16. Это конкретный ложноположительный результат слабого
критерия; смешанная конфигурация и точные имена устраняют его.

## 3. Доказательство F⁴=id для FIG2A_BITS_ONLY при любом L

Работаем на непустых конечных направленных циклических словах с точностью
до вращения, без отождествления отражений. I — проекция сохранённого I2:
для каждого канала c чистое состояние A_c+B_c заменяется парой A_c,B_c,
а соседняя пара A_c,B_c сливается обратно. Другие биты исключают этот редекс.
Редексы не пересекаются, I²=id. Различный порядок имён второго канала не
меняет данную проекцию: по направлению b->a дети снова стоят A_2,B_2.

Обозначим обратный полусдвиг с заменой источников битов через Q. Прямой
подстановкой Q²=id на словах. Это равенство относится только к проекции.

Определим J=QIQ. У J есть независимое локальное описание:

`s,t  <->  s,0,t`,

если b-половина s содержит ровно одну частицу канала c, а a-половина t —
ровно одну частицу того же канала. Остальные, внешние половины s и t
произвольны. Здесь 0 — полностью пустая четырёхбитная вершина.

Почему это J: в первом Q обращённые друг к другу половины попадают в одну
чистую двойную вершину; её I-расщепление и второй Q вставляют между исходными
состояниями пустую вершину. В обратном случае чистая пара для I после первого
Q требует ровно одного пустого старого среднего узла и тех же наружных
половин. После слияния и второго Q этот пустой узел исчезает.

J меняет только нулевые промежутки; состояния непустых вершин сохраняются.
Он одновременно переключает промежутки длины 0 и 1, а более длинные не
трогает. Удаляемые нули не соседствуют. Разные переключения могут делить
неизменяемую граничную вершину. Поэтому описание корректно также на малых
кольцах, включая самозамыкание, и J²=id.

**I и J коммутируют.** Внутреннее ребро I-пары A_c->B_c имеет пустые
обращённые друг к другу половины: b(A_c)=0 и a(B_c)=0. Оно не является
допустимым промежутком J. При split/merge внешние половины a слева и b
справа сохраняются; следовательно, допустимость всех прилегающих J-переключений
не меняется. В свою очередь J не меняет непустые состояния и вставляет/удаляет
ноль только между вершинами с непустыми b слева и a справа. Такое ребро не
является I-парой; J не создаёт и не разрушает I-редекс. Это покрывает также
общие граничные вершины и разные каналы. Итак, IJ=JI.

Для полного шага F=QI:

`F² = QIQI = JI`,

`F⁴ = JIJI = J²I² = id`.

Это доказательство для **всех** конечных слов четырёхбитного алфавита,
без ограничения E0 или L. Неограниченный рост числа вершин невозможен,
поскольку длина — функция слова, возвращающегося через четыре шага.
Для произвольного старта грубая верхняя граница длины орбиты по числу вершин
— 4L: I и J по отдельности увеличивают длину не более чем вдвое.

Для X∈E0 имеем IX=X. Из коммутирования следует I(JX)=JX, и орбита имеет вид

`X, QX, JX, QJX, X`.

Её размеры равны **L,L,L',L'**, где `ceil(L/2) <= L' <= 2L`.
Это две ограниченные величины, даже если чередуются split и merge.

Независимые конечные проверки тождеств J=QIQ, J²=id, IJ=JI и F⁴=id
выполнены на всех **1 118 480** словах длины 1–5, через 227 712 представителей
вращений с точными весами. Они проверяют код и локальное описание;
доказательство произвольного L даёт рассуждение выше.

Числа относятся к размеченным исходным словам; вращения использованы только

| 2 | 192 | 86 | 76 | 30 | 30 | 4 |

При L=5 ровно **70 активных стартов имеют период 2**, а не 4. Пример в
целочисленной кодировке `(бит0=a1, бит1=b1, бит2=a2, бит3=b2)`:

`(0,1,6,1,6) -> (1,2,4,3,4) -> (0,1,6,1,6)`

с точностью до вращения. Начало принадлежит E0; во втором слове одновременно
есть один сплит 3 и один мердж 1->2. Размер остаётся 5. Это опровергает
экстраполяцию «все активные старты имеют период 4», но не теорему F⁴=id.

с независимым перебором. В частности, L=5 даёт 301804 тихих, 192320 только
со сплитом, 12920 только с мерджем и 3620 с обоими мотивами.

## 5. Что меняется у FIG2A_FULL: отдельная дихотомия

Для прямых новых рёбер и заменённых источников битов мердж на соседних
w_i,w_(i+1) требует чистого старого сплита в u_(i+1). Поэтому Q переводит
состояние без сплитов в состояние без мерджей.

Если в X нет мерджей, I расщепляет все чистые двойные вершины и не создаёт
новых сплитов. Поэтому QI(X) снова не имеет мерджей. Из E0 по индукции
мерджи отсутствуют на всей орбите, а

`L_(t+1) - L_t = S(X_t) >= 0`.

Если размер ограничен, множество возможных четырёхбитных слов конечно.
Оператор F обратим на этом факторе: I — инволюция, Q — обратимый перенос
половин состояний. Следовательно, ограниченная орбита периодична с самого
начала. Неубывающая периодическая длина постоянна, значит S(X_t)=0 всегда.
Любой хотя бы раз возникший сплит тем самым **доказывает неограниченный рост**.

Итак, для данного FIG2A_FULL и сохранённого I2 при любом L:

- либо старт навсегда тихий и слово периодично;
- либо появляются сплиты и размер неограниченно растёт; мерджей из E0 нет.

В тихом режиме Q по координатам слова сдвигает a-половину на один индекс,
оставляя b-половину на месте, поэтому период слова делит L.
Отсутствия мотивов только на первом полушаге недостаточно для вечной тишины.
Эта теорема не обещает сплит на каждом шаге или линейный рост.

Перебор E0 для L=2..4 с горизонтом 32 проверил отсутствие мерджей,
формулу изменения размера и обратимость. Активные траектории не объявляются
неограниченными по одному горизонту: этот статус следует из доказательства.

| L | FIG2A_FULL: вечно тихие | FIG2A_FULL: неограниченные по теореме | LITERAL_DEF4: вечно тихие | LITERAL_DEF4: неограниченные |
|---:|---:|---:|---:|---:|
| 2 | 162 | 30 | 162 | 30 |
| 3 | 1 682 | 978 | 2 042 | 618 |
| 4 | 16 386 | 20 470 | 25 890 | 10 966 |

В LITERAL_DEF4 действует более сильный механизм: мерджей из E0 нет,
внутреннее ребро каждого расщепления сразу порождает новый сплит, поэтому
число сплитов не убывает. При отсутствии первого сплита Q² возвращает слово;
при его появлении длина впоследствии растёт на каждом полном шаге.
Эти положения также независимо проверены для L=2..4.

Таким образом, дыхательная периодичность соседской ветви — свойство именно
сочетания обратных рёбер с заменёнными битами. Её нельзя переносить на
реконструкцию всего рисунка, проходящую квадрат транспортного оператора.

## 6. Спектры и инвариантность тихого класса

Три характеристических многочлена соседей независимо воспроизведены SymPy 1.14.0:

`chi_E = lambda^14 (lambda²−14lambda+2)`;

`chi_QL = lambda^13 (lambda−1)(lambda²−13lambda+4)`;

`chi_QB = lambda^187 (lambda³−lambda²−2lambda−1)
                   (lambda⁴−13lambda³+6lambda²+7lambda+4)`.

Парная матрица QB имеет 194 состояния и 2424 перехода, как в полученном
отчёте. Её следы степеней 2..5 совпали с независимым перебором:
162,1952,24218,301804; для L=6 получено 3763548.

Для двух обратных вариантов Q²=id на словах. Поэтому множество
`{X: IX=X и I(QX)=QX}` **инвариантно при любом L**: следующий шаг есть QX,
а затем возвращается X, и на обоих шагах I тождественен. Для FIG2A_BITS_ONLY
это в точности считаемый 194-состоянийной матрицей класс. Прежнее ограничение
«инвариантность не доказана для произвольного L» теперь снято для этой ветви.

Доминирующие корни и отношения из соседского отчёта сохраняются:
λ_E≈13.8556546004, λ_QL≈12.6846584384, λ_QB≈12.4718523471;
κ_L≈0.9154860455, κ_B≈0.9001272554. Убывает доля среди E0, не абсолютное число.
Эта матрица **не** считает вечную тишину FIG2A_FULL.

Сектор L=12,(4,6,7,7): старые 33483953832 и 7971639792 относятся к literal.
Они сохранены как ранее полученный результат; дорогой DP здесь не повторялся.
Коэффициент QB для этого сектора по-прежнему не вычислен. Из переноса спектра
на инвариантный тихий класс не следует автоматический перенос секторного числа.

Следующая содержательная работа: согласовать с первоисточником весь оператор
FIG2A_FULL вместе с C2-правилами, затем проверить необходимые временные симметрии
и интерфейс геометрического блока. Отдельный математический вопрос — действие
F⁴ на именах при тождественном слове. Искать растущие слова FIG2A_BITS_ONLY
или снова перебирать малые L для этой цели больше не требуется.

Не начаты: ВМ, большой секторный DP, патч основного NOW-исполнителя, внешняя
переписка. Этот отчёт, исходники, машинные данные и обновление R126 сохраняются
в `main` по действующему разрешению пользователя.
