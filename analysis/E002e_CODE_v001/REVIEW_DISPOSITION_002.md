# Проверка второго ревью и уточнения

1. **Нулевой знак — подтверждённый дефект.** При нулевых значении, ошибке и
   допуске прежняя включённая граница могла подтвердить положительный знак.
   Теперь весь интервал должен строго лежать за положительным/отрицательным
   допуском. Ноль, касание и неразрешённое пересечение — NUMERICALLY_UNRESOLVED;
   уверенно противоположный знак — PREDICTION_FAILED. Добавлены оба знака,
   нулевой/ненулевой допуск, границы, поддержка и опровержение. Все 32 теста
   прошли на финальном коде. Copilot подтвердил исправление, тесты сам не запускал.
2. **Равенство номеров коммитов — замечание снято после проверки.** Рабочее
   ядро пересчитывает SHA256 списка путей и содержимого всех его программных
   зависимостей и inventory. Этот хеш обязан совпасть с review, calibration,
   конфигурацией и проверкой предсказаний. Новая публикация отчёта изменяет
   commit ID, не ядро. Буквальное равенство старого ревью и нового запуска
   создало бы ложный отказ. Copilot рассмотрел код и согласился; научного
   разногласия для арбитража не осталось. Коммиты остаются аудитными указателями.
3. **Граница доверия лаунчера сохранена явно.** Worker сверяет VM_SOURCE_COMMIT
   с заявкой, но сам не запрашивает GitHub и не проверяет Git HEAD. Перед

   дополнительно независимо от этой метки. Если контракт службы не подтверждён,
