# Дополнительная проверка рабочего цикла

После успешных 20 тестов и отправки их пакета Copilot добавлены два
синтетических end-to-end теста. Ядро не меняется. Первый исполняет два малых
случая G с обеими независимыми NESS и проверкой отчёта. Второй заменяет
полный физический сборщик малой моделью только внутри тестового fixture:
NESS/refinement, три частоты, два QRT-шагa, экспорт/контрольные суммы.
Подмена явно тестовая; эти результаты не являются полной физикой E002e.

Ориентир до исполнения **0,8 с [0,35;2,0]** на весь процесс. Основание:
pilot/suite дали ~0,34–0,40 с на запуск/импорты/отчёт; малый NESS+референс
~0,017 с, частотный тест ~0,021 с, QRT ~0,018 с, малый экспорт ~0,027 с.
На более полный двухтестовый цикл оставлен ~0,40 с. Это экстраполяция
из измеренных компонентов, не отдельная калибровка производственного worker.
Проверить ровно два теста, отсутствие ошибок, полный отчёт и паспорт среды.
До исполнения тесты, план и расширенный выбор validate.py закрепляются в Git.
