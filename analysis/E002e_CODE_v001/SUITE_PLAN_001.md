# Полный набор предзапусковых тестов — прогноз до исполнения

Код 25617ee26b6037c46e3e203f821597b5d50fc03e. Пилот выполнил две проверки
полностью, 4 малые сборки и 3 пары новых/старых полных генераторов с 6
комплексными входами. Факт целого процесса 1,980963683 с против предварительных
5 с (−60,3807%). Неоткалиброванный ориентир был завышен; исторический статус
NOT_EVALUABLE сохранён. Сокращения объёма не обнаружено.

Измерено: малые сборки 0,117415856 с; полные 1,462249625 с; остаток процесса
0,401298202 с (импорты, загрузка тестов, паспорт и отчёт). Фактический OpenBLAS
0.3.30, один поток; NumPy 2.3.5, SciPy 1.17.0. Паспорт CPU/квот в pilot_001.

Полный набор — 20 тестов: те же 2 плюс 18 тестов малых решателей, ветвей,
G0, QRT, Schur, масочной деформации, селективных каналов и блокировок запуска.
Предварительный прогноз **3,2 с**, диапазон **[2,1;5,2] с**.
Расчёт: измеренные 1,981 с + ~0,49 с на две дополнительные полные операторные
сборки без полной Liouville-матрицы (масштаб ~половины пары пилота) + ~0,73 с
на дополнительные малые сборки/решения и проверки отчёта. Последние два
слагаемых — инженерная экстраполяция, не отдельные измерения. Разброс пилота
ещё не оценён; диапазон не доверительный интервал. После запуска сравнить
все 20 тестов, среду, пофазные времена и отклонение; при падении не объявлять
набор принятым даже при попадании времени в диапазон.

Новых полноразмерных NESS и производственных прогонов нет. Эти секунды
не являются бюджетом E002e на ВМ. Следующий шаг после успешных тестов —
закреплённый пакет и техническое ревью Copilot, затем проверка его замечаний.
