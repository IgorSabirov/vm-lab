# Разбор первого технического ревью

Содержание Copilot проверено по конкретным функциям. Его «prelaunch-одобрение»
не является пользовательской приёмкой. Большой прогон не запускался и до
целевой калибровки закрыт независимо от мнения Copilot.

|Замечание|Проверка и действие|
|---|---|
|Infinity/NaN/чрезмерный допуск F2|Подтверждено отсутствие конечности и внешнего cap. Добавлены конечный числовой допуск, отдельный закреплённый научный предел, негативные тесты. Предел не задаёт Copilot; он фиксируется в нашей проверке предрегистрации|
|Нет порога согласия LU/GMRES|Подтверждено. Добавлен отдельный refinement_gate для вектора и наблюдаемых с калибруемыми absolute/relative порогами; превышение останавливает этап как неразрешённый|
|Неоднозначный baseline/нет ошибок сырых разностей|Подтверждено. Полный физический ключ, запрет неизвестных override, отказ при дубликатах; ошибки J_h/h6/P складываются из обеих записей|
|Предрегистрация лишь самодекларация|Ограничение было описано, но программная связка недостаточна. Нужен отдельный хешированный отчёт нашей проверки содержимого обучающих файлов/истории коммитов, одинаковые списки входов, baseline digest и научные caps; проверены порядок дат и реальный source commit ВМ|
|Ошибки до/после основного цикла теряются|Подтверждено. Внешняя граница run сохраняет FAILED, terminal_failure и понижает прежний PASS; старый каталог запуска не перезаписывается. Добавлены отказы preflight, F2 evaluation и final export|
|Только две сетки QRT недостаточны для production|Принято как обязательство калибровки. Требуется опубликованная проверка представительного полного случая третьей сеткой либо независимым exp-action. Расширение всей серии без бюджета не запускается|
|Нет memory gate|Подтверждено. Обязательны измеренные RSS/хранение одновременно живых факторов и peak/reserve по этапам; сопоставление с текущими cgroup и MemAvailable|
|Не проверяется full/|Подтверждено. В report добавлен full_manifest с хешами/размерами; worker сверяет полный набор локально. Дистанционный доступ к полному архиву по-прежнему только по указанию пользователя|
|Пакетные статические RHS|Математически допустимо. Не объявлено улучшением производительности без замера на ВМ; выбранный текущий поочерёдный путь корректен и расходует меньше временной памяти. Может быть оценено на калибровке без смены физики|

Дополнительно собственная проверка добавила машинную сверку пар ±ε и ±ω,
а также запрет объявлять случай покрытым подтверждающим предсказанием, если
его коэффициент в вычисляемой комбинации нулевой/отсутствует.

Новые пороги и шаблоны — исходные условия будущей калибровки, не измеренная
точность. История Git/доступ к данным не доказывается одним булевым полем:
проверяющий обязан получить содержимое через GitHub, сверить хеши и порядок,
после чего закрепить отдельный артефакт. Рабочий код проверяет совпадение
артефактов и заявок, но не имеет сетевого доступа для самостоятельного Git API.
