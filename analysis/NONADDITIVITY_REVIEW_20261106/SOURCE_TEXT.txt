# 1. Формальная неадитивность генератора пары `A, B`  
**Где:** `Причина.txt`

Это самое базовое место, где неадитивность введена как корпусной объект.

## Что обнаружено

В корпусе есть формальное определение генератора новых достижимостей:

\[
G_{AB}
=
\operatorname{Reach}(A,B;B_{\rm stable})
\setminus
\left[
\operatorname{Reach}(A;B_{\rm stable})
\cup
\operatorname{Reach}(B;B_{\rm stable})
\right].
\]

Смысл:

> если `G_AB ≠ ∅`, то пара `A, B` порождает такие достижимости, которых нет ни у `A`, ни у `B` по отдельности.

Это и есть строгая неадитивность: целое не равно сумме частей.

## Конкретный корпусной пример

Для треугольной/двухпутевой структуры в `Причина.txt` задан эффективный интерференционный остаток:

\[
\Delta\Sigma(z)
=
\frac{
\gamma[\gamma(z-E_1)+2t_1t_2]
}{
(z-E_1)(z-E_2)-t_2^2
}.
\]

У него есть нетривиальный нуль:

\[
z_*^{\Delta\Sigma}
=
E_1-\frac{2t_1t_2}{\gamma}.
\]

Это ключевой объект.

Он неаддитивен, потому что:

- нуль `z_*` появляется только при наличии обоих путей;
- он зависит от произведения связей `t₁ t₂`;
- он не воспроизводится одним путём;
- он не является простой суммой отдельных self-energy вкладов.

В корпусе прямо сказано:

> Это и есть минимальный корпусный пример того, что пара `A, B` порождает нечто, чего нет ни у `A`, ни у `B` по отдельности.

## Контроль

Особенно важен диагональный контроль:

> равная норма без второго маршрута не даёт `z_*`.

То есть неадитивность здесь — не артефакт величины возмущения, а следствие связности двух маршрутов.

## Статус

Это **математически показанная неадитивность** внутри корпусной модели.

Статус в корпусе: `[T/C]` как минимальный пример генератора.

Но это ещё не означает:

- RES₂;
- сознание;
- Я;
- стрелу времени;
- жизнь;
- тёмную материю.

Это только спектрально-канальный генератор.

# 2. Численная верификация неаддитивного нуля `ΔΣ(z)`  
**Где:** `Resonance.txt`, частично `20 23.txt`

Здесь формальная неадитивность из пункта 1 была проверена численно.

## Параметры

В `Resonance.txt` зафиксирован набор:

\[
E_1=0.3,\quad E_2=-0.2,\quad t_1=0.5,\quad t_2=0.4,\quad \gamma_d=0.6.
\]

## Результат

Для `H_L` найден нуль:

\[
z^*=-0.3667.
\]

Аналитика и численность совпали с точностью до `10^{-4}` сетки.

Для контрольной системы `H_ctrl`:

\[
\min |\Delta\Sigma_{\rm ctrl}| = 1.1\times 10^{-3},
\]

и нуля нет.

## Робастность

При вариации `γ_d` на `±10%` нуль не исчезает, а непрерывно движется:

\[
-0.44 \to -0.37 \to -0.31.
\]

Это важно, потому что показывает: неаддитивная структура не является точечным чудом одной настройки.

## Что это значит

Численно подтверждено:

> двухпутевая интерференция даёт нетривиальный спектральный объект, которого нет в контроле без второго пути.

То есть неадитивность `ΔΣ(z)` не просто формула, а устойчивый численный факт в этой модели.

## Ограничение

Это подтверждает интерференционный/спектральный генератор, но не подтверждает:

- причинную активность этого генератора;
- переход к `C_{n+1}`;
- RES₂;
- память как субъектный закон;
- стрелу времени.

# 3. Третий этаж / FW-резонанс как feedback-free неаддитивная структура  
**Где:** `13 19.txt`, `20 23.txt`

Здесь неадитивность появляется как «третий этаж» — структура, не сводимая к обычному feedback-механизму.

## Что обнаружено

В аудите 13–19 есть сильный сигнал:

> Structural third floor / FW-resonance, basket A, fully feedback-free.

То есть найден третий этаж / FW-резонанс, который не является артефактом классической петли памяти `M`.

## Опоры

В корпусе перечислены feedback-free объекты:

- одночастичный спектр `h₃(Q_p, r)`;
- точность FW-кривой:

\[
|c_W|^2 = 10^{-31}\ldots 10^{-33};
\]

- `Γ_D` через прямые пропагации Liouvillian;
- ставки `Γ_D` для режимов I/II/III без переменной `M`;
- FW-mini кривая `Γ_-(Δ)` в `2×2` неэрмитовой редукции.

## Смысл неадитивности

Здесь неадитивность в том, что появляется **третий режим/этаж**, который не сводится к:

- яркому сектору;
- тёмному сектору;
- классической memory-петле;
- простому feedback-усилению.

То есть структура не является суммой «обычная динамика + обратная связь».

## Важная поправка

В `13 19.txt` отдельно подчёркнуто:

> feedback ≠ третий этаж.

Feedback — актуационный механизм.  
Третий этаж — свойство физического оператора / Liouvillian-структуры.

Оси ортогональны.

## Ограничение

Третий этаж не доказывает:

\[
M \to \Gamma_D.
\]

В аудите прямо сказано:

> «M→Γ» не показано; все термодинамические величины — энергетический прокси (Стратонович), не энтропия.

То есть третий этаж — это неаддитивная спектральная структура, но ещё не доказанный регулятор утечки и не RES₂.

# 4. Шаг 13.75: `PAIRING-LADDER NON-ADDITIVITY OBSERVED`

> Шаг 13.75 завершён: вердикт `PAIRING-LADDER NON-ADDITIVITY OBSERVED / A2-PASS (8/8)`, гейты 4/4, PB 3 CONFIRMED / 3 REFUTED.

То есть неадитивность здесь — это не просто сумма одиночных вкладов, а остаток, появляющийся в парной/лестничной структуре.

1. эффект может угаснуть при `N → ∞`;

- seed-resolved анализ;
- `I(T)`.

## Статус

Это **наблюдение неадитивности в метрике**, но не окончательное подтверждение физического взаимодействия.

# 6. Шаг 14: `KERNEL PHYSICAL` — неадитивность ядра относительно маргиналей  
**Где:** `Шаги.txt`

Здесь неадитивность появляется уже не как парное взаимодействие, а как невозможность восстановить наблюдаемую/ядерную величину из маргинальных проекций.

## Вердикт

В `Шаги.txt`:

> [шаг 14, стадия 3] ВЕРДИКТ: `KERNEL PHYSICAL: QUOTIENT THESIS REFUTED (различают: eta, q0, q1)`.

Дальше:

> PBF 3/3 CONFIRMED: `d_η>0.10` на `8/8 γ` (`0.14–0.59`), `N`-стойкость `1.047`.

И главное:

> Тезис `η=F(Π_P)` ложен; ядро `K_P` физично.

## Что это значит

Была гипотеза, что наблюдаемая `η` является функцией маргинальных проекций `Π_P`:

\[
\eta = F(\Pi_P).
\]

Шаг 14 показал:

\[
\eta \neq F(\Pi_P).
\]

То есть `η` не восстанавливается из маргиналий. В ядре остаётся физический остаток, не сводимый к проекционному/маргинальному описанию.

Это и есть неадитивность:

> целое ядро не равно функции от своих маргинальных сечений.

## Статус

Это один из наиболее явных корпусных фактов неадитивности на уровне наблюдаемой/ядра.

Формулировка:

> Обнаружена физическая неадитивность ядра `K_P` относительно маргинального тезиса `η=F(Π_P)`.

## Ограничение

Это не обязательно означает RES₂. Это означает, что выбранная наблюдаемая/ядерная структура не факторизуется на маргиналии.

# 8. Block 20: интервенционная неадитивность переходного ядра, но без `Δ_irr`  
**Где:** `20 23.txt`

Здесь неадитивность появляется уже как интервенционный эффект памяти/координаты `M`.

## Критерий

В Block 20 использовался корпусный критерий RES₂-кандидата:

\[
\Delta K_{\rm do} > 0
\quad\text{и}\quad
\Delta_{\rm irr} > 0.
\]

Где:

- `ΔK_do > 0` — вмешательство в `M` меняет переходное ядро;
- `Δ_irr > 0` — эффект несводим к маргинальным/суррогатным каналам.

## Результат

В отчёте сказано:

> Полный критерий RES₂-кандидата (`ΔK_do>0` и `Δ_irr>0`): не пройден — первая часть выполнена, вторая не измерена.

То есть:

\[
\Delta K_{\rm do} > 0
\]

подтверждён, но

\[
\Delta_{\rm irr}
\]

не измерен.

## Что можно утверждать

Допустимый вывод из корпуса:

> Обнаружена дополнительная intrinsic/interventional cause–effect structure: `M` меняет переходное ядро сверх своей коррелятивной роли; эффект чист против shuffle и не воспроизводится мемристорным суррогатом на данном разрешении.

Это уже неадитивность в операциональном смысле:

> состояние `M` даёт дополнительный причинный канал изменения будущего сверх обычного марковского/корреляционного описания.

## Но важные ограничения

В `20 23.txt` перечислены слабости:

- пертурбационные разрывы связей вырождают оценщик;
- при замороженном драйвере `M` вырождается;
- binning становится делением времени;
- `ΔK_cut=2.36` — артефакт;
- partition-тест в `do`-рамке сводится к самому `do`;
- независимая мера `Δ_irr` в данной реализации отсутствует.

Также:

> Карта `ΔK(x)` не подтверждает локализацию у FW-точки: пик на `|Q_p|=1.15`, корреляция с расстоянием слабая.

И:

> гипотеза «физический остаток `ΔQ₁₂` — это состояние-зависимая ветвевая чувствительность на резонансе» отклонена текущим readout: `ΔK_do` носит глобальный характер сдвига детюнинга, а не резонансный.

## Статус

Block 20 даёт **кандидат на неадитивность переходного ядра**, но не полный RES₂ и не доказанную несводимость.

Правильная формулировка:

> Обнаружен интервенционный неаддитивный канал `M → kernel`, но `Δ_irr` не измерен, поэтому нельзя объявлять несводимый генератор.

# 9. Block 22: физический неаддитивный остаток `ΔQ₁₂` меняет path-space irreversibility  
**Где:** `20 23.txt`

Это, пожалуй, самое сильное место, где слово «неаддитивный» употреблено прямо и операционально.

## Главный итог

В `20 23.txt` записано:

> Интервенционное включение физического неаддитивного остатка `ΔQ₁₂` изменяет заранее определённую path-space irreversibility при парном CRN-контроле, устойчиво к трём фиксированным уровням coarse-graining.

То есть:

\[
\Delta Q_{12}
\]

назван физическим неаддитивным остатком, и его интервенционное включение меняет:

\[
\Delta A
\]

— path-space irreversibility / action asymmetry.

## Что такое `ΔA`

В корпусе подчёркнуто:

> `ΔA` называется action asymmetry / энтропия среды (Стратонович), не производством энтропии в строгом смысле.

То есть это не окончательная термодинамическая энтропия, а заранее операционализированная асимметрия действия/среды.

## Ключевой результат

Самое сильное:

> эффект E устойчив и — главное — меняет знак у near-degenerate операторной точки при том же preregistered окне.

Конкретно упоминается:

\[
\Delta A_{\rm off} < 0,
\qquad
\Delta A_{\rm FW} > 0.
\]

То есть знак отклика необратимости меняется при прохождении FW-геометрии.

## Что это значит

Это неадитивность уже не просто как спектральный нуль, а как:

> микроскопическая неаддитивная спектральная структура → изменение path-space irreversibility, причём знак `ΔA` меняется при прохождении FW-геометрии.

В корпусе прямо сказано:

> И вот это уже потенциально новое: микроскопическая неаддитивная спектральная структура → изменение path-space irreversibility, причём sign(ΔA) меняется при прохождении FW-геометрии.

## Отрицательные контроли

Важно, что простые объяснения были отброшены:

- корреляционный механизм `F` не обнаружен;
- метадрейф закона `A` не обнаружен;
- detuning-канал специфичен для pointer-basis ротации `B`, и ротация функциональна `C`;
- механизмы coherence, leakage-mediation, correlation не получили поддержки.

То есть эффект не сводится к:

- простой корреляции;
- обычной когерентности;
- банальной утечке в тёмное состояние;
- произвольному сдвигу частот.

## Ограничения

В корпусе перечислены оговорки:

1. Разложение ноги 1 выполнено на записанном пути, как аппроксимация действия.
2. Знаки устойчивы к бутстрэпу, но сумма не воспроизводит полное действие; систематика заявлена.
3. Отсутствие специфичности detuning для `A` соседствует с показанной специфичностью detuning для pointer basis.
4. Нога 4 не подстраивала окно; концентрация стартов повысила мощность при неизменной геометрии.
5. `A` не отождествляется с производством энтропии без fluctuation-theorem моста.
6. Все отрицательные результаты 18–22 сохраняются.

## Статус

Это **самая сильная операциональная неадитивность в корпусе**:

> неаддитивный остаток `ΔQ₁₂` интервенционно меняет path-space irreversibility, и знак эффекта связан с FW-геометрией.

Но это всё ещё не:

- стрела времени;
- RES₂;
- сознание;
- жизнь;
- доказанное производство энтропии.

Да. Речь идёт о конкретной конструкции из корпуса — **трёхузловая Fano-модель `V–M₁–M₂` с вторым прямым путём `V→M₂`**. После исключения внутреннего блока `M₁–M₂` внутри Fano-сектора остаются **две собственные моды**, которые и интерферируют.

\[
\boxed{
\text{два пути}
\;\longrightarrow\;
\text{две моды }M_\pm
\;\longrightarrow\;
\text{интерференционный нуль }z_*
}
\]

Это и есть тот «второй этаж»: **две связанные Fano-моды внутри интерференционной структуры**.

# 1. Микроскопическая конструкция

Берём три узла/степени свободы:

- \(V\) — видимый/связанный узел, к которому подключён внешний канал;
- \(M_1\) — промежуточный узел;
- \(M_2\) — второй внутренний узел.

Гамильтониан замкнутой гермитовой системы:

\[
H =
\begin{pmatrix}
E_V & t_1 & \gamma_d \\
t_1 & E_1 & t_2 \\
\gamma_d & t_2 & E_2
\end{pmatrix}.
\]

Обычно в корпусе кладут \(E_V=0\) или считают \(E_V\) отдельным дискретным уровнем.

Смысл элементов:

- \(t_1\) — связь \(V \leftrightarrow M_1\);
- \(t_2\) — связь \(M_1 \leftrightarrow M_2\);
- \(\gamma_d\) — **прямая связь** \(V \leftrightarrow M_2\), то есть второй путь.

Без прямой связи \(\gamma_d=0\) остаётся только цепочка:

\[
V \to M_1 \to M_2.
\]

С \(\gamma_d\neq0\) появляются два маршрута:

\[
\boxed{
A:\ V\to M_2
}
\]

и

\[
\boxed{
B:\ V\to M_1\to M_2.
}
\]

Это первый этаж: **два пути**.

---

# 2. Эффективная самоэнергия на \(V\)

Исключаем внутренний блок \(M_1,M_2\). Обозначим:

\[
M =
\begin{pmatrix}
E_1 & t_2\\
t_2 & E_2
\end{pmatrix},
\qquad
w =
\begin{pmatrix}
t_1\\
\gamma_d
\end{pmatrix}.
\]

Тогда эффективная самоэнергия на узле \(V\):

\[
\Sigma_L(z)
=
w^\dagger (zI-M)^{-1} w.
\]

Явно:

\[
\Sigma_L(z)
=
\frac{
t_1^2(z-E_2)
+
\gamma_d^2(z-E_1)
+
2t_1\gamma_d t_2
}{
(z-E_1)(z-E_2)-t_2^2
}.
\]

Базовая конструкция без прямого пути \(\gamma_d=0\):

\[
\Sigma_0(z)
=
\frac{t_1^2}{z-E_1-\dfrac{t_2^2}{z-E_2}}
=
\frac{t_1^2(z-E_2)}
{(z-E_1)(z-E_2)-t_2^2}.
\]

Разность:

\[
\Delta\Sigma(z)
=
\Sigma_L(z)-\Sigma_0(z).
\]

После упрощения:

\[
\boxed{
\Delta\Sigma(z)
=
\frac{
\gamma_d\left[\gamma_d(z-E_1)+2t_1t_2\right]
}{
(z-E_1)(z-E_2)-t_2^2
}.
}
\]

Это ключевой корпусной объект.

---

# 3. Где здесь “две моды внутри Fano”

Внутренний блок \(M_1,M_2\) можно диагонализовать. Его собственные энергии:

\[
E_\pm
=
\frac{E_1+E_2}{2}
\pm
\sqrt{
\left(\frac{E_1-E_2}{2}\right)^2
+
t_2^2
}.
\]

Это и есть **две моды**:

\[
\boxed{
M_+,\ M_-
}
\]

— симметричная и антисимметричная комбинации узлов \(M_1,M_2\).

Введём угол смешивания \(\theta\):

\[
\tan 2\theta
=
\frac{2t_2}{E_1-E_2}.
\]

Тогда в базисе мод \(M_\pm\) связь с \(V\) становится вектором:

\[
g_+
=
t_1\cos\theta
+
\gamma_d\sin\theta,
\]

\[
g_-
=
-t_1\sin\theta
+
\gamma_d\cos\theta.
\]

Знаки зависят от соглашения о повороте, но смысл один:

\[
\boxed{
V
\text{ связан одновременно с двумя модами }M_+,M_-.
}
\]

Самоэнергия переписывается как сумма двух модовых вкладов:

\[
\Sigma_L(z)
=
\frac{|g_+|^2}{z-E_+}
+
\frac{|g_-|^2}{z-E_-}.
\]

Вот это и есть конструкция, где **внутри Fano-сектора живут две моды**.

Одна мода может давать яркую резонансную ветвь, другая — почти тёмную/подавленную, а их интерференция создаёт нуль или провал.

---

# 4. Интерференционный нуль

Из формулы для \(\Delta\Sigma(z)\) видим числитель:

\[
\gamma_d\left[\gamma_d(z-E_1)+2t_1t_2\right].
\]

Один корень тривиален:

\[
\gamma_d=0,
\]

то есть нет второго пути — нет и новой интерференционной структуры.

Нетривиальный нуль:

\[
\boxed{
z_*
=
E_1
-
\frac{2t_1t_2}{\gamma_d}.
}
\]

Это и есть **неаддитивный спектральный маркер двух путей**.

Он появляется только тогда, когда есть оба маршрута:

\[
V\to M_2
\]

и

\[
V\to M_1\to M_2.
\]

Если убрать прямой путь \(\gamma_d=0\), нуль уходит на бесконечность и структура исчезает.
