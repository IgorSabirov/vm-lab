## Научный результат и предел

Для авторски уточнённой кольцевой C1/A выполнен оставшийся подготовленный
протокол: Lemma 1/проекция на 5460 входах; 10920 коротких траекторий по 128 шагов;
28 длинных по 4096 и две обратные по 16384. В сохранённом аналитическом разборе
восстановлена цепочка конечности прямых слияний, роста порядка sqrt(t) вперёд
и t назад, логарифмического роста глобальной энтропии и убывания средней
локальной энтропии фиксированного окна. Конечные результаты согласуются с ней.
Гипотеза роста не применялась к контролям без одного/обоих типов частиц.

При объявленных S=ln binom(2k,q), k=min(L,2r+1) буквальный коэффициент Theorem 4
не подтверждён. На L=13, p=2, r=1 получено 0.8269659089 против 0.1538461538.
Оценка S_r <= (2r+1)ln(4r+2)p/L сохраняет вывод о локальном разрежении.
Нормировка/коэффициент остаются конкретным вопросом автору.

Ранее зарегистрированные результаты C2 — локальная симметрия обращения для
явного оператора и активная орбита слова (1,2,12) при постоянном L=3 — повторно
проверены в первом блоке пакета; это не новый R-результат. Универсальный или
типичный рост смешанной C2, C3 и damping этим прогоном не установлены.
Полезная функция, чтение следа, воспроизводство условий и происхождение
пространства-времени остаются открытыми.

## Исполнение и честное сопоставление

Все 11 входных файлов совпадают с архивом. Скачанные 144 файла Actions
совпали с Git blob SHA публикации. Все 91 raw совпадают после декомпрессии.
В 46 JSON: 80 различий времени/среды/прогноза, 15 добавленных вычисляемых
inverse_tail_status, одно различие prior_harness_failure; необъяснённых различий нет.
PNG совпал по пикселям. Исходный статус COMPLETE_REVIEW_DIFFERENCES сохранён.

Локальный пакет включал продолжение после исправления чрезмерного требования
линейного хвоста уже к t=4096. Copilot получил конечный код и исполнил весь
подготовленный корпус без resume. Старую ошибочную остановку он не повторял.
Среда GitHub: Python 3.12.16, NumPy 2.3.5, Matplotlib 3.10.7.
Семь команд — 63.626091 с, включая 0.905211 с двух калибровок; подготовка и
публикация исключены. Полного сопоставимого wall всей первой локальной попытки нет.
Исторические platform/timing_note в научных файлах не заменяют новую внешнюю квитанцию.
Copilot вызывал фиксированные execute/status; самостоятельный ремонт научного кода
этим исполнением не проверен.
