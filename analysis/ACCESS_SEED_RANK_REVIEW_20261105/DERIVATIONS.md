## 1. Строгая частичная ассоциативность и сильная связность

Пусть |X|=3 и x⊗a — частичная операция. Строгость означает совпадение
определённости и значений (x⊗a)⊗b и x⊗(a⊗b). Граф имеет рёбра x→x⊗a.
Предположим, все элементы лежат в одной сильной компоненте.

Любой непустой путь x→…→y можно свернуть в один шаг x⊗a=y:
по строгой ассоциативности существование очередной левой скобки обеспечивает
существование композиции меток пути и соответствующей правой скобки.
Для x=y непустой путь также есть: через любую другую вершину и обратно.
Значит, каждая строка таблицы принимает все три значения. В ней только
три клетки, поэтому каждая строка тотальна и является перестановкой X.
В частности, вся операция тотальна.

Обозначим L_x(y)=x⊗y. Все L_x — перестановки, и ассоциативность даёт
L_x L_y=L_{x⊗y}. Образ H={L_x} — конечная непустая подполугруппа группы
перестановок, следовательно группа: для любого элемента его конечные степени
содержат единицу и обратный.

Все слои отображения x↦L_x имеют одинаковую мощность. Действительно,
перестановка y↦L_z(y) переводит слой h биективно в слой L_z h; действие H
на себе слева транзитивно. Поэтому |H| делит 3: |H|=1 либо |H|=3.

При |H|=1 единственная перестановка p удовлетворяет p²=p, значит p=I.
Получаем правопроекцию x⊗a=a. При |H|=3 отображение x↦L_x биективно,
и X — группа порядка 3. На фиксированных метках {0,1,2} это ровно три
таблицы x⊗a=x+a+k mod 3, k=0,1,2. Выбор единицы даёт три таблицы;
для каждого выбора перестановка двух неединичных элементов — автоморфизм.

Итого ровно четыре строго ассоциативных таблицы со всеми тремя вершинами
в одной SCC. Это самостоятельное доказательство числа 4, не проверка
всего заявленного числа 442 строгих частичных таблиц.

## 2. Разные циклические предикаты

Если за три шага требуются попарно различные состояния x₀,x₁,x₂
и попарно различные использованные метки, в группе среди меток обязательно
есть единица. Соответствующий шаг оставляет указатель на месте и нарушает
условие попарной различности соседних состояний. Такая группа не проходит.

Правопроекция проходит: выбираем состояния 0→1→2→0 и метки 1,2,0.
По пункту 1 других строгих сильно связных таблиц нет. Значит, ровно один
строгий свидетель этого трёхшагового предиката — правопроекция.

При разрешении более длинного замкнутого пути все группы могут посетить
все состояния и использовать все метки, включая единицу как петлю.
Поэтому таких строгих таблиц четыре. Это не противоречит предыдущему числу 1.

## 3. Семена в новой копирующей семантике

Событие: x′=r=x⊗a, c′=c−e_x+e_r+e_a; запуск c=e_x.
Результаты разрешено использовать как новые метки доступа. Предполагается
именно соседский guard c_a≥1, допускающий совмещение ролей при x=a.

Все виды токенов, не предоставленные семенем, впервые возникают как r:
копируемая метка a уже должна присутствовать. Поэтому успешный замкнутый
маршрут с наличием всех типов посещает все состояния и требует полной SCC.
По пункту 1 остаются четыре таблицы. В правопроекции единственный начальный
тип порождает только себя. В группе начальная единица также остаётся единицей;
два неединичных элемента являются генераторами и имеют успешный путь.

Для x⊗a=x+a−1 mod 3 и семени 0:

| До: x,c | a | r | После: c |
|---|---|---|---|
| 0,(1,0,0) | 0 | 2 | (1,0,1) |
| 2,(1,0,1) | 2 | 0 | (2,0,1) |
| 0,(2,0,1) | 2 | 1 | (1,1,2) |
| 1,(1,1,2) | 1 | 1 | (1,2,2) |
| 1,(1,2,2) | 0 | 0 | (3,1,2) |

Перестановка меток переносит пример на все три таблицы и оба неединичных
семени. Таким образом, три успешные строгие таблицы и шесть семян следуют
аналитически при указанном guard; код Карпа—Миллера для этого вывода не нужен.

Пяти шагов достаточно и меньше недостаточно. В обычной записи Z₃ с единицей
0 стартуем с генератора s. Для трёх шагов, использующих все метки, сумма
меток равна 0; однако до применения нулевой метки её токен надо произвести.
Первый шаг s+s=2s, а использование следующей ненулевой метки 2s вернёт s
без производства 0. Нулевая метка пока недоступна. Для четырёх шагов,
использующих все метки, условие закрытия требует повторить именно нулевую
метку (сумма всех трёх меток равна 0). Поэтому ненулевая метка s используется
только один раз, а следующий возможный ненулевой шаг с 2s вновь не создаёт 0.
Успех за четыре шага также невозможен. Показанный путь из пяти шагов минимален.

## 4. Два отдельных участника: препятствие для однородного семени

Если реакция x+a→r+2a требует двух отдельных токенов, условие запуска
c≥e_x+e_a сильнее соседского guard. При a=x и c=e_x оно нарушено.
Поэтому однотокенное семя не делает ни одного шага ни в какой таблице.

При любом однородном семени c=n e_s, x=s, n≥1, сохраняется инвариант

\[
c=m e_s+e_x,\qquad m\ge0.
\]

Первоначально m=n−1. Если x≠s, в населении есть только токены s и один
токен x. Единственный потенциально новый доступ a=x требует второй
экземпляр x и потому запрещён. Если x=s, иных типов в населении нет.
Следовательно, любое исполнимое событие использует только a=s. Для него

\[
c'=(m e_s+e_x)-e_x+e_r+e_s=(m+1)e_s+e_r,
\]

и новый указатель r сохраняет тот же инвариант. Поэтому никакой тип,
отличный от s, не может быть впервые использован в качестве доступа.
При n=1 нет первого шага; увеличение n само по себе не решает задачу
появления используемого разнообразия. В обоих приведённых соседями примерах
краткий маршрут блокируется уже при попытке самоиспользования впервые
произведённого типа, если требуется два отдельных участника.

Граница вывода: один отмеченный текущий указатель участвует в каждом событии,
его токен заменяется результатом, дополнительных событий нет, guard требует
отдельных участников, а единственное начальное население однородно. Это
не запрет для произвольных реакционных сетей, многокомпонентных семян,
нескольких параллельных указателей или явно разрешённых однотокенных актов.

Это различие guard существенно: одинаковый вектор изменения численностей
не определяет потребность во входных участниках реакции.
