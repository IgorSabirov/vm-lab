# Пятый шаг R130. Откуда берутся 13 и 14

В первом пакете одинаковые начальные статистики пар, детерминант R141 и счётчики R135 оставляли открытой причину расхождения двух слов на пятом шаге. Здесь установлена точная формула для целого семейства. Выполнен расчёт графа. Сопоставление с наблюдаемой на физических конфигурациях ЯМ остаётся предложением.

## Условие и результат

Пусть исходное бинарное кольцо длины n содержит k≥1 единиц и между каждыми соседними единицами по кругу лежат по меньшей мере два нуля. Применяем подготовку 0→1, 1→2 и один канал C1 с шагом F=QI. Пусть bⱼ — исходные биты, индексы циклические,

    C₃ = Σⱼ bⱼ bⱼ₊₃.

Тогда длины с нулевого по пятый шаг равны

    n, n−k, n, n+k, n+2k, n+3k−C₃.

C₃ считает ориентированные пары единиц со сдвигом +3. При условии на пробелы это число промежутков ровно с двумя нулями. Для одиночной отметки длины 3 сдвиг +3 возвращает её в себя.

## Прямой вывод из локального шага

На внутреннем алфавите C1 буква 3 расщепляется в 12, пара 12 сливается в 3. Правила выполняются одновременно. После этого Q оставляет b-бит сайта и берёт a-бит следующего сайта. Выход Q в позиции j равен (sⱼ & 2) | (sⱼ₊₁ & 1). Q сохраняет длину. При любом внутреннем слове прирост за такт равен числу букв 3 минус число соседних пар 12.

Начальное внутреннее слово — циклическая склейка блоков 2·1ᵍ, где g≥2 — число нулей между очередными единицами входа. Ниже степени задают число повторов символа 1. Внутри каждой строки соответствующие блоки склеиваются в прежнем порядке. Начало чтения кольца можно циклически сдвигать.

| t | Блок для пробела g |
|---|---|
| 0 | 2 · 1ᵍ |
| 1 | 3 · 1^(g−1) |
| 2 | 0 3 · 1^(g−1) |
| 3 | 0 1 0 3 · 1^(g−2) |
| 4 при g=2 | 1 0 1 0 2 |
| 4 при g≥3 | 1 0 1 0 3 · 1^(g−3) · 0 |

В первом переходе последняя 1 каждого промежутка сливается со следующей 2. На втором шаге вход Q в каждом блоке равен 1 2 · 1^(g−1), а следующий блок опять начинается с 1. На третьем шаге вход Q равен 0 1 2 · 1^(g−1). Выход равен 1 0 3 · 1^(g−2) · 0, и последний 0 можно отнести к началу следующего блока. На четвёртом шаге вход Q равен 0 1 0 1 2 · 1^(g−2). Сайт с b-битом 2 получает a-бит 0 от начала следующего блока при g=2 и a-бит 1 от ближайшей внутренней единицы при g≥3. Поэтому в первом случае он становится 2, во втором 3.

В слове на шаге t=4 каждая оставшаяся 2 имеет слева 0, поэтому слияний на следующем шаге нет. Всего букв 3 ровно k−C₃. Сумма длин блоков при t=4 равна n+2k. Сложение даёт заявленную формулу. Вывод не требует предела по размеру кольца.

| Бинарный вход | Пробелы по кругу | C₃ | Длина после четырёх шагов | Расщепления на пятом | Длина после пяти шагов |
|---|---|---:|---:|---:|---:|
| 00001001 | 2 и 4 | 1 | 12 | 1 | 13 |
| 00010001 | 3 и 3 | 0 | 12 | 2 | 14 |

## Оператор и физическая проверка

В обозначениях проекторов R132 положим P|j⟩=bⱼ|j⟩, S|j⟩=|j+1⟩. Тогда Tr(P S³ P S⁻³)=Σⱼbⱼbⱼ₋₃=C₃. Счётчик инвариантен при выборе другого начала обхода.

Для сопоставления с полем требуется определить наблюдаемую при глобальном циклическом переименовании центровых меток. Возможный выбор на линии из n сайтов — E₃=Σⱼ 1[aⱼ=aⱼ₊₃]. На бинарной подготовке E₃=n−2k+2C₃, поэтому для пары он равен 6 и 4. На трёх центровых секторах E₃ непосредственно определён как сумма по трём проекторам. Бинарная формула длины сама по себе не предсказывает ансамблевое значение E₃ на SU(3). Это кандидат в двухточечную наблюдаемую при пространственном смещении, дополняющую четырёхточечный D₄.

Для физического испытания нужны независимые конфигурации SU(3) или заранее определённая процедура их генерации, локальные центровые сектора по фазе петли Полякова, правило для пограничной фазы, шаг решётки и пространственное расстояние, нормировка и конкретный заранее заданный контраст между независимо приготовленными или отобранными выборками. Отдельная от калибровки серия проверяет прогноз и даёт ошибку с учётом автокорреляции. Графовая пара служит контролем реализации. ## Проверка границы

Прямой перебор отбирает среди всех 778 бинарных колец длин 6–12 с точностью до поворота 32 кольца, удовлетворяющих предпосылкам. Именованный двигатель подтверждает на каждом и формулу длин, и точное циклическое слово на каждом из первых четырёх шагов.

Вне этого семейства 000100111 и 000111001 имеют одинаковые 4 соседних счётчика (3,2,2,2), D=26, M₊=M₋=0 и C₃=1. На пятом такте длины равны соответственно 16 и 15. Эта пара подходит для следующего исследования смешанных серий и коротких промежутков.
