## PLAN · ядра

Первый ограниченный опыт: один замороженный гамильтониан с документированной обучающей выборкой, одна базовая модель, одна целиком отложенная изотопная цепочка, два семейства наблюдаемых. Проверить историю подгонки до назначения цепочки; при утечке сменить цепочку до открытия результатов. Архивировать версии взаимодействия, AME и ENSDF, перечень изотопов и пропуски. Для чётных ядер рассчитать E(2₁⁺), S₂ₙ и производную щели δ₂ₙ; для общего вектора масс M переносить ковариацию как AΣAᵀ. При отсутствии внедиагональных ковариаций показать чувствительность, не приписывать измерениям независимость. Первичная метрика — разность взвешенных квадратичных ошибок двух моделей на той же цепочке; отдельно ошибки по наблюдаемым. Бюджет — по одному прогнозу каждой модели без переподгонки. k=1 только для условной вариации одной силы ℓ·s при замороженных остальных коэффициентах. Сотни спинов, моментов и изомерных данных — потенциальная выборка; фактический p и независимость от обучения требуют поимённой сверки.

## PLAN · MOND

Первый опыт: один замороженный релиз [SPARC](https://astroweb.cwru.edu/SPARC/), разбиение по целым галактикам (сортировка по имени, каждая пятая в проверку), одна оценка a₀ на обучении и прогноз без повторной калибровки. До открытия проверки зафиксировать наклоны, расстояния, газ, отношение масса/свет и ковариации. Первичная метрика — ошибка log g_obs на отложенных галактиках; вторичная — остаток BTFR при фиксированном наклоне 4. RAR и BTFR используют общие расстояния и скорости; единица повторной выборки — галактика. Для совпадения с космологией заморозить три масштаба ускорения: cH₀, cH₀/(2π), **c²√(Λ/3)** при Λ в м⁻². Последний масштаб коррелирован с H₀ в ΛCDM. На 10 000 симуляциях нуля повторить выбор лучшего из трёх по |log(a₀/a_ref)|, сохраняя общие ошибки; до запуска зафиксировать модель генерации a₀ и внешнюю выборку H₀. Бюджет поиска одинаков в данных и симуляциях. Параметр галактической модели уже T2; численное космологическое отношение остаётся T3. План ретроспективной проверки нового разбиения не является слепым историческим прогнозом.

## Факторизация и дополнительные контроли

В 10D аномалию задаёт **I₁₂**, а X₈ — один из сомножителей. В конвенции Tr по присоединённому представлению, tr по векторному для кривизны, опуская общий нормировочный множитель и подразумевая внешние произведения:
  
I₁₂ ∝ (tr R² − Tr F²/30) X₈,

X₈ = tr R⁴ + (tr R²)²/4 − tr R² Tr F²/30 + Tr F⁴/3 − (Tr F²)²/900.

Для so(32) можно подставить Tr F²=30 tr F² и Tr F⁴=24 tr F⁴+3(tr F²)². Для e₈⊕e₈ следы суммируются по двум факторам и в каждом Tr F⁴=(Tr F²)²/100. Обе подстановки проверяют сокращение членов в одной конвенции. Число 496 убирает неприводимый гравитационный член; локального полинома недостаточно для утверждения уникальности двух допустимых полных теорий.
