## Доноры, физические утверждения и проверка охвата

Поэтому одно число может иметь несколько доноров: 8 нейтронов и 8 глюонов требуют совершенно разных объяснений. В графе «прибавка» повтор учитывается один раз. ## Три дополнительные числовые позиции

1. **Эфимов, 22,7.** Для трёх одинаковых бозонов с резонансным короткодействующим взаимодействием теория задаёт геометрическое отношение последовательных масштабов длины. Первый трёхчастичный резонанс задаёт опорный масштаб; второй испытывает отношение. Huang et al. получили 21,0±1,3 в газе цезия. Остаток относительно идеального значения равен −1,30 экспериментальной стандартной ошибки. Конечная температура и конечный радиус взаимодействия ограничивают такое сравнение. [Первое наблюдение](https://doi.org/10.1038/nature04626) · [Измерение второго резонанса](https://arxiv.org/abs/1402.6161)
2. **Переход Березинского–Костерлица–Таулеса, 2/π.** В нормировке фазовой жёсткости Υ как энергии универсально отношение Υ(Tc⁻)/(kBTc)=2/π. У разных плёнок сами Tc и плотности различны. Сопоставлять жёсткость со стороны сверхтекучей фазы, учитывая частоту прибора и конечный размер. [Предсказание Nelson и Kosterlitz](https://doi.org/10.1103/PhysRevLett.39.1201) · [Плёнки гелия Bishop и Reppy](https://doi.org/10.1103/PhysRevLett.40.1727)
3. **Щель Холдейна, Δ/J≈0,41.** Числовая цель относится к бесконечной изотропной антиферромагнитной спин-1 цепочке Гейзенберга с ближайшими соседями. Положительная щель и значение её амплитуды — разные утверждения. White и Huse дают численный эталон; нейтронное рассеяние в CsNiCl₃ даёт отдельный физический тест с поправкой на межцепочечную связь. Для испытания амплитуды J надо определить независимо. [Расчёт](https://doi.org/10.1103/PhysRevB.48.3844) · [Эксперимент](https://doi.org/10.1103/PhysRevLett.56.371)

## Что можно воспроизвести немедленно

Следующий код на стандартном Python проверяет три ряда и счёт уникальных позиций. Именованные позиции обозначены строками, чтобы точность десятичного округления не меняла мощность множества.

~~~python
from itertools import accumulate, product
from math import pi

def oscillator(d, kmax):
    states = list(product(range(kmax + 1), repeat=d))
    return list(accumulate(2 * sum(sum(x) == k for x in states)
                           for k in range(kmax + 1)))

dot = oscillator(2, 5)
osc = oscillator(3, 6)
atomic = [sum(2*(2*l+1) for l in range(n)) for n in range(1, 7)]
assert dot == [2,6,12,20,30,42]
assert osc == [2,8,20,40,70,112,168]
assert atomic == [2,8,18,32,50,72]
groups = [[2,8,20,28,50,82,126], [16,32,34], osc, [2,10,18,36,54,86,118],
          [2,8,20,40,58,92], dot, atomic, [26,10,496], [8,230,12],
          [136,137,'Wyler'], ['Koide'], ['phi'], ['delta'], ['angle'],
          ['Dirac'], ['Lambda'], ['MOND']]
base = set().union(*groups)
extended = base | {'Efimov','BKT','Haldane'}
assert (len(base),len(extended)) == (40,43)
print('initial, expanded:', len(base), len(extended))
print('Efimov standardized residual:', (21.0-22.6942)/1.3)
print('BKT stiffness ratio:', 2/pi)
~~~
