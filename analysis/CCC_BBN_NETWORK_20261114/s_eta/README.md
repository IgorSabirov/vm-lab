# Sη — автоматический следующий этап после S0/S1

Вопрос: как изменятся стандартные BBN-выходы при eta/eta₀=0.99 и 1.01?
Эталон F0 переиспользуется. Варьируется только `Omegabh2`, полученная из
`eta_target / Omegabh2_to_eta0b`; обратный остаток сохраняется до интеграции.
Это локальная чувствительность на конечном интервале, без CMB prior, likelihood
или меняющейся истории барионов/фотонов. Новая микрофизика не вводится.

Исполнитель — неизменённый S1 worker в режиме S0; wrapper задаёт только
новый common/config и аудит eta. Состав 59 нуклидов/427 ядерных каналов плюс
агрегированный слабый канал; прежние RTOL/ATOL, фон 8000, таблицы 16000,
неизменные захешированные weak-кеши. Два новых полных прогона и короткая
калибровка целевого исполнителя; F0 не пересчитывается.

Критерий завершения: оба прогона завершены, фактическая eta соответствует
плану, сохранены все эры/сырые массивы, выполнены прежние проверки барионного
баланса/положительности и целостности. Знак отклика не является гейтом.
Сохраняются секущие ΔlnY/Δlnη, односторонние секущие и их отличие.
Ширина ±1% — проектный диагностический выбор, не наблюдательная неопределённость.

Пакет исполняется общим контроллером через GitHub Actions. Прогноз до двух
строгих прогонов масштабируется по короткому target probe относительно
архивного R8. Максимум пакета 5400 с, процесса 2400 с, памяти 4 GiB,
выходов 2 GiB. Публикуются прогноз, допуск к запуску, каждый завершённый
прогон и итог. Повторы, изменение порогов и научное повышение статусов
автоматически запрещены. Чат не нужен для завершения начатого пакета.
