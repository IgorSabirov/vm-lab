# S3: входы и перенос неопределённости eta

Предшественник: PR #53, S_ETA_20261114_r1. Здесь запускается короткая алгебраическая диагностика после полной сети: остатки относительно двух исторических наблюдательных ориентиров и коэффициент ковариации J J^T для будущего независимого Var(ln eta). Это не новый прогон BBN и не likelihood.

Источники чисел: Cooke, Pettini, Steidel 2018, arXiv:1710.11129v3; Aver, Olive, Skillman 2015, arXiv:1503.08146. Это версионированные исторические ориентиры, не заявление о самых новых данных. Данные He и D не объединяются, sigma не превращается в меру значимости. Перед likelihood требуется согласовать массовую конвенцию He, источники систематики, ядерную ковариацию и независимый CMB-вход. Численная ошибка не заменяет физическую.

Запуск после фиксации source commit: `python runner.py SOURCE_SHA && python verify.py`. Только стандартная библиотека Python; бюджет 60 с, 4 GiB, без сети. Повтор при существующем results запрещён. Поля likelihood и significance намеренно null. Нулевой ранг/знак не является физическим критерием: проверяется тождество C_eta = J J^T Var(ln eta), без назначения Var.

Приёмка науки и R/C/L/U не меняются. S2 и BH1 не затрагиваются. Следующий вход: физическая ковариация ядерных/слабых скоростей закреплённого PRIMAT, затем независимый CMB-only prior и аудит перекрытия данных.
