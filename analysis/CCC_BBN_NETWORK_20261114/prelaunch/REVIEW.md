# Краткая независимая ревизия и исправления

Проверены закреплённый исходник PRIMAT и собственный адаптер. Ревизор расчётов не запускал.

| Замечание | Решение |
|---|---|
| G1 ошибочно блокировал S0 аудитом S1 | G1-S0 и G1-S1 разделены; требования назначены по веткам |
| P0 high-precision и отдельные cold overlays | Полные P0/P1 конфигурации; P0 и P1 используют разные каталоги |
| Масштабирование слабого сектора дважды | HT: weak callbacks / f; MT/LT: исходные weak callbacks, весь RHS/Jacobian / f |
| Изменение H после построения фона — пустой контроль | Контроль изменяет t(T), сохраняя скорости; проверяется полный Y(T) |
| Zero-fill до начала ядерного интегрирования | Экспортируются отдельно реальные HT/MT/LT dense solutions, 10→0.001 MeV |
| Финальный clamp скрывает отрицательные Y | Сохранены исходные минимумы и барионные остатки всех внутренних шагов |
| `zip` допускает неполное сравнение | Требуются ровно HT/MT/LT, species, shape (401,n), finite values |
| Допуск может быть от другого baseline | Перед сравнением сверяются хеши baseline TRACE/RESULT и координаты envelope |
| exit 0 не равен numerical PASS | Явный engineering gate; итоговый агрегатор также проверяет исходные флаги и residuals |
| runtime PASS при ошибке экспорта | В ранней квитанции это только попадание во временной диапазон. Сохранена без переписывания; поздний launcher разделяет FORECAST_IN_RANGE и execution_status |
| SHA запуска не сверялся с локальным кодом | Поздний launcher сравнивает байты исполняемых файлов/config с git show замороженного GitHub SHA; ранние запуски имеют отдельную сверку hashes |

Границы: это ревизия программной реализации и условий запуска. Физический закон S2, отождествление кинетических часов с метрическим временем, независимый BBN solver и BH1 не выведены.
