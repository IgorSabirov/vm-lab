## Численная проверка

- Все три эпохи завершены; LT содержит 59 видов и 428 каналов.
- COLD/WARM **побитово совпадают**: все сырые узлы, финальные abundances и 1203 точки плотного вывода.
- Сырые массивы конечны, времена строго возрастают. Максимальный барионный остаток **1.65246e-12** при допуске 1e-10.
- Минимум по сырым массивам **−2.36343e-17** (MT), внутри заранее заданного допуска −1e-12. Итоговые LT abundances положительны; финальный clamp не изменил ни одного вида.
- Внешние слабые таблицы фактически прочитаны и неизменны. Единственный новый cache — electron thermo; WARM использует тот же overlay.

## Исправленные дефекты

1. `100` → `100.0`: upstream сериализация различает эти типы и давала неверный fingerprint слабого cache. Добавлена проверка реальных fingerprints до интегрирования.
2. Устранено ошибочное разрешение двух независимых локальных бюджетов по 600 s. Все попытки переносятся в единый ledger при смене исполнителя.
3. NumPy int32 в финальной печати преобразован в Python int. Локальную уже завершённую пробу восстановили из сохранённых данных, без повторной интеграции.
4. После каждой эпохи сохраняются исходные массивы и компактные recovery-данные. Ошибка/тайм-аут не выдаётся за физический отрицательный результат или успешное завершение.

## Что закрыто и что остаётся

Закрыт пробел **исполнения стандартной полной сети S0**, включая калибровку целевой машины, strict cold/warm, сохранение исходных данных и проверку воспроизводимости. Реестр может ссылаться на этот артефакт как на исполненный S0-профиль.

Не получены закон дрейфа S2, независимый решатель, ограничения S3 или связь BH1. S1 на полной сети здесь не запускался; прежний P1-S1 остаётся отдельным результатом. Эти границы не мешали завершить S0. Работающая полная сеть даёт проверенный вычислительный компонент для дальнейших условных опытов, но не вывод происхождения параметров и не доказательство модели «сейчас».
