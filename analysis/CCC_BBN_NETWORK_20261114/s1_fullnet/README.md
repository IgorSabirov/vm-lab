# S1_FULLNET: условное общее масштабирование на полной сети

План и критерии зафиксированы до результатов: [PLAN.json](PLAN.json),
[ENVELOPE.json](ENVELOPE.json). Исполнение — этап
[общего пайплайна](../pipeline/README.md), а не отдельная ручная процедура.

Родитель — R8/F0 после OPERATING_POINT_STABILITY_PASS, commit
`c658466f839e9ae7de7a4f051792f7eee40e8551`. Полная сеть: 59 нуклидов,
427 ядерных каналов плюс агрегированный слабый канал. PRIMAT закреплён на
`6f7e5680614fb119d65a6c9c65a292240b27c61e`. Формат и точность, кэш BG8000,
физические параметры и нейтринная история одинаковы во всех трёх строгих опытах.

| Опыт | Изменение | Ожидаемый различающий результат |
|---|---|---|
| CONTROL | Стандартный S0, конфигурация R8 | Совпадение с архивным F0 в замороженных допусках |
| S1 | Общее масштабирование RHS, Jacobian, слабых скоростей и охлаждения | Y_i(T) сохраняется в численном допуске |
| NEGATIVE | Меняется только ход охлаждения | Отчёт уверенно обнаруживает нарушение инвариантности |

Используется уже проверенный [P1 clock adapter](../prelaunch/s1_adapter.py):
`f(tc)=3.66 exp(alpha tc)`, `alpha=-1.5426109418e-18 s^-1`,
`du/dtc=1/f(tc)`, `dY/dtc=F(Y,T)/f(tc)`. Одинаковый множитель сокращается
в `dY/dT`; численный опыт проверяет реализацию этого условного тождества.
Это не вывод общего масштабирования из микрофизики и не идентификация tc
с физическим космологическим временем. Почти постоянный f на интервале BBN
не задаёт динамику безразмерных параметров S2.

Адаптер масштабирует полный MT/LT RHS и Jacobian с исходными weak-callbacks,
чтобы слабые процессы не делились на f дважды. Для HT используются изменённые
weak-callbacks фона. Инвентарь действительных каналов, число вызовов каждого
пути, фактические tolerances и clock-roundtrip сохраняются в результатах.
Опциональная поздняя DT-эпоха не включена, как и в исходном S0.

## Численная приёмка

- Конечные наблюдаемые и лёгкие виды: прежние бюджеты N1, включая Y_n.
- Траектории: по каждой эпохе и активному виду фиксируется абсолютный envelope
  `5*max(max_T|F_RATE-F0|,max_T|F_ATOL-F0|) + 1e-10*max_T|F0| + 1e-14`.
  Он рассчитан только из предыдущих S0-данных до нового запуска. Абсолютный пол
  не является подтверждением относительной точности сверхмалых тяжёлых хвостов.
- CONTROL и S1 должны пройти соответствующие сравнения. NEGATIVE должен
  превысить envelope минимум в 100 раз и бюджет Yp или D/H минимум в 100 раз.
- Общие проверки: целостность, одинаковая среда, все HT/MT/LT, барионный бюджет
  без перенормировки, неизменные загруженные таблицы и полный инвентарь сети.

Результат `CONDITIONAL_INVARIANCE_PASS` относится только к этому контракту.
Neff в этой постановке использует неизменный нейтринный фон, поэтому его
совпадение само по себе не подтверждает охват ядерных реакций.

## Исполнение и время

Три строгих процесса с прогнозом >600 s выполняются на GitHub Actions VM.
Единственный предварительный PROBE ограничен 120 s и служит для переноса
измеренного времени R8 на текущий исполнитель. Коэффициенты стоимости:
CONTROL=1, S1=1.5, NEGATIVE=1.5; инженерный диапазон 0.5–1.8 от центрального
прогноза. Учтён дополнительный путь clock-адаптера, но его фактическая цена
не известна до исполнения; жёсткие пределы отдельно: 7200 s пакет, 2400 s
процесс, 4 GiB адресное пространство, 2 GiB выходы.

Данные каждого завершённого процесса публикуются сразу. Ошибка останавливает
оставшиеся процессы и сохраняет точную причину; повтор автоматически не делается.
Итоговый отчёт и общий STATE.json формируются без участия чата.
