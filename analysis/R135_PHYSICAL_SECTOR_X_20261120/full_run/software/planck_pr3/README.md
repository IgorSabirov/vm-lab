# Planck PR3 для R135

Исполняемая комбинация Planck 2018 TT,TE,EE+lowE состоит из полного бинированного Plik, Commander TT и SimAll EE. Архив ESA R3.00 содержит 60 323 470 байт. Его SHA-256 равен `0b73171e3acc671c28184466a45485a2d1c1d93676b832abdfe688c7b04024e6`. Для всех 134 обычных файлов трёх используемых каталогов записаны путь, размер и SHA-256. Полные пути и длины входных векторов находятся в манифесте. [Архив ESA](https://pla.esac.esa.int/pla/aio/product-action?COSMOLOGY.FILE_ID=COM_Likelihood_Data-baseline_R3.00.tar.gz) · [Манифест и контрольные значения](release.json) · [Planck 2018 V](https://arxiv.org/abs/1907.12875).

| Компонент | Данные для оценки вероятности | ln L на собственном тестовом векторе |
|---|---|---:|
| Plik TTTEEE | Полная обратная ковариация 2289 × 2289 после отбора бинов. Записаны матрица, маска, порядок и частотные шаблоны. TT до ℓ=2508, TE/EE до ℓ=1996. На интерфейсе clik три массива подаются длиной 2509 | −1172,46541801 |
| Commander TT | Преобразование TT и ковариация преобразованных переменных в sigma.fits. HDU 2 при нумерации с нуля содержит 249 × 249, активная область ℓ=2…29 | −11,62574086 |
| SimAll EE | Эмпирическая таблица log L для 28 мультиполей и 3000 уровней мощности на мультиполь | −197,98979216 |

В принятой конфигурации Cobaya из 47 имён полного вектора Plik 21 параметр варьируется, 26 фиксированы. Оба низкомультипольных компонента используют общий A_planck. Его нормальный приор применяется один раз. Совместный SZ-приор действует на $A_{\rm kSZ}+1.6A_{\rm tSZ}$ с центром 9,5 и шириной 3. В машинной записи находятся все фиксированные значения, границы равномерных приоров, средние и ширины нормальных, версии и хеши исходных файлов Cobaya. Ковариация данных и приоры параметров входят в разные части расчёта. [Параметры и приоры](nuisance.json) · [Исходная конфигурация Cobaya](https://github.com/CobayaSampler/cobaya/blob/b76b6fed2a6c8c5594c6f92d5058bef10079746a/cobaya/likelihoods/planck_2018_highl_plik/TTTEEE.yaml).

**Контроль при нулевом дополнительном X.** Опубликованный спектр base-ΛCDM R3.01 получен из ESA и IRSA с идентичными байтами. Его исходная подгонка включала линзирование, в проверяемую здесь функцию входят только три компонента выше. Код переводит $D_\ell$ в $C_\ell$ в мкК² и использует у всех компонентов один набор nuisance с $A_{\rm Planck}=1.000442$. Суммарно $\ln L=-1382.11612551$, отдельно $\ln\pi=-19.97069280$ с нормированными приорами принятой конфигурации. Спектры TT/TE/EE этого файла после перевода совпадают с тестовыми спектрами Plik. Повтор проверяет конвенции и сборку каналов. Для SimAll собственный тест использует A_planck=1, что объясняет изменение до −198,02496665 при общей калибровке. Допуск на повтор каждого опубликованного теста и совместных компонент равен 0,00001 по ln L с учётом округления встроенных эталонов. Для сравнения моделей R135 ещё предстоит передать спектры из её собственной космологической истории и профилировать параметры. [Спектр ΛCDM](https://irsa.ipac.caltech.edu/data/Planck/release_3/ancillary-data/cosmoparams/COM_PowerSpect_CMB-base-plikHM-TTTEEE-lowl-lowE-lensing-minimum-theory_R3.01.txt).

## Воспроизведение

Команды запускаются из planck_pr3 под Linux x86_64 с Python 3.12, использован CPython 3.12.14. Версии и SHA-256 закреплены для всех колёс и исходного ZIP clipy. Программа проверяет SHA до распаковки, состав используемых каталогов, симметрию и положительную определённость матрицы Plik и разложение активной ковариации Commander. При расхождении проверка завершается ошибкой. [Среда](wheels.lock) · [Версия clipy](clipy.lock) · [Исполнитель](verify_planck.py).

```sh
python3.12 -m venv /tmp/r135-planck-env
P=/tmp/r135-planck-env/bin/python
"$P" -m pip install --require-hashes --only-binary=:all: -r wheels.lock
"$P" -m pip install --require-hashes --no-deps --no-build-isolation -r clipy.lock
A=COM_Likelihood_Data-baseline_R3.00.tar.gz
S=COM_PowerSpect_CMB-base-plikHM-TTTEEE-lowl-lowE-lensing-minimum-theory_R3.01.txt
curl -fL --retry 2 "https://pla.esac.esa.int/pla/aio/product-action?COSMOLOGY.FILE_ID=$A" -o "/tmp/$A"
curl -fL --retry 2 "https://irsa.ipac.caltech.edu/data/Planck/release_3/ancillary-data/cosmoparams/$S" -o "/tmp/$S"
OPENBLAS_NUM_THREADS=1 "$P" verify_planck.py "/tmp/$A" "/tmp/$S"
```

## Прямое получение данных

Из этой директории команда загружает и проверяет закреплённые файлы авторов. Повтор с флагом `--offline` проверяет те же байты без сети. [Источники и физический смысл проверок](../donors/README.md).

```sh
OPENBLAS_NUM_THREADS=1 "$P" verify_planck.py --cache /tmp/r135-donors
```
