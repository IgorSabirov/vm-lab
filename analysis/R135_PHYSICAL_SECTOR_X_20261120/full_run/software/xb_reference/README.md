# Размерные подготовки X-B

Для чистой SU(3) у Forestell, Morrissey и Sigurdson заданы четыре пары массы скалярного глюбола и отношения энтропий после конфайнмента. Все четыре взяты с рисунка 3, до сопоставления с бюджетом R135. Они дают начальную поверхность, пригодную для проверки эволюции глюболов в изолированной ветви. Координаты ниже рассчитаны здесь при дополнительном условии равновесия на холодной стороне перехода. Начало перехода, выделение тепла и доживание остатка до BBN требуют собственной эволюции. [Рис. 3 и определение R, ур. (5)](https://arxiv.org/pdf/1605.08048v2) · [Исходные числа, происхождение и SHA-256](inputs.json).

| Панель рис. 3 | Масса 0⁺⁺, ГэВ | R после перехода | T_X, ГэВ | T_γ, ГэВ | T_X/T_γ |
|---|---:|---:|---:|---:|---:|
| Верхняя левая | 1 | 10⁻⁹ | 0,17713 | 34,976 | 0,0050643 |
| Верхняя правая | 100 000 | 10⁻⁹ | 17 712,6 | 3 285 940 | 0,0053904 |
| Нижняя левая | 1 | 10⁻³ | 0,17713 | 0,40427 | 0,43814 |
| Нижняя правая | 100 000 | 10⁻³ | 17 712,6 | 32 882,5 | 0,53866 |

В конвенции авторов Λ_X обозначает массу 0⁺⁺. Для перевода к температуре перехода служат два измерения в одной единице длины Зоммера, которая сокращается в отношении. Из $r_0T_c=0.7457(45)$ и $r_0m_0=4.21(11)(4)$ следует $T_c/m_0=0.17713$. Линейная ошибка при некоррелированных входах равна 0,00504. Учтён второй вклад ошибки массы от анизотропии. У экстраполяции $r_0T_c$ авторы указывают χ²/dof = 6,7, поэтому её точность ограничивает и нашу оценку. В рабочем приближении самих FMS используется $T_c\simeq m_0/5$. [Francis et al., ур. (6)](https://arxiv.org/pdf/1503.05652v2) · [Morningstar и Peardon, табл. VII](https://arxiv.org/pdf/hep-lat/9901004v2).

Для каждой подготовки решается уравнение
\[
 \frac{2\pi^2}{45}\,g_{*s}^{\rm SM}(T_\gamma)\,T_\gamma^3
 = \frac{s_X(T_c^-)}{R}
 = \frac{0.2928\,T_c^3}{R}.
\]
Для холодной фазы решётка даёт $s_X(T_c^-)/T_c^3=0.2928(38)$. Для видимого сектора использованы столбцы температуры, энтропийного числа степеней свободы и его ошибки из таблицы Saikawa–Shirai. Интерполяция линейна по $\ln T$, корень ищется внутри опубликованного интервала. В JSON хранятся диапазоны при переборе всех 32 сочетаний знаков сдвига входов на опубликованные ошибки. Это чувствительность к входам с общими систематиками для всех четырёх строк. Выбранные автором массы и R условно фиксированы, доверительная вероятность диапазона не назначалась. [Giusti et al., ур. (16) версии v1](https://arxiv.org/pdf/2502.03875v1) · [Таблица энтропии СМ](https://arxiv.org/src/1803.01038v2/anc/standardmodel2018.dat) · [Координаты и диапазоны в МэВ](coordinates.json).

**Что остаётся для G3.** Решётка фиксирует отношение $T_c/m_0$. Пересчёт $m_0\mapsto k m_0$, $T_c\mapsto k T_c$ сохраняет это отношение при любом $k>0$. В опубликованных четырёх подготовках массу и R выбирают авторы. Для абсолютного прогноза R135 нужен независимо определённый размерный вход именно нашего X — например его масса с ошибкой или связь его калибровочной константы с измеренным УФ-порогом и расчётом сопоставления. Для эпохи события отдельно нужен исходный тепловой баланс. Эти подготовки входят в P0 в роли literature_benchmark. Роль physical_candidate требует отдельных, адресуемых по SHA-256 свидетельств калибровки и начальной истории. Для X-A остаётся собственная проверка размерной энергии, отображения и часов. [Задание P1](../../DEVELOPMENT.md).

Из каталога xb_reference для повтора достаточно Python 3.11+.

```sh
curl -fL --retry 2 'https://arxiv.org/src/1803.01038v2/anc/standardmodel2018.dat' -o /tmp/standardmodel2018.dat
python compute.py /tmp/standardmodel2018.dat --verify
```

## Прямое получение данных

Из этой директории команда загружает и проверяет закреплённые файлы авторов. Повтор с флагом `--offline` проверяет те же байты без сети. [Источники и физический смысл проверок](../donors/README.md).

```sh
python compute.py --cache /tmp/r135-donors --verify
```
