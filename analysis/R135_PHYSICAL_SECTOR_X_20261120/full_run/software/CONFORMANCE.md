# R135. Сверка исполнителя #159 с проектом #160

Реестр P0 содержит также 48 диагностических подготовок. Число независимо калиброванных физических точек X равно нулю. Ветви XA, XB и «граф как маркер XB» сохраняют собственные ключи. Расчёты чистой SU(3) и космологии XB допускают отдельное исполнение. Физическое отождествление с графом проверяется на своей ветви. ## Получение входов и вызов

Из `full_run/software` команда `python donors/fetch.py glueball_spectrum --cache CACHE` загружает архив Athenodorou–Teper v2 и проверяет размер и SHA-256. P1 принимает `donor_inputs.spectrum_model` со значением `fms` или `athenodorou_teper`. Выбор `scale_method` независим. В сравнении идеального газа доступны общий квартет состояний и весь список каждого донора. Строки с возбуждениями и неоднозначным спином сохраняют метки первоисточника. [Реестр байтов](donors/sources.json) · [исходная статья Athenodorou–Teper](https://arxiv.org/abs/2007.06422v2) · [результаты по всем четырём точкам](validation/conformance/spectra.json).

P7 принимает `history_refinement.coarser_levels` из двух объектов с `rtol`, `atol_relative` и `max_step_H0`. Третий уровень задаёт основная конфигурация. `max_abs_normalized_change` применяется к изменению доли, нормированных H и температуры X и переданной энергии в единицах начальной комовой скрытой теплоты. Вычисляются разности 11full−11add и 11full−10−01+00. Соблюдение `balance_rtol` проверяется на всех трёх уровнях. Предел по умолчанию равен 10⁻⁶. Для кинетических видов энтропия вычисляется по заполнениям ячеек. Для пылевого замыкания без распределения неопределённая энтропия записывается как null. Равенство плотностей использует сумму bulk X и остатка, а для видимой стороны фотоны и нейтрино. Свободное излучение выделено отдельно. [Реализация](r135/history_observables.py) · [15 интегрирований](validation/conformance/history.json).

Вход P8 `weak_precision_reference` индексируется по углам. Каждая эталонная запись содержит `input_sha256` полного подготовленного BBN-входа, источник, `solver_sha256`, `included_corrections`, `time_s`, `unit: s^-1`, обе скорости, `Yp` и `Yp_abs_uncertainty`. Кандидат и эталон имеют разные идентификаторы решателя. Допуски задаются до расчёта через `weak_precision_policy` с `atol_s_inv`, `rtol` и `max_abs_delta_Yp`. P10 считает для каждого BBN-решателя сумму абсолютного расхождения по гелию и заявленной абсолютной ошибки эталона. Оба результата должны уложиться в бюджет. [Проверка](r135/weak_precision.py).

Вход P8 `pion_conversion_kernels` содержит для каждого угла SHA истории, временную сетку P7, источник и две таблицы `sigma_v` в см³/с с осями времени и комового импульса. Популяции пионов читаются из той же `kinetic_species`. Слабые и мезонные скорости сохраняют отдельное происхождение. При требовании нетеплового ядерного расчёта поддержанная ветвь указывается в `applicability.nonthermal_nuclear_channels` как `["charged_pion_free_nucleon_conversion"]`. Численный контроль использует заданный разбавленный импульс. Изменение Yp равно 0,01934895 в LINX и 0,01934796 в PRIMAT. [Численный результат](validation/conformance/pions.json) · [реакции, приложение D](https://doi.org/10.1103/PhysRevD.104.023517).

P9 принимает файл `nuclear_rate_ensemble` с источником, порядком реакций `reaction_order` из LINX, необязательным `central_q` и узлами `nodes` с вектором `q` и весом `weight`. Сумма положительных весов равна единице. Каждый элемент матрицы строится для конкретного решателя и угла в координатах (log₁₀ D/H, Yp). Архив сохраняет исходные таблицы, вариации, связи с углами и число уникальных интегрирований. Постоянная внешняя ковариация остаётся отдельным режимом. Политика `lithium_policy=excluded` оставляет Li7 и Be7 в сети и фиксирует причину исключения лития из likelihood. [Контроль одной реакции](validation/conformance/nuclear.json) · [приор в закреплённом LINX](https://github.com/cgiovanetti/LINX/blob/bfba07c77a5fcba1cc772d42f2d9e9be8a542df8/scripts/run_numpyro.py#L141).

Сетка запускается командой `python r135_stage.py --joint-grid GRID.json --out OUT`. Схема `r135-joint-grid-v1` использует `axes.eta_b_gamma`, дополнительные параметры CLASS, необязательный список идентификаторов `X_points`, один `corner` и один `cmb_release` из `Planck_PR3`, `ACT_DR6_CMBONLY`, `SPT3G_D1_LITE`. Каждая запись `cells` содержит `coordinates`, выбранный `X_point_id` при включённой оси и две ссылки `pipelines.baseline` и `pipelines.X` с именем файла, SHA-256 и ID узла P9. Недостающая ячейка блокирует вывод об оптимуме. Ωᵦh² вычисляется по конечным изотопам и поздней η. [Рабочий пример генерации входов](pr160_reference/validate_joint_grid.py).

P10 принимает файл `gw_evidence` с ключами `point_id`. Для каждой записи допускаются связанные по SHA файлы `history` и `response` прежнего формата, `inapplicability_evidence` либо `physical_evidence`. В последнем варианте архивируются исходные веса приора, массивы signal/null log L, foreground, систематика и политика перекрытия отдельно для PTA и LVK. Из сохранённых чисел повторно вычисляется разность маргинальных log L. Идентификатор `decision_id` может ссылаться на уже ратифицированное научное решение D с записью `gw_dispositions`. До такого решения результат имеет статус для рассмотрения. [Код P10](r135/gw_review.py).

## Что необходимо для физического вывода

Для XA открыты размерный закон энергии, физическое отображение меток и часы. Для независимой XB нужны масштаб в МэВ и предыстория, реальные ансамбли и отклик, метастабильная EOS, нуклеационный префактор, трение и теплоотвод. Ранний каскад требует спектров инжекции и сопряжения с тепловым бюджетом. Для полной сети глюболов нужны парциальные ширины, реакции C-чётных и C-нечётных состояний и физическая неопределённость этих величин. За пределами упругого ETHOS необходимы уравнения возмущений выбранного X. Открыты обратная связь всей популяции карманов, трёхароматная кинетика при её применимости и полная наблюдательная калибровка GW. [Матрица реализованных режимов и открытых работ](CAPABILITIES.json).

Для повторения контролей используются `pr160_reference/validate_spectra.py`, `validate_history_refinement.py`, `validate_nuclear.py`, `validate_pions.py` и `validate_joint_grid.py`. Все принимают новый каталог `--out`. Спектральный контроль принимает `--cache CACHE --offline`. Два ядерных контроля запускаются в закреплённой среде LINX/PRIMAT. Для сквозного контроля дополнительно нужны `--class-root`, `--planck-root` и `--planck-python`. Общая серия выполняется командой из [описания интеграции](PR160_INTEGRATION.md).
