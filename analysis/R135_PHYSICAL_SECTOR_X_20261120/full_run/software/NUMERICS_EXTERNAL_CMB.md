# P9: собственные спектры CLASS → ACT DR6 и SPT-3G

## Что реализовано и исполнено

`r135/external_cmb.py` принимает вычисленные линзированные спектры, вызывает
закреплённые официальные likelihood ACT DR6 CMB-only и SPT-3G D1 lite и сохраняет
отдельные значения данных, приоров и их суммы. `r135/external_cmb_audit.py`
проверяет эти значения в P10 и может повторно исполнить native likelihood в
новом процессе. Общая космологическая оптимизация через функцию `profile_pair`
реализована как интерфейс к двум вычисляющим спектры провайдерам. Она не
подменяется оптимизацией калибровок на одном фиксированном спектре.

Исполненный контроль содержит **два новых расчёта CLASS до ℓ=9000**, их оценки
двумя likelihood и отдельные nuisance-профили. Космологии назначены для
программного контроля: вторая отличается увеличением `A_s` на 2%. Это не
подготовки физического X и не область его совместимости или исключения.

Сохранены [команда и программа контроля](external_cmb_reference/validate_native.py),
[исполненный результат](external_cmb_reference/native_control/VALIDATION.json),
[фиксированные оценки](external_cmb_reference/native_control/fixed.json) и
[результаты профилирования](external_cmb_reference/native_control/profiled.json).

- [Официальная спецификация SPT на закреплённом commit](https://github.com/SouthPoleTelescope/spt_candl_data/blob/f22611a9671d50af6135f048a2ea3f43ef4c2f62/spt_candl_data/SPT3G_D1_TnE_v0/lite/SPT3G_D1_TnE_lite.yaml).
- [Официальные данные и окна SPT](https://github.com/SouthPoleTelescope/spt_candl_data/tree/f22611a9671d50af6135f048a2ea3f43ef4c2f62/spt_candl_data/SPT3G_D1_TnE_v0/lite).

Байты каждого использованного исходного файла сверяются с
[`donors/sources.json`](donors/sources.json). Receipt хранит URL, SHA-256,
размер, выбранные окна, размер и хеш реально используемой ковариации.

На входе — **`convention: "Cl"`, `unit: "microK^2"`, `lensed: true`**,
целые последовательные ℓ начиная с 2 и массивы TT, TE, EE. Native интерфейсам
передаётся ровно одно преобразование

\[
D_\ell=\frac{\ell(\ell+1)}{2\pi}C_\ell.
\]

Для ACT индексы массива совпадают с ℓ; позиции 0 и 1 добавляются нулевыми.
Для SPT массив начинается с ℓ=2. Дополнительного умножения на температуру CMB
нет. Знак TE сохраняется. Пропуски, дубли, обрезанные высокие мультиполи,
нелинзированные спектры и несовместимые единицы отклоняются. Проверяется
неотрицательность TT/EE и неравенство `TE²≤TT×EE` с численной погрешностью.

Ковариации передаются native коду без диагонализации, изменения масок и
выбрасывания внедиагональных элементов. У опубликованной текстовой ковариации
SPT измерена небольшая асимметрия записи: максимальная разность, нормированная
на `sqrt(C_ii C_jj)`, равна **1.3091438014×10⁻¹⁰**. Поэтому проверка использует
порог `10⁻⁸` для этой безразмерной величины и положительность Cholesky. Матрица
**не симметризуется**; измеренная асимметрия записана в receipt. Строгая проверка
абсолютного равенства элементов на уровне `10⁻¹⁴` ошибочно отвергала бы сам
опубликованный выпуск при большом диапазоне дисперсий.

## Приоры и независимые варианты анализа

Для SPT native candl включает приоры в `log_like`. Адаптер независимо вычисляет
их штрафы и проверяет равенство native `prior_logl` сумме этих штрафов. Затем
возвращает три разных числа: `logL`, `log_prior`, `log_posterior`. Значение τ
берётся из **того же CLASS producer receipt**, что породил спектр; оно не
является независимой nuisance-переменной. `spt_tau_prior: "omit"` удаляет только
штраф τ, сохраняя калибровочный приор Tcal. Для Ecal Gaussian-приор не
добавляется.

ACT, SPT и Planck сохраняются **тремя отдельными вариантами**. Код отклоняет
`combine_with`, `sum_likelihoods`, `derived_cmb_constraints` и другие
незарегистрированные варианты автоматического сложения. Общие участки неба,
калибровки и приоры требуют определённой совместной ковариации и политики
данных. Простая сумма likelihood или добавление Gaussian для уже полученных
из этих CMB данных `N_eff`, `Y_p` либо `ω_b` такой модели не задаёт. В этой
поставке совместная Planck+ACT+SPT likelihood не реализована.

## Оптимизация: два разных режима

`evaluate_batch` вычисляет фиксированные спектры. При
`profile_nuisance: true` для каждого спектра исполняется Powell-профиль по
калибровкам выбранной likelihood. Сохраняются все старты, завершение
оптимизатора, число вычислений, границы и лучший успешный результат. У SPT
численная область Ecal задаётся явно; попадание на её границу не принимается
как внутренний минимум. Эта область не объявляется физическим приором.

`profile_pair(likelihood, baseline_provider, x_provider, policy)` вызывает
провайдер заново на каждом шаге. Для baseline и X обязательны один набор
изменяемых параметров, одни границы, масштабы и допуски, минимум два одинаковых
старта и одна likelihood. Провайдер возвращает `spectra`, фактически
вычисленную `cosmology`, её `cosmology_sha256` и `execution_receipt`. Каждый
вызов оставляет след входных параметров, хеша спектра и receipt. Ошибочный хеш
космологии отклоняется.

Полный статус `PROFILED_COMMON_COSMOLOGY_AND_NUISANCE` возможен лишь когда
меняются `ω_b`, `ω_cdm`, `A_s`, `n_s`, `τ`, `h` или `H0`, а также все nuisance
параметры выбранной likelihood. Более узкая оптимизация получает
`PROFILED_REGISTERED_PARAMETER_SUBSPACE`. Разность `−2 log posterior` сама по
себе не превращается в доверительную вероятность.

В текущем исполненном контроле выполнен только первый режим. Для второго
реальный X-провайдер должен согласованно пересчитывать требуемую физическую
историю, BBN/гелий и возмущения при изменении космологии. Одни сохранённые Cl
этого не обеспечивают. P9/P10 поэтому явно сохраняют
`cosmological_optimization: "NOT_PERFORMED"` и
`confidence_calibrated: false`.

## Подключение к P8/P9 и независимый аудит

P8 выбирает `external_cmb_variants`; это повышает требуемый CLASS `l_max_scalars`
до максимума выбранных вариантов. P9 получает отдельный блок, например:

```json
{
  "external_cmb": {
    "variants": ["ACT_DR6_CMBONLY", "SPT3G_D1_LITE"],
    "cache": "/path/to/verified/donors",
    "offline": true,
    "python": "/path/to/pinned/cmb-environment/bin/python",
    "python_sha256": "SHA256_OF_INTERPRETER",
    "spt_tau_prior": "include",
    "profile_nuisance": true,
    "profile_policy": {
      "spt_ecal_bounds": [0.8, 1.2],
      "starts": {
        "ACT_DR6_CMBONLY": [
          {"A_act": 1.0, "P_act": 1.0},
          {"A_act": 1.02, "P_act": 0.99}
        ],
        "SPT3G_D1_LITE": [
          {"Tcal": 1.0, "Ecal": 1.0},
          {"Tcal": 1.003, "Ecal": 1.01}
        ]
      },
      "maxiter": 300,
      "ftol": 1e-9,
      "xtol": 1e-7
    },
    "max_delta_logL": {"ACT_DR6_CMBONLY": 0.1, "SPT3G_D1_LITE": 0.1}
  }
}
```

Это пример **численной политики**, не физически обоснованная подготовка X и
не обоснование допусков для окончательного анализа. Точность CLASS задаётся
отдельными двумя или тремя монотонно ужесточаемыми `class_refinement` уровнями.
Гейт проверяет изменение результата выбранной likelihood при неизменном
физическом входе и одной nuisance-процедуре. Единственный уровень получает
`NOT_VALIDATED`.

P9 пишет `external_cmb_request.json`, `external_cmb_evaluations.json` и
`external_cmb_convergence.json`. Набор содержит обе BBN-ветви × пять углов
отклика × все уровни точности. τ, байты Cl и producer receipt привязаны
хешами. Интерфейс не принимает внешние Cl, если их receipt не устанавливает
использованную космологию.

`audit_external_cmb(root, config, replay_config, workdir)`:

1. Проверяет хеш исходного запроса **до** изменения путей при переносе.
2. Восстанавливает пути по зарегистрированным `engine/corner@accuracyN`,
   сверяет локальные файлы и original producer receipts. Сохранённый внешний
   абсолютный путь не становится источником данных аудитора.
3. Восстанавливает Cl из исходной линзированной таблицы CLASS, проверяет
   фактический `parameters.ini`, совпадение τ, покрытие ℓ, уровни точности и
   одинаковые физические входы при уточнении сетки.
4. Проверяет реестр данных, маски и размер ковариации, nuisance-векторы,
   аналитическую арифметику приоров и пересчитывает каждый гейт сходимости.
5. При наличии `replay_config.external_cmb = {python, python_sha256, cache}`
   запускает native likelihood в **новом** рабочем каталоге и сверяет данные,
   ковариацию, nuisance-минимумы и численные значения.

Отсутствующие заказанные артефакты дают `OPEN_INPUT`. Недоступная среда
независимого повторения даёт `PARTIAL`, а не численный успех по сохранённой
сводке. Даже успешное native повторение фиксированных спектров оставляет
открытыми общий космологический профиль и калибровку статистического вывода.

## Исполненные числа и воспроизведение

Назначенная baseline: `H0=67.4`, `ω_b=0.02242`, `ω_cdm=0.12`, `T_cmb=2.7255`,
`τ=0.054`, `n_s=0.965`, `A_s=2.1×10⁻⁹`, `N_ur=3.044`, `YHe=0.245`.
CLASS commit `e85808324f51fc694d12e3ed7439552a3c3f9540`.

| Контроль | ACT log posterior | SPT log posterior |
|---|---:|---:|
| Baseline, центральные калибровки | −91.4119411001 | −85.5098883743 |
| `A_s × 1.02`, центральные калибровки | −121.8996922058 | −97.5579222025 |
| Baseline, nuisance-профиль | −90.6930970490 | −83.4293808087 |
| `A_s × 1.02`, nuisance-профиль | −90.1957072292 | −84.1268715737 |

При фиксированных калибровках изменение спектра существенно меняет обе
likelihood. Профиль калибровок может поглотить значительную часть этого
изменения, поэтому сравнение сырых значений при фиксированной калибровке
нельзя выдавать за оптимизированное космологическое сравнение.

Отдельно воспроизведено официальное контрольное значение SPT
`−83.20924274362947` при `Tcal=1.001`, `Ecal=0.999`, `τ=0.054`. Исключение
только τ-приора увеличивает результат ровно на `0.125`, не меняя data logL.

Фиксированная среда: Python 3.12/Linux/x86_64; NumPy 2.5.5, SciPy 1.18.1,
Cobaya 3.6.2, sacc 2.4, astropy 8.0.3, candl-like 2.2.0, PyYAML 6.0.3.
[`external_cmb_sources.lock.json`](external_cmb_sources.lock.json) хранит
инвентарь `.py`/`.so` этих семи пакетов; каждое чтение native worker проверяет
их версии, wheel RECORD и совокупные хеши кода. Это закрепление выбранного
численного пути, а не декларация герметичности всех системных библиотек.
Для другой платформы нужен отдельный проверенный lock. CAMB для приёма
собственных Cl не требуется.

Из каталога `software`, в закреплённой среде:

```bash
OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=2 python external_cmb_reference/validate_native.py \
  --cache /path/to/verified/donors \
  --class-source /path/to/pinned/CLASS \
  --out /fresh/native-control

R135_EXTERNAL_CMB_NATIVE=1 R135_DONOR_CACHE=/path/to/verified/donors \
OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=2 python -m unittest discover \
  -s tests -p 'test_external_cmb*.py' -v
```

Два CLASS-расчёта, оценки и nuisance-профили заняли **54.09 с** в финальной
среде. Это время только этого контрольного задания; оно не оценивает стоимость
полного P0–P10, сетки X или совместной оптимизации космологии.

[`native_control/PUBLICATION.json`](external_cmb_reference/native_control/PUBLICATION.json)
описывает компактную публикацию: сохраняются исходные spectra JSON, параметры,
неизменённые producer receipts, запросы и результаты; шесть больших raw-выходов
CLASS перечислены с оригинальными SHA-256 и размерами, но не дублируются.
Поэтому опубликованный каталог не объявляется полным CLASS checkpoint для
повторного использования в P9. Для получения полного checkpoint используется
приведённая команда с **новым** `--out`. Native worker может независимо
повторить ACT/SPT по сохранённым спектрам без повторного CLASS-расчёта; такой
тест включён в набор проверок.

Отдельный [исполненный контроль аудитора](external_cmb_reference/audit_control/VALIDATION.json)
занял **10.21 с**. [Программа контроля](external_cmb_reference/validate_audit.py)
создала полную диагностическую раскладку десяти P9-слотов из **двух**
уникальных реальных CLASS-спектров, выполнила ACT/SPT, затем повторила обе
likelihood другим свежим worker через `audit_external_cmb`. Копирование
производных файлов не объявляется десятью новыми CLASS-решениями или
физической five-corner историей. Аудитор подтвердил потреблённые Cl, параметры,
data/covariance hashes и значения likelihood; его физический статус остался
`PARTIAL`. Компактная публикация содержит отдельный manifest исключённых
дублирующихся спектров и raw-файлов. Для нового полного контроля:

```bash
OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=2 python external_cmb_reference/validate_audit.py \
  --control /fresh/native-control \
  --cache /path/to/verified/donors \
  --out /fresh/audit-control
```

Снимок выполненной функции CLASS берётся до нативных расчётов и сохраняется
как `executed_run_class.py`. В финальном контроле отдельно проверено, что хеш
этой функции и всего `backends.py` после исполнения совпадает с захваченным
в начале; результат — [SOURCE_CHECK.json](external_cmb_reference/native_control/SOURCE_CHECK.json).

## Что остаётся открытым

Реализованы приём реальных спектров, native оценки, nuisance-профили,
callback-интерфейс общего профиля и независимый аудит. В этой поставке не
исполнены общий baseline/X космологический fit, физический X-источник этих Cl,
совместная Planck+ACT+SPT ковариация, уточнение CLASS для опубликованного
двухточечного контроля и калиброванная область наблюдательной совместимости.
Эти состояния отражены в машинных статусах и не скрываются успешными тестами
программного интерфейса.
