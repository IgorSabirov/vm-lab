# Взаимодействующие возмущения X: реализованная ветвь ETHOS

`r135/perturbations.py` добавляет сопоставление рассчитанной истории P7 с
**реальными уравнениями IDM–IDR закреплённого CLASS**. Поддержаны холодный
стабильный компонент и термальное безмассовое излучение с упругим обменом
импульсом. Излучение может иметь собственную иерархию мультиполей либо находиться
в проверяемом пределе идеальной жидкости. Плотность X и скорость взаимодействия
вычисляются из истории; независимые подстановки этих параметров запрещены.

Это расширение программного покрытия. Оно **не доказывает, что космологический X
или чистая SU(3) после конфайнмента принадлежат этому семейству**. Физический
полный прогон R135 здесь не запускался.

## Какие уравнения действительно исполняются

В конформном ньютоновском калибровочном представлении для давления IDM,
которым можно пренебречь на заявленных масштабах, используемые уравнения имеют
следующий вид. Штрих обозначает производную по конформному времени:

\[
\delta_m'=-\theta_m+3\phi',\qquad
\theta_m'=-\mathcal H\theta_m+k^2\psi
             -\frac{4\rho_r}{3\rho_m}\,d\mu(\theta_m-\theta_r),
\]
\[
\delta_r'=-\frac43\theta_r+4\phi',\qquad
\theta_r'=k^2(\delta_r/4-\sigma_r)+k^2\psi
             +d\mu(\theta_m-\theta_r).
\]

В режиме `free_streaming` CLASS эволюционирует также сдвиг и высшие мультиполи;
их столкновительное затухание содержит
`alpha_l*dmu_idm_dr + beta_l*dmu_idr`. Название режима обозначает наличие
иерархии: при ненулевой непрозрачности излучение продолжает взаимодействовать.
В режиме `fluid` используется предел нулевого сдвига. Метрика, фотоны, барионы,
нейтрино и IDM–IDR интегрируются совместно самим CLASS, включая его переходы к
приближениям сильной связи. Адаптер не вычисляет X на фиксированной чужой метрике.

В коде отдельно проверяется действие и противодействие:

\[
\rho_m C_m+\frac43\rho_r C_r=0.
\]

`collision_drag` воспроизводит только эти два столкновительных члена для
независимой проверки знака, единиц, сохранения импульса и затухания относительной
скорости. Полные спектры получают вызовом настоящего CLASS.

## Сопоставление с историей P7

Дополнительно к времени, масштабу, H, температуре фотонов и барионной плотности
история должна содержать рассчитанные массивы:

| Поле | Смысл и единица |
| --- | --- |
| `rho_idm_MeV4`, `p_idm_MeV4` | Плотность и давление холодного компонента. |
| `rho_idr_MeV4`, `p_idr_MeV4` | Плотность и давление безмассового компонента. |
| `Gamma_idr_idm_s_inv` | Физическая скорость релаксации импульса DR при столкновении с DM, `s^-1`. |
| `Gamma_idm_idr_s_inv` | Обратная скорость в уравнении скорости DM, `s^-1`. |
| `Gamma_idr_self_s_inv` | Физическая самонепрозрачность DR, `s^-1`; нуль допустим для иерархии без саморассеяния. |

Суммы компонент должны воспроизводить `rho_extra_MeV4` и `p_extra_MeV4`.
Нужны как минимум три поздние точки с изменением масштабного фактора не менее
10%, `T_gamma <= 0.01 MeV`, завершением однородного энергообмена и аннигиляции
электронов. Упругий обмен импульсом между IDM и IDR при этом сохраняется.

Проверяются постоянство `T_gamma*a`, `rho_idm*a^3`, `rho_idr*a^4`, `rho_nu*a^4`,
барионного отношения, давление DR и взаимность скоростей. По умолчанию
относительная ошибка замыкания — `1e-6`; нельзя ослабить её выше `1e-3`.
Давление IDM имеет отдельный предел `w <= 1e-6` по умолчанию и обязательное
обоснование малости давления **на всём диапазоне нужных масштабов**.
Энергия термальных частиц DR должна быть мала по сравнению с массой IDM.
Проверяется также соответствие H(t) плотностям плоского FLRW с точностью `1e-3`.
Последний допуск покрывает различие постоянных донора и предварительную
барионную массовую нормировку; это не заявленная точность наблюдательного расчёта.

При нормировке сегодняшнего масштаба к единице:

\[
a_* = k_B T_{\rm cmb}/T_{\gamma,*},\quad
\omega_m=\omega_\gamma\frac{\rho_m}{\rho_\gamma}\frac1{a_*},\quad
N_{\rm idr}=\frac{\rho_r}{(7/8)(4/11)^{4/3}\rho_\gamma}.
\]

`N_ur` получается из `rho_nu` отдельно: IDR не добавляется ещё раз в свободные
нейтрино. Нормировка `omega_gamma` вычисляется из явно записанных постоянных
закреплённого CLASS. Обычный `omega_cdm` описывает отдельный компонент и не
подменяет рассчитанную плотность IDM.

Положительная конформная непрозрачность в соглашении CLASS:

\[
d\mu\,[{\rm Mpc}^{-1}]
   =a_*\Gamma_{r\leftarrow m}\,[{\rm s}^{-1}]
       \frac{1\,{\rm Mpc}}{c}
   =\omega_m a_{\rm idm\_dr}\left(\frac{1+z}{10^7}\right)^n.
\]

Код выводит `a_idm_dr` из всех выбранных отсчётов и проверяет одну степень
`n=0,2,4`. Аналогично получается `b_idr` из саморассеяния. Обратная скорость
должна равняться `(4*rho_idr/(3*rho_idm))*Gamma_idr_idm`.

Для `fluid` нужны реальная самонепрозрачность не менее
`100*max(k_max,aH)` в окне сопоставления и отдельный источник, обосновывающий
предел жидкости на последующей истории. Одного флага «жидкость» недостаточно.
Для свободной иерархии конечное саморассеяние поддержано при ненулевом IDM–IDR
взаимодействии; комбинация `a_idm_dr=0,b_idr>0` отклоняется, поскольку в этом
закреплённом CLASS затухание иерархии проверено только в ветви `has_idm_dr`.

Все соответствующие моды должны оставаться снаружи горизонта при сопоставлении;
проверяется объявленный `k_max/(aH)`, по умолчанию не более `0.05`. Для CMB до
`ell=2508` объявленный диапазон должен покрывать хотя бы `k_max=1/Mpc`.
Это необходимая проверка, а достаточность раннего продолжения, отсутствие
изокривизны и допустимая ошибка истории перехода требуют независимого
модельного обоснования. Стандартный CLASS не получает произвольную историю X
до сопоставления и не может автоматически воспроизвести её след в возмущениях.

## Интерфейс и защита от независимых подстановок

```python
from r135.perturbations import match_ethos_history, validate_ethos_input

class_input = match_ethos_history(actual_P7_history, registered_class_configuration)
checked = validate_ethos_input(class_input)
```

Модель задаётся как `perturbation_model.kind = "class_ethos_idm_idr"`.
Исполненный пример структуры — `perturbations_reference/control.py`.
В `ethos_matching_evidence` сохраняются исходные ряды, замороженная конфигурация,
хеш всей P7-истории и отдельный хеш свидетельства. Перед запуском сопоставление
повторно восстанавливается. Изменение плотности, непрозрачности, H0 или
первичного спектра отдельно от этого свидетельства отклоняется.
Допустимые изменения P9 — `omega_b` и `YHe` из рассчитанных ядерных обилий,
а также зарегистрированные уточнения численной точности.

## Исполненные проверки

```bash
python -m unittest discover -s tests -p 'test_perturbations.py' -v
python perturbations_reference/control.py \
  --class-root /path/to/pinned/class \
  --output /new/isolated/output
```

Модульные проверки проверяют единицы, три степени непрозрачности, сохранение
импульса, оба вида излучения, смену знака относительной скорости, тёплый/неверно
разбитый X, изменённые P7-входы, независимые подстановки и неверные физические
часы. Нативный контроль использует 6 реальных расчётов CLASS с
`ell=2..512` и `P(k)`: нулевую связь против эквивалентных CDM+UR, жидкость против
свободной иерархии, ненулевую связь в обоих режимах и уточнение точности.
Сохраняются исходные спектры, входы, параметры, действительно прочитанные CLASS,
SHA-256 файлов и статус каждой проверки. Таблица чисел находится в
[`perturbations_reference/native_control/report.json`](perturbations_reference/native_control/report.json).

Получено **13/13 модульных проверок** и `PASS` всех шести нативных случаев.
Для контроля ненулевой связи использованы диагностические
`omega_idm=0.012`, `N_idr=0.2`, `n=0`, `a_idm_dr=1/Mpc`; жидкостная ветвь
имеет `b_idr=10^12/Mpc`. Эти значения не являются оценкой параметров X.

| Нативное сравнение | Измеренный результат |
| --- | --- |
| Нулевая связь, иерархия IDR против эквивалентных CDM+UR | `max abs(delta TT/TT) = 2.1536173e-4` |
| Ненулевая связь против нулевой, жидкость | `max abs(delta TT/TT) = 0.01155921` |
| Ненулевая связь против нулевой, иерархия | `max abs(delta TT/TT) = 0.01405064` |
| Жидкость против иерархии при нулевой связи DM–DR | `max abs(delta TT/TT) = 0.01348657` |
| Уточнение численной точности связанной жидкости | `max abs(delta TT/TT) = 0.00101031` |
| `P(k=0.2 h/Mpc)` связанной/несвязанной жидкости | `0.85823846` |

Отклик TT на связь превышает сдвиг при уточнении более чем в пять раз.
Все автоспектры конечны и неотрицательны. Суммарное время шести вызовов CLASS
на использованном локальном стенде — около **23.6 с**; точные времена каждого
вызова сохранены в отчёте. Это стоимость данного контроля до `ell=512`, а не
прогноз стоимости физических точек или полного R135.

Это контроль уравнений и передачи данных на явно диагностических параметрах.
В нём не оценивается Planck likelihood и не подтверждается точность полного
наблюдательного сканирования до `ell=2508`; для каждого физического расчёта
остаются обязательными предусмотренные P9 уточнения и контроль likelihood.

## Что осталось открытым

Продолжающиеся распады, рождение частиц, теплообмен с видимым сектором,
полурелятивистский остаток, произвольные нетермальные распределения DR,
изокривизна, возмущения стенок/карманов и произвольная зависимость непрозрачности
от времени требуют другого замыкания или расширения исходных уравнений CLASS.
Одно соответствие фоновых плотностей их не задаёт.

Особенно важно не отождествлять этот режим с четырьмя опубликованными точками
чистой SU(3): [Forestell et al., arXiv:1605.08048v2,
Phys. Rev. D 95, 015032](https://doi.org/10.1103/PhysRevD.95.015032) описывают
конфайнмент в массивные глюболы, числоизменяющие реакции и возможные распады.
Наличие после перехода отдельного безмассового термального IDR из этого не
следует. Сопоставление конкретной ветви R135 с ETHOS должно быть выведено
отдельно; без него физический вход остаётся открытым.
