## Контрольные расчёты

- **T1.** На шагах 1–8 абсолютный счётчик 12 различает исходную пару на шаге 1, счётчик 21 — на шагах 3, 4, 5, 6 и 8. На шаге 7 плотности 21 различны из-за разных длин при равном числителе 3. На шаге 2 все пять счётчиков совпадают при длинах 23 и 24. Ни один из пяти не различает пару на каждом шаге 1–8. После первого шага идентификация всей орбиты с трёхсекторным словом теряет определённость. В CSV пустые M_plus и M_minus означают отсутствие определения на полном слове. Отдельные masked-колонки дают буквальный счёт шести троичных шаблонов с указанием доступного покрытия. Маскирование — выбранная диагностика. [Орбиты и покрытие](reference/features.csv).
- **T2.** При $u=2$ на 64 интервалах от 2 до 4 обнаружен один интервал перемены знака и бисекцией получено $b_*=3.635949241037133$. Это локализованный корень для заданных весов и ансамбля. Сканирование не доказывает единственности всех корней. При $b=2^{-k}$, $k=3,\dots,8$, проверяется экстраполяция $\Delta S/b^{12}$ по двум младшим шагам. Нулевые веса при $u=0$ допустимы только как математический контроль. Дополнительное слово 0321 даёт веса (1,2,2,1) при $u=2$ и следы 12 и 58. На панели PCG64(13521) при $b=1$ найденный по собственным частотам шестой момент сравнивается с целым обходом матрицы. У панели нет независимых экспериментальных мишеней. [Асимптотика](reference/spectrum.csv) · [32 контрольных слова](reference/panel.csv).
- **T3.** Вход — три строки пяти положительных значений D/H, столбцы 00, 10, 01, 11-full, 11-add. Для технического теста принят фиксированный пол $d=10^{-6}$ для относительного остатка $r=(O_f-O_a)/O_{00}$. Каждое из двух уточнений должно менять каждое $O$ не более чем на $0.1d\,O_{\rm fine}$, а остаток — не более чем на $0.1\max(d,|r_{\rm fine}|)$. Иначе возвращается FAIL_CONVERGENCE. Только после этого проверяется $|r_{\rm fine}|>d$. Значение ниже порога описывает численную разрешимость. Уровни точности являются инженерным выбором для испытания. Пять историй × три допуска × два backend дают 30 BBN-интегрирований на одну физическую точку.
- **G4.** На двух искусственных стратах непосредственно проверена инвариантность разности связных кумулянтов при обоих ненулевых вращениях глобального центра. Полосу эквивалентности $\pm10^{-3}$ сохранить фиксированной. Пилот определяет достижимую ошибку, число цепей и блоков. По замечанию о прогреве для планирования выделять не менее 20 измеренных времён автокорреляции на прогрев и 30 после него; проверка смешивания остаётся отдельной. Угловая отсечка у границ секторов и возможный порог малого модуля петли меняют выборку по-разному. Сравнение страт при фиксированной плакеточной процедуре считать исследовательским. Для утверждения о совпадении младших маргиналов нужен отдельный опыт.

## Почему G6a пока не исключает X-B

Поздняя квитанция даёт $B=0.044518075411783944$. Для этого события $\xi_{\min}=[B/(\epsilon L/T_c^4)]^{1/4}$. При единичной эффективности получаются 0.44118895 и 0.45651298. Оба ряда используют свою теплоту. Вторая работа определяет скачок энергии. Чтобы получить абсолютную горячую плотность этой ветви, требуется согласованная нормировка. Число $0.84486$ из отзыва предполагает заимствование горячей плотности первой ветви. [Giusti и соавт.](https://arxiv.org/abs/2502.03875) · [Borsányi и соавт.](https://pure.psu.edu/en/publications/precision-study-of-the-continuum-su3-yang-mills-theory-how-to-use/) · [восемь строк бюджета](reference/summary.json).

Проверим предложенную оценку на $T_X=35T_c$. Здесь уже есть данные. Подстановка в высокотемпературные аппроксимации уравнений (8), (10) и (11) Giusti–Pepe даёт $s/T_X^3=6.69185$, $p/T_X^4=1.66682$, $\rho/T_X^4=5.02502$. Авторы указывают около 0.5% для $\rho/T^4$ в этом диапазоне. Горячую ветвь у самого перехода в контрольном сопоставлении берём по обновлённому определению 2025 г. Эта проверка на двух температурах не является сшивкой EOS с полной ковариацией. [Высокотемпературная EOS](https://arxiv.org/pdf/1612.00265) · [у перехода](https://arxiv.org/abs/2502.03875).

В качестве контрпримера к универсальному множителю из отзыва примем изолированный обратимый X **до** перехода, уже независимо краснеющий температурный эталон нейтрино с $T_\nu a=\mathrm{const}$ и одинаковую позднюю нормировку горячей фазы. Тогда $s_Xa^3=\mathrm{const}$ и
$$
\frac{(\rho_X/\rho_{\nu,1})_{35}}{(\rho_X/\rho_{\nu,1})_{c^+}}=
\frac{(\rho_X/T_X^4)_{35}}{(\rho_X/T_X^4)_{c^+}}
\left[\frac{(s_X/T_X^3)_{c^+}}{(s_X/T_X^3)_{35}}\right]^{4/3}
=0.45870 .
$$
При нормировке $0.3684853$ это даёт около $0.16903$ в единицах одной нейтринной плотности, условно при $\epsilon=1$. Это пример влияния скрытой энтропии на отношение температур. При продолжающейся развязке нейтрино, обмене с X или другом начальном состоянии историю надо решать заново. Момент $T_X=35T_c$ сам по себе не задаёт эпоху видимого сектора. Для настоящего BBN требуется $H(t)$ и согласованные с историей слабые скорости. Для поздней оценки требуются судьба остатка и наблюдаемая история.

## Внешние входы и передача исполнителю

Для G3 Francis и соавт. приводят $T_c/\Lambda_{\overline{\rm MS}}=1.24(10)$, а более ранняя термодинамическая работа даёт $1.26(7)$. Выбирать основной источник и раздельно вести ошибки, не усредняя по умолчанию. Из безразмерного отношения не получается абсолютный масштаб нового сектора. Для G4 табл. I Francis даёт бесконечнообъёмные $\beta_c=5.69275(28),6.06239(38)$ при $N_t=4,8$. На конечных объёмах нужен контроль сдвига. ILDG каталогизирует ансамбли калибровочных полей. Для приёмки поля записать идентификатор ансамбля, действие, границы, шаги цепи, плакетку, тип сохранённых данных, права получения и контрольную сумму. Для заданных четырёх решёток проверяемая поставка пока открыта. [Francis и соавт.](https://doi.org/10.1103/PhysRevD.91.096002) · [Borsányi и соавт., масштаб](https://arxiv.org/abs/1204.6184) · [ILDG](https://hpc.desy.de/ildg/).

Для G5 сохранять $H_0(t_{99}-t_{50})$ и $H_0(t_{100}-t_0)$ с разными подписями. В обратимой модели изолированной смешанной фазы они равны 0.72536 и 0.96667. Скорость нуклеации задаётся $A(T)e^{-S_3/T}$, её крутизна зависит также от температурной истории. Значения скорости стенок из другой модели требуют сверки теплоотвода. Для G6b в манифест включить массу остатка с ошибкой и источником, время жизни, каналы и вероятности распада, термализацию и параметры likelihood. [Родительский расчёт](../../REPORT.md#thermal) · [GKL](https://arxiv.org/abs/2311.00029).

Проверенная схема последнего исполнения — [Actions 44719756079](https://github.com/IgorSabirov/vm-lab/actions/runs/44719756079), [исходный workflow](https://github.com/IgorSabirov/vm-lab/blob/7b26fd4a6cfa20d9768ee295917b10926537d60b/.github/workflows/bbn-copilot.yml) и [сырые результаты в PR #144](https://github.com/IgorSabirov/vm-lab/tree/d503ee0f1f89c99c8560803dc46277d544ef15ba/reproductions/BBN_COSMO_20261120/results/44719756079). Там есть SHA кода, закреплённые версии решателей, нативный Copilot CLI, журнал фактического вызова, квитанция исполнения, результаты, контрольные суммы и отдельная публикация. Итог исходной серии — COMPLETE_CONTROL_DISCREPANCY. Для R135 необходимо связать собственную команду с отдельным операторским заданием, закрепить execution SHA комплекта и выполнить публикацию квитанций именно этого запуска. Родительская base_commit относится к происхождению данных. Перенос workflow BBN без замены исполняемого задания повторит прежний опыт.

Контрольный пакет запускается из корня клона. Зависимости для эталона — Python 3.12, NumPy 2.3.5, mpmath 1.3.0.

```bash
d=analysis/R135_PHYSICAL_SECTOR_X_20261120/run_design/preflight
out=$(mktemp -d)
python "$d/measure.py" "$out"
```

Выходы — [орбиты](reference/features.csv), [спектральный предел](reference/spectrum.csv), [панель](reference/panel.csv) и [численный итог](reference/summary.json). Скрипт сам сравнивает два расчёта малых спектральных разностей при точности 80 и 100 знаков и проверяет точные тождества. Запуск здесь воспроизводит контрольные результаты. Физическое исполнение, новые наблюдательные ограничения и научная приёмка остаются отдельными этапами.
