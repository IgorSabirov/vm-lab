# Какой хиральный индекс задаёт R150

**Ответ для текущей модели.** На полном устойчивом носителе фиксированной нечётной длины индекс нулевой фазы шага F равен 3 в принятой ориентации T. При L=7 его разложение по активной и пассивной частям равно 2+1. Счёт по пяти представлениям Стандартной модели из этих входов не определяется. Ниже для обоих утверждений приведены проверяемые основания.

## Оператор и прямой счёт

Пусть T²=1, F унитарен, TFT=F†. Для безразмерного массового параметра m выбрана конкретная реализация знакового (overlap) оператора на графе:

$$H_m=T[(1-m)I-F],\qquad D_m=I+T\,\mathrm{sign}(H_m).$$

Это дополнительный выбор ядра на графе конфигураций. Четырёхмерная решётка, спиновые поля и калибровочные связи в него не входят. Использовано соотношение Гинспарга–Вильсона при единичном шаге. [Neuberger, 1998](https://arxiv.org/abs/hep-lat/9801031).

При m=1 имеем H₁=−TF и H₁²=I, поэтому D₁=I−F. Из TFT=F† прямо следует TD₁+D₁T=D₁TD₁. Индекс в заданной ориентации равен

$$\nu_0=\operatorname{Tr}[T(I-D_1/2)]
=\tfrac12\operatorname{Tr}(T+TF)
=\operatorname{Tr}\bigl(T\vert_{\ker(I-F)}\bigr).$$

Последнее равенство следует разложением по фазам. Пространства сопряжённых фаз взаимно переставляются под T. На фазе π множитель 1+F равен нулю. Постоянные векторы на орбитах F образуют базис нулевой фазы. След T на них равен числу орбит, которые T переводит в себя. Это второй способ расчёта без диагонализации. Для альтернативной градуировки FT след на нулевой фазе тот же, а знак следа на фазе π меняется. Это объясняет, почему при сравнении со статическим i(F−F†) важно указывать, включена ли π-фаза.

При 0<m<2 из H_m²=[(1−m)I−F]†[(1−m)I−F] следует нижняя граница щели 1−|1−m|. Индекс постоянен на этом интервале. Точная перестановочная проверка проведена для L=3,5,7,9,11,13,15. На носителях размерности до 130 дополнительно построена численная матричная sign(H_m) для m=0,25; 1; 1,75 и проверено соотношение Гинспарга–Вильсона. Для прочих нечётных длин используется опубликованный орбитный вывод фазового дисбаланса. Утверждение относится к устойчивому носителю фиксированной длины. Переходы, меняющие длину, в этот оператор не включены. ## Почему пять физических индексов не восстанавливаются

Пусть к тому же графу присоединено внутреннее пространство W размерности шесть. Берём F⊗I и T⊗I. Две допустимые реализации обладают тождественными матрицами графового опыта, за одинаковый результат отвечают все его измеримые истории.

1. Пусть W несёт одно представление Q=(3,2) с гиперзарядом 1/6. Нормированный индекс в секторе Q равен 3, в секторе L равен 0.
2. Пусть W несёт три копии L=(1,2) с гиперзарядом −1/2. Нормированный индекс в секторе Q равен 0, в секторе L равен 9.

Оба примера служат расширениями для теста идентифицируемости. Они не предлагаются как физически полные спектры. Можно также взять одно стандартное семейство W или его комплексно-сопряжённое семейство. В обоих случаях размерность 15, а калибровочные аномалии компенсированы внутри семейства. Графовые матрицы снова совпадают, при этом калибровочные представления различаются.

В общем виде для заданного W=⊕ mᵣr эквивариантный индекс равен 3[W]. Нормированный по размерности компоненты результат 3mᵣ и число графовых пар 10mᵣ при L=7 наследуют выбранный состав W. Присоединение по одной копии каждого из Q, uᶜ, dᶜ, L, eᶜ даёт условный вектор (3,3,3,3,3). В этом вычислении список и кратности входных мультиплетов заданы заранее.

**Статус исходного условия.** Графовый индекс для указанного оператора вычислен. Для текущих гипотез установлена невозможность однозначного вывода индекса по представлениям СМ. Для нового физического вывода нужны действие калибровочной группы на собственных степенях свободы, физическая градуировка, сохраняющий их кинетический оператор и счёт зеркальных пар по каждому представлению. Донор Kaplan–Sun задаёт отдельную орбифолдную проекцию со спинорным γ₅. В R150 такой проекции сейчас нет.
