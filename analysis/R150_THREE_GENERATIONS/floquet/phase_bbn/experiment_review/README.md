# R150 ↔ BBN. Итог проверки постановки и замечаний E1–E6

**Дополнение по десяти замечаниям.** Выполнены ансамбль из 200 историй, сканы параметров и расчёт G до допуска 10⁻¹¹. При L=7 графовый индекс нулевой фазы равен 13−10=3. По представлениям СМ текущая модель допускает разные ответы. [Итоговая проверка десяти пунктов](followup/README.md) · [Индекс и зеркальные пары](followup/INDEX.md).

**Решение от 26 ноября 2026 года.** Вычислительная серия на восьминуклидном стенде завершена. Ядерное вмешательство меняет состояние графа в модели с заданным взаимодействием. Физический опыт по взаимному формированию остаётся открытым. Из имеющихся микроскопических данных нельзя определить скорость переключения шва, создаваемый им сдвиг ядерных энергий и обмен энергией с плазмой.

Исходный вопрос — можно ли по ранней динамике графа R150 и поздним продуктам первичного нуклеосинтеза установить взаимное влияние графа и ядерной сети. Здесь сведены исходные условия, исправления и фактические прогоны. Численные параметры вмешательства и контроль корреляции выбраны для проверки стенда. Протокол не был зарегистрирован до первого анализа данных. [Исходные критерии](../seam_audit/README.md#условия-общего-опыта-и-площадка) · [61 исходный сценарий и результаты](../NETWORK_RESULTS.md) · [Полный разбор замечаний до интервенции, PDF](R150_E1_E6.pdf) · [Его автономный комплект воспроизведения, ZIP](R150_E1_E6_replay.zip).

## Вмешательство E6

Входы заданы конфигурацией [example.json](../network_bench/example.json) на одном и том же космологическом фоне. При охлаждении от 80 до 60 кэВ коэффициент захвата умножен на 1 + 0,1 sin²(π log(T/60)/log(80/60)), где T в кэВ. Обратный ядерный коэффициент пересчитывается из того же прямого коэффициента по детальному балансу. Начальный состав и обе температурные истории совпадают. Это внешнее изменение кинетики конкретной реакции. Прямая стрелка граф→ядра сдвигает B_D через z. Обратная стрелка ядра→посредник добавляет к источнику z член, пропорциональный Y_D. Переменная p — вероятность периодического сектора графа.

Основная серия содержит 17 сценариев при каждом из двух допусков BDF. Дополнительно четыре ветви при включённом и выключенном импульсе проверены ещё на двух более строгих допусках. Итого 50 результатов E6, включая 16 целевых уточнений.

Два самых строгих расчёта G различаются на 4,02·10⁻¹⁰. Три более точных расчёта дают один знак, на грубом он меняется. Остаток G для D/H имеет масштаб нескольких 10⁻⁹ в пределах этой модели. На строгом допуске изменения G для ln(Yp), ln(³He/H) и ln(⁷Li/H) составили соответственно −1,31·10⁻⁹, +3,97·10⁻⁹ и −4,18·10⁻⁸. Смешивать эффект импульса с самим стационарным сравнением ветвей нельзя. Например, до импульса G для ln(D/H) равен +1,50·10⁻⁷ на самом строгом допуске.

Здесь M = ln y₁₁ − ln y₁₀ − ln y₀₁ + ln y₀₀, где индексы включают прямую и обратную стрелки. Этот контраст включает отклик ядер на их собственный вклад в z. Для выделения вклада контакта с графом в G сравниваются (обе стрелки − только прямая) при штатном λ и при λ=0. В обоих контрастах сравниваются прогоны с импульсом и без него. Расхождение двух допусков характеризует численную устойчивость и не является статистическим доверительным интервалом.

## Почему общий физический опыт остаётся открытым

1. **Переключение шва.** Одни и те же статические блоки F₀ и Fπ совместимы с нулевым переходом между секторами и с переходом gA, где A=|2⟩⟨0|. Матричные элементы дают разные скорости, а статические данные в обоих случаях совпадают. Для определения перехода требуются динамическая переменная, физический оператор среды, её спектральная плотность и нормировка связи.
2. **Перенос в ядерную сеть.** Требуются независимо полученные знак, амплитуда и температурная история сдвигов B_D и Qₙₚ, история H(T), граничные значения и неопределённости. Наблюдаемый после подбора остаток по гелию относится к двум заданным профилям. Для проверки на данных нужны отложенные выходы и совместные ошибки ядерных скоростей, космологических параметров и наблюдений.
3. **Энергия.** В исходном фоне Qγ=Qν=0 и работа портала исключена из эволюции фона. Даже при сохранении барионного числа общий тепловой баланс двух взаимодействующих подсистем таким стендом не проверяется. Для его проверки нужен член обмена с противоположными знаками в уравнениях обеих подсистем. [Баланс стенда](../network_bench/results/energy.json).
4. **Площадка.** Завершённая серия выполнена на CPU. Число и размер будущих физических прогонов зависят от микроскопического оператора и числа независимых профилей. Дополнительная вычислительная мощность сама по себе не определяет эти входы. Для общего опыта площадка пока не выбрана.

## Данные и повтор

Результаты E1–E5, повтор исходных ячеек и обе точности E6 находятся в [results](results).
```sh
export OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1
export R150_BENCH="$(cd ../network_bench && pwd)"
python finite_audit.py > finite-repeat.json
python weak_pilot.py 3e-9 > weak-repeat.json
python weak_pilot.py 7e-10 > weak-fine-repeat.json
python intervention.py --rtol 3e-9 --out repeat-base
python intervention.py --rtol 7e-10 --out repeat-fine
python convergence.py --rtol 1e-10 --out conv_1.json
python convergence.py --rtol 3e-11 --out conv_2.json
python verify.py --base repeat-base/summary.json --fine repeat-fine/summary.json
```

Для проверки опубликованных чисел и контрольных сумм достаточно `python verify.py`. Исходное дерево перед дополнением — `91ec6f28f7c143c79f712b576ac4519ce8007879`.
