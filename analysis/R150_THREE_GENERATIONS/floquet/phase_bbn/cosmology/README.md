# Фазы A и B, CCC+TL, первичный нуклеосинтез и R150

REPORT.md — русский разбор. Для повтора нужны Python 3, NumPy, mpmath и SymPy. Из корня распакованного архива выполните:

```sh
python check.py
python which_path/check.py
```

Первый скрипт перерассчитывает отклики LINX/PRIMAT из исходных конечных содержаний, спектральные кратности R150, распределение длин за один такт, контроль термодинамики и альтернативные законы для нейтринных часов. Эталон находится в checks.json. Второй скрипт проверяет именную динамику семи тактов R130, две именные истории H6 и совместные измерения в двухкубитных примерах. Эталон находится в which_path/results.json. Сравнивать JSON при разборе, численные результаты — с учётом округления.

data/summary.json — парные интегрирования, репозиторий IgorSabirov/vm-lab, ревизия d503ee0f1f89c99c8560803dc46277d544ef15ba, reproductions/BBN_COSMO_20261120/results/44719756079/SUMMARY.json. [Условия парного сравнения](../../../../PRIMAT_LINX_BBN_BRIDGE_20261117/PAIRED_RUN_20261120.md). data/s1.json — первичные численные выходы сетевого теста общего времени. data/eta.json — локальные производные по барион-фотонному отношению. [Определение двух тепловых историй](../../../../R135_PHYSICAL_SECTOR_X_20261120/REPORT.md#thermal). Ссылки на публикации и версии отчётов находятся в REPORT.md.

Проверка интерполяции использует результаты ранее рассчитанных окон. Новый нейтринный транспорт, интегрирование BBN с микрофизическим источником R150 и оценка наблюдательной значимости в этот расчёт не входят.
