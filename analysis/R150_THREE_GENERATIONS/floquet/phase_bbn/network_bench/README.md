# Шов R150 и первичный нуклеосинтез

Стенд отвечает на два разных вопроса. Может ли конечный граф передать сигнал ядерной сети при заданном портале? Можно ли по конечным содержаниям установить, что сигнал прошёл через самостоятельную медленную координату? Вход «15» прочитан в контексте двух приложений как R150. Длина графа L=15 также включена в испытания.

## Запуск

Распакуйте архив и перейдите в каталог R150_BBN_bench. Для расчёта достаточно Python 3, NumPy и SciPy. Все таблицы находятся в архиве. Сеть доступна без аккаунтов и доступа в интернет. Проверенная среда указана в results/analysis.json. Matplotlib нужен только для рисунков.

```bash
python -m pip install numpy scipy
OPENBLAS_NUM_THREADS=1 python run_case.py example.json --out my_trial
OPENBLAS_NUM_THREADS=1 python experiment.py --jobs 4 --output my_results
OPENBLAS_NUM_THREADS=1 python replay_attachment.py
```

Первая команда расчёта записывает четыре выхода и историю в новый каталог. Вторая запускает сравнения, решает обратную задачу подбора одной амплитуды, строит десять температурных функций чувствительности и проверяет контрольные допуски. Ненулевой код завершения означает ошибку проверки или интегратора. Для однопроцессного запуска укажите `--jobs 1`. Последняя команда исполняет только заранее проверенные строки приложенного текста с точным SHA-256 и сохраняет stdout, stderr, диапазоны строк и коды завершения. Один исторический блок действительно обрывается на поиске недостижимого корня. Его отказ сохранён как результат аудита. Встроенный check.py отдельно воспроизводит исходную четырёхсостоянийную модель.

## Как менять опыт

Скопируйте example.json. Для `mode="direct"` задайте `reverse=false`. При `mode="mediator"` параметр `tau` задаёт время релаксации в секундах. `reverse` включает источник от возникающих дейтронов, `forward` передаёт сдвиг в ядерные скорости. `layer="A"` задаёт пассивный слой с нулевым детектором, B — активный. `full_contact=true` прибавляет общий диагональный сдвиг, `false` измеряет изменение относительно антипериодического шва. В равновесной интерпретации это два разных определения фона.

`J` и `lam` заданы в МэВ и постоянны в основной серии. `comoving_J=true` задаёт J(T)=J_ref a_ref/a, J_ref при 72,513 кэВ. `p_initial` — вероятность периодического шва на горячей начальной границе. `S` задаёт постоянный барьер, `thermal_c>0` включает S(T)=cJ/T. `clock` растягивает все часы, `graph_clock` умножает только частоту шва. `domains_per_baryon`, `Ec`, `filling` задают плотность доменов, обратную кривизну на домен и вес в источнике. Для имитации внешнего сценария `mode="imposed"` принимает `profile_file` с двумя столбцами T_MeV,deltaBD_MeV по возрастанию T. Для `branch_file` второй столбец — F₁−F₀ в МэВ на домен. Обе таблицы должны покрывать весь период интегрирования. Путь отсчитывается от текущего каталога. Параметры в архивных JSON с префиксом results/ относятся к комплекту по умолчанию. Для собственного --output подставьте его путь при повторе сохранённого JSON.

## Что считать различением моделей

1. Сначала сравните direct с off, затем mediated и coupled с direct при общей амплитуде.
2. Сравните coupled с refit_direct. Вторая модель уже подогнана по D/H. Только остальные содержания дают независимый контраст при такой постановке.
3. Сравните coupled с prescribed. Этот контроль получает полную историю сдвига из coupled. Он проверяет, какую информацию сеть вообще может сохранить о происхождении этой истории.
4. Для обратной связи сравните также self_only. Часть эффекта создаёт ядерная поляризация среды даже при выключенном контакте графа. Смешанная разность четырёх запусков приведена в analysis.json. Сопоставляйте её с вариацией при уточнении допуска.
5. Сравните H-only, B_D-only и оба канала. Для новых форм B_D(T) применимы только ядра именно по B_D. При больших возмущениях повторите прямую интеграцию.

Режим `mode="algebraic", reverse=true` устраняет z в мгновенном минимуме той же свободной энергии. Он сохраняет источник от Y_D и его обратное действие на шов без отдельного уравнения для z. Контроль fast_feedback сопоставляет с ним решение при τ=0,02 с. В режимах off и direct столбец z — неиспользуемый регистр. Физический вход ядерной сети всегда указан отдельно в deltaBD_MeV.
