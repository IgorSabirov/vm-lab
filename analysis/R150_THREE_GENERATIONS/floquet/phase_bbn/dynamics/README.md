# R150 · динамика портовых слов, имён и длины

Полный русский отчёт в report.md. График на месте маркера [FIGURE] — length_probability.png. PDF поставляется отдельно. Все результаты относятся к операторам и приготовлениям, определённым в отчёте.

## Воспроизведение

Из корня распакованного архива, Python 3 с NumPy, SciPy, SymPy и mpmath. Регрессионные сравнения фаз зависят в последних разрядах от библиотеки линейной алгебры. Динамические вероятности и сертификаты классических траекторий проверяются точно.

    export OPENBLAS_NUM_THREADS=1
    python carrier_audit.py > my_carriers.json
    python ray_certificate.py > my_rays.json
    python r150_extension.py > my_extension.json
    python named_control.py > my_named.json
    python scale_checks.py > my_scales.json

carrier_audit.py формирует все четырёхпортовые входы при L=2…25, проверяет быстрый шаг относительно word_rule.py, устойчивый носитель, тип циклов, зарядовые резонансы и распределение возвратов для L=7. В выводе first_return_after_exit ключ отсчитывается от первоначального входа.

ray_certificate.py проверяет на целочисленных аффинных формах бесконечные хвосты, отделяет кратковременные возвраты от периодических орбит, дедуплицирует циклы и хвосты. Отчёт by_seed содержит все 343 индивидуальных результата.

r150_extension.py строит раздельную и общую монеты из исходных переписываний. Во всех 24 шагах при z=−i использованы гауссовы целые числители с общим знаменателем 2ⁿ. Компоненты числителей по модулю не превосходят 2²⁴ и точно представляются в binary64. Квадраты и вероятности суммируются как целые Python. Тысячные и меньшие сдвиги π рассчитываются отдельно в mpmath. На одном слое условия закрепления проверяются как по матрице утечки, так и по собственным значениям.

named_control.py использует имена, рёбра и упрощение из r130_reference.py, не переименовывает вершины. Он сравнивает две возможности приготовления суперпозиции и проверяет первый возврат при четырёх фазах шва. scale_checks.py проверяет оптимальную щель, аналитические производные Коиде и восстановление свободной фазы.

В expected находятся полученные JSON. В архиве transcript.zip лежат оригинальный пользовательский текст (SHA-256 6bdb862746b02c3e025aaebaf95b9ef5113af0ccc29b10191c77ffda6468a32d), извлечённые шесть ячеек и их вывод. Оригинальная ячейка 2 заканчивается IndexError. В cell_2_fix.py исправлена длина массива коэффициентов, остальное оставлено как в оригинале.

Штатные проверяющие программы и их результаты находятся [в фиксированной ревизии](https://github.com/IgorSabirov/vm-lab/tree/2ea30a746f9a39487f1f4841d781160df676b6a3/analysis/R150_THREE_GENERATIONS/floquet).
