# R150. Чётность, H6 и точный Коиде

REPORT.md содержит доказательства, границы применимости и ссылки на источники. Новые вычисления не используют значения масс лептонов.

## Воспроизведение

Для Python 3.10+ установите SymPy (проверено с 1.14.0). Из корня распакованного архива:

    python verify.py > observed.json
    diff -u checks.json observed.json

Для отдельного протокола 48 горизонтов:

    python h6_scan.py > observed_h6.json
    diff -u h6_results.json observed_h6.json

Все сравнения на точный Коиде в новом сканировании выполнены целочисленно. Восемь первых тактов входят в диапазон проверки с прежними счётчиками. Все 40 векторов на такте 8 дополнительно сверяются с независимым архивным экспортом. Положительный голономический контроль и контроль со знаковым ложным совпадением включены в verify.py.
