# Этап 2. Инверсия плотности по шести парам скоростей

Ретроспективный анализ опубликованных сводных таблиц. Критерии сравнения зафиксированы до нового расчёта. Авторские значения плотности из рис. 3b уже известны и используются только для сравнения после инверсии.

- Вход измерений — шесть ненулевых пар из рис. 3a и табличные маргинальные ошибки. Три строки с классификационным нулём сохраняют свой статус. Основная шкала D вычисляется из номинальных n=3,0 мкм⁻² и T=(T/Tc) × 42 нК. Отдельный сценарий использует теоретическую критическую плотность ln(380/g) вместо абсолютной калибровки. Ни один сценарий не фиксирует сверхтекучую плотность.
- EOS — только нормальная термодинамика из θ(X) таблицы I Prokof’ev–Svistunov. Интерполировать полную плотность монотонным кубиком, центрировать в X=0; давление получить интегрированием и согласованием с Hartree–Fock при критическом химпотенциале по Ozawa–Stringari. Проверить альтернативную точку согласования при X=−0,5 и величины cV, s, κ. Не использовать столбец сверхтекучести f(X). Отметить выход за таблицу или термодинамически недопустимые результаты.
- Подгонять обе наблюдаемые скорости в их собственных единицах по двум корням квартики Ландау, один свободный параметр n_s/n для каждой строки, 0≤n_s/n<1. Основной вариант использует ρ=0 для пары скоростей. Исследовать чувствительность к обоим знакам корреляции, используя как минимум −0,9, 0, +0,9 и корреляцию спектра около 0,91 Tс. Сохранять независимые оценки по сумме/произведению, остатки и χ² одного избыточного ограничения. Если χ²>3,84 при заданном T и ρ=0, помечать условную несогласованность по скоростям. Известное слабое взаимодействие как предел EOS и насыщение на холодном конце указывать независимо от теста.
- Статистический интервал по скоростям при фиксированных входах — профиль Δχ²≤3,84; отдельно распространить табличное положение по температуре и общие систематические масштабы n (15%), T (10%), q (5%), g (0,64±0,03). Изменения калибровок действуют на все строки вместе; F₀ из скоростной инверсии выпадает. Показать сценарии и ковариацию при явно заданных допущениях. Ошибки температуры и скорости могут коррелировать. Совместная калибровочная матрица эксперимента не опубликована.
- Проверить изменение интерпретации при смещении критической температуры до 10% и оценить, можно ли выделить предел нулевой частоты по имеющимся размерам и частотам. Сравнение с 4 допускается только после расчёта. Один и тот же опубликованный опыт образует и вход, и авторский контроль. Прогноз времени численного этапа на CPU — 2–180 секунд. Все входы и код доставляются в общем ZIP R143.
