# E55 · Что измеряет вторая мода и что передаётся в R141–R148

**Точка B отличается от объединения первых пяти строк сильнее, чем от соседней A.** Для D₂ = Γ₂/q² эти сравнения дают соответственно 3,54σ и 1,02σ при диагональных статистических ошибках. Частотный отклик поддерживает колебательную интерпретацию второй компоненты B при конечном q. Статическое положение B остаётся открытым. По данным ³⁹K выполнена проверка отображения «генератор двух мод + оператор наблюдения → измеряемый спектр». Отдельно проверено, почему спектральный инвариант кольца R144 сам по себе не определяет фазовую жёсткость газа. На оцифровке Gałka первые пять строк по центральной табличной координате дают среднее D₂ = 6,6085 ± 0,5625 в ℏ/m, если полудлины полос считать стандартными ошибками, а строки независимыми. ## Два порога и проверка классификации B

Для одной компоненты классического S(q,ω) в S4 знаменатель равен (ω²−ω₀²)²+Γ²ω². Минимизация знаменателя даёт ненулевой максимум при r=Γ/ω₀<√2. Решение уравнения полюсов даёт колебательную пару при r<2. При √2≤r<2 полюса колебательные, максимум компоненты находится в нуле. При r=2 полюса сливаются, при r>2 они чисто релаксационные. Критерий для максимума относится к отдельной компоненте; сумма с первым звуком может скрыть слабый пик. Методика статьи использует критерий формы S. [Methods, S3–S4](https://arxiv.org/pdf/2008.06044)

При реконструкции r = kD₂/u₂, где D₂ дан в ℏ/m и k=(ℏ/m)q/cB. Использована размерная опора cB=(ℏ/m)√(n g̃)=2,25849 мм/с для n=3 мкм⁻² и g̃=0,64. Прежнее значение 2,3 мм/с объясняет небольшую разницу центральных чисел. Для каждого сценария ниже даны три оценки расстояния до границы h. Первая воспроизводит линейную ошибку отношения во вложении. Вторая использует непосредственно h u₂−kD₂ при независимых ошибках. Для положительной истинной скорости эта разность имеет тот же знак, что h−r; при совместно гауссовых входах и фиксированной k её ошибка линейна точно. Третья сохраняет опубликованные маргиналы и берёт наихудшую корреляцию, σ_max=h σᵤ+k σ_D. Все оценки условны относительно полос как SE и принятой размерной опоры.

Для B колебательный полюс проходит односторонний ориентир 1,645 в обеих геометриях даже при худшей корреляции в этой модели. Пик B при 23 мкм уже чувствителен к ковариации. Относительная острота B по сравнению с A для четырёх назначений коробок даёт всего 0,08–0,84σ при диагональных ошибках. Размерное r можно прочитать из сырого фита напрямую как Γ₂/ω₂: при согласованном пересчёте уже измеренных частот и ширин q и cB точно сокращаются. Неопределённость коробки возникает при восстановлении размерных величин из раздельно опубликованных агрегатов. Систематики нельзя учитывать повторно как независимые.

Полные спектры позволяют проверить, реалистична ли гипотеза нулевой ковариации. В собственном бутстрэпе подгонки S4 корреляция Γ₂ и ω₂ равна +0,763 для холодной строки (локальная оценка +0,714) и +0,716 для горячей (+0,936). Они относятся к этим двум спектрам. Переносить коэффициенты на A/B нельзя. В холодной строке r=0,579 и положительный частотный максимум выдержал слепую проверку. В горячей r=1,907 в центральном S4-фите; 95%-й профиль ω₀²−Γ²/2 пересекает нуль. Это центральный пример формы, а не калибровка независимого классификатора. Положительность f₂(B) сама по себе даёт всего 1,79 табличной ошибки относительно нуля. Контраст f₂(A)−f₂(B) разрешён лучше. Вес, частота и ширина разделяют один спектр и процедуру выбора моды. [Слепой расчёт и ковариации](../results/BLIND.json) · [Табличные входы](../results/THERMO_INPUTS.csv)

**Проверка вывода «B статически сверхтекучая».** У Wu–Zhang–Zhai при конечном q между Tc и T*(q) возможен колебательный второй звук в нормальной фазе. Простейшая дисперсия иллюстрирует это для чистой температурной волны; общая модель с κₛ≠κₜ смешивает её с плотностью. Для проверки логического следствия мы построили положительный двухкомпонентный продольный отклик. Его лапласовы знаменатели имеют вид s²+Γⱼs+uⱼ²q². Возьмём q=1 в единицах пробного q, наблюдаемые u₁,u₂,f₂ строки B, нормировку f₁=1−f₂, Γ₁∝q² и постоянную Γ₂=r_B u₂. Числитель каждой компоненты пропорционален fⱼq². Полюса устойчивы, высокочастотный коэффициент задаёт единичную сумму весов. В сценарии 33 мкм при q=1 медленная пара равна −0,0718±0,3142i и даёт пик плотностного отклика при ненулевой частоте. При q=0,1 медленные полюса вещественны, а при q→0 один релаксирует как −u₂²q²/Γ₂. Такой отклик совместим с обычной гидродинамикой звука и тепловой диффузии в длинноволновом пределе. Это конструктивная проверка недостаточности данных для присвоения статической фазы. Она не устанавливает микроскопическую модель газа или фактическую фазу B. [Wu–Zhang–Zhai, уравнения 15–19](https://doi.org/10.1103/PhysRevA.102.043311)

Прежние штрафы объёмной кривой PS на строке A составляют 11,91 при фиксированной t, 3,23 с диагональной ошибкой t и 1,42 при плотностной корреляции. Формальные хвосты χ²₁ примерно 0,0006, 0,072 и 0,23. Подкритическая область имеет границу и один свободный минимум достигает t=1, ошибки и EOS заданы условно. Эти числа остаются сценарной проверкой чувствительности к термометрии. [Профили и ограничения](SCALE_AND_SIZE.md)

## Проверка R141, R144 и R148 на 16 измеренных частотах

Для каждой моды генератор времени имеет блок [[0,1],[−uⱼ²,−γⱼ]], где γⱼ=Γⱼ/ωB. Источник возбуждает обе скорости, детектор суммирует смещения с весами f₁ и f₂. Мнимая часть передаточной функции C(−iωI−A)⁻¹b/π точно воспроизводит S4 для нормированного отклика Ã. Одновременная перестановка базиса A, b, C сохраняет измерение с погрешностью порядка 10⁻¹⁶. Перестановка только весов меняет измерение при неизменных собственных значениях генератора.

У холодной строки 0,905779 известна коробка. Подставлены обе скорости из Fig. 3a, f₂ и f_sum из Fig. 2c и обе ширины из Fig. 4.9 Gałka. Параметры на 16 частотах Cambridge заново не подбирались. Сумма квадратов остатка относительно опубликованных ошибок равна **14,22**; при перестановке весов — **201,41**, при передаче всего веса первой моде — **371,16**. При единичной нормировке вместо измеренного полного веса получается 17,87. Это замыкание табличных представлений одного эксперимента, без независимого испытания физической модели и без номинального p-значения. Для горячей строки тепловой вклад требует собственного числителя и амплитуды. Нулевую запись f₂ нельзя использовать для удаления диффузионного отклика. [Данные Cambridge](https://doi.org/10.17863/CAM.66056)

Имеется ещё одна наблюдаемая R142 с точным сокращением масштабов. В одной серии r₂/r₁=(D₂/D₁)(u₁/u₂): q и cB не нужны. По шести строкам центральные отношения равны 1,367; 1,024; 2,048; 1,560; 1,742; 0,836. Эта комбинация сопоставляет относительное затухание двух мод даже без геометрии. Для проверки отличия от единицы нужны совместные ошибки четырёх величин.

## Какую жёсткость проверяет скрут

На полном шестизвенном кольце R141/R144 с диагональю 3 повторены det M(φ)=322−2cos φ и значения 320, 322, 324. На пути из шести вершин введённая на рёбра фаза устраняется унитарной заменой базиса и все три детерминанта равны 377. На кольце кривизна детерминанта при нулевом потоке равна 2. При том же операторе и каноническом одночастичном приготовлении F=−kBT log Tr exp[−M/(kBT)] кривизна свободной энергии F″(0) составляет 0,05548, 0,01331 и 0,001402 в единицах энергии связей для kBT=0,1; 0,5 и 1. Температурное изменение даёт член флуктуаций F″=〈E″〉−Var(E′)/(kBT). Это явная математическая проверка, почему для физического переноса требуются и генератор, и приготовление, и измеряемая функция. [Исходные тождества блока](../../R141_R148_MODEL/PAIRS.md)

Для двумерного газа при определённом равновесном фазовом скруте на величину φ вдоль стороны L∥ выражение для добавки к полной свободной энергии есть ΔF=Υ(L⊥/L∥)φ²/2. Тогда Dₛ=2πΥ/(kBT), и условие Нельсона–Костерлица Υ/(kBT)→2/π даёт 4. Это устанавливает требуемую нормировку и способ измерения. Открытая коробка с продольной силой в E55 сама по себе не реализует такой граничный скрут. Нужны физически наложенный перепад фазы или равновесный поперечный отклик и контролируемое масштабирование. [Nelson–Kosterlitz](https://doi.org/10.1103/PhysRevLett.39.1201)

## Что даст вторая геометрия

У коробок (21,33) и (56,23) мкм отношение q₂/q₁=33/23=1,435, отношение коротких сторон 23/21=1,095, площадей 1,859. При допущении, что округление задаётся только 1/ln²(Lmin/λ), с общей λ=1 мкм и общим коэффициентом ширина во второй коробке была бы в 0,943 раза меньше. Это полезная геометрия для пилота. Поворот направления возбуждения относительно длинной оси, отношение сторон и граничные условия остаются существенными. При отражающих стенках q_drive/q_min для первой коробки равно 1, для второй — 56/23=2,435: во второй коробке есть более длинная волна вдоль другой оси. Ни площадь, ни Lmin в одиночку не фиксируют конечномерный отклик. Зависимость оценки жёсткости от направления и формы известна и в периодической XY-модели; количественный перенос в оптическую коробку требует другого граничного условия. [Геометрия опыта](https://doi.org/10.17863/CAM.82718) · [Исследование зависимости от отношения сторон](https://doi.org/10.1103/PhysRevB.69.014509)

При согласованных T/n и взаимодействии и практически одинаковой скорости для закона Γ=Dq² с постоянной D прогноз Γ₂₃/Γ₃₃=2,059, а для добротности ω₀/Γ отношение 0,697. Для растущей линейно добротности при линейной частоте ожидается отношение Q₂₃/Q₃₃=1,435 и эффективной D₂₃/D₃₃≈0,486 в слабом затухании. В WZZ определена полюсная Q=|Re ω/Im ω|; для S4 она равна √(4/r²−1) при r<2. В области сильного затухания нужно сравнивать обе части полюса, а не переводить ω₀/Γ постоянным множителем. В тексте WZZ рядом с рис. 4 одновременно указаны линейная дисперсия, временное затухание ∝q² и Q∝q. Первые два утверждения при их определении дали бы обратную зависимость Q. Выбор диапазона q и определение ширины надо фиксировать до сравнения. Зависимость D от q может иметь также геометрическое, кинетическое или аппаратное происхождение. Два q способны различить два заданных прогноза при достаточной точности; из них нельзя однозначно вывести вихревой механизм или статический скачок. [Wu–Zhang–Zhai, рис. 4](https://doi.org/10.1103/PhysRevA.102.043311)

**Ближайший вход** — найти среди исходных повторов девяти условий хотя бы одну пару по обеим геометриям с сопоставимыми T/n, g̃ по общей объёмной шкале, затем сравнить Γ, ω и веса из исходных спектров вместе с их ковариацией. Индивидуальные q и калибровки нужны для D₂; отношение Γ₂/ω₂ следует забирать напрямую из одного фита. В открытой матрице геометрически идентифицированных пар при общей температуре по-прежнему ноль. Если такого перекрытия нет, различающий контроль меняет q внутри одной коробки и сохраняет q при изменении подобного размера. Доказательство статического скачка дополнительно требует равновесного, длинноволнового и термодинамического пределов для каждого подкритического T с последующим T↑Tc.

Поиск исходных повторов выполнен по опубликованным таблицам и временным записям обеих геометрий. Термометрическая привязка короткой коробки остаётся открытой. [Какие записи удалось сопоставить](../paired/REPEAT_BOXES.md)
