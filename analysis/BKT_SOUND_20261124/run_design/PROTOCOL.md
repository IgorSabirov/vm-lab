# Аудит второго звука, этап 1 · 24 ноября 2026

Наблюдаемая — подписанная величина d = (ω₂² − Γ₂²/2)/ωB². Пик вклада второй моды в S лежит при ω/ωB = √max(0,d). Граница комплексных полюсов Γ₂=2ω₂ отличается от границы пика. Сравниваем области d>0 и d≤0 одной модели S4. S5 даёт контроль предельного описания в измеренной полосе.

Работа ретроспективна. Публикация, вывод авторов и размеры выборок уже известны. Обе численные ветви используют только анонимный ID, частоту, отклик и опубликованную стандартную ошибку. Ключ с солью зафиксирован по SHA-256. Сначала сохранить расчёт мощности, затем анонимную таблицу коммитом, после этого раскрыть ключ.

1. Подогнать два упорядоченных осциллятора S4 к Atilde. Независимый гауссов шум с указанными по точкам σ, без оценки общего множителя дисперсии. S(ω) из рис. 2b — тот же опыт. Доля i в правиле сумм равна πxᵢωᵢ² в безразмерных единицах. Основная модель фиксирует f₁+f₂=1 (пять свободных параметров), контроль освобождает сумму (шесть). Для S5 интеграл до бесконечности расходится. Ограничение на сумму к S5 не применять.
2. Численные границы основного поиска в единицах ωB: ω₁∈[0.65,3], ω₂/ω₁∈[0.03,0.9999], Γ₁∈[0.035,3], Γ₂/ω₂∈[0.04,18], f₂∈[0,1]. Сравнить минимумы на обеих сторонах границы и на самой границе. Независимый расширенный поиск на реальных данных проверяет чувствительность к этим границам. Указывать достижение границ и локальную обусловленность.
3. До фитирования отклика прогнать мощность на обеих исходных сетках частот с их σ. При ω₁=1.45, ω₂=0.73, Γ₁=0.5, f₂=0.18 задать Γ₂/ω₂=0.56, √2 и 2.4. На каждый режим и сетку 1000 имитаций. Порог по 95-му перцентилю |подписанного LR| на границе для этой сетки; отчёт о долях +/−/? и биномиальной неопределённости. Это локальная сценарная мощность.
4. На данных взять разность лучших χ² при d=0 и при свободном d. Для каждого спектра калибровать граничную статистику 999 параметрическими имитациями от лучшего граничного фита. Двусторонний уровень 5% для каждого спектра. При p≤0.05 и устойчивом знаке сообщать знак d, иначе «неопределённо». Профильный 95% интервал d строить с тем же локальным критическим приращением χ², включая разрывные области при наличии. Это приближённый интервал, без гарантии одновременного покрытия. Сохранять p с поправкой +1, индивидуальные параметры, ковариацию, остатки, веса, правило сумм и результаты удаления каждой точки. Отмечать смену знака/решения. Если свободная нормировка меняет вывод, указывать условность результата.
5. Фиксированный seed 1432411. Прогноз численного исполнения 30–600 секунд при скомпилированном/пакетном решателе на CPU. Проверки — синтетическое восстановление, предел S4→S5, правило сумм, мультистарт, независимый решатель, исходные хеши. Монте-Карло воспроизводится из кода; ошибки калибровки и физики указываются отдельно.
6. Рис. 3a и 2c нужны для этапа термодинамики. Рис. 3b — производный авторский контроль. Инверсия требует EOS, совместных ошибок двух скоростей и общих калибровок.
