# БКТ в ³⁹K. Какие измерения различают две серии

Разбор предложения и повторный расчёт по данным PR #219, 24 ноября 2026 года. Пара A/B уже известна. Все сравнения ниже ретроспективные. Для следующей независимой серии можно заранее зафиксировать измеряемый контраст, способ объединения калибровок и критерий 95%.

## Что определяет температурную ось

В диссертации Christodoulou, рис. 5.7 и 5.8, шкалу приводят к исчезновению веса второго звука. Gałka (§4.3.2) описывает подгонку зависимости веса от температуры. В абсолютных единицах получается 42(4) нК при средней плотности 3,0(5) мкм⁻². Формула для бесконечной системы при центральных входах даёт 36,75 нК, опубликовано 37(6) нК. Гипотетический сдвиг на 5–10% в конечной коробке этими ошибками не разрешён. При бутстрапе каждой серии Christodoulou (§5.3.6) использует зависимость приведённой координаты от T/n и варьирует измеренную плотность данной серии при номинальной T. Это отвечает на вопрос о принципе нормировки. Для воспроизведения двух табличных абсцисс из настроек ловушки по-прежнему нужны численные настройки и привязка шкалы. Подставить 42 нК во все серии или провести вторую поправку 42/37 означало бы ввести дополнительное предположение. [Статья](https://arxiv.org/pdf/2008.06044) · [Christodoulou, §§5.3.2–3, 5.3.6](https://doi.org/10.17863/CAM.82718) · [Gałka, §4.3](https://doi.org/10.17863/CAM.96553)

При общей связи и общей привязке оси центральные оценки дают Tᵦ/Tₐ = 1,010106 nᵦ/nₐ. Достаточно nᵦ/nₐ = 0,989995 для равенства абсолютных температур. Поэтому у разности приведённых координат, разности абсолютных температур и нахождения по разные стороны статического перехода три разные проверки. Даже значение экспериментальной оси выше единицы на 0,00031 для B имеет стандартную ошибку 0,06747. Кроме того, сам экспериментальный репер получен из звукового веса. [Парный расчёт](results.json)

Для ρ = +0,9 получается **0,3388σ**, при ρ = 0 — 0,1125σ и при ρ = +1 — 1,0513σ. [Пересчёт по исходным строкам и проверка трёх спектральных наблюдаемых](../eos/THREE_OBSERVABLES.md)

## Какие калибровки сокращаются

| Вопрос | Что дают источники | Следствие для A/B |
|---|---|---|
| Зависит ли термометр EOS от абсолютной калибровки числа атомов? | В §4.8 Christodoulou и §3.3.4 Gałka одновременно подбирают T и химпотенциал по отношению плотностей в оптической яме и снаружи как функции глубины ямы. | Для общего линейного множителя имиджинга в этом фите β = ∂ln(T)/∂ln(αₙ) = 0. В отдельной величине T/n абсолютная плотность остаётся. В сравнении двух T/n общий усилитель сокращается при неизменной калибровке. Реальное изменение газа между сериями сохраняется. |
| Исчезают ли 10% шкалы глубины? | Одинаковая единица настройки U сокращается в Uᵢ/Uкалибр. Измерение T для самой калибровки использует **размерную** глубину Vdip. Одновременное умножение Vdip, T и μ на один множитель сохраняет предсказание EOS для отношения плотностей. | Ошибку шкалы энергии нельзя дважды вводить в бюджет. Для абсолютных T она может пройти через Vdip. Полное сокращение в Tᵦ/Tₐ требует общей измерительной цепи или проверенной относительной калибровки. Дрейф, нелинейность и смена геометрии требуют отдельных оценок. |
| Какую калибровку η = U/(kᵦT) применять? | На рис. 4.24 Christodoulou 4,7(1) относится к 22×36 мкм. У Gałka на рис. 3.12 имеется пример около 7,5 и указана зависимость от числа атомов и связи. Номинальные звуковые коробки 21×33 и 56×23 мкм. | В обоих источниках есть примеры калибровок. Присвоить один из этих коэффициентов строке A или B по сходству размеров нельзя. Для разных коробок нужны отношение коэффициентов и его ошибка, либо прямая относительная термометрия. |
| Сколько даёт неопределённость связи? | При 0,64(3) относительная ошибка самой связи 4,69%. В ln(380/g̃) коэффициент чувствительности равен −1/ln(380/g̃). | Относительный вклад в этот логарифм около 0,734%. Число 4,7% в квадратуре предложения завышает данный член. В отношении для единой связи он сокращается. |
| Как велики флуктуации n и L? | §5.3.6 сообщает типичные статистические вариации порядка 5% и менее 3% соответственно. Временная потеря плотности во время возбуждения и абсолютная калибровка плотности — другие источники ошибки. | Опубликованные диапазоны не задают точность установки относительной глубины, ошибку отношения средних плотностей A/B или корреляцию их блоков. |

[Первичные описания нормированного термометра и калибровок, Christodoulou](https://doi.org/10.17863/CAM.82718) · [Независимое описание той же установки, Gałka](https://doi.org/10.17863/CAM.96553)

При неизменном положительном множителе удобно проверять знак log(tᵦ/tₐ). Общий множитель сокращается точно. Если η общая, достаточно отношения настроек Uᵦ/Uₐ и плотностей nᵦ/nₐ для приведённой оси. Для абсолютного отношения температур при общей η достаточно Uᵦ/Uₐ. При разных η добавляется ηₐ/ηᵦ. Для оценки ошибки нужны совместные данные либо ошибка готового контраста. В линейном бюджете размерной разности при независимых общем и дифференциальном членах общий вклад действительно пропорционален самой разности. Числа 5σ и 9σ из такого бюджета не задают универсального предела проверки равенства при общей положительной шкале.

Для наблюдаемой разности 0,01000786 двусторонний нормальный интервал исключит нуль при стандартной ошибке меньше 0,005106. В сценарии двух одинаковых независимых ошибок это 0,003611 на строку. Если дополнительно принять независимый общий масштаб 18,75% по сценарию предложения, получится 0,003358. Это требование к комбинации ошибок, не установленная точность каждого U или n. Для опубликованных маргинальных ошибок минимальная σ разности равна 0,009519, максимальная достигает 0,125415. Оценка 1,05σ — максимум по корреляциям. Вычислять из него фактическую посерийную точность 0,67% нельзя. [Расчёт бюджета и контрастов](six_rows.json)

По опубликованным центральным точкам r, c₂/cᴮ и f₂ убывают на всём интервале. Для r контраст крайних строк составляет минимум 3,03 линеаризованной стандартной ошибки по всем корреляциям, для одной пары A/B минимум 1,46. В каждой строке верхняя граница σ(r) равна (σ₂ + rσ₁)/u₁, между строками верхняя граница равна сумме двух границ. Эти оценки описывают опубликованные маргинальные статистические ошибки. Гарантии одновременного покрытия, отдельного открытия после выбора пары или монотонности истинной кривой из них не следуют. c₁ в таблице немонотонна. Её инверсия как термометра потребовала бы выбора ветви EOS и независимой проверки разрешения.

Между A и B вес f₂ уменьшается в 9,55 раза. Для разности **самих весов** 0,143286 наибольшая стандартная ошибка по их табличным ошибкам 0,017409, или минимум 8,23σ. Малый вес B имеет большую относительную ошибку, поэтому отношение 9,55 — центральная оценка. Для второй скорости остаётся минимум 3,14σ. Внутрирядовая модель плотности даёт минимум 3,37σ для (c₂/cᴮ)/√t. Вес, скорости и Dₛ получены из одних спектров. Перемножать их значимости или назначать корреляцию +0,44 от холодного полного спектра всем шести строкам означало бы повторно использовать информацию. Для A смещение точки сшивки давления в EOS меняет Dₛ с 4,29 до 3,12, выбор теоретической шкалы даёт 5,14. Для B соответствующие оценки 2,45, 1,43 и 2,66. При общей подгонке получаются 5,30 и 3,52. Таким образом, даже сторона от 4 для ближайшей нижней точки зависит от модели. Равенство K = Dₛ/(2π) переводит проверку теоретического Kc = 2/π в проверку Dₛ(Tc⁻) = 4. Для этого требуется подход к пределу со стороны сверхтекучей фазы с контролем L и частоты. Номинальные q = π/Lᵧ составляют 0,0952 и 0,1366 мкм⁻¹. Распределить строки по коробкам, сравнить при совпадающем температурном условии и извлечь поправку к статическому пределу по этим двум числам невозможно. ## Что осталось найти

1. Для проверки приведённой температурной разности достаточно независимой парной оценки и её ошибки. Альтернатива — соответствие двух строк сериям, отношение U, отношение средних n, относительная калибровка η при различающихся настройках и совместные ошибки. Поснимочные данные полезны для оценки неопределённости, если готовой оценки нет. Для абсолютного температурного порядка можно использовать прямое отношение T, без плотностей.
2. Для динамической проверки нужны Lᵧ или q по строкам, измеренные частоты, сопоставимые условия при изменении q и размера. Для полного совместного анализа полезны ковариации частот и весов по всем шести строкам либо исходные спектры и блоки. Из двух опубликованных полных спектров ни один не относится к A/B.
3. Для статического скачка нужен контролируемый предел по размеру и частоте либо независимое измерение жёсткости с такой проверкой. Даже точная температура A/B сама по себе эту задачу не решает.
