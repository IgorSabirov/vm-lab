### Как проверены источники

Проверены все 11 числовых таблиц архива Cambridge и три оригинальные книги **Source Data** журнала. Девять листов Excel содержат данные рисунков 1–3. Лист Fig.3a объединяет обе скорости и их ошибки. Все 54 числовые ячейки совпадают с таблицами Cambridge с точностью округления до $5\times10^{-10}$. В книгах нет журнала измерений или соответствия этих двух строк блокам, установкам температуры и плотностям. Поле плотности на рис. 1b — один пространственный профиль. Координата $D/D_c$ на рис. 3b повторяет обратную температурную ось. Ни один из этих материалов не даёт две независимые пары $(T,n)$. [Cambridge Apollo](https://doi.org/10.17863/CAM.66056) · [Source Data журнала](https://doi.org/10.1038/s41586-021-03537-9) · [Листы, заголовки, URL и SHA-256](publisher.json)

В диссертации P. Christodoulou (§§4.7, 4.8, 5.3.6) приведены метод термометрии и схема авторского расчёта ошибок. Температуру задавали глубиной ловушки и калибровали по уравнению состояния. На рис. 4.24 $U_{\rm peak}/(k_BT)=4,7\pm0,1$ для ловушки 22×36 мкм. Коэффициент зависит от геометрии. При обработке отдельного спектра авторы варьировали плотность около измеренного для этой серии значения. Она входит и в $t$, и в $u_2$. Облака рис. 5.13 показывают имитации **внутри** каждой серии. Для парной ошибки между сериями нужны связи реальных измерений A и B. [Диссертация Christodoulou, рис. 4.24 и 5.13](https://doi.org/10.17863/CAM.82718)

Для измерений звука указаны две геометрии, 21×33 и 56×23 мкм, с отдельной калибровкой размера каждой серии. Их номинальные волновые числа вдоль направления возбуждения равны $9,52\times10^4$ и $1,37\times10^5$ м⁻¹. Вторая диссертация (M. Gałka, §4.3) подтверждает объединение данных двух размеров. В открытых материалах не найдена однозначная привязка размеров к A и B. Соответствие двух показанных полных спектров при 0,91 и 1,17 к данной паре неприменимо. [Диссертация Gałka, рис. 4.4–4.7](https://doi.org/10.17863/CAM.96553)

### Абсолютная и приведённая температуры

При общей $\tilde g$ использованная шкала даёт $t\propto T/n$, поэтому
$$
\frac{T_B}{T_A}=\frac{t_B}{t_A}\frac{n_B}{n_A}=1,01010588\,\frac{n_B}{n_A}.
$$
Если плотности равны, точечная оценка $T_B/T_A=1,01011$. Если $n_B/n_A=0,98$, из тех же координат получается $T_B/T_A=0,98990$. Это примеры неидентифицируемости по опубликованным центральным значениям. Они не задают погрешность плотности. Перевод табличной разности в нанокельвины умножением на общие 42 нК требует независимого обоснования одинаковых $T_c$ для обеих серий.

Для приведённой разности $t_B-t_A=0,01000786$ минимальная возможная стандартная ошибка по опубликованным маргинальным ошибкам равна 0,00951908. Даже с корреляцией +1 двусторонний нормальный интервал 95% равен [−0,00865; 0,02866]. Для исключения нуля требуется ошибка разности менее 0,005106. При сохранении прежних маргинальных ошибок формально потребовалась бы корреляция 1,00825. Это уточняет предыдущий этап: одно знание коэффициента корреляции старых точек не решает задачу. Нужна более точная оценка самой разности из исходных измерений. [Расчёт](results.json)

### Что дополнительно можно проверить без плотностей серий

В величине $w=(c_2/c_B)/\sqrt{t}$ плотность сокращается точно при общей $\tilde g$. По двум строкам получаются $w_A=0,58145$ и $w_B=0,32227$. При линейном распространении ошибок по описанной авторами схеме (вклад в статистическую ошибку $t$ от плотности при фиксированном номинальном $T$; размерные скорости независимо от ошибки $n$) отсюда получаются условные стандартные ошибки 0,04685 и 0,03014. Даже при наименее благоприятной корреляции между такими строками разность составляет 3,37 стандартной ошибки. Этот расчёт проверяет, могло ли простое деление на общую плотностную шкалу дать наблюдаемое изменение звука. Он не является независимым термометром и не добавляет независимых измерений звука. Корреляции между $t$ и $u_2$ внутри A и B оценены по этой модели как +0,341 и +0,339. Известную на этапе 2 роль калибровки следует рассматривать с этим уточнением. [Код](pair.py)

### Что позволит завершить измерение

Минимальный вход — независимая оценка $T_B-T_A$ и её стандартной ошибки с указанием, какие ошибки общие для обеих серий. Для порядка точек на приведённой оси требуется также непосредственно оценённая разность $T_B/T_c(n_B)-T_A/T_c(n_A)$ с ошибкой либо плотности соответствующих серий с совместной калибровкой. Если остались исходные записи, нужны идентификаторы серий, времена или блоки измерений, $T$ в нК либо глубины ловушки с калибровками для соответствующих геометрий, $n$ и его ошибки. Для сравнения при разной частоте дополнительно нужны измеренные размеры коробок и частоты каждой серии. Новые независимые температуры можно сравнить напрямую, без привязки к весу или скорости второго звука.

Для уже существующих **действительно парных независимых блоков** предусмотрен расчёт разностей в нК и в единицах $T_c(n)$. CSV содержит столбцы `block_id,T_A_nK,n_A_per_um2,T_B_nK,n_B_per_um2`, одна строка на независимый блок. Общие систематические поправки, не вошедшие в блоковые оценки, учитываются отдельно. Автоматическое сопоставление независимых серий по номеру строки дало бы фиктивные пары. Для непарного плана требуется его фактическая ковариация. Расчёт с экспериментальными блоками ожидает исходных данных.

```sh
python paired/pair.py
python paired/pair.py --blocks /path/to/paired_blocks.csv
python paired/publisher.py /path/to/three_publisher_workbooks
python -m unittest discover -s tests -p test_pair.py
```

Первый запуск воспроизводит проверку открытых данных. Третий использует openpyxl и три оригинальных XLSX, ссылки сохранены в [ведомости](publisher.json). Закрыта проверка предела опубликованных данных. Независимая парная термометрия и измерение статического скачка остаются открытыми.
