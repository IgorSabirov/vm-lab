# Выкладки для фиксированной транзитивной перколяции

Ниже аналитические следствия заданной модели, не новый постулат проекта. Прогоны не выполнялись. Пусть C — конечный частичный порядок, n=|C|, 0<p<1, q=1−p. При рождении b каждый x∈C выбирается независимо с вероятностью p, затем берётся транзитивное замыкание. Случайное множество прямых выборов обозначено A.

## 1. Вероятность конкретного предшествующего идеала

Прошлое b равно идеалу S⊆C тогда и только тогда, когда Max(S)⊆A⊆S. При s=|S|, m=|Max(S)|:

K_C(S)=Σ_{B⊆S\Max(S)} p^{m+|B|}q^{n−m−|B|}
       =p^m q^{n−s} Σ_{B⊆S\Max(S)} p^{|B|}q^{s−m−|B|}
       =p^m q^{n−s}(p+q)^{s−m}=p^m q^{n−s}.

В соседском промежуточном выражении p^m q^{n−s} Σ_t binom(s−m,t)(p/q)^t пропущен множитель q^{s−m}. Конечный ответ верен, но из написанной промежуточной строки не следует.

## 2. Точное сокращение W_a

Для отмеченного a∈C определим верхнее множество U=U_C(a)={x∈C:a≼x}, u=|U|. Новое b лежит выше a тогда и только тогда, когда A∩U≠∅. Действительно, путь из a в b должен последним ребром входить из некоторого x≥a, а такой прямой выбор достаточен для пути.

Независимость прямых выборов даёт

W_a=P(a≺b|C)=1−P(A∩U=∅)=1−q^u.

Это равносильно тождеству

Σ_{S∈I(C):a∈S} p^{m(S)}q^{n−|S|}=1−q^{|U_C(a)|}.

Соседское выражение q^n Σ_{S:a∈S}(p/q)^{m(S)} неверно: правильная сумма после вынесения q^n содержит p^{m(S)}q^{−|S|}. Размер идеала нельзя заменить числом его максимальных элементов.

Контрпример к выводу о фронте: a максимально, значит U={a} и W_a=p. Можно изменять число и связи элементов, несравнимых с a, меняя глобальный фронт, не меняя W_a. Наличие среди слагаемых p^{w(C)} является только нижней оценкой, не доказательством зависимости суммы от w(C).

Для цепи U содержит n−|J⁻(a)| элементов, что даёт соседскую формулу как частный случай. В общем порядке число несравнимых с a элементов вычитается дополнительно.

## 3. Точный фактор по числу потомков

При следующем рождении только новый элемент может пополнить U; отношения между старым a и старыми элементами не изменяются. Поэтому

P(u_{n+1}=u+1|C_n)=1−q^u,
P(u_{n+1}=u|C_n)=q^u.

Правая часть зависит только от u. Это сильная лумпируемость отмеченного процесса по данному признаку. Она доказана для фиксированного p и глобальных шагов рождения. Ни геометрическое время, ни физический доступ из a отсюда не следуют.

## 4. Автономный внутренний порядок потомства

Пусть D=C|U_C(a) — индуцированный порядок на U, с отмеченным корнем a. Он замкнут вверх в C. Для x∈D и y∈C\D отношение x≼y невозможно: иначе a≼x≼y и y∈D.

Следовательно, выборы прямых связей с C\D не могут создавать предшественников b внутри D. Вся структура прошлого b, ограниченная D, равна нижнему замыканию A∩D внутри D. Переменные выбора внутри D независимы от всех внешних выборов, которые при маргинализации суммируются в 1.

Полное ядро для D имеет вид:

- D→D с вероятностью q^{|D|}, если A∩D пусто;
- для каждого непустого идеала T⊆D: D→D⊕_T{b} с вероятностью p^{|Max_D(T)|}q^{|D|−|T|}.

Поскольку a — наименьший элемент D, любой непустой идеал T содержит a. Сумма непустых переходов равна 1−q^{|D|}. При переходе к изоморфным отмеченным типам соответствующие вероятности складываются с кратностями.

Таким образом, одинаковые D в любом внешнем окружении имеют один закон дальнейшего внутреннего порядка потомков при фиксированном p. В момент рождения a имеем D={a}, поэтому этот закон одинаков для всех прошлых историй a.

Если убрать шаги, на которых D не меняется, условный закон очередного рождения внутри потомства равен

K_D^+(T)=p^{|Max_D(T)|}q^{|D|−|T|}/(1−q^{|D|}),  T≠∅.

При фиксированном D число глобальных шагов до такого рождения имеет геометрическое распределение с параметром 1−q^{|D|}. Это описание счётчиков модели, не вывод физических часов.

Ограничения: не включены внешние предшественники b и корреляции с внешней областью; D не объявляется доступной записью в a; не доказано то же для общего набора связей t_k в CSG. Данный результат подтверждает особое отсутствие зависимости от прошлого у транзитивной перколяции, отмеченное Соркиным [S2].

## 5. Что даёт профиль ν_C

ν_C(s,m)=#{S∈I(C):|S|=s, |Max(S)|=m}.

Точно:

P_C(|S|=s,m(S)=m)=ν_C(s,m)p^m q^{n−s}.

Это распределение двух признаков, а не автоматически полное ядро дочерних изоморфных типов. Для последнего требуется знать, каким типам соответствуют конкретные S:

K_C([E])=Σ_{S:C⊕_S{b}≅E}p^{m(S)}q^{n−|S|}.

Например, у родителя с a<b и изолированным c идеалы {a} и {c} имеют одну пару (s,m)=(1,1). Первый даёт развилку a<b,d плюс изолированное c; второй даёт две отдельные двухэлементные цепи. Это разные дочерние типы внутри одного класса признаков.

Пример показывает потерю информации при агрегировании переходов. Он сам по себе НЕ является парой разных родителей с одинаковым полным профилем ν. Общая недостаточность ν для полного ядра здесь отдельно не доказана; исправляется именно необоснованное расширение одношаговой теоремы о признаках. Для отмеченной цели профиль без отметки a уже недостаточен: в одной двухэлементной цепи отметки нижнего и верхнего элементов дают W=1−q² и W=p при одном ν.

## 6. Огрубление устойчивого разбиения не обязано быть устойчивым

Рассмотрим переходы x₁→y, x₂→x₂, y→y с вероятностью 1. Разбиение на одноэлементные классы марковски замкнуто. Его огрубление {{x₁,x₂},{y}} не замкнуто: из x₁ вероятность попасть в {y} равна 1, из x₂ — 0.

Поэтому условие «Φ является огрублением эталонного бисимуляционного разбиения» недостаточно. Нужны равные суммы переходных вероятностей по макроклассам для каждой пары микро-состояний из одного класса Φ. Исходные наблюдаемые/метки также должны быть заданы: без них универсальный класс нормированной марковской цепи тривиально стабилен и не означает информативного настоящего.

## 7. Ожидание фронта без симуляции

Пусть w=|Max(C)|. Старый максимальный элемент перестаёт быть максимальным только если выбран напрямую: у него нет старого потомка, через которого мог бы возникнуть путь в b. Эти выборы независимы. Поэтому условно

w'=1+Binomial(w,q).

Отсюда E w_{n+1}=1+q E w_n. При C₀=∅:

E w_n=(1−q^n)/p.

Уже начальная модель объясняет малый средний максимальный слой. Ни ширина всего порядка, ни его размерность, ни корреляция 0.86 из этой формулы не следуют.

## 8. Изменение p по шагам может разрушить ковариантность

Рассмотрим один конечный порядок a<b, c∥a,b. Пусть p₁ действует при добавлении второй вершины, p₂ — третьей; q_i=1−p_i. Вероятности конкретных естественных нумераций:

- порядок рождения a,b,c: p₁ q₂²;
- порядок рождения a,c,b: q₁ p₂ q₂.

При 0<p_i<1 их равенство требует p₁q₂=q₁p₂, то есть p₁=p₂. Это отдельные каналы рождения фиксированного отмеченного порядкового рисунка, а не суммарные вероятности изоморфных дочерних состояний.

Значит, менять независимую вероятность связи на каждом глобальном шаге без дополнительного обоснования нельзя считать той же ковариантной транзитивной перколяцией. Это отличается от последовательности ансамблей: для каждого N один p_N, постоянный во всей генерации данного N-элементного объекта.

## 9. Масштабирование p_N=c log N/N

При c>0:

(p_N^{-1} log(p_N^{-1}))/N → 1/c.

По теореме 1.4 Brightwell–Georgiou при c>1 получается полуупорядочение на [0,1] с отношением x≺y iff y−x>1/c; при 0<c≤1 — антицепной предел. Для фиксированного p>0 отношение стремится к нулю и предел цепной. Речь о сходимости частот конечных индуцированных порядков в указанном первоисточнике, а не о буквальном равенстве конечного каузета цепи.

## 10. Следствие для предложенного разложения дисперсии

В фиксированной транзитивной перколяции W_a=1−q^{u_C(a)}. Поэтому Var(W_a|u_C(a))=0. После фиксации u никакого дополнительного предсказательного вклада прошлых признаков в этот W нет. Корреляции прошлого с W в выборке могут возникать через корреляции прошлого с u.

Если измеряется частота по конечным роллаутам вместо точного W, появится оценочный шум. Если J⁺(a) взято из окончательно сгенерированного графа, оно содержит будущие данные относительно более раннего шага; это отдельная утечка информации. Если J⁺ берётся только внутри текущего C, оно уже сформировано на этом глобальном шаге, хотя лежит в будущем a. Эти смыслы нельзя смешивать и объявлять подтверждением предсказания будущего самим событием.
