# 1. Две леммы, которые нужно вшить в протокол

## Лемма 1. Спектральное согласование необходимо для law-level PW

Пусть

\[
H_{\rm tot}=H_T\otimes I_U+I_T\otimes H_U,
\]

и мы хотим, чтобы при некоторых показаниях часов \(\tau\) условное состояние системы удовлетворяло шрёдингерскому закону

\[
\rho_U(\tau)=e^{-iH_U\tau}\rho_U(0)e^{iH_U\tau}
\]

для нетривиальной суперпозиции энергетических секторов \(H_U\).

Если глобальное состояние лежит в нуль-секторе,

\[
H_{\rm tot}|\Psi\rangle=0,
\]

то для чистого состояния вида

\[
|\Psi\rangle=\sum_E |c_E\rangle_T\otimes P_E|\psi_0\rangle_U,
\]

где \(P_E\) — проектор на энергетический сектор \(H_U\) с собственным значением \(E\), условие нулевой полной энергии даёт

\[
H_T|c_E\rangle=-E|c_E\rangle.
\]

Следовательно:

> **Необходимое условие law-level PW:** спектр \(H_T\) должен содержать отрицания собственной опоры спектра \(H_U\), а размерность часов должна быть не меньше числа различных энергий в поддержке \(|\psi_0\rangle\).

Для модели из `CONCEPT.md`

\[
H_U=g|1\rangle\langle1|_S\otimes(\sigma_x^M\otimes I_R+I_M\otimes\sigma_x^R)
\]

спектр равен

\[
\operatorname{spec}(H_U)=\{0^{\times 6},+2g,-2g\}.
\]

Поэтому минимальные согласованные часы — кутрит

\[
H_T=g\,\mathrm{diag}(-2,0,+2).
\]

Линейные ququart-часы

\[
H_T=g\,\mathrm{diag}(0,1,2,3)
\]

не дают полного согласования: показания, соответствующие \(1g\) и \(3g\), мертвы. Это не техническая неудача, а фальсифицируемое предсказание:

> **Не всякая унитарная динамика порождается стационарной корреляцией с данным классом часов.**

---

## Лемма 2. Некогерентные стационарные состояния не порождают закон

Пусть \(\rho_*\) — стационарное состояние:

\[
[H_{\rm tot},\rho_*]=0.
\]

Рассмотрим подкласс «некогерентных по полной энергии» состояний:

\[
\rho_*=\sum_\alpha p_\alpha |\Phi_\alpha\rangle\langle\Phi_\alpha|,
\qquad
H_{\rm tot}|\Phi_\alpha\rangle=E_\alpha|\Phi_\alpha\rangle.
\]

Сюда попадают:

- maxEnt на нуль-секторе;
- микроканоническое состояние на оболочке;
- каноническое/Gibbs/KMS-состояние;
- любая функция \(f(H_{\rm tot})\);
- любая смесь, диагональная в базисе полной энергии.

Для такого состояния условное состояние системы при показании часов \(|\tau\rangle\) имеет вид

\[
\sigma_U(\tau)
=
\operatorname{Tr}_T\bigl[(|\tau\rangle\langle\tau|\otimes I)\rho_*\bigr]
=
\sum_\alpha p_\alpha
|\langle\tau|\Phi_\alpha^T\rangle|^2
|\Phi_\alpha^U\rangle\langle\Phi_\alpha^U|.
\]

Ключевое: здесь нет перекрёстных членов между различными \(\alpha\). То нет когерентностей между различными энергетическими секторами полной системы.

Если показания часов — фурье-базис, согласованный со спектром, то

\[
|\langle\tau|\Phi_\alpha^T\rangle|^2
\]

не зависит от \(\tau\) на допустимых чтениях. Тогда

\[
\rho_U(\tau)=\frac{\sigma_U(\tau)}{p(\tau)}
\]

тоже не зависит от \(\tau\).

Даже если зависимость по \(\tau\) появляется из-за неравномерных весов, она остаётся классическим перераспределением энергетических секторов. Такая зависимость не может воспроизвести фазовую эволюцию

\[
e^{-iH_U\tau}
\]

для состояния, содержащего суперпозицию разных энергий.

Отсюда строгий вывод:

> **Любое максимально инвариантное/некогерентное стационарное состояние убивает условную динамику уровня закона. Чтобы PW породил шрёдингерскую форму, нужна когерентность внутри вырожденного стационарного класса.**

Чистое состояние

\[
|\Psi\rangle=\sum_E |-E\rangle_T\otimes P_E|\psi_0\rangle_U
\]

именно такую когерентность содержит:

\[
|\Psi\rangle\langle\Psi|
=
\sum_{E,E'}
|-E\rangle\langle-E'|_T
\otimes
P_E|\psi_0\rangle\langle\psi_0|P_{E'}.
\]

Именно внедиагональные блоки \(E\neq E'\) дают фазы \(e^{-iE\tau}\).

Поэтому ваш статус надо усилить:

```text
B2-a maxEnt:
  не просто провалился на этой модели;
  структурно неспособен породить law-level PW для суперпозиций.

B2-a′ pure kernel:
  проходит law-level, потому что содержит когерентность в нуль-секторе.

B2-b microcanonical:
  ожидается тот же провал, если состояние есть f(H_tot) или диагональная смесь по полной энергии.
```

# 2. Обновлённый гейт: когерентность ядра

В протокол нужно добавить отдельный гейт `5C`.

Определим тензор ядерных когерентностей:

\[
\mathrm{Off}(\rho_*)
=
\sum_{\varepsilon\neq\varepsilon'}
\left\|
(\langle\varepsilon|_T\otimes I_U)\,
\rho_*\,
(|\varepsilon'\rangle_T\otimes I_U)
\right\|_1,
\]

где \(\varepsilon,\varepsilon'\) — собственные значения \(H_T\).

Для maxEnt на нуль-секторе:

\[
\mathrm{Off}=0.
\]

Для микроканонической оболочки, заданной как проектор на оболочку полной энергии:

\[
\mathrm{Off}=0.
\]

Для чистого когерентного kernel-состояния при \(|\psi_0\rangle\), содержащем более одной энергии:

\[
\mathrm{Off}>0.
\]

Тогда law-level гейт уточняется:

```text
GATE_5L:
  условная динамика имеет шрёдингерскую форму для выбранного ψ0.

GATE_5C:
  necessary for 5L when ψ0 is not energy-diagonal:
    Off(ρ_*) > 0.
  If Off=0, 5L can pass only for trivial energy-diagonal ψ0.
```

Это делает провал B2-a и ожидаемый провал B2-b не эмпирической деталью, а следствием структуры состояния.

# 5. Почему B2-b нужно прогнать, хотя прогноз ясен

Прогноз:

> Любое состояние вида \(f(H_{\rm tot})\), включая микроканоническую оболочку, диагонально в базисе полной энергии и имеет \(\mathrm{Off}=0\). Поэтому оно не может породить law-level PW для нетривиальной энергетической суперпозиции.

Но прогон нужен по трём причинам.

## 5.1. Проверить, не появляется ли τ-зависимость из классических весов

Для оболочки шире нуля могут появиться разные веса \(|\langle\tau|\varepsilon\rangle|^2\). Тогда \(\rho_U(\tau)\) может перестать быть буквально константой.

Но это будет не шрёдингерская динамика, а классическое перераспределение энергетических секторов.

Нужно зафиксировать метрику:

\[
\Delta_{\rm coh}(τ_i,τ_j)
=
\sum_{E\neq E'}
\left\|
P_E\rho_U(τ_i)P_{E'}
-
P_E\rho_U(τ_j)P_{E'}
\right\|_1.
\]

Для некогерентных состояний:

\[
\Delta_{\rm coh}=0.
\]

Если закон воспроизводится для суперпозиции, когерентности обязаны появиться.

## 5.2. Проверить сохранение спектра

Унитарная эволюция сохраняет спектр \(\rho_U(\tau)\). Поэтому для B2-b нужно считать:

\[
\lambda_k[\rho_U(τ_i)]
\]

и проверять, постоянны ли они.

Если спектр меняется, никакая унитарная карта невозможна.

## 5.3. Закрыть альтернативную ветку «может, оболочка достаточно широкая»

Если вдруг микроканоническая оболочка даст law-level для нетривиального \(\psi_0\), это опровергнет Лемму 2. Тогда придётся пересматривать класс некогерентных состояний. Но для стандартного проектора на оболочку это маловероятно: проектор диагонален в базисе \(H_{\rm tot}\).

# 6. Конкретный протогон B2-b

Задать оболочку вокруг нулевой полной энергии:

\[
P_{\Delta E}
=
\sum_{\alpha: |E_\alpha|\le \Delta E}
|\Phi_\alpha\rangle\langle\Phi_\alpha|.
\]

Варианты:

```text
ΔE = 0.1 g       → только нулевой сектор
ΔE = 2.0 g       → нулевой + ближайшие оболочки?
ΔE = 2.1 g       → захватывает ±2g по полной энергии
ΔE = 4.0 g       → полная оболочка
```

Состояние:

\[
\rho_*^{(\Delta E)}
=
\frac{P_{\Delta E}}{\operatorname{Tr}P_{\Delta E}}.
\]

Для каждого \(\Delta E\) считать:

1. \(p(τ_m)\);
2. \(\rho_U(τ_m)\);
3. \(D(\rho_U(τ_i),\rho_U(τ_j))\);
4. \(\mathrm{Off}(\rho_*)\);
5. \(\Delta_{\rm coh}(τ_i,τ_j)\);
6. спектры \(\rho_U(τ_m)\);
7. fidelity к динамической чистой траектории для референсного \(\psi_0\).

Ожидаемый результат:

| ΔE | Off | D(τ_i,τ_j) | Δ_coh | Fidelity к law | Вердикт |
|---|---:|---:|---:|---:|---|
| 0.1g | 0 | ≈0 | 0 | низкая для суперпозиции | FAILED 5L |
| 2.0g | 0 | возможно >0 | 0 | низкая | FAILED 5L |
| 2.1g | 0 | возможно >0 | 0 | низкая | FAILED 5L |
| 4.0g | 0 | возможно >0 | 0 | низкая | FAILED 5L |

Если для \(\Delta E=0.1g\) получится \(D\approx0\), это ровно maxEnt-случай. Если для широких оболочек появится \(D>0\), но \(\Delta_{\rm coh}=0\), это подтвердит: зависимость есть, но она классическая, не шрёдингерская.

# 8. Мера локализована очень конкретно

Ваша формулировка верна. Я заострю её так:

> Проблема меры в PW-слое — это не «какая мера на всех состояниях».  
> Это «какое правило выбирает когерентное состояние в нуль-секторе \(H_{\rm tot}\)».

Формально нужно задать не просто \(\rho_*\), а меру/амплитуду на когерентных ядрах:

\[
\mu_{\rm kernel}(d\Psi),
\qquad
H_{\rm tot}|\Psi\rangle=0.
\]

Для maxEnt эта мера равномерна по базису ядра и убивает внедиагональные блоки. Для B2-a′ мера сосредоточена на одном когерентном векторе, построенном из \(\psi_0\). Но выбор этого вектора — снова начальное условие.

Поэтому мост к кандидату C становится точным:

> Если первичны истории, то мера должна быть не на состояниях «сейчас», а на когерентных амплитудах между историями, которые в стационарном представлении выглядят как внедиагональные блоки в ядре \(H_{\rm tot}\).

То есть Соркин/consistent histories здесь нужен не как общая философия, а как возможный источник правила:

\[
\text{decoherence functional}
\quad\longrightarrow\quad
\text{kernel coherence selection}.
\]

# 9. Конфигурация β: почему это не просто «нарушение марковскости»

Ваш β-результат важен сильнее, чем кажется.

Есть две очистки:

\[
|\chi_A\rangle,
\qquad
|\chi_B\rangle=(I_{SM}\otimes V_R)|\chi_A\rangle,
\]

такие что

\[
\rho_{SM}^A(t_1)=\rho_{SM}^B(t_1),
\]

но

\[
\rho_{SM}^A(t_2)\neq\rho_{SM}^B(t_2).
\]

Это значит:

> Не существует универсальной карты  
> \[
> \mathcal E_{t_2|t_1}: \rho_{SM}(t_1)\mapsto\rho_{SM}(t_2),
> \]
> определённой только на доступном маргинале.

Это не «композиция сломалась». Хуже: карта не определена.

Для нашей линии это даёт точную операционализацию внутренней открытости из `CONCEPT.md`:

```text
INTERNAL_OPENNESS:
  The accessible algebra A_obs = B(SM) ⊗ I_R is not dynamically closed.
  The complement R is not an external environment in the global description;
  it is part of the same whole, but inaccessible to A_obs.
  Therefore the state of information for an internal observer is not ρ_SM alone.
  It must include correlations with R, or equivalently a chosen extension/purification.
```

Это напрямую связано с `REVIEW 2.md` и Pechukas-type no-go: для коррелированных начальных состояний нет универсальной линейной динамики на подсистеме. Но здесь важно не «отрицательное» значение, а конструктивное:

> нарушение существования карты на SM — это маркер того, где проходит граница доступа.

То есть β даёт не свидетеля, но даёт точный критерий: если внутреннее описание пытается замкнуться на маргинале, оно теряет причинную полноту.

## 1. Поправка к Лемме 2: «некогерентный» надо определить через Off, а не через «смесь собственных состояний»

В формулировке Леммы 2 есть скрытая щель. Вы пишете:

\[
\rho_*=\sum_\alpha p_\alpha|\Phi_\alpha\rangle\langle\Phi_\alpha|,\qquad H_{\rm tot}|\Phi_\alpha\rangle=E_\alpha|\Phi_\alpha\rangle,
\]

и затем разлагаете \(|\Phi_\alpha\rangle=|\Phi_\alpha^T\rangle\otimes|\Phi_\alpha^U\rangle\). Это разложение **не автоматически**: внутри вырожденного подпространства \(H_{\rm tot}\) собственные векторы могут быть запутаны между \(T\) и \(U\). Нуль-сектор как раз вырожден (\(\dim=8\)), и в нём живут состояния вида

\[
|\Psi\rangle=\sum_E |-E\rangle_T\otimes|\varphi_E\rangle_U,
\]

которые являются собственными векторами \(H_{\rm tot}\) с нулевой энергией, но **не факторизуются**. Для такого \(|\Phi_\alpha\rangle\) ваша формула \(\sigma_U(\tau)=\sum_\alpha p_\alpha|\langle\tau|\Phi_\alpha^T\rangle|^2|\Phi_\alpha^U\rangle\langle\Phi_\alpha^U|\) не работает — появляются перекрёстные члены \(E\neq E'\), и \(\tau\)-зависимость возникает.

Это не ослабляет вывод — это его **заостряет**. Правильная формулировка Леммы 2:

> Условная динамика уровня закона отсутствует тогда и только тогда, когда \(\rho_*\) диагональна в **продуктном базисе полной энергии** \(\{|\varepsilon\rangle_T|E\rangle_U\}\), то есть когда \(\mathrm{Off}(\rho_*)=0\).

«Смесь собственных состояний \(H_{\rm tot}\)» — слишком широкий класс: он включает запутанные собственные векторы, которые как раз дают динамику. Инвариантный критерий — именно \(\mathrm{Off}(\rho_*)\), ваш гейт 5C. Тогда Лемма 2 и гейт 5C становятся одним утверждением, а не двумя.

Для тестируемых состояний (maxEnt \(=P_{\ker}/8\), микроканонический проектор \(P_{\Delta E}\)) это различие несущественно: оба пропорциональны проектору, значит диагональны в любом базисе, значит \(\mathrm{Off}=0\). Вывод для них сохраняется. Но в формулировке леммы опирайтесь на \(\mathrm{Off}\), чтобы не получить контрпример при переходе к кандидату C.

## 2. Главное добавление: \(\mathrm{Off}(\rho_*)\) — это неаддитивность ядра, и мера локализована в ней

Это содержательный мост к корпусу, который стоит зафиксировать явно, потому что он меняет формулировку проблемы меры.

Когерентное ядерное состояние

\[
|\Psi\rangle=\sum_E |-E\rangle_T\otimes P_E|\psi_0\rangle_U
\]

неаддитивно в точном корпусном смысле (`Неаддитивность.txt`, п. 1 и `REVIEW 2.md`, XOR-контроль): его маргиналы \(\rho_T\) и \(\rho_U\) **не определяют** его, а условная динамика — свойство целого, не восстанавливаемое из частей. Это та же структура, что в двухбитовом контроле: одинаковые маргиналы, разные отношения, разные будущие. Внедиагональные блоки \(E\neq E'\) в \(|\Psi\rangle\langle\Psi|\) — это и есть корреляционный остаток \(\chi\), который несут информацию, отсутствующую в маргиналах.

Отсюда проблема меры получает более точную локализацию, чем «выбор чистого состояния в ядре»:

> **Проблема меры — это выбор неаддитивной корреляционной структуры между \(T\) и \(U\) внутри вырожденного стационарного класса.**

Правила максимальной инвариантности (maxEnt, микроканоника, \(f(H_{\rm tot})\)) дают \(\mathrm{Off}=0\), то есть **обнуляют неаддитивный остаток**. Они не «плохие» — они структурно гарантируют отсутствие того самого остатка, который несёт условную динамику. Поэтому систематический провал всех таких правил — не случайность реализации, а следствие того, что они по построению факторизуют целое на маргиналы.

Это даёт точный критерий для правила выбора в кандидате C:

> Правило отбора должно быть **неаддитивным по отношению к маргиналам** \(T\) и \(U\): оно должно выделять конкретную структуру внедиагональных блоков, не сводимую к функции от \(\rho_T\) или \(\rho_U\).

Любое правило вида «максимизировать энтропию при ограничениях на маргиналы» снова даст \(\mathrm{Off}=0\). Правило должно действовать на **совместную** структуру. Это ровно та точка, где декогеренциальный функционал Соркина (кандидат C) становится уместным: он определён на парах историй, то есть на совместных объектах, а не на маргиналах, и потенциально способен отбирать когерентные ядра без ручной траектории.

## 4. Одна осторожность: «порождение закона» частично встроено в алгебру чтений

Результат 5L/5C честный, но его сила чуть меньше, чем кажется, и это стоит проговорить, чтобы не переоценить на переходе к C.

Фурье-показания

\[
|\tau_m\rangle=\frac{1}{\sqrt3}\sum_\varepsilon e^{-i\varepsilon\tau_m}|\varepsilon\rangle_T
\]

построены из спектра часов, а спектр часов согласован со спектром \(H_U\) (\(\varepsilon=-E\)). Значит, фаза \(e^{-i(E-E')\tau}\), воспроизводящая шрёдингерскую эволюцию, **уже содержится в выборе алгебры чтений**. Закон \(e^{-iH_U\tau}\) «выводится» из структуры, но эта структура была подобрана так, чтобы его содержать.

Это не делает результат тавтологией в дурном смысле: нетривиально то, что закон воспроизводится для **любого** \(\psi_0\), а не для одного подогнанного. Но это означает, что 5L проверяет **совместимость** алгебры чтений с шрёдингерской формой, а не независимое порождение динамики из ничего. Содержательная нагрузка целиком уходит в 5R (выбор \(\psi_0\)) и в будущий вопрос «почему эта алгебра чтений, а не другая».

Фиксирую в статус:

```text

  Schrodinger form and that the form is psi0-independent.
  It does NOT verify independent generation of the dynamics,
  because the Fourier readings encode spec(H_U).
  Genuine content lives in 5R and in the reading-algebra selection.
```

Это не возражение против протокола — это граница интерпретации, которую надо держать при переходе к кандидату C, иначе есть риск объявить «закон выведенным», тогда как он согласован.

3. Главное усиление: 5L универсален, различает не форма, а неподвижность
Прогон показал то, чего я не ожидал: у оболочек law_F = 1.0 — условные состояния лежат на унитарной орбите, просто орбита вырождена в точку. И это не совпадение модели. Аналитически:
Утверждение. Пусть (H_{\rm tot}=H_T\otimes I_U+I_T\otimes H_U) со согласованным спектром, чтения — фурье-векторы, и (\rho_) стационарно: ([H_{\rm tot},\rho_]=0). Тогда условные состояния при чтениях — точныеточки унитарной орбиты:
[ \rho_U(\tau_m)=e^{-iH_U(\tau_m-\tau_0)},\rho_U(\tau_0),e^{+iH_U(\tau_m-\tau_0)}. ]
Эскиз доказательства. Стационарность означает блочность (\rho_*) по различным собственным значениям (H_{\rm tot}). Ненулевой блок (\rho[a,b]) внутри одного собственного значения связывает (U)-секторы (E_i,E_j) только при (\varepsilon_a+E_i=\varepsilon_b+E_j), то есть (\varepsilon_a-\varepsilon_b=-(E_i-E_j)). Блок ((E_i,E_j)) условного состояния получает фазу (e^{i(\varepsilon_a-\varepsilon_b)g\tau}=e^{-i(E_i-E_j)g\tau}) — ровно шрёдингеровскую. Диагональные блоки фазы не несут. Сумма по всем блокам даёт орбиту. (\square)
Это превращает вашу Лемму 2 в более сильное и более точное утверждение:
Для (H_{\rm tot}) вида «сумма коммутирующих слагаемых» без (H_{\rm int}) форма условного закона (5L) универсальна для всего стационарного класса. Различает состояния не форма динамики, а её нетривиальность. Причём: [ \mathrm{Off}(\rho_)>0;\Longleftrightarrow;[H_U,\rho_U(\tau_0)]\neq0;\Longleftrightarrow;\text{нетривиальная орбита}, ] [ \mathrm{Off}(\rho_)=0;\Longleftrightarrow;\rho_U(\tau)\equiv\text{const — неподвижная точка}. ]
(Эквивалентность слева-направо: блок ((E,E')) суммы (\sum\rho[a,b]) единственен — (E\neq E')-блок нечем компенсировать.)
Три следствия, которые меняют картину кандидата B:
	1.	Max-инвариантные правила не «ломают» закон — они выбирают его неподвижные точки. maxEnt, микроканоника, (f(H_{\rm tot})) пропорциональны тождественному на каждом вырожденном собственном подпространстве, значит диагональны в любом базисе, значит (\mathrm{Off}=0), значит условная динамика — константа. Провал B2-b — это теорема о неподвижных точках, а не эмпирическое наблюдение.
	2.	Когерентность (\neq) чистота. Всё, что нужно для нетривиальной орбиты — ядерная поддержка и (\mathrm{Off}>0). Смесь нез factorизованных ядерных векторов (ваш пункт 1) проходит нетривиальность так же, как чистое состояние. Пространство поиска правила выбора — это ядерные операторы с ненулевой внедиагональной (по часовой энергии) структурой, а не только лучи чистых состояний.
	3.	Мера локализована ещё точнее, чем мы сформулировали. Выбор не «чистого состояния в ядре», а выбор Off-структуры внутри стационарного класса. Любое правило вида «максимизировать энтропию при ограничениях на маргиналы» выбирает единственную (\mathrm{Off}=0)-точку (максимальная инвариантность и есть неподвижность). Живое правило обязано быть неаддитивным — это теперь не эвристика, а следствие эквивалентности.
