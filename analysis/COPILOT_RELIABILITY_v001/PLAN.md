# COPILOT_RELIABILITY_v001 — проверка возможностей устойчивого общения

Дата: 2026-10-30. Запрос пользователя: найти способы стабильного прямого общения ассистента с Copilot, сохранять задания/ответы и восстановление без пользователя-посредника.

Проверяемая текущая реализация: Copilot CLI 1.0.105, сохраненная авторизация; репозиторий на ccdfcdff4b3ea1d81cff2f6fb832665afc7f9a51. Не путать с Copilot cloud agent.
Официальная документация и фактический --help подтверждают --session-id, --resume, --output-format json, --stream, --share, --usage-output-file.

## Живая проба до запуска
Два коротких запроса без инструментов/доступа к репозиторию:
1. Создать собственную UUID-сессию, передать случайную контрольную строку, получить краткое подтверждение. Сохранять JSONL по мере вывода и финальный transcript/usage локально.
2. После нормального завершения первого процесса новым процессом открыть ту же UUID-сессию и попросить вернуть строку без ее повторной передачи.
Критерии: коды завершения 0; явный session UUID; совпадение контрольной строки; поток событий/финальный экспорт сохранены; новые процессы не требуют повторного входа.
Ожидаемое время каждого ответа 20 с, диапазон 5–90 с; источник: предыдущий ping 13.638 с и короткие вопросы 13–15 с. Ориентир не является тайм-аутом.
Это тест продолжения после штатного завершения процесса, НЕ тест выживания при смерти среды ChatGPT/ВМ и НЕ проверка продолжения незавершенного запроса после аварии.
Не читать auth config/токены. Не публиковать gist. Не покупать тариф/кредиты, не назначать облачную задачу. Максимальный кредитный предел CLI сохранен прежним.

## Что выяснить отдельно
- CLI resume сохраняет историю, но не гарантирует продолжение вычисления без живого хоста.
- Cloud agent может работать независимо от клиентского чата; проверить тариф и вид авторизации/API.
- SDK/local server session persistence, stream events и удаленное управление: какие проблемы действительно решают.
- Асинхронный исполнитель на постоянном хосте + журнал заданий + публикация в GitHub: предложение архитектуры, без объявления несуществующей службы развернутой.

Результат: факты, собственная проверка, пределы и минимальное практическое предложение для нашего моста.
