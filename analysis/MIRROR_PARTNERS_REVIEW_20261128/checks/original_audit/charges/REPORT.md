# Проверка зарядов и ориентационных счётчиков в коде Квина

Источник: `upload/Вставленный текст(20261128-114427).txt`, строки 387–480 и 584–634. Самостоятельный replay — `reproduce.py`; полученные целые счётчики и точные рациональные базисы — `results.json`. Исходный корпус не изменён.

## Что он искал

После нахождения зеркала C2′ = M B2, сохраняющего прямой шаг F, Квин искал наблюдаемую, которая различала бы зеркальных партнёров: меняла знак при C2′, но сохранялась бы вдоль движения. Обычные ориентационные счётчики J и M− меняют знак при каждом из двух сомножителей M и B отдельно и поэтому чётны при их произведении. Для обозначения двух партнёрских секторов нужны другие величины. Среди шести ранее установленных зарядов R132 он рассматривает χ = Σ(a1 a2 − b1 b2), затем вычисляет всё пространство общих нечётных комбинаций.

## Что воспроизведено

Для каждой из четырёх ориентаций eps = (++), (+−), (−+), (−−) перебраны все 4368 слова длины 1–3 над 16 метками. Во всех случаях:

- Все шесть зарядов Σ(a1, b1, a2, b2, a1a2, b1b2) сохраняются при F; 0 нарушений.
- χ меняет знак при C2′ и T = I R; 0 нарушений.
- q = Σ(a1 − b1 + a2 − b2) также меняет знак при C2′ и T; 0 нарушений.
- C2′ T сохраняет q и χ; 0 нарушений.

Здесь суммирование по вершинам существенно. M переставляет вершины, поэтому не меняет аддитивный заряд. I сохраняет все шесть зарядов, поэтому действие T на них равно действию R.

## Точные пространства вместо случайного базиса SVD

В порядке плотностей (a1,b1,a2,b2,a1a2,b1b2):

- C2′-нечётные: span{a1−b1, a2−b2, a1a2−b1b2}; размерность 3.
- T-нечётные: span{a1−b2, a2−b1, a1a2−b1b2}; размерность 3.
- Общие нечётные: span{a1−b1+a2−b2, a1a2−b1b2}; размерность **2**.

Следовательно, «единственный общий нечётный заряд» в последней строке вложения — неверная подпись. Сам численный ответ `под обеими: 2` правилен. Напечатанный вектор `[-1,1,-1,1,-0.258,0.258]` — произвольная SVD-смесь двух естественных зарядов, а не новая выделенная физическая величина. Число 0.258 зависит от выбора ортонормированного базиса; научного значения ему этот расчёт не даёт.

### Все шесть зарядов в общем базисе чётностей

Обозначим Ai = Σai, Bi = Σbi, Ni = Ai+Bi, qi = Ai−Bi, KA = Σa1a2, KB = Σb1b2. Тогда точный общий базис имеет вид:

| Заряд | C2′ | T |
|---|---|---|
| N1+N2 | + | + |
| KA+KB | + | + |
| q1+q2 | − | − |
| χ = KA−KB | − | − |
| q1−q2 | − | + |
| N1−N2 | + | − |

Все соотношения проверены точно на 16 локальных метках. Матрица шести комбинаций относительно исходных шести плотностей имеет ранг 6. Таким образом, общий нечётный подпространственный сектор не различает C2′ и T по знаку: оба действия меняют знак одинаково. Но в других зарядах уже имеются противоположные чётности, позволяющие различить эти две операции. Сохранение времени прямого шага и его обращение определяются операторными отношениями с F, а не знаком одного заряда.

Число шесть здесь означает размерность пространства глобальных аддитивных плотностей выбранного класса. Эти величины не являются шестью координатами пространства. Разбиение на три и три нечётных направления для отдельных операций также не задаёт два трёхмерных мира: два трёхмерных подпространства имеют двумерное пересечение, а сам расчёт действует в пространстве наблюдаемых, не строит геометрию пространства-времени.

## Почему упал первый SVD-блок

Q6 имеет размер 16×6: строки — локальные метки, столбцы — шесть плотностей. Требуется решить `(Q6[P] + Q6) c = 0` для шестикомпонентного c. Квин первоначально транспонировал матрицу и получил 6×16. При стандартном `np.linalg.svd` тогда `s.shape=(6,)`, `vh.shape=(16,16)`. Выражение `vh[s<tol]` падает:

`IndexError: boolean index did not match indexed array along axis 0; size of axis is 16 but size of corresponding boolean axis is 6`.

Кроме проблемы индексации, транспонированная задача искала бы коэффициенты по 16 меткам, а не по шести плотностям. Финальный блок исправляет обе проблемы: использует исходную матрицу 16×6 и `full_matrices=False`. Функция `odd_space`, оставленная в первой ячейке, вообще не вызывается.

## Первые проверки J и M− вырождены

Строки 440–458 перебирают 504 бинарных слова, затем заменяют их символы 0→1, 1→2.

1. На любом замкнутом бинарном слове из {1,2} число переходов 1→2 равно числу переходов 2→1: J = N12−N21 тождественно равен нулю. Все 504 J здесь нулевые. Поэтому нулевое число ошибок чётности в этом конкретном переборе не проверяет поведение ненулевого J.
2. `Mminus` ищет 0101 и 1010, хотя ему передают только символы 1 и 2. Оба числа вхождений равны нулю для всех 504 входов. Это отдельная ошибка алфавита.

Алгебраические соотношения J(Mw)=−J(w), J(Bw)=−J(w), J(MBw)=J(w) верны на полном C1-алфавите. Дополнительный невырожденный replay по всем 340 словам длины 1–4 над {0,1,2,3} дал 76 ненулевых J и 0 нарушений. Пример: w=(1,2,0), J=1.

Исправленная ячейка `Mm_mask` в строках 464–479 корректно работает на {0,1}. Воспроизведены 1008 слов длины 4–9, 248 ненулевых M−, 0 нарушений трёх соотношений чётности. Таким образом, Квин сам исправил проблему M−; повторного невырожденного J-перебора в присланном фрагменте нет.

## Проверка imbalance корректна для C1

`count(1) − count(2)` не ломается при появлении меток 0 или 3: для C1 это точно Σ(a−b). У 0 вклад 0−0=0; у 3 вклад 1−1=0. Сохранение верно на полном C1-алфавите. Наш дополнительный перебор 340 слов дал 0 нарушений. Для C2 эта формула по числу меток 1 и 2 уже не представляла бы общий битовый дисбаланс, но Квин применяет её именно в C1-блоке.

Проверка равенства длин на четырёх прямых шагах для 504 пар также воспроизведена с 0 нарушений. Это проверка длины, а не именованного равенства всех состояний: в этой ячейке зеркальному слову заново присваиваются имена.

## Что это означает для стрелы времени

q и χ маркируют сохраняющиеся секторы и различают C2′-партнёров при ненулевом значении. Они не изменяются во времени и потому сами не измеряют рост энтропии, длительность, причинную ориентацию или скорость часов. При ориентациях (+−)/(−+), где T — настоящая инволюция обращения динамики, композиция C2′T обращает F и одновременно сохраняет q и χ. Поэтому даже выбор знаков этих двух зарядов сам по себе не выбирает статистическую стрелу.

Здесь не утверждается, что C2′T сохраняет все шесть зарядов по отдельности: на них она меняет местами каналы a1↔a2, b1↔b2, оставляя две смешанные плотности. Она сохраняет рассматриваемую пару q,χ.
