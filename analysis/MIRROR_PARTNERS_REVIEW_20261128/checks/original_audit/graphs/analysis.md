# Графовые проверки Квина: цель, воспроизведение, границы

Проверен файл `upload/Вставленный текст(20261128-114427).txt`: графовые блоки 108–314 и 481–581. Независимое воспроизведение: `verify_graphs.py`; полные числа: `results.json`. Исходный корпус не изменён.

## 1. Что хотел выяснить

Квин превратил идею «6+1 похоже на 3+1+3» в несколько различимых вопросов:

1. Дают ли семь вершин сами по себе одну нулевую моду и три пары ±E?
2. Есть ли реальное отражение, обменивающее две тройки вершин и сохраняющее единственный центр?
3. Совпадает ли центральная вершина с нулевой модой; имеет ли мода определённую зеркальную чётность?
4. Сохраняет ли отражение сам оператор с Wilson-швом или только его спектр?

Для этого сопоставлены три разные матрицы смежности размера 7, а не три перенумерации одного графа.

## 2. Три графа: результаты подтверждены

| Граф | Пространственные орбиты выбранного отражения | Размеры ±-секторов R | Нулевая мода | Её R-чётность | Вес на указанном центре/порту |
|---|---|---:|---:|---:|---:|
| Бензил C6+лист | 3 фиксированные вершины и 2 пары | 5 / 2 | 1 | +1 | 4/7 |
| Две ветви P3 с общим центром, то есть P7 | 1 фиксированная вершина и 3 пары | 4 / 3 | 1 | −1 | 0 |
| Два треугольника, каждый связан с общим центром | 1 фиксированная вершина и 3 пары | 4 / 3 | 0 | — | — |

Во всех трёх случаях заданное отражение действительно является инволюцией и коммутирует с вещественной матрицей смежности; численные остатки равны 0.

Точные характеристические многочлены:

- Бензил: λ(λ−1)(λ+1)(λ⁴−6λ²+7).
- P7: λ(λ²−2)(λ⁴−4λ²+2).
- Два треугольника: (λ−2)(λ+1)³(λ³−λ²−4λ+2).

Спектры совпали с вложением. У бензила ±√(3+√2), ±√(3−√2), ±1,0. У P7 — 2cos(kπ/8), k=1,…,7. У двух треугольников нуля нет, спектр не симметричен относительно 0.

Вывод: пространственное разбиение на две тройки с общей вершиной, хиральные пары ±E и центральная нулевая мода — разные свойства. P7 имеет буквальные зеркальные тройки, но его нулевая мода не имеет амплитуды на центральной вершине. Бензильный порт несёт 4/7 нормы нулевой моды, однако геометрическое отражение не имеет орбит «один центр плюс три пары».

Метка `center` просто выбирает вершину для чтения веса. Код не задаёт физические часы, наблюдателя, энтропию или направление термодинамической стрелы.

## 3. Автоморфизмы бензила

Получены ровно две перестановки: identity и (0,5,4,3,2,1,6). Этот результат воспроизведён полным перебором 7! перестановок.

Но строка `exchange=[p for p in autos if set(p[i] for i in A)==B]` сравнивает образ множества из 3 вершин с множеством из 4. Равенство невозможно уже по мощности. ## 4. Ошибка порядка базиса: исправлена Квином правильно

Q имеет строки (0,2,4) и столбцы (1,3,5,6). Вектор `np.r_[zeros(3),b]` записан в порядке (0,2,4,1,3,5,6), но `refl=[0,5,4,3,2,1,6]` действует в порядке физических вершин (0,1,2,3,4,5,6).

Из смешения получаются фиктивные «чётности» 5/7,3/5,1/3. При φ=0 такой неправильно расположенный вектор вообще не лежит в ядре H: ||Hψ||₂=1.0690449676496974.

Корректно `psi[[1,3,5,6]]=b`, то есть

ψ₀(φ)=(0,1,0,−1,0,1,−(1+e^(−iφ)))/sqrt(5+2cosφ).

Он имеет Hψ=0, Rψ=ψ и портовый вес (2+2cosφ)/(5+2cosφ). Все эти равенства подтверждены. Именно этот вектор уже дан в первичном R149 REPORT.md, строки 90–114.

## 5. Осталась важная ошибка интерпретации при φ≠0

Rψ₀=ψ₀ не означает RH(φ)R=H(φ). Для конкретного seam-базиса Квина

||RH(φ)R−H(φ)||₂ = 2sqrt(2)|sin(φ/2)|.

При φ=.9 это 1.2302683150099178. При φ=π/2 — 2, при φ=π — 2sqrt(2). Нулевая мода случайно остаётся R-чётной в данном представлении, хотя весь оператор не имеет этой простой перестановочной симметрии.

Спектры RH(φ)Rᵀ и H(−φ) всё равно равны. Первое всегда изоспектрально H(φ) для любой унитарной R; второе равно H(φ)* и имеет тот же вещественный спектр. Поэтому спектральный тест Квина не проверяет, корректно ли выбрано пространственное зеркало.

## 6. Точная операторная формулировка со швом и калибровкой

Пусть H_{φ,s} имеет фазу exp(iφ) в элементе (s,s+1 mod6) и сопряжённую фазу обратно, а порт (0,6) вещественен. Код использует s=5. Тогда точно:

R H_{φ,5} R = H_{−φ,0},
H_{φ,5}* = H_{−φ,5}.

Определим G±=diag(1,e^(±iφ),e^(±iφ),e^(±iφ),e^(±iφ),e^(±iφ),1). Тогда

G− R H_{φ,5} R G−† = H_{−φ,5}.

Для антиунитарного Θφ = G+ R K, где K — комплексное сопряжение,

Θφ H_{φ,5} Θφ⁻¹ = H_{φ,5},
Θφ²=1.

Остатки на проверенных фазах не превышают 2.1e−16. Голое RK без G+ в том же фиксированном seam-базисе не является симметрией; при φ=.9 его остаток тоже 1.2302683150099178.

Поскольку Θ антиунитарно, Θ exp(−iHt) Θ⁻¹=exp(+iHt). Это отношение к обращению параметра времени. При φ=0 обычная унитарная R, напротив, коммутирует с exp(−iHt). Ни одно из равенств само по себе не выводит термодинамическую стрелу.
