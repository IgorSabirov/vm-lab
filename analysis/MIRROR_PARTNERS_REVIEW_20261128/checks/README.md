# Сохранённые проверки разбора зеркальности

Этот каталог переносит ранее выполненные проверки и их результаты. При
упаковке научные расчёты **не запускались повторно**. Индекс прежних результатов
и границ их происхождения — [RESULTS.json](RESULTS.json).

## Состав

- `original_audit/` — прежний переносимый пакет аудита кода Квина, включая
  исходный текст, четыре исходных отчёта корпуса, проверочные программы,
  сохранённые `stdout`/`stderr`, окружение, манифест и `run_receipt.json`.
- `followup/algebra/` — последующая проверка утверждений о зеркальных
  преобразованиях и самозеркальности.
- `followup/graphs/` — последующая проверка условной графовой леммы и
  контрпримеров к её неограниченной формулировке.
- `followup/corpus/REPORT.md` — сопоставление с первичными текстами корпуса;
  это чтение и аналитическое сопоставление, отдельного численного запуска нет.
- `PACKAGING.json` — изменения при переносе и проверка синтаксиса, без
  объявления нового научного прогона.

## Повторить проверки

Из корня репозитория, в подготовленном Python-окружении:

```bash
python -m pip install -r analysis/MIRROR_PARTNERS_REVIEW_20261128/checks/original_audit/requirements.txt
python analysis/MIRROR_PARTNERS_REVIEW_20261128/checks/run_all.py
```

Можно указать новый каталог результатов:

```bash
python analysis/MIRROR_PARTNERS_REVIEW_20261128/checks/run_all.py --output /tmp/mirror-review-reproduction
```

Каталог `--output` должен отсутствовать до запуска. Без него создаётся уникальный
каталог в `checks/runs/`. Программы выполняются в отдельной копии; сохранённые
исторические результаты и квитанция в этом каталоге остаются неизменными.
Новая копия получает собственные журналы и `RUN_RECEIPT.json`.

Порядок: прежний `original_audit/run_all.py`, затем `followup/algebra/check.py`
и `followup/graphs/verify.py`. Первый скрипт воспроизводит в том числе ошибки
исходных ячеек Квина; перехваченная ожидаемая ошибка исходной ячейки не означает
сбой самого проверочного скрипта. Сведения об этих случаях сохранены в
`original_audit/original_cells_replay.json` и объяснены в прежнем README.

Для переносимости изменена одна строка в `followup/algebra/check.py`:
локальный абсолютный адрес `source_engine.py` заменён адресом относительно
расположения скрипта. Содержимое движка совпадает с использованным ранее.
Остальные скопированные программы, результаты, тексты и журналы сохранены
побайтово. Новая оболочка запуска при упаковке проверена только на синтаксис.

Исторические записки сохранены без исправления прежних формулировок. Актуальная поправка атрибуции R052/R053 и итоговая оценка находятся в [основном отчёте](../REPORT.md#internal-detection).

Обозначения «первый» и «второй» текст в исторических записках `followup/algebra/REPORT.md` и `followup/graphs/NOTE.md` местами не совпадают с окончательной нумерацией вложений. Таблица с ошибочным обращением полного шага операциями M/B находится в `sources/quinn_review_2.txt`, а расширенный запрет индекса 1 — в `sources/quinn_review_1.txt`. При идентификации источников следует использовать `sources/MANIFEST.json` и нумерацию основного отчёта.
