## Одна петля и три показания

Пусть $U_0,\dots,U_{n-1}\in SU(3)$ — упорядоченные звенья замкнутого контура, $n\ge3$, $H=U_0\cdots U_{n-1}$, $T=\operatorname{Tr}H$. При смене реперов $U_i\mapsto G_iU_iG_{i+1}^{-1}$ произведение меняется сопряжением. Конфигурационное значение фундаментальной петли Вильсона равно $W=T/3$. Для решёточной петли с обратным звеном используют обратную матрицу. В R140/H6 сама подстановка относительного переноса в пространственный контур по-прежнему является выбором приготовления. [Вильсон, 1974](https://doi.org/10.1103/PhysRevD.10.2445).

Ставим на одно ребро дополнительный центральный множитель $z_j=\exp(2\pi i j/3)$ и измеряем $D_j=\det(I+B_jB_j^*)$ на целом кольце, где $B_j=S_{z_jH}-I$ после переноса звеньев к шву. Пусть $\varphi=(1+\sqrt5)/2$, $u=\varphi^{-2n}$, $L_k$ — числа Люка, $C=L_{2n}=u+u^{-1}$, $A=L_{4n}-L_{2n}=(C-2)(C+1)$. Из формулы шва, для всякого $|z|=1$,

$$D(z)=u^{-3}\left|\det(I-uzH)\right|^2,\qquad \det(I-uzH)=1-uzT+u^2z^2\bar T-u^3z^3.$$

Последний коэффициент и сопряжение у второго коэффициента используют $\det H=1$ и унитарность. Складывая коэффициенты степеней $z$ с равными остатками по модулю 3, получаем два точных тождества

$$M=\frac{D_0+D_1+D_2}{3}=L_{6n}+C|T|^2-2,\qquad Y=\frac{1}{3}\sum_{j=0}^2 \bar z_jD_j=-A T-\bar T^2.$$

Отсюда $\chi_{\rm adj}(H)=|T|^2-1=(M-L_{6n}+2)/C-1$ в силу $3\otimes\bar3=1\oplus8$. Для нормированной присоединённой петли делим на 8. Для фундаментальной решаем второе уравнение на диске $|T|\le3$. Если $T,S$ лежат в этом диске, то $|Y(T)-Y(S)|\ge(A-6)|T-S|$. При $n=3$ уже $A=304$, далее $A$ растёт. Единственность доказана. Явный алгоритм начинает с нуля и повторяет проекцию $-(Y+\bar T^2)/A$ на диск радиуса 3. Константа сжатия не больше $6/A$, а истинный след — неподвижная точка. Характеристический полином $\lambda^3-T\lambda^2+\bar T\lambda-1$ восстанавливает три собственных значения с кратностями. Для унитарной матрицы этого достаточно, чтобы определить класс сопряжённости.

| $H$, длина 6 | $D_0$ | $D_1$ | $D_2$ | $W$ |
|---|---:|---:|---:|---|
| $I$ | 32 768 000 | 33 698 267 | 33 698 267 | $1$ |
| $\omega I$ | 33 698 267 | 33 698 267 | 32 768 000 | $\omega$ |
| $\omega^2 I$ | 33 698 267 | 32 768 000 | 33 698 267 | $\omega^2$ |
| Циклическая перестановка $M_3$ | 33 385 280 | 33 385 280 | 33 385 280 | $0$ |

У двух центральных матриц исходное показание одинаково, а порядок трёх показаний различает ориентацию. У перестановки с нулевым следом показания совпадают даже на целом кольце. После выключения одной вершины все четыре строки дают один и тот же ответ $89^3$ во всех столбцах. Более общая маска с разрезом даёт $Z(w)^3$ независимо от $H$. Поэтому обращать измерение можно только при известном замыкании. При использовании одного размера кольца для усреднения по физическим конфигурациям надо сначала восстановить $T$ в каждой из них. Восстановление по среднему $Y$ зависело бы также от $\langle\bar T^2\rangle$. Есть и линейный способ для ансамбля. В том же измерительном кольце заменим одно звено $U$ двумя $V,V^{-1}U$, сохранив ровно то же $H$. Тогда при $A_n=L_{4n}-L_{2n}$ имеем $T=(Y_n-Y_{n+1})/(A_{n+1}-A_n)$. Квадратичная часть сократилась. Формула переносится на средние по одному ансамблю при таком разделении каждого исходного звена. У физического контура и масштаба решётки ничего менять не требуется.

## Фибоначчи, характер SU(2) и дзета Римана

Это второй маршрут. Индекс $\ell$ нумерует симметрические степени двумерного представления, а $U_\ell$ в этой формуле — полином Чебышёва второго рода. Характер $\chi_\ell(g)=U_\ell(\operatorname{Tr}g/2)$ на $SU(2)$ продолжим как полином на $SL_2(\mathbb C)$. При $g=I$ имеем $\chi_\ell(I)=\ell+1$. При $g=\operatorname{diag}(\varphi^2,\varphi^{-2})$ имеем $\operatorname{Tr}g=3$. Рекурсия с начальными значениями $D_0=1,D_1=2$ даёт

$$D_\ell(1)=U_\ell(3/2)-U_{\ell-1}(3/2)=F_{2\ell+1},\qquad U_{-1}=0.$$

Таким образом определитель открытой серии в R149 есть разность двух соседних характеров в гиперболической точке. Эту точку реализует и матрица переноса R141 со следом 3. Она лежит вне компактной группы $SU(2)$, где след вещественен и по модулю не превосходит 2. [Формула характера, приложение E, (E.3)](https://www.lpthe.jussieu.fr/~zuber/Cours/InvariancesGroupTheory-2014.pdf).

Для **другой** операции с тем же семейством берём размерности при единице. Дзета представлений $SU(2)$ есть $\sum_{\ell\ge0}\chi_\ell(I)^{-s}=\zeta(s)$ при $\Re s>1$ и совпадает с ней при мероморфном продолжении. В двумерной чистой теории Янга–Миллса при стандартной нормировке теплового ядра на замкнутой ориентированной поверхности рода $g\ge2$ предел статсуммы при площади, стремящейся к нулю, равен $\zeta(2g-2)$. Род 2 даёт $\pi^2/6$, род 3 — $\pi^4/90$. В этих физических пределах аргумент принимает положительные чётные значения. У $SU(3)$ размерности равны $ab(a+b)/2$, $a,b\ge1$. Сумма по ним даёт собственную дзета-функцию Виттена $2^s\sum_{a,b\ge1}[ab(a+b)]^{-s}$ в области абсолютной сходимости. [Виттен, 1991](https://doi.org/10.1007/BF02100009) · [Двумерная формула, (5.36)](https://doi.org/10.1007/s00220-020-03902-1) · [Тип A₂](https://www.kurims.kyoto-u.ac.jp/~kyodo/kokyuroku/contents/pdf/1665-15.pdf).

## Какие дзета-функции читает само кольцо

У графа-цикла есть два ориентированных примитивных обхода без возврата по только что пройденному ребру. Для скрученной дзеты Ихары отсюда $Z_{C_n,H}(v)^{-1}=\det(I-v^nH)\det(I-v^nH^{-1})$. В точке $v=\varphi^{-2}$ это ровно $u^3D(1)$ для трёх каналов. Логарифм даёт проверяемое разложение $\log(u^3 D(1))=-2\sum_{k\ge1}u^k\Re\operatorname{Tr}(H^k)/k$. Каждое слагаемое читает $k$ обходов того же контура. После разреза активный граф становится лесом, его произведение Ихары пусто и равно 1. У открытого оператора R149 при этом остаётся граничный множитель Фибоначчи. [Определение скрученной дзеты Ихары, §6](https://www.kurims.kyoto-u.ac.jp/~kyodo/kokyuroku/contents/pdf/0820-01.pdf).

В модулярной задаче R149.10 коэффициент рассеяния $\Phi(s)=\Lambda(2s-1)/\Lambda(2s)$ даёт для нетривиального нуля Римана $\rho$ резонанс при $s=\rho/2$, где $\Lambda(s)=\pi^{-s/2}\Gamma(s/2)\zeta(s)$. Отдельная классическая связь с Фибоначчи следует из длины примитивной геодезической матрицы следа 3, $\ell_0=4\log\varphi$. Поэтому число $u=\exp(-n\ell_0/2)$ из нашего измерения совпадает с весом этой геодезической в первом множителе произведения Сельберга при $s=n/2$. Этот фактор относится к одной геодезической. Для полного рассеяния нужны вся модулярная поверхность и её касп. [Геодезическая в корпусе](../../R149_DEFECT_ATLAS/REPORT.md) · [Произведение Сельберга, (4.1)](https://ems.press/content/serial-article-files/43056) · [Модулярное рассеяние](https://math.dartmouth.edu/~specgeom/Borthwick_slides.pdf).
