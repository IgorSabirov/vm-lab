## Проверенные числа и остающиеся вопросы

В этой сверке заново исполнены три восстановленных фрагмента, сравнены метки независимых шагов с R130, проверена смена фазы в трёхузловом примере и запущен [арифметический пересчёт BBN](../../NEIGHBOR_EXTERNAL_DATA_USE_20261119/bbn_transfer_controls.py). Для четырёх производных он даёт 0,8715%, 2,8337%, 0,4266% и 16,9325%. В двух линейных историях при одинаковом сдвиге гелия +0,132% сдвиги D/H равны +0,072% и +0,880%. Для тепловых фотонов контроль даёт η′/η = 0,97101289. Различие двух вариантов нейтринного спектра даёт ΔYp = 0,00008.

Для S3 открыты сопоставление фактических профилей скоростей и запуск двух решателей на одном физическом входе. Для BH1 нужны носитель энергии и общий энергобаланс. Для R133 открыты T3/T4 и физическое время, для R134 — вывод смешанных вычетов и космологического источника из амплитуд. Ранее сохранённые численные проверки и аналитические доказательства остальных строк сверены по артефактам. Сессия аудита не добавляет сквозной расчёт космологической модели.

В ходе этой сверки [тест контракта](../../PRIMAT_LINX_BBN_BRIDGE_20261117/test_validate_contract.py) с NaN на исходной версии завершился ещё при подготовке примера. После исправления теста проверяется ошибка самого валидатора для H_s_inv[1]. Также уточнён [путь проверки реестров в CI](../../../infra/REGISTRY_MAINTENANCE.md): действующий маршрут — Development checks → integrity.
