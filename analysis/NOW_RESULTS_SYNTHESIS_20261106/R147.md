#### Клиффорд и рассеяние · общая модель

В исходном случае <code>S₃ = [[−2, 1], [1, 2]]</code>. После положительного дополнения $I_2$ получаем сигнатуру $(3,1)$ и центр чётной алгебры Клиффорда $\mathbb Q(\sqrt{-5})$. Для полной группы Бьянки $\mathrm{PSL}_2(\mathcal O_{K^-})$ классовые характеры дают два канала. При $w=1+2i$ их фазы равны +2,9546326624 и −0,6525249472 радиана. Повторены тета-суммы решёток и независимое вычисление отношений завершённых функций Дирихле. Решение исходной геометрической краевой задачи без подстановки формулы рассеяния остаётся открытым.

Что меняет $q=4$. Примитивная форма <code>S₄ = [[−2, 1], [1, 1]]</code> имеет определитель −3. С тем же дополнением центр становится $\mathbb Q(\sqrt{-3})$. Приведённые положительные формы дискриминанта −20 представлены $(1,0,5),(2,2,3)$, а дискриминанта −3 — единственной $(1,1,1)$. Для полной группы Бьянки число каспов равно числу классов. Значит, у нового полного аналога один касп и один скалярный канал постоянных по сечению функций. Это определяет размер матрицы такого рассеяния; амплитуда при $q=4$ в этой сборке не вычислялась. Определитель бинарной формы зависит от масштаба квадратом, а изменение положительного дополнения может сменить поле. Для подгруппы число каспов может увеличиться. Теорема 2.6 о каспах · поле дискриминанта −3.

**Какой вход проверен для двух каналов**

Разность коэффициентов двух форм дискриминанта −20 проверяет арифметический вход нетривиального классового характера для группы Бьянки. При n ≤ 1000 согласовались все коэффициенты. Для фазы рассеяния требуется ещё нормировка непрерывного спектра и решение краевой задачи. Статус этого геометрического шага остаётся открытым. Формы, знаки и определение коэффициента.
