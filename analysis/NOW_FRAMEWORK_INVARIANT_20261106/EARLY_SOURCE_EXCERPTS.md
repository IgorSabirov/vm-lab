 Режим --skip-numerics может вернуть общий pass при пропущенных численных проверках. В данном запуске проверки не пропускались.
 При отсутствии SciPy биномиальная функция для 0 < k < n использует приближение, а не точную границу Clopper–Pearson. В данном окружении SciPy доступен; ветка k = 0 точна и без него.
