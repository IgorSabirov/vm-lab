# S5 — Record leakage: ослабленная операциональная постановка

**Статус: РЕШЕНО (с допущениями, см. §8).** Достаточные условия (i)+(ii)+(iii)
сформулированы и доказаны на информационном ярусе [T1]; ресурсный ярус с явным
T_rec дан в [T2] и содержит единственную гипотезу [H1]. Оба яруса проверены
численно на малой модели [C1]; контрпримеры [C-ex] показывают, что каждое
условие несущее. Позитивность Lindblad нигде не используется как аргумент.

---

## 1. Архитектура и определения [Def]

**[Def 1] (Модель уровней).** Гильбертовое пространство
`H = H_V ⊗ H_M1 ⊗ H_C2` (+ окружение `E`, недоступное всегда).
V — система (d_V = 2), M₁ — память уровня 1, C₂ — континуум уровня 2 с двумя
направленными секторами `C₂ = C₂⁺ ⊕ C₂⁻` и стоками в E (rate κ). В идеализации
C₂ — континуум; в вычислениях — усечение (по 1 моде на сектор, d=2).

**[Def 2] (Ориентация, ветви, история).** Ориентация `h ∈ {±1}` — собственное
значение σ_z^V. Запись — CPTP-эволюция `E_T` (Lindblad + изометрия записи на
t=0), дающая ветви `ρ_h(T) = E_T(|h⟩⟨h|_V ⊗ |0⟩⟨0|_M1 ⊗ |vac⟩⟨vac|_C2)`.
«История» — произвольное входное состояние V, включая когерентный пробник:
половина |Φ⟩_{RV} (максимально запутанное с эталоном R). Восстановить историю =
вернуть входной канал на V, а не один фиксированный вектор (иначе константный
канал тривиально «восстанавливает» известное чистое состояние — ложная метрика).

**[Def 3] (A_obs — явно).**
`A_obs := { A ⊗ I_C2 : A ∈ B(H_V ⊗ H_M1) } ≅ B(H_V ⊗ H_M1)`.
Операционно: разрешены (а) POVM с элементами `{E_a ⊗ I_C2}`; (б) любые каналы
на V⊗M₁; (в) эволюции под H ∈ A_obs^sa, ‖H‖ ≤ J. Запрещено: наблюдаемые,
содержащие микросостояние C₂ (популяции/когерентности секторов R±, их моды и
фазы). Расширенный вариант для контрпримеров и яруса [T2]:
`A_obs^band = A_obs ⊕ A_band`, где `A_band = span{Π_b}` — коммутативная алгебра
грубых энергетических полос C₂. В картине состояний ограничение доступа —
проекция `π(ρ) := Tr_C2 ρ` (пинчинг/условное ожидание на A_obs; в терминах
Buscemi et al., arXiv:2504.12738 — M_P, а A_obs — алгебра неподвижных точек
MPPP).

**[Def 4] (ε_rec — явно).** Два зафиксированных варианта (основной — (а)):
(а) *когерентный*: восстановление с точностью ε_rec ⟺
`F_e(R ∘ π ∘ E_T, id_V) ≥ 1 − ε_rec`, где
`F_e = ⟨Φ| (id_R ⊗ R∘π∘E_T)(|Φ⟩⟨Φ|) |Φ⟩` — энтанглмент-фиделити;
(б) *битовый*: ошибка различения ветвей `p_err ≤ ε_rec` (Хелстром по данным
A_obs). Пороговое значение по умолчанию: **ε_rec = 1/2** (т.е. требуем
F_e ≥ 1/2 при базовой линии угадывания F_e = 1/d_V² = 1/4, p_succ = 1/2).

**[Def 5] (T_rec и класс ℛ — явно).** `ℛ(T_rec)` = все каналы
`R : B(H_V⊗H_M1) → B(H_V)`, реализуемые композицией (а) инструментов с POVM из
A_obs, (б) эволюций exp(−iHt) с H ∈ A_obs^sa, ‖H‖ ≤ J, суммарным временем
≤ T_rec, (в) фиксированных ансилл, трассируемых в конце. Ключевое свойство:
**каждый R ∈ ℛ факторизуется через π** (видит только πρ). Ярус [T1] от T_rec не
зависит (информационный no-go); T_rec входит только в ярусе [T2].

**[Def 6] (R_ε — выбор зафиксирован).**
`R_ε(T_rec) := max_{R ∈ ℛ(T_rec)} F_e(R ∘ π ∘ E_T)`.
Восстановление невозможно с точностью ε_rec за время T_rec ⟺
`R_ε(T_rec) < 1 − ε_rec`. (Эквивалентные квалификации через fidelity-of-recovery
SDP и Хелстрома — см. §7.)

## 3. Теорема [T1] — достаточные условия (информационный ярус)

Пусть `E_acc := π ∘ E_T : B(H_V) → B(H_V⊗H_M1)` — редуцированный канал,
`σ̄ := E_acc(I_V/2)`, `E₀(X) := Tr(X)·σ̄` (константный канал).

**Условия.**
- **(C1) запись в C₂** [условие (i) постановки]: на окне `[T_*, T_* + T_rec]`
  `r(T) := ½‖Tr_VM1(ρ₊(T) − ρ₋(T))‖₁ ≥ r₀ > 0` — ориентация коррелирует с
  внутренними степенями свободы C₂ (микросостояния секторов различимы).
- **(C2) доступная слепота** [условие (ii)]: `η_tot := max_{i,j∈{0,1}}
  ½‖(E_acc − E₀)(|i⟩⟨j|)‖₁ ≤ η` на том же окне (при η = 0 — точная независимость
  доступных данных от истории, включая когерентности).
- **(C3) факторизация** [условие (ii), архитектурная часть]: каждый
  R ∈ ℛ(T_rec) факторизуется через π (Def 5).

**Утверждение.** При (C1)–(C3) для всех T_rec и всех R ∈ ℛ(T_rec):
```
R_ε(T_rec) ≤ 1/d_V² + 2 η_tot ,        p_succ(h) ≤ 1/2 + η_diag/2,
```
где η_diag = ½‖πρ₊ − πρ₋‖₁ ≤ 2η_tot. Следствие [условие (iii)]: если
`ε_rec < 1 − 1/d_V² − 2η_tot`, то восстановление истории невозможно; если
`ε_rec < 1/2 − η_diag/2`, невозможно восстановить даже бит h. При η_tot = 0
no-go **точный и не зависящий от T_rec и от ресурсов ℛ**.

**Доказательство.** Битовая часть — Хелстром + контрактивность: любой R ∈ ℛ
видит только πρ₊, πρ₋ (C3), значит `p_succ = ½(1 + ½‖πρ₊ − πρ₋‖₁)`. Когерентная
часть: для любого канала R
`F_e(R∘E_acc) = (1/d_V²) Σ_{ij} ⟨i| R(E_acc(|i⟩⟨j|)) |j⟩`.
Для константного E₀: `F_e(R∘E₀) = (1/d_V²) Σ_i ⟨i|R(σ̄)|i⟩ = Tr R(σ̄)/d_V² = 1/d_V²`.
Далее, по контрактивности ‖R(Y)‖₁ ≤ ‖Y‖₁ и |⟨i|X|j⟩| ≤ ‖X‖₁:
`|F_e(R∘E_acc) − F_e(R∘E₀)| ≤ (1/d_V²) Σ_{ij} ‖(E_acc−E₀)(|i⟩⟨j|)‖₁ ≤ 2η_tot`. ∎

**Замечания.** (1) Условия сформулированы только через редуцированный канал
E_acc: позитивность Lindblad полной динамики не используется. Тем самым снят
явный caveat постановки: «позитивность ≠ невозможность восстановления» — наш
no-go следует из *факторизации доступа*, а не из CP-свойств. (2) Информация
действительно уходит в C₂ и E (C1 гарантирует, что запись физически существует);
невозможность — относительно ℛ. (3) Junge/Kwon–Kim консистентны: при
δ_P ≫ 0 нижняя граница F ≥ e^{−δ_P/2} вырождается, обещаний восстановимости нет.

## 4. [T2] — ресурсный ярус с явным T_rec (содержит [H1], [H2])

Если доступ расширен до `A_obs^band` (грубые полосы C₂ доступны), (C2) падает и
восстановление становится возможным, **но только до тех пор, пока запись не
скремблирована внутри C₂ и не слита стоками в E**. В малой модели (A):
`F_e^full(T)` спадает от 1 экспоненциально с эффективным rate `γ_eff ≈ κ + γ_d`
(сток + внутренняя дефазировка C₂).

**[T2] (формулировка).** Пусть выполнены (C1), (C3) относительно A_obs, но
доступ — A_obs^band. Тогда восстановление с точностью ε_rec невозможно за
`T_rec < T(ε_rec)`, где `T(ε) = γ_eff⁻¹ · ln((F_e^full(0) − 1/d_V²)/(1 − ε − 1/d_V²))`
(для модели A: `T(ε) = (κ+γ_d)⁻¹ ln(0.75/(0.75−ε))`); и невозможно вовсе при
`T > T_drain ≈ γ_eff⁻¹ ln(1/ε)` — порог типа PIR (arXiv:2603.22284).

- **[H1]** (допущение-гипотеза): форма `T(ε) ≍ γ_eff⁻¹ log(1/ε)` переносится из
  PIR (единственный источник с явным T_rec) на нашу архитектуру; в малой модели
  подтверждена численно ([C1], модель A), общий вывод — открыт (§9).
- **[H2]**: количественный штраф доступа (Churilov 2608.05753) как множитель в
  T(ε) при промежуточных A_obs — не вычислен, качественно: рост C_rec по Gu
  (≥ log(1/ε) + log log(1/ε)) означает, что объективная (восстановимая) запись
  требует доступа к числу независимых копий/полос, растущему с точностью.

**Итоговая форма достаточных условий:**
`операционная необратимость ⟺ (C1) ∧ (C2) ∧ [ (C3)  или  (T_rec < T(ε_rec)) по [T2]/[H1] ]`.

## 5. Контрпримеры [C-ex] — условия несущи

- **[C-ex-i] (запись не слита из M₁).** Если сток уровня 2 не сбрасывает M₁
  (gm → 0 в модели B), то h ∈ A_obs: p_succ → 1, no-go ложен. Условие (C2)
  несуще: «запись где-то есть» ≠ «запись недоступна».
- **[C-ex-ii] (обратимость на подпространстве).** Модель A при t = 0:
  `F_e^full = 1.0000` — с доступом к C₂ восстановление точное, хотя динамика
  стоков Lindblad-позитивна на всём протяжении. Позитивность не решает ничего.
- **[C-ex-iii] (нет стоков/дефазировки, полный доступ).** κ = γ_d = 0, доступ к
  C₂: δ_P = 0 и Petz восстанавливает точно (Buscemi). Существование стоков и
  скремблирования несуще для временной части [T2].
- **[C-ex-iv] (ложная метрика).** Fidelity к одному фиксированному чистому
  |ψ⟩ даёт F = 1 константным каналом — поэтому ε_rec задан через F_e
  (ансамбль/когерентность), см. Def 2, Def 4.

Fail-state валиден: если (C2) нарушено (η_tot велико), [T1] молчит, и
восстановление действительно возможно (модель B при малых t — Fe_acc до 1).

## 6. Связь с триадой: где сидит [H]

Цепочка триады:
```
различие направлений (Хелстром на h±; Misumi Im-псевдоэнтропия)
  → запись (C1): r(T) ≥ r₀
  → ограниченный доступ (C2)+(C3): A_obs, δ_P = D − D_dir > 0 (Buscemi)
  → невозможность восстановления: [T1]  — ПЕРЕХОД ИНФОРМАЦИОННЫЙ, без [H].
```
**[H] сидит ровно в одном месте** — в ресурсном ярусе [T2]: утверждение «ни одна
операция ℛ не аппроксимирует Petz-восстановление через разрез A_obs за время
T_rec» опирается на [H1] (форма T(ε) из PIR) и [H2] (штраф доступа, Churilov).
Порог объективной записи Gu (`C_rec ≥ log(1/ε) + log log(1/ε)`) квантифицирует,
сколько доступа не хватает. EP, +i0, вторая память нигде не используются.

## 7. Наблюдаемые для численного теста N5 (точные определения)

Модель (файл `n5_small_model.py`): `V(2)⊗M1(2)⊗R₊(2)⊗R₋(2)`, d=16.
Модель **A**: запись — изометрия `|h⟩_V|0⟩_M|vac⟩ → |0,0⟩|1_h⟩_C2` (swap-
перестановка); далее Lindblad: стоки `L = √κ |0⟩⟨1|_{R±}` (κ = 0.08) и
внутренняя дефазировка C₂ `L = √γ_d |1⟩⟨1|_{R±}` (γ_d = 0.5).
Модель **B**: CNOT V→M₁; слив `L₊ = √γ₊ Π₀^M ⊗ |1⟩⟨0|_{R+}` (γ₊ = 1.5),
`L₋ = √γ₋ |0⟩⟨1|_M ⊗ |1⟩⟨0|_{R−}` (γ₋ = 0.7); сброс V `L = √γ_v |0⟩⟨1|_V`
(γ_v = 5); стоки κ = 0.08.

Наблюдаемые (все — функции T):
```
r(T)      = ½‖Tr_VM1(ρ₊ − ρ₋)‖₁                       [запись в C2, условие (i)]
η(T)      = ½‖Tr_C2(ρ₊ − ρ₋)‖₁                        [доступная различимость]
D_dir(T)  = D( Tr_C2 ρ₊(T) ‖ Tr_C2 ρ₋(T) )            [направленный функционал,
                                                       наты; рег. 1e-10]
δ_P(T)    = D(ρ₊‖ρ₋) − D_dir(T)                       [обсервационный дефицит]
η_tot(T)  = max_{ij} ½‖(E_acc − E₀)(|i⟩⟨j|)‖₁         [параметр теоремы T1]
R_ε(T)    = max_{R CPTP, R∘π} F_e(R∘E_acc)            [Choi-SDP, вход VM1 (d=4),
                                                       выход V (d=2); = F_e^opt]
F_e^full(T) = то же без π                              [бенчмарк полного доступа]
```
**Критерий выполнения достаточных условий на окне [T_*, T_fin]:**
`r(T) ≥ r₀`, `2η_tot(T) < 3/4 − ε_rec`, `R_ε(T) < 1 − ε_rec` для всех T окна.
(Для ε_rec = 1/2: `η_tot < 1/8`, `R_ε < 1/2`.)

**Результаты [C1]** (Choi-SDP, CLARABEL; полные данные `n5_results.json`,
график `n5_plot.png`):

Модель A — **точный no-go**: η(T) ≡ 0, `R_ε(T) = 0.2500` при всех T ∈ [0, 60];
`r(0) = 1.00` (запись в C₂ есть), δ_P ≫ 0. Полный доступ: `F_e^full`: 1.0000 →
0.8643 (t=0.5) → 0.6198 (t=2) → 0.4807 (t=4) → 0.2521 (t=60): окно
восстановления T(ε=1/2) ≈ 3.7 ∈ γ_eff⁻¹-шкале, как в [T2].

Модель B — **количественная форма**: переходное окно утечки.

## 8. Допущения (явно)

1. **[H1]**: перенос формы T(ε) ≍ γ_eff⁻¹ log(1/ε) из PIR 2603.22284 на нашу
   архитектуру (подтверждено только в малой модели A).
2. **[H2]**: штраф доступа Churilov использован качественно.
3. Усечение C₂ до 2 мод (континуум → конечное скремблирование γ_d как суррогат
   dispersion в континууме).
4. ε_rec = 1/2, d_V = 2 — канонический выбор; теорема параметрическа.
5. A_obs зафиксирована как B(V⊗M₁)⊗I (Def 3); результаты зависят от этого
   выбора по построению — это и есть содержание условия (ii).
6. Литературные «кирпичи» приняты как данность Этапа 0 без независимой проверки.
