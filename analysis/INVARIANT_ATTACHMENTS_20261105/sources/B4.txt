B4

Принимаю поправку. Тогда **шаг B4** нужно формулировать не как «новую модель Казимира» и не как «новый механизм тёмной материи», а как **тест на существование единого генератора**.

Короткая рабочая формулировка:

\[
\boxed{
\text{B4: проверить, является ли связанно-взвешенная спектральная мера }
\mu_V^L
\text{ не удобным обозначением, а минимальным генератором цепочки}
}
\]

\[
\boxed{
\mu_V^L
\;\Longrightarrow\;
\Sigma,\;\vartheta,\;\Delta\rho,\;E_{\rm Cas}^{\rm int},\;z_*,\;D,\;K,\;\kappa_C
}
\]

а в релятивистском слое —

\[
\boxed{
\mu_{V,x}^L
\;\Longrightarrow\;
\Sigma_x,\;\vartheta_x,\;E_{\rm Cas}^{\rm loc},\;K(x),\;\Delta L_{\rm meas}.
}
\]

Главный вопрос B4:

\[
\boxed{
\text{Можно ли вывести все эти объекты из одного канал-разрешённого спектрального данных,
не вводя для каждого узла отдельный скрытый формализм?}
}
\]

Если да — B4 не просто сборка известных кирпичей.  
Если нет — B4 распадается на Feshbach + BIC + Casimir scattering + quantum metrology, и тогда это только междисциплинарная аналогия.

# 1. Корректный первичный объект B4

Пусть

\[
\mathcal H=\mathcal H_C\oplus \mathcal H_G(L),
\]

где:

- \(C\) — код / наблюдаемый сектор;
- \(G(L)\) — среда, геометрия которой зависит от границы \(L\);
- \(V(L):\mathcal H_C\to\mathcal H_G(L)\) — связь;
- \(W(L)\) — канал утечки / доступа, если он выделяется отдельно.

Полный гамильтониан:

\[
H_{\rm tot}(L)=
\begin{pmatrix}
H_C & V^\dagger(L)\\
V(L) & H_G(L)
\end{pmatrix}.
\]

Обозначим спектральную проекторную меру среды:

\[
P_G(\Delta;L)
\]

для борелевских множеств \(\Delta\subset\mathbb R\).

Тогда **связанно-взвешенная операторная спектральная мера** равна

\[
\boxed{
\mu_V^L(\Delta)
=
V^\dagger(L)\,P_G(\Delta;L)\,V(L).
}
\]

Это положительная операторнозначная мера на \(\mathcal H_C\). В конечномерном случае, если

\[
H_G(L)=\sum_k E_k(L)|k;L\rangle\langle k;L|,
\]

то

\[
\boxed{
\mu_V^L(dE)
=
\sum_k
|V_k(L)\rangle\langle V_k(L)|
\,\delta(E-E_k(L))\,dE,
}
\]

где

\[
|V_k(L)\rangle = V^\dagger(L)|k;L\rangle
\]

или, в матричных элементах,

\[
[\mu_V^L(dE)]_{\alpha\beta}
=
\sum_k
\langle \alpha|V^\dagger|k;L\rangle
\langle k;L|V|\beta\rangle
\delta(E-E_k(L))\,dE.
\]

Именно эта мера входит в самоэнергию:

\[
\boxed{
\Sigma(z;L)
=
\int \frac{\mu_V^L(dE)}{z-E}.
}
\]

Эквивалентно,

\[
\boxed{
\Sigma(z;L)
=
V^\dagger(L)(z-H_G(L))^{-1}V(L).
}
\]

То есть

\[
\boxed{
\Sigma \text{ — преобразование Коши от } \mu_V^L.
}
\]

Это математически стандартно: Herglotz–Nevanlinna, Feshbach, operator-valued spectral measures. Но физический статус в B4 другой:

\[
\boxed{
\mu_V^L \text{ рассматривается не как промежуточная запись, а как кандидат на генератор доступа.}
}
\]

# 2. Важно: \(\mu_V^L\) сама по себе видит только связанную часть среды

Здесь нужно быть строгим.

Если в среде есть собственное состояние \(|d\rangle\), такое что

\[
V^\dagger(L)|d\rangle=0,
\]

то оно не оставляет следа в \(\mu_V^L\).

Следовательно:

\[
\boxed{
\mu_V^L \text{ генерирует код-видимую спектральную структуру, но не обязательно полный тёмный сектор.}
}
\]

Поэтому B4 надо формулировать в двух ярусах.

---

## Ярус I: visible / code-accessible генератор

Из одной меры \(\mu_V^L\) выводятся:

\[
\mu_V^L
\longrightarrow
\Sigma(z;L)
\longrightarrow
D_L(z)
\longrightarrow
\vartheta_L(E)
\longrightarrow
\Delta\rho_L(E)
\longrightarrow
E_{\rm Cas}^{\rm int}(L).
\]

Здесь

\[
D_L(z)=zI_C-H_C-\Sigma(z;L),
\]

\[
\vartheta_L(E)
=
\operatorname{Im}\operatorname{Tr}\log D_L(E+i0^+),
\]

\[
\Delta\rho_L(E)
=
\frac{1}{\pi}\partial_E\vartheta_L(E),
\]

и

\[
E_{\rm Cas}^{\rm int}(L)
=
\operatorname{Reg}
\frac{1}{2\pi}
\int d\omega\,
\operatorname{Im}
\operatorname{Tr}
\log
\left[
1-G_C(\omega+i0^+)\Sigma_L(\omega+i0^+)
\right].
\]

Это строгий visible-ярус.

---

## Ярус II: full channel-resolved spectral datum

Для тёмного сектора и ранговой геометрии доступа одного \(\mu_V^L\) может быть недостаточно. Нужен более полный объект:

\[
\boxed{
\mathsf{Spec}_V(H_G;L)
=
\bigl(P_G(\cdot;L),\,V(L),\,W(L)\bigr).
}
\]

Его видимое сжатие — \(\mu_V^L\). Его нулевое сжатие — тёмный сектор:

\[
\boxed{
D(L)=\ker W^\dagger(L)
}
\]

при условии инвариантности:

\[
[H_{\rm tot}(L),P_D(L)]=0.
\]

Тогда B4 можно сформулировать честно:

\[
\boxed{
\text{Единый генератор — не просто скалярная DOS и не просто } \mu_V,
\text{ а канал-разрешённая спектральная пара }
(P_G,V,W).
}
\]

Но ключевой нетривиальный вопрос:

\[
\boxed{
\text{Достаточно ли для всех код-видимых наблюдаемых одной } \mu_V^L,
\text{ а для тёмного сектора — её нулевого дополнения?}
}
\]

Если да, B4 имеет смысл как единая архитектура.  
Если для каждого узла нужен отдельный независимый объект — B4 не состоит.

# 3. Что уже установлено корпусом как [T] или [C]

## 3.1. Самоэнергия из замкнутой эрмитовой системы

Из `Resonance.txt`:

\[
\Sigma_0(z)
=
\frac{t_1^2}{z-E_1-\frac{t_2^2}{z-E_2}}
=
\frac{t_1^2(z-E_2)}
{(z-E_1)(z-E_2)-t_2^2}.
\]

После добавления прямого пути \(V\leftrightarrow M_2\) с амплитудой \(\gamma_d\):

\[
M=
\begin{pmatrix}
E_1&t_2\\
t_2&E_2
\end{pmatrix},
\qquad
v=
\begin{pmatrix}
t_1\\
\gamma_d
\end{pmatrix},
\]

\[
\Sigma_L(z)
=
v^T(zI-M)^{-1}v.
\]

Разность:

\[
\Delta\Sigma_L(z)
=
\Sigma_L(z)-\Sigma_0(z)
\]

имеет числитель

\[
\boxed{
\gamma_d\bigl[\gamma_d(z-E_1)+2t_1t_2\bigr].
}
\]

Следовательно, интерференционный нуль:

\[
\boxed{
z_*^{\Delta\Sigma}
=
E_1-\frac{2t_1t_2}{\gamma_d}.
}
\]

Диагональный контроль равной нормы даёт

\[
\Delta\Sigma_{\rm ctrl}
=
\frac{\gamma_d t_1^2t_2^2}{\text{den}},
\]

и нуля не имеет.

Значит:

\[
\boxed{
\text{нуль } \Delta\Sigma \text{ — следствие второго маршрута / связности, а не просто величины возмущения.}
}
\]

Это [T] аналитически и [C] численно.

# 4. Гипотеза B4-U: unified coupling-measure invariant

Теперь можно сформулировать сам шаг.

## Гипотеза

Существует фиксированный набор отображений \(\Phi_i\), не зависящих от \(L\) произвольно, таких что для семейства границ \(L\):

\[
\boxed{
\Sigma(z;L)=\Phi_\Sigma[\mu_V^L](z),
}
\]

\[
\boxed{
\vartheta_L(E)=\Phi_\vartheta[\mu_V^L](E),
}
\]

\[
\boxed{
\Delta\rho_L(E)=\Phi_\rho[\mu_V^L](E),
}
\]

\[
\boxed{
E_{\rm Cas}^{\rm int}(L)=\Phi_E[\mu_V^L](L),
}
\]

\[
\boxed{
z_*(L)=\Phi_z[\mu_V^L](L),
}
\]

и, при добавлении нулевого канала,

\[
\boxed{
D(L)=\Phi_D[P_G,V,W](L),
}
\]

\[
\boxed{
K(x)=\Phi_K[P_G,V_x,W_x](x,L).
}
\]

Для метрологии:

\[
\boxed{
F_Q(L;x)
=
\Phi_Q[\mu_{V,x}^L,\rho_{\rm probe},\partial_L H,\text{protocol}](L,x).
}
\]

Важно: QFI не выводится из одной \(\mu_V\) без подготовки и протокола. Поэтому сильная версия B4 должна включать:

\[
\boxed{
\mathcal G_{\rm metro}(L,x)
=
\bigl(
\mu_{V,x}^L,\;
\rho_{\rm probe},\;
\partial_L V,\;
\partial_L H_G,\;
\text{detector window}
\bigr).
}
\]

Если этого не сделать, в B4 появится скрытый параметр, и унификация рухнет.

# 5. Главный тест B4: isospectral but not isocoupling

Самый сильный первый тест — не Казимир.

Он такой:

\[
\boxed{
\text{Зафиксировать } \operatorname{Spec}H_G(L) \text{ и } \rho_G^L,
\text{ но изменить } V(L) \text{ так, чтобы cambia } \mu_V^L.
}
\]

Тогда B4 требует:

\[
\mu_V^L\neq \mu_{V'}^L
\quad\Rightarrow\quad
\Sigma_L\neq\Sigma_{L'},
\]

\[
\vartheta_L\neq\vartheta_{L'},
\]

\[
z_*(L)\neq z_*(L'),
\]

\[
D(L)\neq D(L'),
\]

\[
K(L)\neq K(L').
\]

И обратно:

\[
\mu_V^L=\mu_{V'}^L
\quad\Rightarrow\quad
\text{все код-видимые наблюдаемые совпадают.
}
\]

Это и есть проверка, что первична не среда, а **связная спектральная мера среды**.

---

## Конкретные варианты теста

### T1. Сохранить DOS, изменить signs / phases связи

Взять одну и ту же \(H_G\), но заменить

\[
V\rightarrow V'
\]

так, чтобы

\[
|\langle k|V\rangle|^2
\]

частично сохранилось, но матричная операторная мера изменилась:

\[
\mu_V\neq\mu_{V'}.
\]

Ожидание:

- скалярная DOS может остаться близкой;
- но \(\Sigma\), фаза, нули, доступ меняются.

Это ломает редукцию к \(\rho_G\).

---

### T2. Random \(V\) при той же \(\rho_G\)

Случайная связь с теми же нормами, но другими собственными векторами.

Ожидание:

\[
\rho_G \text{ фиксирована},
\qquad
\mu_V \text{ случайно меняется},
\qquad
\Sigma,\vartheta,D,K \text{ меняются}.
\]

Если нет — \(\mu_V\) не генератор.

---

### T3. Invisible gauge

Изменить \(H_G\) только в подпространстве \(\ker V^\dagger\).

Тогда:

\[
\mu_V \text{ не меняется},
\]

и все код-видимые наблюдаемые не должны меняться.

Но тёмный сектор может меняться, если меняется \(\ker V^\dagger\).

Это проверяет разделение visible / dark ярусов.

---

### T4. Диагональный контроль равной нормы

Из `Resonance.txt`:

- второй путь даёт нуль \(\Delta\Sigma\);
- диагональная добавка равной нормы нуля не даёт.

Это уже корпусный позитивный контроль для связной меры.

---

### T5. Sign-flip канала

Из корпуса B3/GOE:

\[
W=(\gamma,\gamma,\kappa)
\]

может давать тёмное антисимметричное состояние, а

\[
W=(\gamma,-\gamma,\kappa)
\]

уже нет:

\[
W^\dagger A=\sqrt2\gamma\neq0.
\]

Значит тёмный сектор зависит от операторной структуры канала, а не от норм.

---

### T6. Split-bath

Разделить общий интерференционный канал.

Ожидание:

\[
\text{общий канал} \Rightarrow \text{защитное окно};
\]

\[
\text{split-bath} \Rightarrow \text{окно исчезает}.
\]

Это проверяет, что защита — свойство единой \(\mu_V\), а не отдельных мод.

---

Я бы назвал шаг:

\[
\boxed{
\text{B4-U: Unified Coupling-Measure Invariance Test}
}
\]

или короче:

\[
\boxed{
\text{B4: spectral boundary selector}
}
\]

но с обязательным уточнением:

\[
\boxed{
\text{B4 начинается не с Казимира, а с } \mu_V^L \text{ и ранговой геометрии доступа.}
}
\]

---

## B4.1. Visible self-energy gate

Цель: проверить, что

\[
\Sigma(z;L)
=
V^\dagger(z-H_G)^{-1}V
\]

точно совпадает с

\[
\int \frac{\mu_V^L(dE)}{z-E}.
\]

Выход:

\[
\|\Sigma_{\rm direct}-\Sigma_{\mu}\|<\tau.
\]

Это базовый математический гейт. Если он не проходит, вся конструкция разваливается.

---

## B4.2. Pole-zero / phase gate

Для каждой \(L\) вычислить:

\[
\text{poles}(\Sigma_L),
\qquad
\text{zeros}(\Sigma_L),
\qquad
\vartheta_L(E).
\]

Проверить чередование полюсов и нулей в конечной эрмитовой системе.

Для однородной цепочки с локальной связью есть точная форма:

\[
\boxed{
\Sigma_L(z)
=
\frac{g^2}{t}
\frac{U_{L-1}\left(\frac{z}{2t}\right)}
{U_L\left(\frac{z}{2t}\right)}.
}
\]

Полюса — нули \(U_L\), нули — нули \(U_{L-1}\).

Это идеальный носитель для проверки visible-яруса.

Но важно: локальная связь к однородной цепочке не даёт точных тёмных состояний, потому что

\[
\langle k|1\rangle\neq0.
\]

Поэтому B4.1/B4.2 проверяют только:

\[
\boxed{
L\rightarrow\mu_V^L\rightarrow\Sigma_L\rightarrow\vartheta_L.
}
\]

---

## B4.3. Two-route interference gate

Перейти к двухпортовой модели или модели Friedrich–Wintgen.

Проверить:

\[
\Delta\Sigma_L(z_*)=0,
\]

\[
\partial_z\Delta\Sigma_L(z_*)\neq0,
\]

и что диагональный контроль равной нормы нуля не даёт.

Это отдельный гейт для интерференционного нуля.

Нельзя объявлять этот нуль BIC без отдельной проверки.

## B4.4. Constructive dark-sector gate

\[
P_D^2=P_D,
\]

\[
[H_{\rm tot},P_D]=0,

\[
W^\dagger P_D=0.

Запрещено получать \(P_D\) как top-k support утечки.

Это прямой урок Step20.1: концентрация может быть, но динамика irrelevant, конструкция fragile.

Для BIC-модели проверить:

\[
z_*^\Sigma(\gamma_{\rm dark})=E_-,
\]

\[
\Gamma_p(\gamma_{\rm dark})=0,
\]

\[
\Gamma(\gamma)\simeq c_2(\gamma-\gamma_{\rm dark})^2.

И обязательно sign-control:

\[
W=(\gamma,\gamma,\kappa)
\]

против

\[
W=(\gamma,-\gamma,\kappa).
\]

L_C(L)=\Pi_C|_{D(L)},
\]

\[
M_C(L)=L_C^\dagger(L)L_C(L).

Отчитывать не одно число, а:

\boxed{

\kappa_C(L),\quad
F_{\rm ch}(L),\quad
\operatorname{rank}L_C(L).
}

Где

\kappa_C(L)
=

{\lambda_{\max}(M_C)}.

Проверить интерфейс S5:

\boxed{

# 7. Релятивистский слой B4-rel: не новая субстанция, а причинная компрессия той же меры

Если нас интересует именно релятивистское ограничение точности измерений, то B4 должен добавить слой:

\[
\boxed{
\mu_V^L
\longrightarrow
\mu_{V,x}^{L,\sigma,\tau,T}.
}
\]

Здесь:

- \(x\) — событие наблюдения;
- \(T\) — длительность окна;
- \(\sigma\) — пространственное разрешение;
- \(\tau\) — временное разрешение;
- причинная область — \(J^-(x)\).

Локальный детектор задаётся смазывающей функцией:

\[
\operatorname{supp} f_x\subset J^-(x).
\]

Тогда локальная самоэнергия:

\[
\boxed{
\Sigma_x(z;L)
=
\int
\frac{\mu_{V,x}^L(dE)}{z-E}.
}
\]

В полевой форме:

\[
\Sigma_x(z;L)
=
\lambda^2
\int d^4y\,d^4y'\,
f_x(y)f_x(y')
V^\dagger
G_R(y,y';L)
V.
\]

Микропричинность:

\[
\boxed{
[\Phi(y),\Phi(y')]=0,
\qquad
(y-y')^2<0.
}
\]

В решёточной замене можно использовать Lieb–Robinson cone:

\[
\boxed{
\|[A_n(t),B_m]\|
\le
C e^{-(|n-m|-v_{\rm LR}t)/\xi}.
}
\]

Это позволит сделать первую численную проверку без полной КТП.

---

## Пределы точности

Для локального наблюдателя:

\[
\boxed{
\Delta E
\gtrsim
\frac{\hbar}{T}
\gtrsim
\frac{\hbar c}{R_x}.
}
\]

Если граница восстанавливается по Казимировой силе:

\[
\boxed{
\Delta L
\gtrsim
\frac{\Delta E}{|F_{\rm Cas}|}
\gtrsim
\frac{\hbar c}{R_x |F_{\rm Cas}|}.
}
\]

Квантовый метрологический предел:

\[
\boxed{
F_Q(L;x,T)
\le
\frac{4T^2}{\hbar^2}
\operatorname{Var}_{\psi_x}(\partial_L H),
}
\]

\[
\boxed{
\Delta L
\ge
\frac{1}{\sqrt{F_Q}}
\ge
\frac{\hbar}{2T\Delta F_{\rm rms}}
\gtrsim
\frac{\hbar c}{2R_x\Delta F_{\rm rms}}.
}
\]

УФ-предел от конечного разрешения:

\[
\boxed{
\Delta L_{\rm UV}
\gtrsim
\frac{b_{\rm UV}(\sigma)}
{|\partial_L E_{\rm Cas}^{\rm ren}|}.
}
\]

Информационный предел:

\[
\boxed{
R_\varepsilon^{\rm rel}(x)
\le
\frac14+2\eta_{\rm tot}^{\rm rel}(x),
}
\]

\[
\boxed{
\varepsilon_{\rm rec}^{\rm min,rel}(x)
\ge
\frac34-2\eta_{\rm tot}^{\rm rel}(x).
}
\]

Комбинированно:

\[
\boxed{
\Delta L_{\rm meas}
\ge
\max
\left[
\frac{\hbar c}{R_x |F_{\rm Cas}|},
\;
\frac{\hbar c}{2R_x\Delta F_{\rm rms}},
\;
\frac{b_{\rm UV}(\sigma)}{|\partial_L E_{\rm Cas}|},
\;
\frac{1-\frac14-2\eta_{\rm tot}^{\rm rel}(x)}
{|\partial_L\vartheta|}
\right].
}
\]

Но важно: это не планковская длина и не гравитационный предел. Это специально-релятивистский + квантовый + информационный предел.

# 8. Обязательные гейты B4

## G0. Cauchy-gate

\[
\Sigma_{\rm direct}(z;L)
=
\int\frac{\mu_V^L(dE)}{z-E}
\]

с точностью до численного шума.

---

## G1. No-EP-in-closed-H gate

Нельзя объявлять EP/Jordan в замкнутом эрмитовом \(H_{\rm tot}\).

EP допускается только как объект редуцированного неэрмитова описания.

---

## G2. Separate-zero gate

Раздельно проверять:

1. нуль \(\Delta\Sigma\);
2. нуль полного dressed \(\Sigma\);
3. Fano transmission zero;
4. BIC condition \(V^\dagger|d\rangle=0\).

Нельзя смешивать.

---

## G3. Constructive-dark gate

\(P_D\) должен удовлетворять:

\[
P_D^2=P_D,
\qquad
[H_{\rm tot},P_D]=0,
\qquad
W^\dagger P_D=0.
\]

Запрещён top-k support.

---

## G4. Rank-access gate

Отчитывать:

\[
\operatorname{rank}L_C,
\qquad
\lambda_{\min}/\lambda_{\max}(L_C^\dagger L_C),
\qquad
\bar p_C,
\qquad
F_{\rm ch}.
\]

Нельзя сводить доступ к одному скаляру.

---

## G5. S5-interface gate

Проверить:

\[
\eta_{\rm tot}\ge\eta_{\rm obs}/2,
\]

\[
R_\varepsilon\le\frac14+2\eta_{\rm tot}.
\]

И статистически охарактеризовать соотношение.

---

## G6. Metric-normalization gate

Основная метрика — ненормированная trace-decreasing.

Postselection — только диагностический контроль.

Урок Step6: нормированная \(P_{\rm BIC}\approx0.99\text{--}1.00\) может скрывать отсутствие реальной глубины.

---

## G7. Isospectral-coupling gate

Сохранить \(\rho_G\), изменить \(V\).

Требовать изменения \(\mu_V\) и всех dependent code-observables.

Если нет — \(\mu_V\) не генератор.

---

## G8. Invisible-gauge gate

Изменять только \(\ker V^\dagger\).

Код-видимые наблюдаемые не должны меняться.

Тёмный сектор может меняться, но только через явный null-space data.

---

## G9. Split-bath gate

Разделить общий канал.

Ожидание: интерференционная защита исчезает.

---

## G10. Sign-control gate

Смена знака \(W\) должна менять наличие/отсутствие тёмного состояния там, где корпус это уже показал.

---

## G11. Diagonal-equal-norm gate

Диагональная добавка равной нормы не должна давать нуль \(\Delta\Sigma\), если нуль связан со вторым маршрутом.

---

## G12. Theta-control gate

Любая заявленная асимметрия времени должна исчезать при \(\Theta\)-симметризации, если она arises из редукции/граничных условий.

Из WS9/WS10/WS11/stage6:

\[
\boxed{
A=0
}
\]

в T-инвариантном замкнутом классе, а видимые ненули — артефакты приготовления или ручного ретардированного усечения.

---

## G13. QFI-hidden-parameter gate

Для метрологии нельзя писать:

\[
F_Q=F_Q[\mu_V]
\]

без указания:

\[
\rho_{\rm probe},
\qquad
\partial_L H,
\qquad
\text{measurement protocol},
\qquad
\text{causal window}.
\]

Иначе появляется скрытый параметр.

---

## G14. No-self-loop gate

B4 со статическим внешним \(L\) даёт максимум:

\[
\boxed{
\mathcal I_{\rm weak}
}
\]

или частичный:

\[
\boxed{
\mathcal I_{\rm int}.
}
\]

Но не:

\[
\boxed{
J_{\rm self}^{\rm func}.
}
\]

Для self нужен цикл:

\[
\boxed{
\operatorname{Rep}_{\mathcal A^{\rm int}}(S_t)
\to
S_{t+1}.
}
\]

Пока \(L\) задан извне, это внешний селектор.

---

# 9. Критерии успеха B4

## S1. Сильный успех

Выполнены все гейты, и найдено нетривиальное окно \(L\in[L_1,L_2]\), где:

1. одна и та же \(\mu_V^L\) воспроизводит \(\Sigma\), фазу, spectral shift;
2. нули/полюса управляют интерференционными маркерами \(z_*\);
3. тёмный сектор конструктивно лежит в \(\ker W^\dagger\);
4. доступ определяется \(L_C^\dagger L_C\), а не скаляром;
5. Казимироподобная энергия получается как регулярзованный фазовый/спектрально-сдвиговый интеграл;
6. релятивистская локализация даёт предсказуемые пределы точности;
7. контроли не дают ложных срабатываний.

Тогда можно сказать:

\[
\boxed{
\text{Казимир, резонанс, тёмный сектор и доступ — разные срезы одной канал-разрешённой спектральной меры.}
}
\]

Но всё ещё не:

\[
J_{\rm self},
\qquad
\text{стрела времени},
\qquad
\text{онтологическая тёмная материя}.
\]

---

## S2. Умеренный успех

Visible-ярус работает:

\[
\mu_V^L
\rightarrow
\Sigma
\rightarrow
\vartheta
\rightarrow
\Delta\rho
\rightarrow
E_{\rm Cas}^{\rm int},
\]

но dark/access-ярус требует отдельных структур.

Тогда вывод:

\[
\boxed{
\text{граница управляет резонансом и энергией, но тёмный сектор/доступ — отдельный слой.}
}
\]

---

## S3. Слабый успех

Работает только

\[
L\rightarrow\Sigma_L\rightarrow\vartheta_L.
\]

Тогда B4 полезен как spectral boundary toy model, но не как unified architecture.

---

## F1. Провал по генератору

Для разных узлов нужны независимые скрытые объекты:

- отдельный параметр для \(\Sigma\);
- отдельный для \(D\);
- отдельный для \(K\);
- отдельный для \(F_Q\).

Тогда B4 распадается.

---

## F2. Провал по тёмному сектору

\(D\) получается как top-k support или не коммутирует с \(H\).

Тогда:

\[
\boxed{
\text{тёмный сектор — артефакт проекции.}
}
\]

---

## F3. Провал по метрике

Глубина зависит от нормировки, postselection скрывает потерю нормы.

Тогда нужно переписать наблюдаемую.

---

## F4. Провал по причине

Корреляции исчезают после вычета тривиальных масштабов:

\[
t(L),\quad g(L),\quad \|V(L)\|.
\]

Тогда нет единого инварианта, есть только совместная зависимость от масштаба.

---

## F5. Провал по релятивистскому слою

QFI заявляется как функционал только от \(\mu_V\), хотя фактически зависит от состояния, протокола и окна.

Тогда метрологическая ветвь не унифицирована.

---

\[
\Sigma(z)=V^\dagger(z-H_G)^{-1}V
=
\int \frac{\mu_V(dE)}{z-E}
\]

следует непосредственно из спектральной теоремы.

Если

\[
H_G=\sum_k E_k |k\rangle\langle k|,
\]

то

\[
(z-H_G)^{-1}
=
\sum_k \frac{|k\rangle\langle k|}{z-E_k},
\]

и поэтому

\[
V^\dagger(z-H_G)^{-1}V
=
\sum_k
\frac{V^\dagger |k\rangle\langle k|V}{z-E_k}.
\]

Это буквально определение

\[
\mu_V(dE)
=
\sum_k V^\dagger |k\rangle\langle k|V\,\delta(E-E_k)\,dE.
\]

Так что как математический факт это очень стандартно:

- Feshbach projection formalism;
- Herglotz–Nevanlinna operator-valued measures;
- spectral theorem;
- resolvent representation;

## 3.1. Да, математическое ядро можно было получить без моделирования

Можно было сесть и написать:

\[
H_G=\sum_k E_k|k\rangle\langle k|,
\]

\[
\Sigma(z)=V^\dagger(z-H_G)^{-1}V
=
\sum_k \frac{V^\dagger|k\rangle\langle k|V}{z-E_k}.
\]

Отсюда сразу:

\[
\mu_V(dE)
=
\sum_k V^\dagger|k\rangle\langle k|V\,\delta(E-E_k)\,dE,
\]

и

\[
\Sigma(z)=\int \frac{\mu_V(dE)}{z-E}.
\]

Дальше:

- фаза \(\vartheta\) — functional of \(\Sigma\);
- spectral shift \(\Delta\rho\) — derivative of phase;
- zeros/poles — functionals of \(\Sigma\).

Это можно вывести аналитически.

Также можно было привести тривиальный контрпример DOS-онтологии.

Например, пусть код двумерен, среда имеет одну моду \(E\), а связь — вектор в коде:

\[
V_1=
\begin{pmatrix}
1\\
0
\end{pmatrix},
\qquad
V_2=
\begin{pmatrix}
0\\
1
\end{pmatrix}.
\]

Тогда скалярная DOS одинакова:

\[
\rho_G(E)=\delta(E-E_0),
\]

trace-вес тоже одинаков:

\[
\operatorname{Tr}\mu_{V_1}=\operatorname{Tr}\mu_{V_2}=1,
\]

но операторные меры разные:

\[
\mu_{V_1}=
\begin{pmatrix}
1&0\\
0&0
\end{pmatrix}
\delta(E-E_0),
\]

\[
\mu_{V_2}=
\begin{pmatrix}
0&0\\
0&1
\end{pmatrix}
\delta(E-E_0).
\]

Следовательно,

\[
\Sigma_1\neq \Sigma_2.
\]

Это можно было понять из литературы по LDOS, spectral density matrix, Feshbach formalism.

Так что если вопрос был только:

> «Важна ли ориентация связи, а не только DOS?»

то да, это было известно.

# 6. Самый честный итог

## Что мы получили

Мы получили **сертифицированный visible-layer invariant**:

\[
\boxed{
\mu_V^L(dE)=V^\dagger dP_G(E;L)V
}
\]

достаточен для восстановления проверенного набора видимых объектов:

\[
\boxed{
\Sigma,\quad z_*,\quad \vartheta,\quad \Delta\rho.
}
\]

И одновременно получили явный запрет:

\[
\boxed{
\rho_G^L \text{ недостаточна для visible-слоя.}
}
\]

Более того, недостаточно даже совпадения скалярных trace-весов:

\[
\operatorname{Tr}\mu_V
\]

при одинаковой DOS. Нужна операторная ориентация связи.

---

## Насколько это тривиально

Как математика — почти тривиально.

Как физическая идея — не ново.

Как научный гейт для вашей программы — нетривиально и полезно.

То есть B4.0 не «открыл новую природу». Он сделал гигиеническую, но критически необходимую вещь:

\[
\boxed{
\text{показал, на каком объекте можно дальше строить visible-слой,}
}
\]

и

\[
\boxed{
\text{запретил строить его на скалярной DOS.}
}
\]
