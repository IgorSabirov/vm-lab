**Дата:** 2026-09-01 · **Исполнитель:** Kimi K3 Swarm · **Основание:** ТЗ WS9 v1.1 (заморожено с 5 блокировками рецензии) · **Стоп-правило автора:** не задействовано — ни на одном этапе не потребовалось упрощения конструкции; все промежуточные результаты и код сохранены.

## 1. Резюме: класс результата

**Главный вопрос (0.3):** C_past ≟ C_future — возникает ли A ≡ C_past − C_future ≠ 0 без ручной ориентации в замкнутой архитектуре (V,M₁,M₂,ξ) с полной эндогенной обратной связью при T-инвариантном микроскопическом H.

**ИТОГОВАЯ КЛАССИФИКАЦИЯ: класс (1)** — замкнутая архитектура стрелы не дала: A = 0 в пределах чувствительности конвейера для разрешённого класса предикторов.

Детализация:
- Носитель нуля — предиктор P3 (кусочно-модальный, оба листа): A = 0 во всех 6 базовых ячейках (L1/L2/L3 × c(0)=0/c(0)≠0), p = 0.28–0.93; нуль устойчив к разрешению (Δ = 0.125/0.25/0.5), представлению (R1/R2/R3), ансамблю (M = 50/200), возрасту системы.
- Обнаруженные ненулевые A (аномалии F-1, F-3, F-9: предикторы P2, P1, одна ячейка P3 на коротком окне) **не прошли лестницу §3.5**: усиливаются на коротком окне (T_w=32), размываются на длинном (T_w=256), умирают с возрастом системы (t_age=256), машинно переворачиваются под Θ (|A+A_Θ| = 0.0) и обнуляются Θ-симметричным будущим гранусловием (B2-бридж: A_bridge = 0 машинно). По пре-регистрированному правилу они отнесены к **артефактам класса (2)** — краевой транзиент односторонней подготовки записи (имитатор типа «старение», предсказанный Этапом 0, L0.6/M3), а не к физической асимметрии.
- Класс (3) исключён уже на 3.3 (эффект предиктор-зависим и убит B2); класс (2) как глобальный вердикт исключён контролем 3.6 (36/36 парных сравнений R1↔R2↔R3 в пределах порога — представления асимметрию не порождают).
- §3.7 (повестка механизмов) **не запускался** — по ТЗ он активируется только при классе (3).

**Смысловая граница результата** (честная фиксация): A = 0 получен для конкретной гамильтоновой реализации класса DNLS/Hartree (ДОПУЩЕНИЯ №1–2 реестра) на разрешённом горизонте (T_w ≤ 256, M ≤ 200). Это свидетельство против стрелы в данном классе конструкций, а не теорема о всех замкнутых архитектурах — что согласуется с Этапом 0 (L0.1: Φ-выводимые самосогласованные петли T-инвариантны; L0.5: спонтанная асимметрия записей в полностью замкнутом T-инвариантном цикле — открытый слот, который данный прогон не закрыл в положительную сторону).

## 3. Этап 0 (блокирующий): чек литературы — ЗАКРЫТ, противоречий постановке нет

| Пункт | Вердикт | Ключевое |

**Внутрилитературное противоречие** (нестоп): статус Past Hypothesis (Albert–Loewer vs Gołosz 2025/bottleneck 2024 vs Ebtekar 2024) — задокументировано; обе позиции согласны, что асимметрия записей не следует из одних T-инвариантных законов.

**Выданные определения (блокировки рецензии №1, №2):** оператор Θ = K∘ℛ на полном состоянии (V,M₁,M₂,ξ) с правилом C_past↔C_future; [Def] C_past/C_future — парный misfit восстановления сегментов двустороннего окна от t₀ разрешённым классом 𝒫 на уровнях L1/L2/L3, с гарантией Θ-ковариантности 𝒞.

**Решение по носителю:** конечномерная DNLS/Hartree-«звезда с регистрами» (гарантия эрмитовости и T-инвариантности по L0.3); представления R1 (полная микродинамика), R2 (SOE + гибридный псевдомодный резервуар), R3 (state-space).

## 5. Этап 2 (численика)

### 5.1 Калибровка 3.0 (до всех прогонов)
Среда: 2 CPU; **cgroup-лимит RAM 3.0 GB жёстко** (рабочий бюджет ~2 GB/процесс — жёстче предварительной оценки §4); BLAS 40 GFLOPS; FFT 2²⁰ ≈ 59 мс. Сжимаемость хвоста t^(−3/2) с биением: r(N_t,ε) = c₁·log₁₀N_t + c₀, c₁ = 4.8/7.9/10.9 на декаду (ε=1e-6/9/12), R²=0.997 — **логарифмическая, worst-case §4 отклонён**. Рабочие точки: R1 N_t ≤ 1.1·10⁴; R2 продакшн N_t=10⁶; R3 N_t=10⁷. Пороги: κ_exc=30 при δ_scheme=2.6e-12; θ(M)=5.5745·MAD/√M; порог 3.6 max(θ, 30·δ_scheme). Для T-контроля пре-регистрирован унитарный CN/Magnus (RK45 непригоден: дрейф нормы 7e-9).

### 5.2 Реализация 3.1 — все валидации PASS
R1 (N=2050, sparse): max|‖ψ‖²−1| = 6.6e-9, max|Δ𝓗| = 4.0e-9 за T=256; CN/Magnus ‖U(−8)U(8)ψ−ψ‖ = 1.5e-15. Линейный предел: mse vs эталон 1.2e-22; хвост |V|·t^{3/2} → 0.0461 (аналитика краёв 0.046056 — решение лида №01: наследный диапазон [0.005,0.014] относится к фону после вычитания полюса, не к полному |V|). R1↔R2↔R3 на T_w=64: sup|ΔV| ≤ 2.2e-10. Якобиан: ∂ℳ₁/∂M₂ = 0.0; композит ratio→1.0002. Ничего из списка 0.4 не вырезано.

### 5.3 Интервенции 3.2 — PASS по всем каналам
do(M₂)→V и do(M₂)→M₁ (медиированный): 150/150 киков выше порога 30·δ_scheme; наклон против D(τ)=−κg²ρτ — медиана отношения **1.0000** [0.9998, 1.0001]. do(M₂)→M₁ при заблокированном V→M₁: **1.1e-16, p=0.794** — запрещённый канал машинный нуль. Информационный ярус: TE(M₂→M₁|V,ξ) ≈ 0 (p=0.200) — архитектурный нуль подтверждён; разрешённые каналы z=8.9–71.4. Контроль неколлапса: err(M₂|V,M₁)≈1.0 (не лучше нулевого предиктора) против err(M₁|V)=3.6e-3 — отношение 276≫30.

### 5.4 Главный тест 3.3
Конвейер наследия WS8 (двустороннее окно T_w=64, Δ=0.25, t₀ в середине, L1/L2/L3, P1/P2/P3, парная статистика, M=200×2 подкласса, seed master 20260901+idx). Θ-ковариантность 𝒫 машинная (P3M нарушает 4.9–10.1 ната — как задумано).

**Результат: A=0 для разрешённого класса** — P3: нуль во всех 6 ячейках; P1: нуль в 4/6; P2: систематический позитив +0.478…+0.945 (p=1e-4) — аномалия F-1. **T-контроль:** B4: A(Θ-ансамбль) = −A точно (|A+A_Θ|=0.0, 18/18 ячеек; record-flip заверен динамически 4.8e-9); **B2 (Θ-симметричное будущее гранусловие): A_bridge = 0 машинно (≤2.5e-8)** — все ненулевые A не переживают Θ-симметризации ⇒ бридж/гранусловный артефакт по пре-регистрированному правилу. Калибратор P3-MANUAL: +2.59…+3.34 ната (ложная асимметрия 13–27×) — чувствительность откалибрована (ожидание WS8 «5+ порядков» в нашей метрике не воспроизведено, F-2, не критерий).

### 5.5 Семь отрицательных контролей 3.4 — все PASS
1. **Линейный предел:** P1/P2 — нули 12/12; P3-сдвиг +0.92…+1.49 атрибутирован транзиенту подготовки (исчезает на сдвинутом окне 18/18, A_Θ=−A машинно) — F-6. Спектральная регрессия: |Δz*| = 4.2e-10 ≪ 1e-6 (mpmath dps=50, фильтр р12); эталон WS8 идентифицирован как z*=(7−i√11)/12 при ε₀=1/2.
2. **W=0:** W-звено разомкнуто машинно (двойная мутация W=0,κ=0: отклики ≤4.5e-11); κ-остаток атрибутирован (пре-регистрация v1.1).
3. **Атомарный предел:** μ₁^ac лестница ∝(J_A/g)² (1.0→4.0e-4); M₁-опосредованный M₂-контент подавлен 1.1·10⁶×.
4. **κ=0:** деградация к одноуровневой — sup‖δV‖ от c(0) ≤ 4.0e-16; mse vs прогон без регистра 1.9e-26; тёмная мода по T9.4.3(а).
5. **Экзогенная ξ (отключение V→ξ):** **A=0 в 18/18 ячейках** — нуль WS8 воспроизведён; аномалии F-1/F-3 при экзогенной ξ исчезают ⇒ они эндогенного происхождения (требуют и нелинейности, и замыкания), но убиты B2 — эффект взаимодействия эндогенного замыкания с односторонней подготовкой.
6. **T-контроль:** ‖U(−t)U(t)ψ−ψ‖ ≤ 1.44e-14 (T=32); Θ²=Id и Θ-ковариантность rhs — точно 0.0.

### 5.6 Лестница 3.5 и эквивалентность 3.6 — PASS
- **3.6 (центральный контроль):** 36/36 парных сравнений A_{R1} vs A_{R2/R3} в пределах max(θ(ΔA), 30·δ_scheme): P2/P3 — 1e-8…1e-10 (машинная эквивалентность), P1 — до 0.90 порога. Представления асимметрию не порождают и не стирают.
- **Лестница:** нулевые ячейки устойчивы к Δ, T_w, возрасту, ансамблю; Θ-контроль Δ=0.125 машинный. Аномалии F-1/F-3 (+ новая F-9: P3 B1 L3 на T_w=32, +1.63): устойчивы к Δ, **усиливаются на T_w=32, размываются на T_w=256, умирают при t_age=256** (парный сдвиг p=1e-4), переворачиваются под Θ, убиты B2. **Закрыты как имитаторы** (старение/краевой транзиент — предсказанный Этапом 0 класс артефактов).
- **Фильтры имитаторов:** старение/WEB — нулевые ячейки возраст-инвариантны 16/18; ненормальный транзиент — монотонного роста A нет ни в одной из 18 ячеек (все наклоны <0).

### 5.7 Спектральный сервис (вход для T9.6)
Подтверждено [C]: машинерия L(z;ρ) (невязки ≤1e-46), исправленная dz*/dρ (FD-проверка 4.0e-33), тауберова пара α=1.5000000000000004 ↔ края ±2 на полной рабочей точке, отсутствие EP (|∂L/∂z| ≥ 0.857). | A ≠ 0 (но убит B2 → класс B) | **A = 0** | **NH-механизм специфичен** |

Реализовалась первая строка пространства исходов пары: **на уровне observable — «NH-механизм специфичен»**. Редукционно возникающая неэрмитовость (WS10) давала сильную асимметрию A≠0 с доза-ответом (впоследствии убитую B2 — граничная индуцированность); флуктуационная структура эрмитовой микроскопики при T-инвариантном ρ_E (WS11) не даёт даже observable-уровня.

**Полная картина серии (уровень observable, единый harness и модель):**

| Прогон | Upstream-механизм | A (observable) | Вердикт |
|---|---|---|---|
| WS9 | Полная микродинамика, замкнутая архитектура | A = 0 | класс (1) |
| WS10 | Редукционная NH (марковский on-shell M₂^R) | A ≠ 0 → убит B2 | W10-B |
| WS11 | Флуктуационная структура C_E → ℱ → 𝒟 → histories | A = 0 | NO-GO / NULL |

**Итоговое утверждение серии [C]:** ни чистая эрмитова замкнутая архитектура (WS9), ни флуктуационная структура при T-инвариантном ансамбле окружения (WS11), ни редукционная NH (WS10) не дают стрелы сверх граничной индуцированности в данном классе конструкций. Единственный наблюденный ненулевой A в серии (WS10) целиком принадлежал марковской on-shell редукции и полностью устранялся Θ-симметричным гранусловием.

**Зафиксированная оговорка о совместимости (ТЗ §5):** полного аналога dose-response (λ-диала) в WS11 нет — совместимость вердиктов частичная; сравнение ведётся на вердиктном уровне, не битовом (ДОПУЩЕНИЕ W11-1: реконструкция носителя). Это зафиксировано, а не замаскировано.
