# R132 · R133 · R150. От битового хода до контактного оператора Дирака

Вторая редакция от 26 ноября 2026 года. В report.md помещён полный текст 17-страничного отчёта с доказательствами. Три приложения доступны отдельными файлами для переноса в тематические разделы.

## Воспроизведение

Проверенное окружение — Python 3.12.14, NumPy 2.3.5, SciPy 1.17.0 и mpmath 1.3.0. Запускайте из распакованной папки в обычном режиме Python с включёнными assert. Скрипты используют локальные модули из этой папки. Каждый перезаписывает соответствующий JSON. Доступ к сети для прогонов не требуется.

    sha256sum -c SHA256SUMS
    export OPENBLAS_NUM_THREADS=1
    python donor.py
    python check.py
    python factor_audit.py
    python resolvent.py
    python frame_audit.py

| Программа | Данные на выходе | Что измерено |
|---|---|---|
| donor.py | donor.json | Перепись битовых слов, обмен между портом и узлом, проекторы, поправки старой квантовой монеты |
| check.py | checks.json | Конечный фактор и независимо построенный квадрат, форма на гладких пробах, тёмный луч, два вложения, контроль переноса на именованном ходе |
| factor_audit.py | factor_audit.json | Правильный и ошибочный скачки, остаток формы, полный спектр при N=300, энтропии с повтором при 55 и 75 знаках, независимый контроль теплового следа |
| resolvent.py | resolvent.json | Интегралы ядра Грина, вложенные ступенчатые входы и полное L², влияние обрезания Фурье, вырожденный контакт и развязанные контроли |
| frame_audit.py | frame_audit.json | Оба внедиагональных блока первого порядка, шов, плоская связность, усреднение SU(2), исключение Шура на Q8 |

Случайные пробы детерминированы. В check.py используется seed 132133150, в factor_audit.py — 3, в frame_audit.py — 133150 и 133. Конечные спектры и нормы операторов строятся детерминированно. Числа, полученные средствами BLAS, могут отличаться последними разрядами на другой платформе.
