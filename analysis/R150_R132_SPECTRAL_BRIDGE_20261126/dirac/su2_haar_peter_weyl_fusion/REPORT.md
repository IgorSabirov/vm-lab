**Основные адресаты:** R139 (Haar-рамка и изометрия), R133 (ковариантный перенос и Peter–Weyl), R150 (микроскопический канал обмена и слияние). **Связанные проверки:** R140 (числитель Фешбаха, без нового результата по I₂), R132 (различие фундаментального и присоединённого представлений). ## 1. Haar и проектор Шура

40 000 нормированных гауссовых кватернионов дают элементы SU(2). Максимальные ошибки унитарности и определителя: 5.56·10⁻¹⁶ и 6.68·10⁻¹⁶.

Для фундаментального неприводимого представления:

\[
\mathcal T(B)=\int_{SU(2)}x^\dagger Bx\,dx
=\frac{\operatorname{Tr}B}{2}I_2.
\]

Конечные Frobenius-ошибки Monte Carlo: 0.00946750 для σₓ, 2.22·10⁻¹⁹ для I₂, 0.00946750 для σₓ+I₂/2. Усреднение присоединённого оператора имеет норму 0.00600346, средний фундаментальный вектор — 0.00326178; это конечные оценки нулевых Haar-средних.

**Важная поправка:** точный Haar-интеграл является проектором на коммутант. Эмпирическое среднее по конечной выборке не идемпотентно и не строго инвариантно. Для trace-free теста ||T₁||=0.00742766, ||T₂||=4.66167·10⁻⁵, ||T₂−T₁||=0.00739987. Не записывать конечное np.allclose(T1,T2) как PASS.

## 2. QBP-изометрия и два разных проектора

Положим Bₓ=xσₓx†, P_av — проектор на постоянные по рамке сечения, Q=I−P_av. Поточечно Bₓ†Bₓ=Bₓ²=I. По Haar-инвариантности P_av B P_av=0. Поэтому в точном Haar-пределе

\[
(QBP_{\rm av})^\dagger(QBP_{\rm av})
=P_{\rm av}B^2P_{\rm av}
-P_{\rm av}BP_{\rm av}BP_{\rm av}
=P_{\rm av}.
\]

То есть QBP_av — изометрия. При конечном n=400: ||PBP||₂=0.0391852, ||QBPv||=0.999232, дефект грамовой матрицы 0.00153548. Это не точное конечномерное равенство.

Дополнительный независимый опыт: 100 повторов для каждого размера. Наблюдаемая величина — ||I−(QBP)†(QBP)||₂=||PBP||₂².

| n | Средний дефект | n × средний дефект |
|---:|---:|---:|
| 100 | 0.01013248 | 1.01325 |
| 400 | 0.00276417 | 1.10567 |
| 1600 | 0.00060707 | 0.97131 |
| 6400 | 0.00016712 | 1.06959 |

Для изотропных единичных векторов в R³, E||PBP||₂²=1/n. Данные согласуются с O(n⁻¹), а не доказывают точное равенство при конечном n.

Не смешивать P_av с физическим калибровочным проектором P_G=UP_avU†. В существующем dirac/report.md для ковариантного контакта отдельно доказано (1−P_G)BP_G=0. В данном тесте проверяется именно утечка из постоянного сектора.

## 3. Ковариантный перенос и материальная проба

Для Ψχ(x)=x†χ и Bₓ=x†B₀x:

\[
B_x\Psi_\chi(x)=x^\dagger B_0\chi.
\]

Максимальная ошибка равна 1.49·10⁻¹⁵. Проверка правого переноса рамки даёт 9.39·10⁻¹⁶. Это точное алгебраическое тождество для объявленного действия, численно подтверждённое до машинной точности; оно не доказывает транспорт через слияние, удаляющее отмеченную вершину.

Локальная проба O(A,p)=|η†Ap|² даёт последовательность 1→0→1 при A=I,iσₓ и обратном переносе состояния. Это проверка согласованности состояния и оператора, а не механизм генерации материи.

## 4. Peter–Weyl: один точный канал j=1

\[
f(x)=x\sigma_xx^\dagger\psi
\]

является вектором матричных коэффициентов присоединённого представления SU(2), то есть имеет точную поддержку только при j=1. При соглашении C₂=j(j+1) и генераторах iσₐ/2, собственное значение равно 2; для j=1/2 оно равно 3/4.

При m=1500 обычная all-pairs V-статистика имеет диагональную добавку d_j²/m, d_j=2j+1. Сумма сырых весов 1.059031 не является нормированной вероятностью. После исключения диагональных пар U-статистика даёт:

| j | U-оценка |
|---:|---:|
| 0 | −0.000262 |
| 1/2 | 0.001088 |
| 1 | 1.004826 |
| 3/2 | −0.001706 |
| 2 | −0.000444 |
| 5/2 | −0.004471 |

Сумма 0.999031. Малые отрицательные боковые оценки — статистический шум несмещённого оценивателя, не отрицательные точные спектральные вероятности.

Если кинетический оператор рамки действительно является Casimir с указанной нормировкой и связь имеет образ только в этом j=1-канале, то условная формула самодействия:

\[
\Sigma_{\rm av}(E)=\frac{h^2}{E-2}P.
\]

Это не универсальная формула для произвольного frame Hamiltonian; она требует указанного спектра и ограничения образа связи.

## 5. Слияние двух спинорных каналов: относительная мода

Исправленная модель использует волокна C². Старое пространство имеет каналы (p,v₁,v₂), размерность 6; новое — (p,w), размерность 4, где

\[
w=c_1v_1+c_2v_2,\qquad |c_1|^2+|c_2|^2=1.
\]

Старый оператор B_old связывает порт только с v₁, с амплитудой h. В ограниченном новом анзаце сохраняется только связь p–w. Получено:

\[
h'=hc_1,\qquad
\|QBP\|=h|c_2|,\qquad
(PBQBP)|_p=h^2|c_2|^2I_2.
\]

Для h=1:

| (c₁,c₂) | Остаточная связь | h′ | Feshbach-числитель на p |
|---|---:|---:|---:|
| (1,0) | 0 | 1 | 0 |
| (0.8,0.6) | 0.6 | 0.8 | 0.36 |
| (1/√2,1/√2) | 0.707107 | 0.707 | 0.5 |
| (0.6,0.8) | 0.8 | 0.6 | 0.64 |

Точное переплетение в **ограниченном** анзаце, где относительный канал удалён и остаётся только один эффективный p–w контакт, возможно при c₂=0 (для h≠0). Это не общий no-go для слияния: если относительный канал сохраняется или используется полная энергозависимая Feshbach-резольвента, редукция имеет дополнительный член. PBQBP — числитель/вес; полный self-energy содержит резольвенту относительного сектора.

Проверка только для вещественных неотрицательных c₁,c₂; общий комплексный случай требует явного учёта фаз/перефазировок. Эта модель не утверждает, что коэффициенты cᵢ или h выводятся из ADD.

## 6. Центральный знак Z₂

Для k=iσₓ: k²=−I. Центральный элемент −I действует тривиально в присоединённом представлении, но меняет знак фундаментального спинора. Это показывает, почему чтение только через Ad или квадрат оператора не сохраняет всю информацию о фундаментальном спиноре. Сам по себе глобальный знак вектора не является наблюдаемой; значим относительный знак при сравнении путей/интерференции.

## 7. Ошибки промежуточных вариантов исходного текста

1. Первые варианты fusion смешивали одномерный порт с блоками 2×2: присваивание hI₂ строке размера 2 вызывает ошибку размерностей. Воспроизводится только исправленная модель 6×6/4×4.
2. Первая Gram-формула einsum('ni,ki->ik',...) даёт форму 2×m, не m×m.
3. Первая формула парного следа einsum('nij,nkj->ik',...) даёт 2×2, не m×m. Корректная формула — einsum('iba,kba->ik',...).
4. V-статистика Peter–Weyl включает диагональное смещение; использовать U-статистику без диагонали.
5. Конечное Haar-среднее не является точным проектором.

- **R139:** Haar-рамка, постоянный проектор, QBP-изометрия и конечная оценка утечки.
- **R133:** ковариантное действие на материальном спиноре, Peter–Weyl канал и различие фундаментального/присоединённого представлений.
- **R150:** двухканальный оператор обмена и остаточная относительная мода после слияния.

Не получены физическая величина h, динамика слияния, общий закон переноса при удалении отмеченной вершины, новый индекс поколений или BBN-предсказание. Научная приёмка R132/R133/R139/R140/R150 не повышается. U006 остаётся OPEN.
