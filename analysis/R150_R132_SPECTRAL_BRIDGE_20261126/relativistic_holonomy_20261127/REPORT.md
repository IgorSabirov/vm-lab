## 2. Аналитический механизм R149: первый различающий момент

Δ_p=Tr K_pi^p−Tr K_0^p. При p<N ноль: замкнутый ход не обходит кольцо. При p=N Δ_N=−4N(−J)^N. Для N=6 Δ_6=−20738.555811661688 keV^6. Это для свободного ближайшесоседнего кольца. Для f(K) уже Δ_1=.0014907269737931998613433 keV>0; Δ_2=−.0472560450692444, Δ_3=.919049326979686, Δ_4=−10.7806002008790, Δ_5=17.8081024946776, Δ_6=1530.07320176105 в keV^p.

Доказательство для M,J>0 и фиксированного N≥3:
f(K)=sqrt(M/(2π)) ∫_0^∞ (I−exp(−sK)) exp(−Ms/2) ds/s^(3/2).
D_N(s)=Tr exp(−sK0)−Tr exp(−sKpi)=4N exp(−2Js) Σ_{r≥1 odd} I_{rN}(2Js)>0.
Поэтому Δ_1=sqrt(M/(2π))∫ exp(−Ms/2)D_N(s)ds/s^(3/2)>0. При s→0 D_N=O(s^N), при ∞ экспоненциальный массовый множитель обеспечивает сходимость. Независимая квадратура и прямая сумма согласуются лучше 1e−45 keV. f(K) не ближайшесоседний оператор, хотя K локален; это не новая нелокальная фундаментальная динамика и не новый I₂. Любая положительная смесь тепловых ядер такого типа даёт аналогичный знак при ненулевой мере на s>0.

При фиксированном конечном N, T→∞: C_NR(iso)~4N(J/T)^N/[(N+1)N!]; C_rel(iso)~Δ_1/[(N+1)T]. Для free заменить N+1 на N. Не переставлять пределы T→∞ и N→∞. T_scan в JSON. Это предсказание модели без подгонки, не BBN температурная история.

## 4. R132/R133: массивный первый порядок

Свободная инцидентность A=N(I−S_phi), A†A=K/E*. D_M=[[MI,√(2ME*) A†],[√(2ME*) A,−MI]]. D_M²=diag(M²+2ME*A†A,M²+2ME*AA†). Положительная ветвь −M даёт f(K). Для порта расширить A нулевым блоком, выбрать одну положительную ветвь на кинетическую моду (дополнительное физическое допущение, не число фермионных семейств). Локальное удвоение не доказывает лоренц-ковариантность. Для K+V с отрицательными уровнями факторизация A†A=K+V невозможна без сдвига; физический mass term, домен, порядок включения контакта и проекция OPEN. Сдвиг s внутри f(K+E*sI), с вычетом общего f(E*s) после преобразования, меняет дисперсию: s=−5,0,5,10,20 даёт C×10^6=4.096885,3.409200,2.856180,2.407851,1.740536.
