## 1. Точная функция Грина

N — длина цикла, L=N+1, порт p, twist φ=π, K_N=N²(2I−F−F†). Полный скалярный H_N=K_N⊕(−u)−gN P₀+h√N(|p><0|+h.c.). u,g,h фиксированы при уточнении; величины безразмерны. G_N=N<0|(K_N−E)⁻¹|0>=Σ(λ_j−E)⁻¹, λ_j=4N²sin²((2j+1)π/(2N)), j=0,…,N−1. Вне полюсов k=√E, θ=2 asin(k/(2N)), G_N=tan(Nθ/2)/(2N sin θ). Из det(K_N−E)∝1+cos(Nθ) и G_N=−∂_E ln det(K_N−E) следует точная формула (θ'=1/(2N²sin θ)). Для E<0 гиперболическое продолжение, при E=0 предел. В девяти проверках N=12,48,192 и E=7.820855,50,86.822538 max abs(sum−closed)=8.76e−13.

## 2. Доказательство поправки

t=N⁻², k=√E, T=tan(k/2), S=sec²(k/2). В окрестности простого изолированного корня вне полюсов:
Nθ/2=k/2+k³t/48+3k⁵t²/1280+O(t³);
1/(2N sin θ)=(1/(2k))(1+k²t/8+3k⁴t²/128+O(t³)).
Отсюда G_N=G+t C₂+t² C₄+O(t³), G=T/(2k),
C₂=k²S/96+kT/16,
C₄=(3/2560+1/768)k⁴S+k⁵TS/4608+3k³T/256.
a(E)=g−h²/(E+u), F=1−aG; F_N=F−taC₂−t²aC₄+O(t³).
G'=S/(8k²)−T/(4k³), a'=h²/(E+u)², F'=−a'G−aG'.
При F(e)=0, F'(e)≠0 аналитическая теорема о неявной функции даёт E_N=e+At+Bt²+O(t³). Сравнение коэффициентов:
A=a(e)C₂(e)/F'(e);
B=[a(e)C₄(e)+(aC₂)'(e)A−F''(e)A²/2]/F'(e).
N⁻⁴ теперь подтверждён аналитически, а не только численно. Не применять на E=−u, свободных полюсах и при вырождении без регуляризованной системы.
