## 2. Что именно надо определить

Пусть K_N и D_N безразмерны. Защищённая мода в антипериодическом секторе имеет нечётный волновой номер m, 0<m<N (а не m-й уровень отсортированного спектра):
\[
K_N f_m=\lambda_m f_m,\quad \lambda_m=4N^2\sin^2(m\pi/(2N)).
\]
При квадратичном энергетическом чтении H_phys=E_ref I+E_* K_N:
\[
E_*=\frac{E_3-E_1}{4N^2\sin(2\pi/N)\sin(\pi/N)}
\longrightarrow\frac{E_3-E_1}{8\pi^2}.
\]
J=N²E*. E_ref — конвенция измерительного нуля, а не автоматически абсолютный гравитирующий нуль. Узловые моды тёмные для локального контактного пробника: нужен независимый пространственный/импульсный инструмент.

**Неидентифицируемость абсолютной единицы из чисто безразмерных данных.** Для любого a>0 и b∈R замена H→aH+bI, T→aT (T в энергетических единицах) сохраняет нормированную матрицу Гиббса; отношения энергетических интервалов также инвариантны. Безразмерная геометрия, кратности, индексы, голономии, Haar/Casimir и нормированные тепловые функции не выделяют a. Доказательство: exp(−(aH+bI)/(aT))=exp(−b/(aT))exp(−H/T), общий множитель сокращается. Это препятствие относится к данным без размерного якоря, а не запрет физической калибровки с дополнительным независимым измерением.

Не смешивать три чтения: K (квадратичная пространственная энергия), D (первый порядок), F (унитарный такт). Если физический оператор пропорционален положительной ветви D, защищённые уровни имеют вид E_ref+E_D sqrt(λ_m+s), с согласованным сдвигом s, а не E_ref+E*λ_m. Для временного F требуется независимый физический такт и выбранная ветвь логарифма; фазовый угол не равен пространственному импульсу. Выбор закона дисперсии должен предшествовать извлечению масштаба; два произвольно подогнанных уровня сами по себе не различают модели.

## 4. Единственный критический маршрут закрытия

### SCALE-09 — независимый физический якорь и словарь (OPEN, первый приоритет)

Поиск в корпусе и первичных данных: кандидат должен содержать измеренный или независимо выведенный размерный интервал (с единицами и ошибками) либо физическую длину и массу при обоснованной дисперсии, либо физический такт с генератором. Для каждого донора оформить паспорт: источник и версия, носитель/гильбертово пространство, оператор, измерительный инструмент, фаза, волновое число или проектор состояния, размерность, ковариация, применимость и связь с R150. Сначала внутренние R130/R132/R133/R135/R139/R149/R150 и их доноры; затем первичные данные внешних кандидатов. Сопоставление чисел без словаря не допускается.

Развести уровни закрытия: реальная лабораторная аналоговая модель может закрыть метрологию метода, но не идентификацию космологического X. Для полного PHYSICAL PASS требуется якорь именно заявленного физического носителя R150 либо независимо обоснованное отображение донора на него. Если якорь отсутствует, честный результат NO_ANCHOR_IN_SEARCHED_SCOPE, приложить протокол поиска/отрицательные контроли и оставить физический гейт OPEN.

### SCALE-10 — идентификация закона дисперсии и измерительного канала (OPEN)

До использования энергий объявить K/D/F-ветвь, геометрию, фазы, нормировку, физические единицы и правило выбора мод. Не подбирать закон по двум калибровочным точкам. Проверить узловой характер и независимость от контактов (или доказать/учесть поправки в доноре). Для K-ветви узловые уровни m=1,3 дают E*; хотя бы ещё один независимый интервал/уровень (например m=5, N>5) и/или периодическая лестница дают предварительно объявленный holdout. Нужны реально различающие модели наблюдаемые. В D-ветви использовать соответствующее sqrt(λ+s), с независимо установленным s либо достаточными дополнительными данными. Для переходов учитывать общий уровень отсчёта и правила отбора.

### SCALE-11 — совместная метрология (OPEN)

Новые вычисления, не повторять известную синтетику: полный измерительный вектор и ковариация → E*, E_ref (если определим) → u,g,h² по активным уровням → независимый holdout. Передавать общие систематические ошибки; A C Aᵀ для калибровки, полная совместная ковариация с активными линиями, положительность масштаба, h²≥0, ранги/обусловленность, контроль h=0, профильные интервалы или иной обоснованный статистический метод. Не выдавать старые 12000 реплик при фиксированных безразмерных E*/offset за эту задачу. Порог приёмки и модель ошибок зарегистрировать до вскрытия holdout; например проверка согласованности с заранее заданной ковариацией/систематикой при 95% уровне, с явным указанием числа степеней свободы и мощности. Отдельно сравнить конечную и континуальную формулы на известной сетке, не смешивать физическое расширение с уточнением N.

### SCALE-12 — выход в размерных единицах (OPEN)

Опубликовать измеренный/независимо предсказанный E* (или E_D, τ с отображением) с доверительным интервалом и бюджетом систематик; для K: J(N)=N²E*, U_p=E*u, G=E*g C_X, W=E*h√C_X при условной пространственной модели. Только если известна квадратичная пространственная дисперсия, E*=ℏ²/(2m_X C_X²); одного E* недостаточно, чтобы по отдельности получить m_X и C_X. Указать независимый источник размерной информации; зафиксировать, что именно калибровано, а что назначено. Holdout должен воспроизводиться без изменения масштаба. При отрицательном результате публикуется FAIL/OPEN, а не подбор J по Yp/D/H или целевой фазовой чувствительности.
