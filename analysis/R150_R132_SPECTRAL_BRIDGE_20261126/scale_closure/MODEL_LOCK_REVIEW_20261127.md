## 2. Ансамбли и опорный порт

Аналогично любое точно совпадающее опорное состояние двух ансамблей. Нормированные заселённости без общей энергетической опоры не дают отношение двух Z; отдельные фазозависимые offsets не сокращаются. Port-on может разрушить опору — использовать отдельный port-off режим/проверенную reference либо независимую free-energy measurement, не подставлять произвольные populations. ## 3. Порядок контакта: уточнение дискриминатора

H1=f(K)+V, H2=f(K+V), f(x)=√(M²+2Mx)−M. Для малых V и спектра внутри области sqrt, в eigenbasis K:
(Df_K[V])_ij=f[k_i,k_j] V_ij, f[a,b]=2M/(√(M²+2Ma)+√(M²+2Mb)); при a=b f'(a)=1/√(1+2a/M).
Отсюда модозависимое подавление линейного матричного элемента в H2, а не произвольного конечного расщепления. Для резонансной вырожденной пары с чистым внедиагональным V: Δ_ac(H1)=2|Vij|, Δ_ac(H2)=f'(k)·2|Vij|+O(||V||²); для чистого 2×2 блока точное f(k+|v|)−f(k−|v|). При нерезонансе использовать полный спектр, разделённую разность, detuning и eigenvectors. f' при K/M=.1,.5,1,2,4 = .912871,.707107,.577350,.447214,.333333. При (u,g,h)=(5,5,3) условный contrast H1/H2 3.409199/4.182431e−6 (~22.7%). Предрегистрировать Δ_ac(n,φ), V, M, port-off → port-on, domain, linewidth; forward modeling полезен лишь если реально измерены независимые K,V,M в соответствующем физическом словаре, а не синтезированная квадратнокорневая функция по тем же данным.
