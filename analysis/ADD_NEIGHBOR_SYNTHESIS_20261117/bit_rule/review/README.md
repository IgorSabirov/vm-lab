# Что сохраняет битовое правило C2

У двухканального кольца с ориентацией (+1,−1) шесть одноузловых зарядов и восемь счётчиков соседств образуют полный набор независимых сохраняющихся сумм по ориентированным парам над $\mathbb F_3$ и $\mathbb Q$. При равных значениях всех 14 зарядов длина одной орбиты периодична, у другой растёт без границы. Доказательство и оба входных слова приведены в [исследовательском отчёте](REPORT.md). Численные расхождения в отзывах о переносе поля локализованы в [сверке рецензий](AUDIT.md).

Три битовые постановки, исправленное считывание выходных секторов и нормировка при внесении фазы на первом такте собраны в [пересмотренных результатах](REVISION.md). [Точные значения](revision-results.json) · [Повтор расчёта](revision.py).

## Как повторить

Использовались Python 3.12.14 и версии NumPy, SciPy и SymPy из [requirements.txt](requirements.txt). Из каталога этой страницы выполните команды в рабочей копии репозитория.

```sh
OPENBLAS_NUM_THREADS=1 python replay.py > /tmp/bit-rule-replay.json
diff -u results.json /tmp/bit-rule-replay.json
OPENBLAS_NUM_THREADS=1 python audit.py > /tmp/bit-rule-audit.json
diff -u audit-results.json /tmp/bit-rule-audit.json
```

[Основной расчёт](replay.py) вызывает [классификацию зарядов](ports.py), [геометрию](geometry.py) и [сравнение переносов](transport.py). Поле `C2_pair_certificate.certifying_inputs` в [результатах](results.json) содержит 227 входных слов. [Повторная сверка](audit.py) вычисляет интерференцию по конечным проекторам, сопоставляет её с прямым прогоном и проводит точные проверки регулярных покрытий. Её [машинный вывод](audit-results.json) содержит дроби по каждому событию.

Входы берутся непосредственно из репозитория. Имена и перестройки определены в [движке R130](../../verify.py). Для R140 используются [сырые истории](../../../R140_HAAR_SORKIN/HISTORIES.json) и [оператор перехода](../../../R140_HAAR_SORKIN/verify.py). Сопоставляемая таблица R149 находится в поле `checks.raw` [модели атласа](../../../R149_DEFECT_ATLAS/R149.html). Независимый расчёт восьми шагов использует [движок H6](../../../R141_RIEMANN_CORPUS/donor_replay/previous.py). Исходное состояние этих файлов зафиксировано в [ревизии корпуса](https://github.com/IgorSabirov/vm-lab/tree/4c62eaa7c2f0b04b62b1e1ac362168f14f3bad17).
