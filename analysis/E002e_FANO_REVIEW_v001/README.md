# Разбор рецензии и поиск Фано — E002e

Для чтения и пересылки соседям:

- [RESULT.md](RESULT.md) — выводы из рецензии, новые проверки, границы выводов.
- [CONCEPT.md](CONCEPT.md) — самостоятельный подробный концепт для рецензирования.
- [checks.json](checks.json) — полные числа 20 пар, кривизн, операторных симметрий и вспомогательного контроля Фано.
- [checks.py](checks.py) — воспроизводимые офлайн-проверки; [PLAN.md](PLAN.md) — заранее записанный план.
- [provenance.json](provenance.json) — версии, источники и контрольные суммы.

Новых производственных запусков нет. Точный Фано q=0 подтверждён в явно вспомогательной одноэкситационной двухпортовой задаче с замороженной геометрией m6. Поиск в полном Lindblad-генераторе и связь с условным стационарным током — задачи концепта, а не уже полученные результаты.

## Воспроизведение

Используются Python, NumPy, SciPy и код моделей в этом репозитории, совпадающий по SHA256 с исходниками отчёта. Нужен локальный кэш отчёта E002d_PROD_v003_r001, полученный и проверенный через `infra/github_result_reader.py` при ref `071e15ebc37227b1549e660121bc735a1d86cb13`: `run.json`, `files/metrics.json`, `files/analysis.json.gz`, `files/case_registry.json`. Скрипт дополнительно проверяет их размеры/хеши и хеши четырёх модулей модели.

Из корня репозитория:

```bash
python analysis/E002e_FANO_REVIEW_v001/checks.py /path/to/verified_report_cache
```

Скрипт заново записывает `checks.json`, включая новый замер времени. Его исходный опубликованный результат нужно сравнивать на закреплённом коммите. Проверяется алгебра генераторов, а не проводится новая эволюция.
