# Условия расчёта до запуска
Первичный источник R140 — архив предыдущего опыта, исходное слово (1,2,0), θ=π/4, логический срез после первой отметки. Сохраняем отметку на втором шаге. Единственное конечное наблюдение — длина. Время t=1…8. Эталон на t=8 уже известен, результаты при промежуточных t — поисковые. Сравнить точные ранги и возможные потери. Проверить изометрию логического вложения на каждом шаге.
R132 — ориентированное циклическое слово, d=target−source, binary alphabet, длины 2…8, с точностью до циклического начала. Для открытого перехода брать K=(P₁ d P₁)(P₁ d P₁)*. Сравнить det(I+K) для слов с одинаковыми всеми одношаговыми секторными следами. Предсказание для разбиений серий 3+1 и 2+2 при одинаковых парных частотах — 26 и 25. Негативные контроли — полный набор степенных следов и зеркала. Минимальную длину искать полным перебором.
Парсеваль — прямой подсчёт нулей Q=Σx_i x_(i+1) и суммирование по чётным координатам на F_p, p=3,5,7, k=2…6. На R140 вычислить преобразование Уолша по 8 битам действий stay/flip (idle кодируется 0), без промежуточного маркера, сверить для каждого выхода с полной записью пути и прямой динамикой со знаками. Предсказание для №19 — средний вес 1/64.
Цена — построить J=∂q/∂(x,y,z) на t=8. Для специально заданного симметричного канала, который с вероятностью 0.1 заменяет длину равномерной из 1…5, проверить сокращение контрастов за m шагов. Инверсия должна обеспечивать ошибку координат ≤0.1 при ограничении евклидовой ошибки частот 0.0005. Получить точный ранг, сингулярные числа, последнюю допустимую целую длину m. Нулевой контроль — полная замена. Для равновероятных приготовлений ±Y отдельно вычислить информацию Шеннона одного отсчёта длины, условно на одинаковые локальные матрицы. Это проверка считывания, не генезиса Θ.
Эти условия записаны до запуска новых вычислений, после предыдущего исследования R140/H6. Это локальный протокол, без внешней временной регистрации.
