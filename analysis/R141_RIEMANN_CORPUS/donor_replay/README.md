# Alpöge–Claude, R132 и R140

Стартовая точка — REPORT.md. DESIGN.md содержит условия испытаний до их запуска. Снимок состояния независимых аудитов относится к 22 ноября 2026 года. Для пяти итоговых Lean-утверждений в lean_sources.json приведены адреса первичных файлов и Git blob SHA. Полный проект Lean для повторения четырёх конечных опытов не требуется.

Команды из этого каталога (Python, NumPy, SymPy):

    python experiments.py > replay.json
    python followup.py > replay_followup.json
    diff results.json replay.json
    diff followup.json replay_followup.json

Версии окружения для побайтового сравнения чисел с плавающей точкой — NumPy 2.3.5, SymPy 1.14.0. Истории и алгебраические проверки точны. Только информация Шеннона, сингулярные числа и значения нормы погрешности представлены десятичными приближениями.

Результаты A находятся в ports и time; B — binary; C — quadric и walsh; D — cost. В строках quadric стоят p, число переменных, ранг билинейной формы, число решений для значений 0 и 1 и сумма нетривиального характера. В binary.by_length — длина кольца, число циклических классов и число классов одношаговых частот, внутри которых определитель различает слова. В followup.json сохранены эффекты каждой пары длин, детерминант при частичной промежуточной записи и случаи арифметической делимости. В следовой таблице нумерация шагов начинается с единицы, нумерация выходов графа — с нуля. Измерение в момент 7 для дополнительного контроля — измерение длины с сохранением суперпозиций внутри её сектора.

Для R140 использованы HISTORIES.json из analysis/R140_HAAR_SORKIN на ревизии 7a797cbe6f834d0e723b0af00a66227b4a0191c4 репозитория IgorSabirov/vm-lab, опубликованный графовый движок и вспомогательные функции предыдущего воспроизводимого разбора H6. Проверка R132 использует d=T−I и тот же именованный движок.
