## Гипотеза Римана, Гильберт–Пойа и Конн

Арифметический вход даёт явная формула Гинана–Вейля. Операторный вход даёт семейство дзета-троек Конна–Консани–Московичи. В R132 оба кольца удовлетворяют конечной теореме Конна–ван Сёйлекома после циклического усреднения. В этот момент они становятся одной и той же матрицей, хотя до усреднения разность детерминантов равна $t^3$. В R140 три взвешенных чтения конечной длины восстанавливают три координаты состояния. Запись длины на седьмом шаге понижает их ранг до двух. [Генеалогия, сравнение доноров и доказательства](HILBERT_POLYA.md).

Для двух гауссовых тестов интервальная проверка подтверждает остаток меньше $10^{-30}$. Для произведения в точке $z=1$ порог $10^{-3}$ впервые достигается на 596 положительных нулях при абсолютной ошибке и на 617 при относительной. [Числа, нормировка и хвосты](spectral/ARITHMETIC.md).

**Пять выходов.** Для состояния с координатами Блоха r=(x,y,z) измеренные длины имеют вид 256q=a+Br. Строки [a | B] в порядке длин 1…5 равны (31,0,−4,−19), (51,−4,−4,1), (64,4,8,−8), (70,0,0,2), (40,0,0,24). Они восстановлены из 92 историй. Для произвольной предъявленной таблицы q необходим и достаточен следующий тест.

1. Проверить сумму пяти чисел, равную 1, и тождество 96q₄−8q₅=25.
2. Вычислить z=(32q₅−5)/3, y=(31−256q₁−19z)/4, x=(51+z−256q₂)/4−y.
3. Проверить x²+y²+z²≤1. Подстановка возвращает все пять чисел, включая q₃ по нормировке. Шар даёт положительность всех эффектов и вероятностей. Контроль r=(1,1,0) даёт пять положительных нормированных чисел, удовлетворяющих линейному тождеству, но описывающих невозможное приготовление.

При классической рандомизации только первого шага доступны точно отрезок между этими состояниями и интервал q₁ от 3/64 до 31/256. Кинематический минимум по шару меньше 3/64. Возможности более богатого управления и самоподготовки должны быть исследованы на своём множестве траекторий. [Прямое вычисление](reproduce.py).

**Дополнительная степень свободы.** Прибор E⊗I сохраняет старую нижнюю границу даже для запутанного состояния с окружением. Для предложенного четырёхмерного евклидова шара и коэффициента −αw условие достижимости 10/256 равно |α|≥8. При |α|=8 предъявлен *весь* нормированный набор из пяти положительных эффектов на двух кубитах. В конструкции Γ=(X⊗I,Y⊗I,Z⊗Z,Z⊗X). Старые коэффициенты умножаются на первые три Γ, столбец для четвёртой Γ равен (−8,8,0,0,0)/256. Сжатие на вспомогательное |0⟩ возвращает каждый старый эффект. Состояние (I+(4Γ₂+19Γ₃+8Γ₄)/21)/4 достигает q₁=5/128. Другой прибор реализует ту же таблицу в размерности три добавлением одного ортогонального флага и скалярных эффектов на этом флаге. Данные расширенной таблицы допускают разные физические реализации. В исходном опыте необходимость расширения отсутствует. [Обе реализации](CHECKS.json).

<a id="schedule"></a>

**Смена расписания и запись.** Пара путей A и B к графу №19 задана двумя полными историями длины. Для каждого из 256 расписаний сохранены метки событий, амплитуды обеих историй, комплексное скалярное произведение, μ(A), μ(B), I₂, P₁₉ и контрольный P₄. Это двухпутевой опыт без промежуточного маркера. Тела классов историй заданы общей последовательностью проекторов на длину, с переходом выбранного расписания между соседними проекторами. Амплитуды в файле — их действие на фиксированный вход. При 00000000 оба плеча исчезают. При 11111111 веса плеч равны 1/128 и I₂=−1/64. Оба расписания дают P₁₉=0. По всем расписаниям с равным весом получаем 765/16384. Общий конечный проектор при разных динамиках может иметь разные эффекты Uₛ†EUₛ на входе. Для независимо выбранного расписания и общей подготовки работает средний эффект ΣwₛUₛ†EUₛ; при корреляции приготовления с расписанием усредняются пары (ρₛ,Eₛ). [Все 256 строк](SCHEDULES.json).

При одинаковых локальных матрицах графа и регистра два совместных состояния в опыте с общей дальнейшей динамикой дают полную вариацию будущих графовых распределений 1/32. В опыте с противоположными фазами ±π/2 она равна 1/16. Замена координат описания вместе с операторами сохраняет вероятности. Физическое усреднение фаз при фиксированном приборе меняет состояние. В опыте с чтением только длины восьмого шага ранг матрицы эффектов равен 4 с учётом нормировки. Фактическая запись длины на седьмом шаге понижает ранг до 3 даже при сохранении обоих показаний. При вероятности промежуточной записи η один точный минор равен 25(η−1)/4194304. [Данные о маргиналях и фазе](review/evidence.json) · [ранги и минор](donor_replay/followup.json).
