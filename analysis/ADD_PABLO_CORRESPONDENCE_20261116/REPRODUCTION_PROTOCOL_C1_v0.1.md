## 2. Нормативная спецификация C1

### 2.1. Состояние и граф

Каждая вершина C1 несёт два бита a(u),b(u)∈{0,1}, по одному на порт a,b. Кольцо конечное, непустое, с ориентированными портовыми рёбрами. Для нумерации:
u_i:b → u_(i+1):a, индексы по модулю L.

Каждый порт используется ровно один раз; граф удовлетворяет алгебре имён и A1 из Definition 8–9. Состояние графа — не только циклическое слово битов: хранятся имена вершин, разложения/слияния имён, портовые рёбра и внутренние состояния.

Вырожденные кольца L=1,2, если они дают петли или кратные рёбра, обрабатываются отдельно. Их нельзя молча включать в класс обычных простых циклов. Основной exhaustive suite начинается с минимального размера, для которого выбранное представление удовлетворяет графовым аксиомам.

### 2.2. Алгебра имён

Реализовать термы:
- атомы;
- u.l, u.r;
- u∨v.

Обязательные равенства:
(u∨v).l=u; (u∨v).r=v; u.l∨u.r=u.

Проверять A1: активные имена не должны иметь запрещённых пересекающихся потомков в смысле Definition 9. Нельзя заменять точные имена индексами или факторизовать по вращению до проверки графовых равенств.

### 2.3. Полусдвиг Q_A — авторски разъяснённая версия

Для каждого старого ребра u_i:b→u_(i+1):a создаётся новая вершина:
w_i=u_i.r∨u_(i+1).l.

Новые рёбра:
**w_i:b→w_(i+1):a.**

Биты:
**a(w_i)=a(u_(i+1)); b(w_i)=b(u_i).**

Правила применяются поканально, если позже будет добавлено расширение числа битов. Первый нормативный запуск — только C1.

### 2.4. Полный транспорт τ

τ перемещает частицу каждого типа по соответствующему порту на полное ребро. При выбранной ориентации:
a'_i=a_(i+1), b'_i=b_(i−1).

Эталон τ задаётся отдельной функцией, не вычисляется через Q_A. Иначе тест Q_A²=τ станет тавтологией.

### 2.5. Взаимодействие I

Реализовать буквально Definition 3:
- split вершины с a(u)=b(u)=1 на u.l,u.r, с частицами на соответствующих дочерних портовых позициях;
- merge соседней back-to-back пары u,v, где a(u)=1, b(v)=1, b(u)=0, a(v)=0, в u∨v.

Условия применимости, одновременность локальных правил и граничные случаи должны быть явно закодированы. I не должен использовать скрытый порядок обхода списка вершин для выбора rewrite. Непересекающиеся редексы применяются одновременно; потенциально пересекающиеся случаи отдельно классифицируются и сверяются с Definition 3/Fig. 2(b).

Контракт: I²=Id.

### 2.6. Полный и обратный шаг

Зафиксировать порядок композиции:
F=Q_A∘I.

Тогда:
F⁻¹=I⁻¹∘Q_A⁻¹=I∘Q_A⁻¹, если I²=Id.

Порядок применения всегда писать явно.

## 7. Фаза 3 — Lemma 1 (merger instability)

Это первый научный гейт, не сводимый к проверке кода.

Merger pattern — соседние вершины u,v, для которых:
a(u)=1, b(v)=1, b(u)=0, a(v)=0.

Lemma 1 утверждает: для любого такого паттерна в X∈C1 существуют вершины u.r,v.l∈V(F⁻¹(X)), которые также образуют merger pattern.

Порядок:
1. Переписать доказательство по Fig. 5 в локальную алгебру для P и A отдельно.
2. Для каждого локального входа вычислить точный F⁻¹, не только Q⁻¹.
3. Проверить соответствующую пару u.r,v.l с точными именами, портами и битами.
4. Перебрать все локальные окрестности, достаточные для паттерна и его обратного образа, включая внешние биты и конфликтующие соседние мотивы.
5. Сопоставить перебор с общим алгебраическим выводом. Перебор не заменяет доказательство для произвольного графа.

Статусы:
- LEMMA1_PROVED_FOR_A — общее локальное доказательство для авторской спецификации;
- LEMMA1_FINITE_ONLY — конечный перебор прошёл, общего доказательства нет;
- LEMMA1_FAIL_A — найден точный контрпример; Theorem 1 не переносится автоматически.
Аналогичные статусы для P.

При FAIL не подгонять I, не менять определение паттерна и не переориентировать кольцо без отдельного источникового основания.

## 8. Фаза 4 — Theorem 1 и Appendix B

Переходить сюда только при общем доказательстве Lemma 1 для рассматриваемой спецификации.

Theorem 1: для любого X∈C1, содержащего хотя бы одну частицу каждого типа:
|V(Fⁿ(X))|=Θ(√n).

Восстановить структуру Appendix B, не заменяя её фитированием конечной трассы:
1. n_f(X) — число merger patterns.
2. d_f(X) — минимальное расстояние от merger pattern до частицы, движущейся к нему, с оговорками статьи.
3. Показать строгое лексикографическое уменьшение пары (n_f,d_f).
4. Из Lemma 1 вывести, что новые merger patterns не возникают, а столкновение уничтожает паттерн.
5. Получить конечный момент m, после которого новые слияния не происходят.
6. После m каждое collision создаёт дополнительную вершину.
7. Использовать оценку числа столкновений c=2 n_a n_b и восстановить неравенства Appendix B (B1)–(B16).
8. Получить нижнюю и верхнюю оценки размера порядка √n.

Для A все шаги выводятся заново. Доказательство для P не является доказательством для A.

### Численная проверка

Для выбранных X с n_a,n_b≥1 сохранять траектории:
(|V(FᵗX)|, n_f, d_f, #split, #merge).

Проверять следствия доказательства: отсутствие новых merger patterns после соответствующего момента, конечность числа слияний, рост размера после последнего слияния. Конечный фит не объявлять доказательством Θ(√n).

Если Lemma 1 доказана, а конечная трасса кажется противоречащей ей, отдельно расследовать реализацию, наблюдаемую и горизонт; доказательство и контрпример сохранять раздельно.

## 10. Фаза 6 — энтропийные следствия

Использовать определение статьи:
S'(X)=log binom(2|V(X)|,p(X)),
где p(X) — общее число частиц.

Проверить:
- Corollary 1: при прямом росте Θ(√n), S'(FⁿX)=Θ(log n);
- Corollary 2: аналогичный порядок в обратном направлении;
- Theorem 2: общую связь роста размера и энтропии при оговорённых ограничениях плотности.

## 11. Фаза 7 — локальная энтропия и thermal death

После закрытия ядра воспроизвести:
S_r(X)=(1/|V(X)|) Σ_u S(X^r_u).

Проверить Theorem 4:

Это относится к определению локальной энтропии фиксированного радиуса в статье, не универсальное утверждение о любой физической локальной структуре.

## 16. Критерии завершения и STOP

### Успех воспроизведения оператора
- G1–G4 PASS;
- Q_A²=τ на именованных графах;
- TQ_AT=Q_A⁻¹;
- независимые реализации совпадают на объявленном конечном наборе.

### Успех воспроизведения основной теоремы
- общее доказательство Lemma 1 для A;
- Appendix B восстановлено для A;
- Theorem 1 выведена без конечного численного фитирования;
- конечные трассы согласуются со структурными следствиями доказательства.

### Немедленный STOP
- неоднозначность локального правила;
- нарушение A1 или портовой связности;
- Q_A²≠τ;
- несохранение частиц;
- неинволютивность I;
- расхождение независимых реализаций;
- контрпример Lemma 1 для A;
- превышение лимита без пересмотра плана.

При STOP сохранить точный вход, полный граф, минимальный контрпример, SHA кода и этап обнаружения. Не исправлять тест под желаемый ответ.
