## Проверенные утверждения

### 1. Конечная унитарная система: вечная монотонность

Для конечномерного постоянного H=H† и rho(t)=U_t rho(0) U_t† существуют t_n→∞ с rho(t_n)→rho(0): конечный набор энергетических фаз возвращается сколь угодно близко к исходному. Если непрерывная F(rho(t)) не убывает на всей полуоси, для любого фиксированного t≥0:

`F(rho(0)) ≤ F(rho(t)) ≤ F(rho(t_n)) → F(rho(0))`.

Значит, она постоянна. Обращение времени как отдельная симметрия H не требуется. Энтропия фиксированной конечной подсистемы является непрерывной функцией полного состояния, поэтому тоже подчиняется этому запрету при условии монотонности на всей полуоси.

Добавление конечного автономного организатора внутрь той же замкнутой системы сохраняет предпосылки. Поэтому этот результат ограничивает A, B и C одинаково. Он не может сам по себе быть доказательством «A невозможно, C спасает стрелу».

Контрпример к запрету всякого роста: H=g X⊗X, начальное |00>, S_A(t)=h₂(sin²(gt)). Энтропия возрастает от 0 до 1 бита на [0,π/(4g)] и затем убывает. Это конечный эпизод роста при заданной подготовке; происхождение подготовки и внутренние причинные записи пример не объясняет.

### 2. Инвариантная вероятностная мера: уточнение гипотез

Пусть каждое T_t сохраняет вероятностную меру μ, F измерима и конечна почти всюду, а на одном общем множестве меры 1 вся траектория F(T_t x), t≥0, не убывает. Берём G=arctan F. Для каждого рационального q≥0 приращение G(T_q x)−G(x) неотрицательно и имеет нулевой интеграл. Следовательно, оно равно нулю почти всюду. Счётное пересечение даёт общее множество для всех рациональных q. Монотонность на всей вещественной полуоси зажимает значение в любой вещественный момент между равными рациональными значениями.

Вывод: F(T_t x)=F(x) для всех t≥0 на одном множестве полной меры. Интегрируемость самой F и непрерывность орбит не нужны при указанных сильных кванторах. Если сравнение задано только «для каждого t почти всюду», нельзя без дополнительных условий переставить «для каждого t» и «почти всюду».

Мера должна относиться к исследуемому распределению состояний. Дельта-мера на неподвижной точке ничего не запрещает для остальных состояний. Отсутствие подходящей инвариантной вероятностной меры означает неприменимость этой леммы, а не доказательство организатора.

Проверен пример сдвига U_tψ(x)=ψ(x−t): F(U_tψ)=∫_{−t}^∞|ψ(y)|²dy не убывает для любого нормированного ψ. Здесь H=P имеет спектр R, движение вправо и выбор полупрямой заданы конструкцией. Это не термодинамическая энтропия и не модель происхождения внутренних записей; но это контрпример универсальному запрету монотонного наблюдаемого во всех замкнутых унитарных системах. Неограниченность P снизу описывает этот пример, не доказывая, что всякая бесконечная система с ограниченной снизу энергией обязана быть рекуррентной.

### 3. Симметрия закона историй: ограничение ансамблевого вывода

При Θ_*P=P и ковариантном наблюдении ΓΘ=θΓ получаем θ_*(Γ_*P)=Γ_*P. Отсюда среднее любого интегрируемого нечётного маркера равно нулю. Это доказательство относится к распределению историй, а не к отсутствию стрелы в каждой истории.

Смесь (P₊+Θ_*P₊)/2 показывает логическую совместимость симметричного закона и противоположно ориентированных ветвей. Она сама по себе ещё не строит физическую систему с самоподдерживающимися записями: такие истории и их реализация должны быть отдельно определены и построены. Отмена среднего после симметризации поэтому не является универсальным тестом «физика или артефакт».

Для произвольного P и ковариантного Γ верно:

`D_KL(Γ_*P || θ_*Γ_*P) ≤ D_KL(P || Θ_*P)`.

Проверка: положим R=Θ_*P и f=dP/dR. При наблюдении Γ плотность выходного закона относительно Γ_*R задаётся условным ожиданием f по наблюдению. Выпуклость u log u и неравенство Йенсена дают обработку данных; ковариантность отождествляет Γ_*R с θ_*Γ_*P. Если правая дивергенция бесконечна, верхняя оценка может не нести информации. Для стандартных измеримых пространств тот же аргумент проходит через совместное распределение со стохастическим ковариантным ядром.

Условный выбор одной ориентации меняет входной закон. Нельзя применить прежнюю оценку к отобранной ветви так, будто условие не вводилось. Аналогично, асимметричное наблюдение, нарушающее ковариантность, выходит за предпосылки указанного неравенства.

## Следующий предмет доказательства

Сначала задать независимо:

- класс C замкнутых систем, разбиение, допускаемые приготовления и правило построения историй;

После этого цель имеет честную форму: для всех моделей выбранного C доказать D_T⇒M либо предъявить модель C с D_T и ¬M при тех же условиях. Если M означает любое правило или взаимодействие, режим A исчезает по определению — такой результат не отвечает исходной исследовательской цели.

Граничные условия могут быть эффективным описанием влияния остальной системы.
