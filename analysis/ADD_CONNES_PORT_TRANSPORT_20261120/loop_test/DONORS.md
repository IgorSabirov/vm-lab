## 1. Спиновая сеть на фиксированном графе

Grzegorz Czelusta и Jakub Mielczarek исследуют четырёхвалентные сети со спином рёбер `j = 1/2`. Эталон первого сравнения — диполь из двух узлов и четырёх соединяющих их рёбер. В базисе двух интертвинеров каждого узла авторское нормированное состояние имеет компоненты `(1,0,0,1)/√2`. Тест воспроизводимости должен сохранять порядок рёбер, базис и относительную фазу. В коде авторов величина `fidelity` для диполя — модуль перекрытия векторов. При сравнении с величиной, определённой как квадрат модуля, это соглашение необходимо учесть. [Статья](https://arxiv.org/abs/2304.03559) · [Репозиторий и MIT LICENSE на проверенной версии](https://github.com/Quantum-Cosmos-Lab/Ising-spin-networks/tree/05c4fc0574a185262bccca1e0489053bba96a724)

Проверка файла на закреплённом коммите дала 74 уникальных базисных метки, 74 ненулевых амплитуды и сумму квадратов 0.9999999999999998. Первая амплитуда, для метки `0000000000`, равна 0.3049339225225648. SHA-256 файла — `688c9ecd56a2186c1556b0efebc110268e5df037daba8fb0705de8e2d0d32a1f`. Для проверки достаточно стандартного Python из корня донорского репозитория.

```python
import csv
from math import fsum

with open("deka.csv", newline="") as data:
    rows = csv.reader(data)
    next(rows)
    amplitudes = {}
    for bits, amplitude in rows:
        label = "".join(bits.split())
        assert len(label) == 10 and set(label) <= {"0", "1"}
        assert label not in amplitudes
        amplitudes[label] = float(amplitude)

assert len(amplitudes) == 74 and all(amplitudes.values())
assert abs(fsum(a*a for a in amplitudes.values()) - 1) < 1e-12
```

Блокноты Python просмотрены, целиком в этом аудите не исполнялись. Готовый вектор и диполь позволяют независимо проверить чтение амплитуд и соглашения базиса. Получение этого вектора средствами ADD или спектральной тройки потребует отдельно задать отображение состояний.

Эта же группа опубликовала следующий пакет о голономиях SU(2). В нём находятся `BlockDefinitions.py` с реализацией тензорных блоков, `BlocksTests.ipynb` со сравнением с аналитическими тензорами и `Pentagram.ipynb` с примером сети. На закреплённой ревизии в дереве нет отдельного LICENSE. Использовать как источник соглашений и внешних сравнений. Условия копирования исходника следует уточнить отдельно от лицензии первого репозитория. [Статья](https://doi.org/10.1103/PhysRevD.111.066012) · [Репозиторий](https://github.com/Quantum-Cosmos-Lab/Tensor-network-representation-of-Ising-spin-networks/tree/0891baf7f30ce4137744132bc4fd20798b4ca46e)

## 2. Изменение графа

Thiago L. M. Guedes, Guillermo A. Mena Marugán, Markus Müller и Francesca Vidotto публикуют код канонической LQG. Точная ссылка стоит под №55 в подробной работе. Раздел `More results` содержит входные спиновые метки, состояния после одного и двух действий ограничения `Const4`, оператор объёма `VolOb2` и скалярные произведения `InProd`. Это прямой кандидат для будущего сравнения того, что происходит с наблюдаемой при перестройке. Физический шаг под действием ограничения и описание того же состояния на более мелком графе — разные операции. Сопоставление с шагом ADD потребует выбора операции и наблюдаемой с обеих сторон. [Статья, разделы VII–IX и ссылка 55](https://doi.org/10.1103/hjdk-kdhk) · [Краткая публикация той же группы](https://doi.org/10.3390/universe11120387)

В репозитории один файл `GC_canonicalLQG.nb`, созданный в Mathematica 13.1. В нём есть исходные ячейки, конкретные входы и сохранённые ответы. По исходному тексту сверены пары `In/Out` из раздела `More results`.

| Авторское выражение | Сохранённый результат |
|---|---|
| `InProd[Volss0compN, ss0compN]` (91) | `2^(-1/4)` |
| `InProd[Volss0compN, ss1compN]` (92) | `0` |
| `N[InProd[Volss0compN, ss2compN]]` (94) | `5.636811087512063 + 0. i` |

SHA-256 блокнота — `3daed69a623d1196905a02dd77d05b25299e7f0620daaca6d0d8c9e9053dbe08`. В доступном дереве нет отдельного набора CSV и лицензии на код. Часть крупных выводов Mathematica сохранена как сокращённое представление. Первым эталоном для повторения служат явно сохранённые скаляры. В этом аудите ядро Wolfram не запускалось. Для интеграции в Python возможна сверка самостоятельной реализации по формулам статьи с этими числами. [Авторский блокнот](https://github.com/ThiagoLMGuedes/Canonical_LQG/blob/03f789295d92e60ae18bf1745aafd6239a7cbf83/GC_canonicalLQG.nb)

## 3. Ковариантная LQG и спектральная геометрия

Для ковариантных амплитуд есть независимый от двух предыдущих групп источник. Francesco Gozzini предоставляет библиотеку `sl2cfoam-next` на C с интерфейсом Julia, лицензией LGPL-3.0-or-later и тестом `test/lib_test.c`. Pietro Donà и Pietropaolo Frisoni предоставляют блокноты `VertexComputation.ipynb`, `VertexContraction.ipynb` и численные амплитуды в CSV и JLD2. В проверенной таблице при `γ=0.1, j=0.5` содержится 16 строк для отсечки от 0 до 15 и две колонки для интертвинеров 0 и 1. Первая строка содержит 4.812467345775396e-21 и 3.876803037456568e-20. Файл разделён табуляцией и читается без сборки библиотеки. Собственная лицензия репозитория с таблицами не указана отдельным файлом. Это резерв для вопроса об амплитуде спиновой пены. [Библиотека](https://github.com/qg-cpt-marseille/sl2cfoam-next/tree/052e4346028870bd76f69a3034e6cae8defb8f7f) · [Авторская таблица](https://github.com/PietropaoloFrisoni/HowToSpinFoamAmplitude/blob/4fa7e31ffc6553e56da94a443a53a4059a5d2035/Delta_4_ampls/Immirzi_0.1/j_0.5/CSV_format/Delta_4_ampls_Dl_max_15.csv) · [Статья](https://doi.org/10.3390/universe8040208)

Для оператора Дирака на пространстве связностей источником остаётся работа Johannes Aastrup, Jesper M. Grimstrup и Ryszard Nest. В просмотренных источниках не удалось подтвердить авторский репозиторий с исполнимым оператором и контрольными значениями. Найденные пакеты дают вычислительную сторону петлевой теории. Данные для прямого сравнения операторов Дирака на вложенных графах пока остаются открытыми. [On Spectral Triples in Quantum Gravity I](https://arxiv.org/abs/0802.1783) · [On Spectral Triples in Quantum Gravity II](https://doi.org/10.4171/JNCG/30)
