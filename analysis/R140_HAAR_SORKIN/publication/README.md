## Проверка

Из каталога распакованного ZIP установите версии библиотек и запустите команду. Без сетевого доступа она проверяет манифест, температурную реконструкцию, GLS, межобъёмный контраст и все 4186 пар историй.

~~~bash
python -m pip install -r analysis/R140_HAAR_SORKIN/publication/requirements.txt
python analysis/R140_HAAR_SORKIN/publication/replay.py
~~~

Для повторного считывания исходных EPS и PDF, воспроизведения статистической карты и полной динамики R140 задайте параметр ниже. Программа сверяет контрольные суммы внешних входов перед использованием. Для автономного повтора доступны --source-dir для трёх авторских файлов и --donor-checkout для локального экземпляра исходных вычислительных модулей.

~~~bash
python analysis/R140_HAAR_SORKIN/publication/replay.py --fetch-sources
~~~

Для повторной сборки запустите build.py с тремя аргументами: каталогом версии R136, каталогом версии R140 и именем выходного ZIP. Реестр INVENTORY.json позволяет установить, из какой ветки и файла получена каждая запись. Сведения о пределах проверки исследовательских сценариев сохранены в EXTENDED_CHECKS.json. Научный статус R136, U013 и R140 остаётся открытым.
