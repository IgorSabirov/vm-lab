# 3. Тёмный сектор и доступ: не «слабый сигнал», а нуль канала

Из `Расширение.txt`, `B4.txt`, `Причина.txt` и `Релятивизм.txt` тёмный сектор определяется не как «мало видно», а как **нулевое направление канала**.

Для спектрального канала:

\[
\boxed{
D_{\mathcal V}(L)
=
\operatorname{Inv}(H_{\mathrm{tot}})
\cap
\ker \mathcal V^\dagger(L)
}
\]

Для канала доступа наблюдателя:

\[
\boxed{
D_{\mathcal W}(L)
=
\operatorname{Inv}(H_{\mathrm{tot}})
\cap
\ker \mathcal W^\dagger(L)
}
\]

С проектором:

\[
P_D^2=P_D,
\qquad
[H_{\mathrm{tot}},P_D]=0,
\qquad
\mathcal W^\dagger P_D=0.
\]

Ключевое:

\[
\boxed{
\text{dark}\neq \text{weak signal}
}
\]

Состояние может быть полностью нормированным:

\[
\|\psi_D\|=1,
\]

но недоступным:

\[
P_{\mathrm{obs}}\psi_D=0.
\]

---

## 3.1 Доступ как операторная геометрия

Наблюдатель имеет не весь инвариант, а канал чтения:

\[
\boxed{
K = \mathcal W_{\mathrm{obs}}\,U_T\,\mathcal E
}
\]

Первичен не скаляр \(p\), а оператор:

\[
\boxed{
M_C = L_C^\dagger L_C
}
\]

Из него:

\[
\bar p_C = \frac{\operatorname{Tr}M_C}{d_V},
\]

\[
\kappa_C = \frac{\lambda_{\min}(M_C)}{\lambda_{\max}(M_C)}.
\]

И обязательно разделять:

\[
\boxed{
\text{probability loss}
\neq
\text{coherence loss}
}
\]

Можно потерять вероятность в недоступный канал, но сохранить логическую когерентность.

Также из `Релятивизм.txt` важно дисциплинарное ограничение:

\[
\boxed{
P_D\text{ нельзя получать как top-k support}
}
\]

То есть тёмный проектор не должен строиться эвристически «по самым большим амплитудам». Он должен следовать из ядерной/инвариантной структуры канала.

# 4. Стоимость границы: главный новый слой из `Цена границы.txt`

Теперь к спектральному ядру добавляется **стоимостная геометрия сохранения различия**.

Вводятся контактные наблюдаемые:

\[
\boxed{
\Phi(w)=(\kappa,\Delta,p)
}
\]

где:

- \(\kappa\) — связь / живость контакта;
- \(\Delta\) — различие / неслиянность путей;
- \(p\) — проходимость контакта.

В игрушечной модели:

\[
\kappa = |g t_1 t_2|,
\]

\[
\Delta =
\left|
g-\frac{t_1t_2}{z-E_1}
\right|,
\]

\[
p=|G_{02}|^2.
\]

Здесь \(g\) — прямой путь \(\gamma\), а \(t_1t_2/(z-E_1)\) — косвенный путь. Значит \(\Delta\) — мера интерференционного различия между маршрутами.

---

## 4.1 Локальная выходная достижимость, но не полная управляемость

Якобиан:

\[
J=\frac{d\Phi}{dw}
\]

в рабочей точке имеет полный строковый ранг:

\[
\boxed{
\operatorname{rank}(JJ^\top)=3
}
\]

Но это означает только:

\[
\boxed{
\text{локальная выходная достижимость }(\kappa,\Delta,p)
}
\]

а не полную управляемость исходной динамической системы.

Особенно важно, что в расчётах использовалось:

\[
A=0,
\qquad
B=I.
\]

При такой постановке управление весами задано почти напрямую. Поэтому корректный статус:

> система локально различима по трём контактным координатам, но это ещё не доказательство динамической достижимости бассейна выхода \(B_{\mathrm{exit}}\).

---

## 4.2 Анизотропия: \(\Delta\) — мягкое/дорогое направление

Относительный выходной грамиан:

\[
M=J_nJ_n^\top,
\qquad
J_n=DJ,
\qquad
D=\operatorname{diag}(1/|y|)
\]

имеет сильно различающиеся собственные значения. Примерно:

\[
\lambda\approx (7009,\;12.36,\;1.139),
\]

то есть обусловленность:

\[
\frac{\lambda_{\max}}{\lambda_{\min}}
\sim 6\times 10^3.
\]

Мягкое направление почти совпадает с осью \(\Delta\):

\[
v_{\mathrm{soft}}
\approx
(0.364,\,-0.931,\,0.016).
\]

Угол мягкого направления к оси \(\Delta\):

\[
\boxed{
21.4^\circ
}
\]

а к оси \(\kappa\):

\[
68.6^\circ.
\]

Жёсткое/дёшевое направление почти совпадает с осью \(p\):

\[
99.9\%.
\]

Интерпретация:

\[
\boxed{
\Delta\text{ — геометрически выделенная, трудноуправляемая координата}
}
\]

Но важно не путать:

1. **произвольно двигать/удерживать \(\Delta\)** становится дороже;
2. **целенаправленно уничтожать \(\Delta\)** по merger-пути может становиться дешевле при росте связи.

Это двухкоординатная геометрия:

\[
\boxed{
\kappa\uparrow
\quad\Rightarrow\quad
\Delta\text{ структурно выделен, но бюджетно уязвим}
}
\]

## 4.3 \(E_{\mathrm{merge}}\): стоимость уничтожения различия

Определяется:

\[
\boxed{
E_{\mathrm{merge}}(\gamma,\Delta_{\mathrm{hold}})
=
\min_{\delta w}
\|\delta w\|_{\mathsf g_w}^2
}
\]

при ограничениях:

\[
\Delta(w_0+\delta w)\le \Delta_{\mathrm{floor}},
\]

\[
\kappa(w_0+\delta w)\ge \kappa_{\mathrm{floor}}\kappa(w_0),
\]

\[
\Delta(w_0)=\Delta_{\mathrm{hold}}.
\]

В расчётах, например:

\[
\Delta_{\mathrm{floor}}=0.05,
\qquad
\kappa_{\mathrm{floor}}=0.5.
\]

Смысл:

> сколько минимальной стоимости в пространстве параметров нужно, чтобы стереть различие, не развалив сам контакт.

## 4.5 Окно сопряжения

Появляется операциональное сравнение:

\[
\boxed{
E_{\mathrm{merge}}(\gamma,\Delta_{\mathrm{hold}})
\quad\text{vs}\quad
E_{\mathrm{noise}}
}
\]

Безопасная зона:

\[
\boxed{
\Omega(E_{\mathrm{noise}})
=
\left\{
(\gamma,\Delta_{\mathrm{hold}})
:
E_{\mathrm{merge}}(\gamma,\Delta_{\mathrm{hold}})
>
E_{\mathrm{noise}}
\right\}
}
\]

Смысл:

\[
\boxed{
E_{\mathrm{merge}}>E_{\mathrm{noise}}
\Rightarrow
\text{различие защищено от естественного шума цикла}
}
\]

\[
\boxed{
E_{\mathrm{merge}}<E_{\mathrm{noise}}
\Rightarrow
\text{различие уязвимо; слияние становится дешёвым}
}
\]

Это первый количественный кандидат на **правый край окна сопряжения**.

---

## 4.6 Форма окна

Из расчётов следует:

\[
\boxed{
\gamma_{\max}(\Delta_{\mathrm{hold}})
\text{ растёт с } \Delta_{\mathrm{hold}}
}
\]

То есть чем больше исходное различие, тем более сильную связь система может позволить себе, не теряя различие под шумом.

Но при малом \(\Delta_{\mathrm{hold}}` окно схлопывается:

\[
\boxed{
\Delta_{\mathrm{hold}}\text{ мало}
\Rightarrow
\text{нет безопасной силы связи даже при слабом }\gamma
}
\]

Это даёт принцип:

\[
\boxed{
\text{Различие — валюта, которой покупается право на связь.}
}
\]

Не просто:

\[
\Delta>0
\]

как формальное условие, а:

\[
\boxed{
\Delta\text{ — ресурс устойчивости сопряжения.}
}
\]

---

## 4.7 Метрическая осторожность

Прямое сравнение одинаковых численных \(E_{\mathrm{noise}}` в абсолютной и относительной метриках нечестно: единицы стоимости различаются.

Но при метрик-согласованном бюджете, например:

\[
E_{\mathrm{noise}}=q\cdot \max E,
\]

топология окна сохраняется хорошо:

| \(q\) | расхождение топологий abs/rel |
|---:|---:|
| 0.5 | 0.08 |
| 0.7 | 0.03 |

Корректная формулировка:

> структура окна устойчива при согласованной нормировке бюджета, но не «метрически инвариантна» в наивном смысле одинаковых чисел.

# 6. Причина и результат из `Причина.txt`

Теперь инвариант должен включать не только «что есть», но и **как причина становится внутренним узлом мира**.

Базовая рекурсия:

\[
\boxed{

\rightarrow
W_n
\rightarrow
\operatorname{Rep}_{W_n}(C_n)
\rightarrow
C_{n+1}
}
\]

Это не термостат и не простая память. Это самореферентный причинный контур.

---

## 6.1 Причина как внешний селектор до встраивания

Коротко:

\[
\boxed{
\text{причина}
=
\text{внешний параметр до встраивания}
}
\]

Она становится значимой, только если меняет статистику доступных исходов:

\[
\boxed{
P(y\mid do(c_n=r))
\neq
P(y\mid do(c_n=\tilde r))
}
\]

Если нет, встраивание декоративно.

## 6.2 Результат как валидированный доступный след

\[
\boxed{
\text{результат}
=
\text{валидированный доступный след после встраивания}
}
\]

Не всё, что произошло. Не весь мир. А только то, что осталось различимым для данного наблюдателя, при данном окне, данном разрешении и данном канале.

То есть:

\[
\boxed{
\text{результат}
=
\text{проекция инварианта на канал чтения}
}
\]

---

## 6.3 \(\operatorname{Rep}_{W_n}(C_n)\) — не память, а внутренний узел

Важно:

\[
\operatorname{Rep}_{W_n}(C_n)
\]

— это не «запись в память».

Это представление причины как внутреннего оператора/канала/граничного узла в \(\mathfrak I\):

\[
\boxed{
C_n
\mapsto
\text{оператор/канал/граничный узел в }\mathfrak I

Конкретно:

\[

\leadsto

## 6.4 Новизна/интерес как информационный поток

«Интерес» операционализируется не как эмоция, а как ненулевой информационный поток.

Пусть:

- \(R_n\) — доступный результат;
- \(C_{n+1}\) — следующий селектор.

Тогда:

\[
\boxed{
I(C_{n+1};R_n\mid C_n)>0
}
\]

То есть следующий отбор содержит информацию о результате, которой не было в старой причине.

Или в энтропийной форме:

\[
\boxed{
H(W_{t+1}\mid W_t,C_t)>0
}
\]

# 13. Главный концептуальный сдвиг после новых файлов

Раньше картина была примерно такой:

\[
\kappa\uparrow
\Rightarrow
\Delta\downarrow
\]

то есть сильная связь ведёт к слиянию.

Теперь из `Цена границы.txt` появляется более тонкая геометрия:

\[
\boxed{
\kappa\uparrow
\quad\text{может locally увеличивать }\Delta,
}
\]

но одновременно:

\[
\boxed{
\kappa\uparrow
\quad\Rightarrow\quad
E_{\mathrm{merge}}(\Delta)\downarrow
}
\]

То есть сильная связь может создавать большое различие в данной точке, но делать это различие **более хрупким относительно дальнейшего управления и шума**.

Это гораздо интереснее простой картинки «сильная связь = слияние». Появляется двухкоординатная геометрия:

\[
\boxed{
(\kappa,\Delta)
}
\]

где важно не только положение системы, но и **стоимость выхода из него**.

Финальный принцип:

\[
\boxed{
\text{Связь должна находиться в окне, а не максимизироваться.}
}
\]

Потому что:

\[
\boxed{
\text{право на сильную связь покупается различием,}
}
\]

и если различие дешевле шума,

\[
\boxed{
E_{\mathrm{merge}}<E_{\mathrm{noise}},
}
\]

то окно закрывается, и система теряет способность сохранять себя как различённую.
