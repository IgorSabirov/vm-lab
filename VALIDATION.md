## Живой GitHub ↔ ВМ — ещё не выполнен в новом репозитории

Прежний тест из удалённого репозитория не используется как доказательство.

После установки без очистки ВМ проверить:

1. Исходный коммит A: ожидаемая сумма 10. После изменения main запустить именно A.
2. Получить `run.json`, подробные JSON/CSV/Markdown и журнал только через GitHub;
   проверить код 0, сумму 10, версию A и хеши. Убедиться по отчёту, что полный
   бинарный файл описан как оставленный на ВМ и не входит в опубликованные артефакты.
3. Коммит B: ожидаемая ошибка, код завершения 7. Проверить её только по GitHub.
4. Повторить заявку A. Проверить, что опубликованный отчёт и идентификатор
   выполнения не изменились.
5. Записать здесь точные номера запусков и коммиты отчётов; окончательная приёмка — пользователем.

Заявки направляются ассистентом прямо на ВМ; исходники и версия берутся из GitHub.
ВМ не очищается. Старые проекты, данные и результаты сохраняются и переезжают постепенно.

Отсутствующий отчёт означает «результат не подтверждён». Прямое чтение
результатов, журнала или статуса расчёта с ВМ для этой проверки не используется.
Дальнейший доступ к полным данным допустим только по отдельному указанию пользователя.
