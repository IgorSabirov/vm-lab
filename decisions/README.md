# Записи решений

D — решения, не результаты R и не статусы рабочих Issues. Каждая запись содержит вопрос, область, альтернативы с причинами, источник принятия, последствия и условия пересмотра. Статусы: PROPOSED, RATIFIED, SUPERSEDED, REOPENED.

Для научного решения RATIFIED требуется явное решение пользователя по научному содержанию. Разрешение менять репозиторий этого не заменяет. D001 относится только к инфраструктуре и сохраняет точный источник разрешения. Автоматические помощники могут создать предложение, но не принять научную архитектуру.

Файлы JSON здесь — источник истины; `tools/registry_links.py --write` включает их в общий граф. `decision:D001` не совпадает с D1–D6 из обсуждений дизайна опытов. Поля `scope` используют полные типизированные ID. Обратные ссылки и Markdown-карточки генерируются.
