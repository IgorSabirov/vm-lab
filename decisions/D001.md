Область: infrastructure. Статус: RATIFIED.

Как сохранять происхождение разработок, решений и результатов без дублирования научного реестра?

[Все связи решения](../analysis/REGISTRY_LINKS/INDEX.md#decision-d001)

## Альтернативы

- A — SELECTED: Сохранить PR #3, объединить с main, использовать типизированный граф, адресные проверки и PR результатов.
- B — REJECTED: Публичный репозиторий ради бесплатной защиты не соответствует частной публикации проекта.
- C — DEFERRED: Автономные LLM workflows требуют отдельной настройки учётных данных и бюджета; сначала детерминированные помощники.
