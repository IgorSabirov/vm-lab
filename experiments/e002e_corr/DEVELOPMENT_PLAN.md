# План локальной проверки до её исполнения

1 ноября 2026. Только разработка/синтетическая валидация; новых полных NESS нет.

Среда локальная, не производственная ВМ. Из предыдущего аудита:
Xeon Platinum 8573C, Python 3.12.14, NumPy 2.3.5, SciPy 1.17.0.
Перед тестом записать актуальный environment(), включая BLAS, affinity, память,
потоки и недоступные параметры. Задать по одному BLAS/OpenMP потоку.

Ориентир первого запуска 6 с, диапазон 1–20 с, НЕОТКАЛИБРОВАННЫЙ.
Основание: прежние 42 теста E002e занимали несколько секунд; добавляются
16 тестов, три сборки 216×216 без L/NESS и два полных синтетических worker-цикла
в размерности 4/16 по 1500 блочных шагов при H=1. Остальные малые сравнения
добавляют около 1700 шагов; точные счётчики worker проверяются тестами.
Точное число unittest case и фактические времена записать автоматически.
Первый запуск нового набора — калибровка: время NOT_EVALUABLE как прогноз,
корректность тестов оценивается отдельно. Не присваивать ему PASS бюджета.

Состав: формирование canonical_numbers/evidence из опубликованных JSON,
16 новых тестов, затем существующий набор tests/test_e002e*.py.
Не выполняются численные интеграции полной сети, новые NESS, QRT или спектры.
У новых тестов положительный классический контроль и независимое dense-expm
сравнение малого процесса; отрицательные/пограничные и повреждённые отчёты.
Все неудачные попытки сохраняются с исходным прогнозом.

Production: только после собственной проверки, технического ревью и отдельной
