# NOW_INTEGRATED_CONTINUATION_V1 — исполняемый пакет

Версия 0.2-reviewed. Исправления после соседских ревизий и Copilot; исходник
этой версии фиксируется до авторских дымовых. Журнал исполнения хранится отдельно
от нормативной спецификации. Старый кандидат 0.1 сохранён в commit 18aa961.

Путь: источник → доставка → локальная запись/чтение → производство A → списание
унаследованного A → оплаченный контакт → коррекция → передача аппарата и содержания
потомку. Все ветви используют этот исполнитель и общий баланс.

## Основание и границы

[Общая постановка](../../analysis/INTEGRATED_EXPERIMENT_20261107/EXPERIMENT_DESIGN.md)
сохраняется целиком. Её исторический baseline 55a9e69 и baseline реализации
0cf0f113 — последовательные ревизии, а не конкурирующие реестры. Авторитетный
реестр содержит 125 R, 42 C, 10 L; карточки не переписывались из соседского пересказа.
Полные основания и нормы входят в source manifest.

Даны: закон синтеза, геометрия Минковского 1+1, потенциальные носители и адреса,
собственные часы, первичный катализатор, расписание, конечный донор и банки памяти.
Новый A — новый материальный экземпляр заданного операционального типа. Его
компетентность теперь проверяется по шаблону и интерфейсам; химическое происхождение
этих возможностей не выведено. Контакт — локальный оплаченный gate, не генезис
геометрии. Контактный адрес и адрес потомка разделены.

A совмещает писателя, читателя, катализатор и корректирующий аппарат. Рабочие
действия нового A проверяются после удаления унаследованного A, в том числе
при записи/чтении на следующем носителе. Мутантный шаблон и отключённые интерфейсы
являются отрицательными контролями. Разные физические Aw/Ar остаются расширением.

Кредиты ≠ джоули; отдельные точные балансы кредитов и материала включают донор,
транзит, недоступные остатки, расход и отходы. В matched-контролях отключённые
производство, ремонт и коррекция удерживают свои лимиты. Natural-контроли сохраняют
неиспользованный ресурс доступным. Это два разных вопроса, оба явно заданы.
Термодинамическое замыкание, reset среды и бесконечное питание не заявляются.

Разделены конечный inbox с TTL, физический банк записей и decode slots.
Подготовка самих банков импортирована. Расписание однократное; содержание
определяет выполнение действий, но не порождает расписание. Поздняя доставка
проверяет конкретный дедлайн. Транспорт надёжный: весь R125 lease/cancel/loss/multi
этим не объявляется исправленным. Чужое состояние и журнал исследователя
не входят в локальный контроллер.

Квантовая ветвь — конечная унитарная память ортогонального классического содержания
с bright/dark, конечными модами и CP-чтением. Нормировка, PSD, условное состояние
и фактическое clip/renormalization проверяются. Неизвестное квантовое состояние
не копируется. Нет континуального BIC, носителя C021/R097, PW или доказанного
универсального генетического инварианта. Импульс загрузки задан и оплачен кредитом.

## Объём и предрегистрация

59 конфигураций, 44 контраста. Основной пакет: 59 полных конечных перечислений
и 192 контрольных Monte Carlo-траектории (3×64). Четыре классических входа имеют
точные рациональные веса. В квантовой ветви суммируются все положительные
вычисленные исходы, без отсечения вероятности; линейная алгебра остаётся численной.
У каждого дерева предел 4096 узлов: превышение — остановка, не скрытый переход
к выборке. Укрупнённая задача перечисления не тождественна одной траектории.

[PROTOCOL.json](preregistration/PROTOCOL.json) задаёт единственные пороги;
[CASES.json](preregistration/CASES.json) — вмешательства;
[ANCESTOR_FORECAST.md](ANCESTOR_FORECAST.md) — предзапусковые обещания предкам.
Число поддержанных поколений, условная передача, функция потомка, ресурс и
совместный профиль считаются отдельно. TV относится к заранее названным конечным
наблюдаемым; оценка на выборке не доказывает близость полных распределений.
Возврат предку трёхзначный: SUPPORTED / REFUTED / INCONCLUSIVE для прогноза кандидата.
Старое научное утверждение предка этим автоматически не подтверждается.

## Среда, хранение и остановка

[Измеренная ВМ](../../analysis/VM_ENVIRONMENT_20261107/RESULT.md): квота 7 CPU,
лимит worker 12,49 ГиБ, свободно 4,34 ГиБ; фактический BLAS однопоточен.
Базовый исполнитель использует один процесс/один поток. Параллелизм — предмет
последующей калибровки, не обещанное семикратное ускорение.

Дымовой лимит: 600 с, 2 ГиБ адресного пространства/RSS, 256 МиБ вывода на запуск.
Весь smoke_suite ограничен 600 с. Перед записью проверяется запас 2 ГиБ диска.
Основной черновой предел — 3600 с / 4 ГиБ / 1 ГиБ; это предел, не прогноз.
Объём и время main подтверждаются калибровкой исправленного исполнителя на ВМ.

Внешний supervisor ограничивает время и RSS даже при зависшем численном коде.
Попытки имеют отдельный журнал затрат; возобновление не обнуляет время.
Если сам supervisor погиб без финальной записи, его неучтённая попытка консервативно
списывает зарезервированный предел. Прерывание SIGTERM записывается корректно.
Контрольные точки атомарны с fsync файла/каталога; готовые строки проверяются
по хешам. Полный журнал не сериализуется после каждого события, сохраняется
выбранная подробная трасса. Итоговые данные не дублируются в TRAJECTORIES.json.

## Команды

После публикации создаются SOURCE_MANIFEST.json и REVIEW_ACCEPTANCE.json,
которые связывают все локальные файлы с проверенным GitHub commit/tree/blob.
Они лежат вне хешируемой нормативной спецификации, чтобы не создавать самохеш.
Подмена коммита или файла блокирует старт и возобновление. Git checkout не
обязателен на изолированной ВМ: допустим проверенный экспорт того же коммита.

```bash
python tools/smoke_suite.py --output /ABS/NEW_SMOKE_DIR --source-commit COMMIT --source-manifest /ABS/SOURCE_MANIFEST.json --acceptance /ABS/REVIEW_ACCEPTANCE.json
python run.py --phase smoke --output /ABS/NEW_DIR --source-commit COMMIT --source-manifest /ABS/SOURCE_MANIFEST.json --acceptance /ABS/REVIEW_ACCEPTANCE.json
# После остановки — та же команда с --resume и без диагностического --fault.
```

smoke_suite запускает unit-тесты, весь набор smoke-кейсов и реальные сбои:
после записи строки, после checkpoint (оба после ≥80%), при финализации,
SIGTERM после ≥80%, зависание с watchdog, испорченная готовая строка и неверный
коммит. Возобновлённые научные payload-хеши должны совпасть с непрерывным запуском.
Это ограниченная проверка надёжности, а не гарантия отсутствия любых отказов.

Main дополнительно требует успешный полный smoke, совпадающую среду ВМ,
измеренный прогноз и актуальное разрешение main в квитанции. Данная работа
разрешает сборку и дымовые; основной опыт не отправляется автоматически.

## Остатки общего проекта

[IMPLEMENTATION_MAP.json](preregistration/IMPLEMENTATION_MAP.json) сохраняет
X01–X16 и именованные непокрытые механизмы. Пакет полный для объявленного
вычислительного класса; библиотека модулей не закрывает L01–L10. Генеалогия
оценивает исходное обещание, а не количество файлов или ссылок.
