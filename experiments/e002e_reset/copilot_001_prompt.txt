## 3. Операция и её физический смысл

Для каждой модели воспроизводится её собственная NESS ρ₀. Затем один раз
фиксируется τ_E=Tr_Nρ₀. В каждой конечной точке и при каждом применении карты
τ_E остаётся тем же; адаптации к текущему состоянию нет:

\[
\mathcal R_E(X)=\operatorname{Tr}_E(X)\otimes\tau_E,\qquad
\mathcal L_\gamma=\mathcal L+\gamma(\mathcal R_E-\mathcal I).
\]

Каждое пуассоновское событие заменяет рёбра независимой копией τ_E и
сохраняет полную узловую матрицу. При baseline обе локальные матрицы
сохраняются, как в CORR. При γ>0 текущий marginal рёбер вообще отличается
от τ_E: вмешательство сочетает удаление N–E корреляций и закрепление рёбер.
Это не универсальная нелинейная операция ρ→ρ_N⊗ρ_E с текущими marginals.

При τ_E=Σ_aλ_a|a⟩⟨a| полный набор K_ab=I_N⊗√λ_a|a⟩⟨b| реализует
R_E, Σ_abK_ab†K_ab=I. Поэтому γ(R_E−I) имеет Lindblad-форму.
Каждое событие удаляет все N–E корреляции, включая классические;
стационарная взаимная информация с ростом γ не обязана убывать.

## 4. Сектор, единственность и измеряемая производная

Q=N_nodes⊗I_edges; q=0 означает [X,Q]=0. Это не фиксированное население N
или маски. R_E сохраняет q=0 при любом τ_E, поскольку Tr_E X коммутирует
с N_nodes. Карта не проецирует состояние: off-sector и pack/unpack проверяются
до решения и после него. Её ранг на q=0 равен 20; доказательство через образ
карты дано в [DERIVATIONS.md](DERIVATIONS.md).

Алгебраический сертификат v=0 переносится на v=1: возвращённые hopping12
элементы не отменяют прежнюю сильную связность. Полный reset добавляет в
H_eff только −iγI/2 и оставляет старые порождающие связи. Поэтому QS и RR
имеют единственную полноранговую NESS при всех γ≥0. Для конечномерного
GKSL это обеспечивает релаксацию и сходимость интеграла ниже; численная
величина щели и размер хвоста отсюда не известны.

Будущая реализация экспортирует `uniqueness_scope_v1.json` с точными
параметрами, хешами операторов и проверками предпосылок этого доказательства.
Текущий текст — аналитическое расширение прежнего сертификата, не новый
численный спектральный расчёт. При несовпадении операторных условий гейт
блокируется; minimum-norm выбор ветви или скрытая проекция запрещены.

Определяем q=R_Eρ₀−ρ₀. Это точно тот же kick, что начальный сдвиг CORR.
Решаем

\[
\mathcal L X=-q,\quad \operatorname{Tr}X=0,\quad
S_F=\operatorname{Tr}(F X)
=\left.\partial_\gamma F_{ss}(\gamma)\right|_0
=\int_0^\infty\Delta F_{CORR}(t)dt.
\]

Равенство — следствие уравнений, а знак S_F — неизвестный результат.
Новая прямая величина Δ_tail=S_F−A₂₀ публикуется с u_tail=u_S+u_A.
Она измеряет знаковую площадь хвоста; не является временем релаксации,
спектральной шириной или доказательством отдельной медленной моды.

## 5. Гипотезы и прогнозы

**Primary H_sign: S_F(QS)>0.** Прогноз мотивирован положительной A₂₀;
последний отсчёт не даёт границы хвоста и не делает знак предрешённым.
Для RR положительный знак — вторичный прогноз.

- S−u_S>0: SUPPORTED;
- S+u_S<0: REFUTED;
- иначе UNRESOLVED.

**Secondary H_window:** |S−A₂₀|≤0,20|A₂₀|. Проверяет достаточность прежнего
окна для этой производной. Отказ означает хвостовую площадь вне полосы;
он не объясняется нелинейностью конечного γ и не доказывает спектральный механизм.

**Secondary weak regime:** Q_γ=(F_ss(γ)−F₀)/γ удовлетворяет
|Q_γ−S|≤0,10|S| для обеих γ и |Q_0.002−Q_0.001|≤0,10|S|.
Поддержка требует всех трёх проверок; любой разрешённый отказ означает
отказ выбранного слабого режима. При отсутствии отказов и хотя бы одной
неразрешённой проверке общий статус UNRESOLVED. Это не меняет H_sign.

Центральные значения γA₂₀ **при малом хвосте и линейном режиме**:

| Модель | γ=0,001 | γ=0,002 |
|---|---:|---:|
| QS | ΔF≈+0,000046451296 | ΔF≈+0,000092902592 |
| RR_QS | ΔF≈+0,000067933401 | ΔF≈+0,000135866801 |

Это прогнозы на основе известных данных, не новые результаты и не
независимые подтверждения H_window. Изменение разности QS−RR вторично.
Предсказания не переобучаются после открытия S или конечных точек.

## 6. Полностью определённые интервальные правила

Предлагаемые новые guards до freeze: относительный тест со знаменателем z
выполняется только при |z|>max(10u_z,10⁻⁶). Иначе
NOT_ASSESSED_SMALL_SIGNAL. Для H_window z=A₂₀, для слабого режима z=S.
Guard не превращается в положительный научный порог H_sign.

Для каждого |x−y|≤α|z|:

\[
\begin{array}{ll}
SUPPORTED:& |x-y|+u_x+u_y\le\alpha\max(0,|z|-u_z),\\
REFUTED:& \max(0,|x-y|-u_x-u_y)>\alpha(|z|+u_z),\\
UNRESOLVED:& \text{остальные случаи.}
\end{array}
\]

Это консервативная арифметика инженерных интервалов. Общие ошибки не
объявляются статистически независимыми; повторяющиеся S/F₀ не дают права
заменять сумму ошибок корнем суммы квадратов. Научные полосы 20% и 10%
отдельны от численных гейтов.

Требуются измеренный пик памяти, запас доступной памяти, BLAS/LAPACK identity,

Исходные source/report SHA остаются явными pin, а не удаляются ради гибкости.

Поручение пользователя 1 ноября 2026: «Изучи мнение соседей и собери полный

Приняты машиночитаемые правила, явная primary LU-ветвь без усреднения с GMRES,
хеши ρ₀/τ/q/X, сертификаты обоих генераторов, полный PSD, настоящая относительная
невязка, точный список случайных калибровочных RHS и счётчики всех обращений
к факторам. В калибровке не решаются новые S_F или finite-γ NESS.
Научные критерии фиксируются **до** калибровки и ею не изменяются.

Исправления к отзыву:

- τ_E=Tr_Nρ₀. В отзыве снова ошибочно написан след по рёбрам.
- Не было ошибки применения адаптивного канала в выполненном CORR:
  `prepare` задавал одно начальное состояние, затем действовала исходная L.
- Используется именно Q=N_nodes⊗I_edges. Добавление рёберных зарядов
  перенесло бы другую модель; τ_E не обязана быть диагональна в рабочем базисе.
  Спектр τ_E сам по себе также не доказывает коммутирование с каким-либо зарядом.
- В Kraus-выводе для общего коррелированного X надо сохранять операторные
  блоки X_N^{bb}; результат Σ_b X_N^{bb}⊗τ_E. Замена узлового блока на I_N
  в промежуточной формуле отзыва некорректна.
- Малый S отключает относительный тест линейности, но не H_window: его
  знаменатель — известная A₂₀. Знак при этом может быть разрешён.
- Сохраняются guards v002: |z|>max(10u_z,10⁻⁶), а не предложенное новое
  абсолютное 10⁻⁵. При предельном u_S это уже требует |S|>10⁻⁵;
  при меньшей фактической ошибке дополнительный запрет не обоснован.
- Интервалы учитывают неопределённость обеих сторон; `max(|S|,floor)`
  не заменяет нижнюю/верхнюю границы |S| после guard.
- Если остатком Taylor можно пренебречь, двухчастотный критерий даёт
  |F''(0)|≲200|S|, не 400|S|; критерий верхней частоты даёт ≲100|S|.
  Это условное прочтение, не измерение кривизны или доказанная граница остатка.
- |F₀,LU−F₀,GMRES| оценивает внутрипроцессную чувствительность.
  Сверка с опубликованным F₀ обнаруживает межпрогонный дрейф, не «гасит» его.

Primary H_sign, 20%-полоса окна, 10%-линейность, QS/RR и три γ сохранены.
Новых моделей, фитов, временных рядов или дальних ε нет. Старое ядро не правится.

LU использует точные разреженные факторы, GMRES — точное действие полной
матрицы с независимым ILU/Woodbury-препобусловливателем. 20 вспомогательных
столбцов на setup, коррекции, condition-estimation и ILU applications
считаются отдельно; число научных задач остаётся 16.

def support_graph(H,jumps):
    loss=sum((c.getH()@c for _,c in jumps),sp.csr_matrix(H.shape,dtype=complex))
    if maxabs(loss-sp.diags(loss.diagonal()))>1e-12:raise ArithmeticError('Original loss is not diagonal')
    effective=H-.5j*loss;edges=set()
    for A in [effective,*[c for _,c in jumps]]:
        a=A.tocoo()
        edges.update((int(j),int(i)) for i,j,v in zip(a.row,a.col,a.data) if i!=j and abs(v)>1e-12)
    ij=np.array(sorted(edges),int).T
    graph=sp.csr_matrix((np.ones(len(edges)),ij),shape=H.shape)
    count,_=connected_components(graph,directed=True,connection='strong')
    return edges,int(count),effective


def uniqueness(model):
    if model['space'].d!=216:raise ValueError('Production certificate requires 216 Hilbert states')
    old=make_full(dict(model['case'],m6_v_over_J=0.),assemble=False)
    names=['node_dephase_'+str(i) for i in range(3)]+['edge_dephase_'+s for s in ('01','12','02')]
    jumps=dict(model['jumps']);diags=[];projector_error=0.
    for name in names:
        op=jumps[name];diag=op.diagonal();spectrum=np.unique(diag)
        if maxabs(op-sp.diags(diag))>1e-12 or len(spectrum)!=(2 if name.startswith('node') else 3):
            raise ArithmeticError('Dephasing premise failed')
        diags.append(diag)
        for value in spectrum:
            p=np.ones(len(diag),complex)
            for other in spectrum:
                if other!=value:p*=((diag-other)/(value-other))
            projector_error=max(projector_error,maxabs(p-(diag==value)))
    if np.unique(np.array(diags).T,axis=0).shape[0]!=216 or projector_error>1e-12:
        raise ArithmeticError('Joint rank-one projectors not complete')
    if set(dict(old['jumps']))!=set(jumps) or any(matrix_hash(c)!=matrix_hash(jumps[n]) for n,c in old['jumps']):
        raise ArithmeticError('v change altered jumps')
    e0,c0,h0=support_graph(old['H'],old['jumps']);e1,c1,h1=support_graph(model['H'],model['jumps'])
    if c0!=1 or c1!=1 or not e0<=e1:raise ArithmeticError('Connectivity extension premise failed')
    return dict(status='OPERATOR_PREMISES_VERIFIED',model=model['case']['model'],dimension=216,
        projectors=216,projector_error=projector_error,strong_components_v0=c0,strong_components_v1=c1,
        original_edges=len(e0),v1_edges=len(e1),lost_edges=len(e0-e1),
        H_effective_v0_sha256=matrix_hash(h0),H_effective_v1_sha256=matrix_hash(h1),

        result='UNIQUE_FAITHFUL_RELAXING_NESS',numerical_gap='NOT_MEASURED')

"""Fixed-target replacement and decisions. No state projection or clipping."""
import hashlib
import numpy as np

from e002_exp.model import maxabs

def matrix_hash(matrix):
    a=sp.csr_matrix(matrix).copy();a.sum_duplicates();a.sort_indices();a.eliminate_zeros()
    h=hashlib.sha256(str(a.shape).encode())
    for x,dtype in ((a.indptr,'<i8'),(a.indices,'<i8'),(a.data,'<c16')):
        h.update(np.asarray(x,dtype=dtype).tobytes())
    return h.hexdigest()


def target_check(tau, tolerance=1e-10):
    a=np.asarray(tau,complex)
    if a.ndim!=2 or a.shape[0]!=a.shape[1] or not np.isfinite(a).all():
        raise ValueError('Invalid target dimensions/data')
    eig=np.linalg.eigvalsh((a+a.conj().T)/2)
    result=dict(trace_error=float(abs(np.trace(a)-1)),hermiticity=maxabs(a-a.conj().T),
                minimum_eigenvalue=float(eig.min()),spectrum=eig.tolist(),sha256=array_hash(a),
                psd_mode='FULL_EIGVALSH_DIAGNOSTIC_SYMMETRIZATION_ONLY',tolerance=tolerance)
    if max(result['trace_error'],result['hermiticity'],-result['minimum_eigenvalue'])>tolerance:
        raise ArithmeticError('Invalid fixed target')
    return result


class Reset:
    def __init__(self, space, tau, dimensions=(8,27)):
        self.space=space;self.dimensions=tuple(dimensions);a,b=self.dimensions
        if space.d!=a*b:raise ValueError('Reset dimension mismatch')
        self.tau=np.array(tau,complex,copy=True);self.target=target_check(self.tau)
        if self.tau.shape!=(b,b):raise ValueError('Wrong edge target size')
        self.tau.setflags(write=False)
        # This experiment's symmetry acts on nodes only. No edge charge is assumed.
        charge=space.charges.reshape(a,b)
        if not np.all(charge==charge[:,0,None]):raise ValueError('Expected Q=N_nodes tensor I_edges')
        pairs=[(i,j) for j in range(a) for i in range(a) if charge[i,0]==charge[j,0]]
        inverse=np.full(space.d**2,-1,int);inverse[space.indices]=np.arange(space.size)
        columns=[];rows=[];cols=[]
        for k,(i,j) in enumerate(pairs):
            node=np.zeros((a,a),complex);node[i,j]=1
            columns.append(space.pack(np.kron(node,self.tau)))
            for e in range(b):
                pos=inverse[(i*b+e)+space.d*(j*b+e)]
                if pos<0:raise ValueError('Partial trace outside q=0')
                rows.append(k);cols.append(pos)
        self.U=sp.csc_matrix(np.column_stack(columns))
        self.V=sp.csr_matrix((np.ones(len(rows)),(rows,cols)),shape=(len(pairs),space.size))
        self.rank=len(pairs)
        err=maxabs(self.V@self.U-sp.eye(self.rank))
        trace_err=maxabs((space.trace_row@self.U)@self.V-space.trace_row)
        if max(err,trace_err)>1e-10:raise ArithmeticError('Reset idempotence/trace identity failed')
        self.certificate=dict(rank=self.rank,rank_formula='sum squared node-charge multiplicities',
            idempotence_core_error=err,trace_preservation_error=trace_err,
            target=self.target,U_sha256=matrix_hash(self.U),V_sha256=matrix_hash(self.V),
            sector_operator='N_nodes tensor I_edges',edge_charge_constraint='NOT_PRESENT')

    def apply(self, x):
        return np.asarray(self.U@(self.V@x))

    def independent_action(self, x):
        rho=self.space.unpack(x);nodes,_=marginals(rho,self.dimensions)
        return self.space.pack(np.kron(nodes,self.tau))

    def certify_action(self, x, tolerance=1e-10):
        rho=self.space.unpack(x);y=self.apply(x);out=self.space.unpack(y)
        sector=sector_check(self.space,rho,out,tolerance)
        before,_=marginals(rho,self.dimensions);after,_=marginals(out,self.dimensions)
        errors=dict(independent_action=maxabs(y-self.independent_action(x)),
                    node_marginal=maxabs(before-after),trace=float(abs(self.space.trace(y-x))))
        if max(errors.values())>tolerance:raise ArithmeticError('Reset action certificate failed')
        return dict(**errors,**sector,target_sha256=self.target['sha256'],status='PASSED')


def sign_decision(value, uncertainty):
    validate_numbers(value,uncertainty)
    return dict(value=float(value),uncertainty=float(uncertainty),interval=[float(value-uncertainty),float(value+uncertainty)],
                status='SUPPORTED' if value-uncertainty>0 else 'REFUTED' if value+uncertainty<0 else 'UNRESOLVED')


def validate_numbers(value,uncertainty):
    if not np.isfinite([value,uncertainty]).all() or uncertainty<0:raise ValueError('Invalid interval')


def relative_decision(x,ux,y,uy,z,uz,alpha,floor=1e-6):
    for v,u in ((x,ux),(y,uy),(z,uz)):validate_numbers(v,u)
    if not np.isfinite([alpha,floor]).all() or min(alpha,floor)<=0:raise ValueError('Invalid rule')
    guard=max(10*uz,floor);d=abs(x-y);u=ux+uy
    lower=max(0.,d-u);upper=d+u;band_lower=alpha*max(0.,abs(z)-uz);band_upper=alpha*(abs(z)+uz)
    if abs(z)<=guard:status='NOT_ASSESSED_SMALL_SIGNAL'
    elif upper<=band_lower:status='SUPPORTED'
    elif lower>band_upper:status='REFUTED'
    else:status='UNRESOLVED'
    return dict(status=status,difference=float(x-y),uncertainty=float(u),absolute_interval=[lower,upper],
                band_interval=[band_lower,band_upper],guard=guard,alpha=alpha)


def analyze(primary, reference, area, area_uncertainty, gammas=(.001,.002)):
    S=primary['S'];uS=max(1e-10,3*abs(S-reference['S']))
    if uS>1e-6:raise ArithmeticError('Reset derivative uncertainty cap failed')
    sign=sign_decision(S,uS);window=relative_decision(S,uS,area,area_uncertainty,area,area_uncertainty,.20)
    finite=[]
    for gamma in gammas:
        key=str(gamma);p=primary['flux'][key];r=reference['flux'][key]
        delta=p-primary['flux']['0.0'];u=max(1e-10,3*(abs(p-r)+abs(primary['flux']['0.0']-reference['flux']['0.0'])))
        if u>1e-8:raise ArithmeticError('Finite reset uncertainty cap failed')
        q=delta/gamma;uq=u/gamma
        finite.append(dict(gamma=gamma,delta_F=delta,u_delta_F=u,Q=q,u_Q=uq,
                           linearity=relative_decision(q,uq,S,uS,S,uS,.10)))
    pair=relative_decision(finite[1]['Q'],finite[1]['u_Q'],finite[0]['Q'],finite[0]['u_Q'],S,uS,.10)

    overall=('NOT_ASSESSED_SMALL_SIGNAL' if 'NOT_ASSESSED_SMALL_SIGNAL' in statuses else

    return dict(sign=sign,window=window,finite=finite,linearity_pair=pair,linearity_status=overall,
                tail=sign_decision(S-area,uS+area_uncertainty),
                tail_meaning='SIGNED_AREA_NOT_LIFETIME_OR_SPECTRAL_WIDTH',

def entropy(rho,tolerance=1e-9):
    vals=np.linalg.eigvalsh((rho+rho.conj().T)/2)
    if vals.min() < -tolerance:raise ArithmeticError('Entropy requires PSD input')
    # Only this diagnostic uses the positive part of eigenvalues; state is not altered.
    pos=vals[vals>0]
    return dict(value=float(-np.sum(pos*np.log(pos))),negative_mass=float(-vals[vals<0].sum()),
                convention='NATURAL_LOG_POSITIVE_EIGENVALUES_ONLY_STATE_UNCHANGED')

"""Bordered shifted sparse factors + rank-20 Woodbury; independent GMRES/ILU.

Every factor application is counted, including columns, residual corrections,
preconditioner applications and inverse-norm estimation. No eigenspectrum repair.
"""
import time
import numpy as np
from scipy import sparse as sp
from scipy import linalg
from scipy.sparse.linalg import splu,spilu,LinearOperator,onenormest
from e002e_exp.compat import gmres
from e002_exp.model import maxabs


class Solver:
    def __init__(self,L,space,gamma=0.,reset=None,method='lu',rtol=1e-11,atol=1e-13,
                 ilu_drop_tol=1e-5,ilu_fill_factor=10.,restart=100,maxiter=400):
        self.L=sp.csr_matrix(L);self.space=space;self.gamma=float(gamma);self.reset=reset
        if not np.isfinite(gamma) or gamma<0 or (gamma and reset is None):raise ValueError('Invalid reset solve')
        if method not in ('lu','gmres_ilu'):raise ValueError('Unknown method')
        self.method=method;self.rtol=rtol;self.atol=atol;self.restart=restart;self.maxiter=maxiter
        self.counts=dict(task_solves=0,factor_calls=0,factor_rhs_columns=0,preconditioner_calls=0,
                         residual_corrections=0,gmres_iterations=0,condition_estimates=0)
        self.times=dict(factor_seconds=0.,low_rank_setup_seconds=0.,factor_application_seconds=0.,solve_seconds=0.,condition_seconds=0.)
        n=space.size;r=space.trace_row.T/space.d
        self.base=sp.bmat([[self.L-gamma*sp.eye(n),r],[space.trace_row,None]],format='csc')
        tick=time.perf_counter()
        self.factor=splu(self.base) if method=='lu' else spilu(self.base,drop_tol=ilu_drop_tol,fill_factor=ilu_fill_factor)
        self.times['factor_seconds']=time.perf_counter()-tick
        self.U=sp.csc_matrix((n+1,0));self.V=sp.csr_matrix((0,n+1));self.W=None;self.small=None
        tick=time.perf_counter()
        if gamma:
            self.U=sp.vstack([reset.U,sp.csr_matrix((1,reset.rank))],format='csc')
            self.V=sp.hstack([reset.V,sp.csr_matrix((reset.rank,1))],format='csr')
            self.W=self.factor_apply(self.U.toarray())
            self.small=np.eye(reset.rank)+gamma*(self.V@self.W)
            self.small_factor=linalg.lu_factor(self.small)
            if not np.isfinite(self.small).all():raise ArithmeticError('Invalid Woodbury core')
        self.times['low_rank_setup_seconds']=time.perf_counter()-tick
        self.operator=LinearOperator(self.base.shape,matvec=self.apply,matmat=self.apply,dtype=complex)
        self.preconditioner=LinearOperator(self.base.shape,matvec=self.precondition,dtype=complex)

    def factor_apply(self,rhs,trans='N'):
        tick=time.perf_counter();self.counts['factor_calls']+=1
        self.counts['factor_rhs_columns']+=1 if np.ndim(rhs)==1 else rhs.shape[1]
        out=self.factor.solve(np.asarray(rhs,complex),trans=trans)
        self.times['factor_application_seconds']+=time.perf_counter()-tick
        return out

    def inverse(self,rhs,adjoint=False):
        z=self.factor_apply(rhs,'H' if adjoint else 'N')
        if self.gamma:
            if adjoint:
                c=linalg.lu_solve(self.small_factor,self.U.getH()@z,trans=2)
                z-=self.gamma*self.factor_apply(self.V.getH()@c,'H')
            else:
                c=linalg.lu_solve(self.small_factor,self.V@z)
                z-=self.gamma*(self.W@c)
        return z

    def precondition(self,rhs):
        self.counts['preconditioner_calls']+=1
        return self.inverse(rhs)

    def apply(self,x):
        return self.base@x+self.gamma*(self.U@(self.V@x))

    def equation(self,x):
        return self.L@x+(self.gamma*(self.reset.apply(x)-x) if self.gamma else 0)

    def solve(self,b=None,trace=0.):
        b=np.zeros(self.space.size,complex) if b is None else np.asarray(b,complex)
        if b.shape!=(self.space.size,) or not np.isfinite(b).all():raise ValueError('Invalid RHS')
        if abs(self.space.trace(b))>1e-11:raise ValueError('RHS is not traceless')
        rhs=np.r_[b,trace];tick=time.perf_counter();self.counts['task_solves']+=1
        if self.method=='lu':
            x=self.inverse(rhs)
            for _ in range(2):
                x+=self.inverse(rhs-self.apply(x));self.counts['residual_corrections']+=1
        else:
            def count(_):self.counts['gmres_iterations']+=1
            x,info=gmres(self.operator,rhs,M=self.preconditioner,rtol=self.rtol,atol=self.atol,
                         restart=self.restart,maxiter=self.maxiter,callback=count,callback_type='pr_norm')
            if info!=0:raise ArithmeticError('Reset GMRES did not converge: '+str(info))
        self.times['solve_seconds']+=time.perf_counter()-tick
        residual=self.equation(x[:-1])-b;bnorm=float(np.linalg.norm(b));rnorm=float(np.linalg.norm(residual))
        checks=dict(absolute_inf=maxabs(residual),absolute_2=rnorm,
                    relative_true=None if bnorm==0 else rnorm/bnorm,
                    relative_true_status='ZERO_RHS' if bnorm==0 else 'DEFINED',
                    relative_normalized=rnorm/max(bnorm,1.),trace_error=float(abs(self.space.trace(x[:-1])-trace)),
                    border_multiplier=float(abs(x[-1])))
        if (not np.isfinite(x).all() or max(checks['absolute_inf'],checks['trace_error'],checks['border_multiplier'])>1e-9):
            raise ArithmeticError('Original reset equation/trace failed: '+str(checks))
        return x[:-1],checks

    def condition_estimate(self):
        if self.method!='lu':return dict(value=None,status='NOT_ESTIMATED_FOR_ILU')
        tick=time.perf_counter();self.counts['condition_estimates']+=1
        inverse=LinearOperator(self.base.shape,matvec=self.inverse,
            rmatvec=lambda x:self.inverse(x,adjoint=True),matmat=self.inverse,dtype=complex)
        # Forming rank-20 update for a norm is cheap; it is never factorized.
        matrix=self.base+self.gamma*(self.U@self.V)
        value=float(sp.linalg.norm(matrix,1)*onenormest(inverse))
        self.times['condition_seconds']+=time.perf_counter()-tick
        if not np.isfinite(value):raise ArithmeticError('Nonfinite condition diagnostic')
        return dict(value=value,status='ONE_NORM_ESTIMATE_NOT_RIGOROUS_BOUND')

    def metrics(self):
        factor_bytes=sum(a.data.nbytes+a.indices.nbytes+a.indptr.nbytes for a in (self.factor.L,self.factor.U))
        return dict(method=self.method,gamma=self.gamma,base_nnz=int(self.base.nnz),
                    factor_nnz=int(self.factor.L.nnz+self.factor.U.nnz),factor_storage_bytes=int(factor_bytes),
                    woodbury_rank=0 if self.reset is None or not self.gamma else self.reset.rank,
                    low_rank_dense_bytes=0 if self.W is None else self.W.nbytes,
                    counts=dict(self.counts),timing=dict(self.times),
                    timing_note='Factor-application time is a subcomponent; do not add twice.')

def preflight(config,env,require_checkout=True):
    allowed={'mode','source_commit','protocol_sha256','implementation_sha256','technical_review','evidence',
             'calibration','forecast','memory_budget','science_freeze'}
    if set(config)-allowed:raise ValueError('Unsupported override')
    mode=config.get('mode');counts=workload(mode)
    if config.get('protocol_sha256')!=protocol_hash() or config.get('implementation_sha256')!=implementation_hash():
        raise ValueError('Implementation/protocol mismatch')
    if not re.fullmatch('[0-9a-f]{40}',config.get('source_commit','')) or (require_checkout and os.environ.get('VM_SOURCE_COMMIT')!=config['source_commit']):
        raise ValueError('Checkout identity mismatch')
    freeze=pinned_file(config['science_freeze'])
    if freeze.get('protocol_sha256')!=protocol_hash() or freeze.get('status')!='SCIENCE_FROZEN_BEFORE_NEW_PHYSICAL_RHS':
        raise ValueError('Science freeze missing')
    review=pinned_file(config['technical_review'])
    if review.get('status')!='REVIEWED_AND_CHECKED' or review.get('implementation_sha256')!=implementation_hash():
        raise ValueError('Current implementation not reviewed')
    evidence=pinned_file(config['evidence'])
    if evidence.get('protocol_sha256')!=protocol_hash():raise ValueError('Evidence protocol mismatch')
    records={}
    for item in evidence['cases']:
        baseline=pinned_file(item['baseline']);corr=pinned_file(item['corr'])
        cid=item['case_id']
        if cid in records or baseline['id']!=cid or corr['id']!=cid:raise ValueError('Duplicate/mismatched case evidence')
        if not baseline['quality']['pass'] or not baseline['refinement']['gate']['pass_gate']:raise ValueError('Invalid baseline evidence')
        records[cid]=dict(baseline=baseline,corr=corr)
    if set(records)!={c['id'] for c in cases()}:raise ValueError('Incomplete evidence')
    for case in cases():
        if any(records[case['id']]['baseline']['case'][k]!=case[k] for k in ('model','epsilon','phi_over_pi','node_noise','m6_v_over_J')):
            raise ValueError('Evidence physics mismatch')
        corr=records[case['id']]['corr']
        if any(corr['case'][k]!=case[k] for k in ('model','epsilon','phi_over_pi','node_noise','m6_v_over_J')):
            raise ValueError('CORR evidence physics mismatch')
        area=corr['result']['signed_area'];u=corr['result']['area_uncertainty']
        if not np.isfinite([area,u]).all() or u<0:raise ValueError('Invalid CORR area evidence')
    comparison=dict(comparable=False,reason='FIRST_BOUNDED_CALIBRATION')
    if mode=='production':
        cal=pinned_file(config['calibration'])
        if (cal.get('status')!='CALIBRATION_REVIEWED' or cal.get('counts')!=workload('calibration')
                or cal.get('implementation_sha256')!=implementation_hash() or cal.get('protocol_sha256')!=protocol_hash()
                or not re.fullmatch('[0-9a-f]{40}',cal.get('report_commit',''))):raise ValueError('Calibration identity mismatch')
        comparison=compare_environment(cal['environment'],env)
        if not comparison['comparable']:raise ValueError('Calibration environment changed')
        if config['forecast']!=cal['production_forecast'] or config['memory_budget']!=cal['memory_budget']:
            raise ValueError('Measured budget mismatch')
    f=config['forecast']
    if not all(np.isfinite(f[k]) for k in ('expected_seconds','lower_seconds','upper_seconds')) or not 0<f['lower_seconds']<=f['expected_seconds']<=f['upper_seconds']:
        raise ValueError('Invalid forecast')
    return dict(evidence=records,counts=counts,environment=comparison,threads=thread_preflight(env),
                memory=memory_preflight(config['memory_budget'],env))

def random_rhs(space,seed):
    rng=np.random.default_rng(seed);rho=np.zeros((space.d,space.d),complex)
    for g in space.groups:
        z=rng.normal(size=(len(g),len(g)))+1j*rng.normal(size=(len(g),len(g)))
        rho[np.ix_(g,g)]=(z+z.conj().T)/2
    rho-=np.trace(rho)*np.eye(space.d)/space.d
    x=space.pack(rho);x/=np.linalg.norm(x)
    return x


def measure_raw(model,x):
    out={}
    for name,op in model['observables'].items():
        v=complex(model['space'].row(op)@x)

        else:
            if abs(v.imag)>1e-9:raise ArithmeticError('Complex observable')
            out[name]=float(v.real)
    return out

def equal(a,b):
    if isinstance(a,dict) and isinstance(b,dict):return a.keys()==b.keys() and all(equal(a[k],b[k]) for k in a)
    if isinstance(a,list) and isinstance(b,list):return len(a)==len(b) and all(equal(x,y) for x,y in zip(a,b))
    if a is None or b is None or isinstance(a,bool) or isinstance(b,bool):return type(a)==type(b) and a==b
    if isinstance(a,(int,float)) and isinstance(b,(int,float)):return bool(np.isfinite([a,b]).all() and np.isclose(a,b,atol=1e-12,rtol=1e-11))
    return a==b


def vector(report,name):
    if not isinstance(name,str) or Path(name).name!=name:raise ValueError('Unsafe vector path')
    with np.load(report/name,allow_pickle=False) as a:
        if a.files!=['vector']:raise ValueError('Unexpected arrays')
        x=a['vector'].copy()
    if not np.isfinite(x).all():raise ValueError('Nonfinite vector')
    return x

"""Fixed-marginal preparation, finite-window propagation and interval decisions.

No projection, clipping, renormalization, inferred infinite tail or Fano label.
The replacement channel has a fixed prepared edge state for each baseline.
"""
import hashlib
import time
import numpy as np
from e002_exp.model import maxabs
from e002e_exp.compat import trapezoid
from e002e_exp.numerics import ratio


def marginals(rho, dimensions):
    a, b = dimensions
    rho = np.asarray(rho, complex)
    if rho.shape != (a*b, a*b) or not np.isfinite(rho).all():
        raise ValueError('Invalid bipartite density matrix')
    tensor = rho.reshape(a, b, a, b)
    return np.trace(tensor, axis1=1, axis2=3), np.trace(tensor, axis1=0, axis2=2)


def replacement(rho, edge_reference, dimensions):
    """Linear CPTP only for a FIXED edge_reference.

    prepare chooses a target from its known baseline; the overall map from an
    arbitrary unknown baseline to its two marginals is not a universal channel.
    """
    nodes, _ = marginals(rho, dimensions)
    b = dimensions[1]
    edge_reference = np.asarray(edge_reference, complex)
    if (edge_reference.shape != (b, b) or not np.isfinite(edge_reference).all()
            or maxabs(edge_reference-edge_reference.conj().T) > 1e-10
            or abs(np.trace(edge_reference)-1) > 1e-10
            or np.linalg.eigvalsh(edge_reference).min() < -1e-10):
        raise ValueError('Invalid fixed reference state')
    return np.kron(nodes, edge_reference)


def physicality(space, state, tolerance):
    if not np.isfinite(state).all():
        raise ArithmeticError('Density matrix is nonfinite')
    rho = space.unpack(state)
    herm = maxabs(rho-rho.conj().T)
    minimum = float(np.linalg.eigvalsh((rho+rho.conj().T)/2).min())
    check = dict(trace_error=float(abs(space.trace(state)-1)), hermiticity=herm,
                 minimum_eigenvalue=minimum, psd_mode='FULL_HILBERT')
    if (not np.isfinite(state).all() or check['trace_error'] > tolerance
            or herm > tolerance or minimum < -tolerance):
        raise ArithmeticError('Density matrix physicality failed: '+str(check))
    return check


def array_hash(a):
    a = np.ascontiguousarray(a, dtype='<c16')
    return hashlib.sha256(str(a.shape).encode()+b'\0'+a.tobytes()).hexdigest()


def sector_check(space, rho, product, tolerance):
    """Certify this builder's complete q=0 block algebra, with no projection.

    The 216-state model has Q=N_nodes tensor I_edges. For [rho,Q]=0,
    [Tr_edges(rho),N_nodes]=0, hence [rho_nodes tensor rho_edges,Q]=0.
    No per-edge superselection rule from an older 512-state model is assumed.
    """
    joined = np.concatenate(space.groups)
    if not np.array_equal(np.sort(joined), np.arange(space.d)):
        raise ValueError('Charge groups do not partition full Hilbert space')
    outside = space.charges[:, None] != space.charges[None, :]
    errors = dict(input_off_sector=maxabs(np.where(outside, rho, 0)),
                  product_off_sector=maxabs(np.where(outside, product, 0)),
                  input_roundtrip=maxabs(space.unpack(space.pack(rho))-rho),
                  product_roundtrip=maxabs(space.unpack(space.pack(product))-product))
    if max(errors.values()) > tolerance:
        raise ArithmeticError('Preparation violates q=0 sector/roundtrip')
    return errors


def prepare(model, state, dimensions=(8, 27), tolerance=1e-10):
    space = model['space']; rho = space.unpack(state)
    before = physicality(space, state, tolerance)
    nodes, edges = marginals(rho, dimensions)
    product = replacement(rho, edges, dimensions)
    sector = sector_check(space, rho, product, tolerance)
    cut = space.pack(product)
    after = physicality(space, cut, tolerance)
    # Verify the actual packed/unpacked state, not just the formal kron target.
    new_nodes, new_edges = marginals(space.unpack(cut), dimensions)
    errors = dict(nodes=maxabs(nodes-new_nodes), edges=maxabs(edges-new_edges))
    if max(errors.values()) > tolerance:
        raise ArithmeticError('Preparation changed a marginal')
    change = space.unpack(cut)-rho
    distance = .5*float(np.abs(np.linalg.eigvalsh((change+change.conj().T)/2)).sum())
    record = dict(marginal_errors=errors, sector_errors=sector,
                  sector_contract='COMPLETE_Q0_CHARGE_BLOCKS_NO_PROJECTION',
                  preparation_type='PRODUCT_OF_KNOWN_BASELINE_MARGINALS_FIXED_TARGET',
                  universal_cptp_channel=False,
                  hashes={n:array_hash(a) for n,a in (('state',state),('cut',cut),('nodes',nodes),('edges',edges))},
                  marginal_spectra=dict(nodes=np.linalg.eigvalsh((nodes+nodes.conj().T)/2).tolist(),
                                        edges=np.linalg.eigvalsh((edges+edges.conj().T)/2).tolist()),
                  sham_physicality=before, cut_physicality=after,
                  trace_distance=distance, frobenius_distance=float(np.linalg.norm(change)),
                  delta_energy=float(np.trace(model['H']@change).real),
                  external_preparation_cost='NOT_ASSUMED_ZERO_NOT_MEASURED',
                  removed_correlations='ALL_NODE_EDGE_CORRELATIONS_NOT_ONLY_ENTANGLEMENT')
    return np.column_stack((state, cut)), record


def grid_steps(horizon, dt, interval):
    if not np.isfinite([horizon, dt, interval]).all() or min(horizon, dt, interval) <= 0:
        raise ValueError('Invalid finite time grid')
    n, stride = round(horizon/dt), round(interval/dt)
    if n < 1 or stride < 1 or abs(n*dt-horizon) > 1e-10 or abs(stride*dt-interval) > 1e-10 or n % stride:
        raise ValueError('Grid must contain exact integral steps and endpoint')
    return n, stride


def propagate(model, initial, *, horizon, dt, sample_interval, physicality_interval,
              tolerance=1e-9, checkpoint=None, density_checks=True):
    """Two density columns (sham/cut), RK4; retain flux at EVERY step.

    Other observables are retained on the declared common grid. Physicality
    is checked at the declared checkpoints, not claimed between checkpoints.
    density_checks=False is reserved for synthetic calibration vectors.
    """
    steps, stride = grid_steps(horizon, dt, sample_interval)
    _, check_stride = grid_steps(horizon, dt, physicality_interval)
    space = model['space']; L = model['L']; y = np.asarray(initial, complex).copy()
    if y.shape != (space.size, 2) or not np.isfinite(y).all():
        raise ValueError('Expected two finite state columns')
    names = tuple(model['observables']); rows = np.vstack([space.row(model['observables'][n]) for n in names])
    frow = space.row(model['observables']['F'])
    times = np.arange(steps+1)*dt; flux = np.empty((steps+1, 2))
    output = []; checks = []; trace0 = space.trace(y)
    start = time.perf_counter()
    for step in range(steps+1):
        if step:
            a = L@y; b = L@(y+dt*a/2); c = L@(y+dt*b/2); d = L@(y+dt*c)
            y += dt*(a+2*b+2*c+d)/6
        f = frow@y
        if not np.isfinite(y).all() or maxabs(f.imag) > tolerance:
            raise ArithmeticError('Evolution is nonfinite or flux is complex')
        flux[step] = f.real
        if step % stride == 0:
            output.append(rows@y)
        if step % check_stride == 0:
            if maxabs(space.trace(y)-trace0) > tolerance:
                raise ArithmeticError('Evolution trace drift')
            if density_checks:
                checks.append(dict(time=float(times[step]), states=[physicality(space, y[:, k], tolerance) for k in range(2)]))
            if checkpoint:
                checkpoint(step, float(times[step]), y)
    return dict(time=times, flux=flux, sample_time=times[::stride], raw=np.asarray(output), names=names,
                time_index=np.arange(steps+1), sample_index=np.arange(steps+1)[::stride], dt=float(dt),
                final=y, checks=checks, steps=steps, checkpoint_calls=steps//check_stride+1,
                block_rhs_calls=4*steps,
                scalar_rhs_equivalents=8*steps, elapsed_seconds=time.perf_counter()-start)


def threshold_decision(value, uncertainty, threshold):
    if (not np.isfinite([value, uncertainty, threshold]).all()
            or value < 0 or uncertainty < 0 or threshold <= 0):
        raise ValueError('Invalid nonnegative interval')
    lo, hi = max(0., value-uncertainty), value+uncertainty
    status = ('MARGINAL_SUFFICIENCY_REJECTED_AT_DECLARED_RESOLUTION' if lo > threshold else
              'MARGINAL_SUFFICIENCY_NOT_REJECTED_IN_WINDOW' if hi < threshold else 'UNRESOLVED')
    return dict(value=value, uncertainty=uncertainty, interval=[lo, hi], threshold=threshold, status=status)


def analyze(fine, coarse, reference, *, baseline_flux, reference_flux, policy):
    for run in (fine, coarse, reference):
        if not np.isfinite(run['flux']).all():
            raise ValueError('Nonfinite trajectory')
    def same_grid(a,b):
        return a.shape == b.shape and np.allclose(a,b,rtol=0.,atol=1e-12)
    if (not same_grid(fine['time'], reference['time'])
            or not same_grid(fine['sample_time'], coarse['sample_time'])
            or not same_grid(fine['sample_time'], reference['sample_time'])
            or fine['names'] != coarse['names'] or fine['names'] != reference['names']):
        raise ValueError('Comparison grids or observables differ')
    if abs(fine['time'][-1]-coarse['time'][-1]) > 1e-12:
        raise ValueError('Comparison horizons differ')
    if baseline_flux <= 1e-6 or reference_flux <= 1e-6:
        raise ValueError('Unresolved normalization flux')
    # Fixed numerical caps are independent of the scientific threshold.
    comparisons = {}
    for name, other in (('dt', coarse), ('initial_condition_and_solver_sensitivity', reference)):
        err = abs(fine['raw']-other['raw'])
        scale = policy['raw_absolute_tolerance']+policy['raw_relative_tolerance']*np.maximum(abs(fine['raw']), abs(other['raw']))
        comparisons[name] = dict(max_abs=float(err.max()), max_scaled=float((err/scale).max()), passed=bool(np.all(err <= scale)))
    if not all(x['passed'] for x in comparisons.values()):
        raise ArithmeticError('Trajectory refinement failed: '+str(comparisons))
    t = fine['time']; H = float(t[-1]); delta = fine['flux'][:, 1]-fine['flux'][:, 0]
    dc = coarse['flux'][:, 1]-coarse['flux'][:, 0]; dr = reference['flux'][:, 1]-reference['flux'][:, 0]
    u = policy['absolute_floor']+policy['safety']*(abs(delta-np.interp(t, coarse['time'], dc))+abs(delta-dr))
    area = float(trapezoid(abs(delta), t)); u_area = float(trapezoid(u, t))
    uf = policy['absolute_floor']+policy['safety']*abs(baseline_flux-reference_flux)
    R = ratio(area, H*baseline_flux, u_area, H*uf)
    if R['value'] is None or R['uncertainty'] is None or R['uncertainty'] > policy['maximum_metric_uncertainty']:
        raise ArithmeticError('Primary uncertainty is unresolved or exceeds fixed cap')
    verdict = threshold_decision(R['value'], R['uncertainty'], policy['primary_threshold'])
    raw_error = policy['absolute_floor']+policy['safety']*(abs(fine['raw']-coarse['raw'])+abs(fine['raw']-reference['raw']))
    h = fine['names'].index('h6'); p = fine['names'].index('P_m6_N2')
    conditional = []
    for i, ti in enumerate(fine['sample_time']):
        row = []
        for k in range(2):
            hh, pp = fine['raw'][i, h, k], fine['raw'][i, p, k]
            if max(abs(hh.imag), abs(pp.imag)) > policy['raw_absolute_tolerance']:
                raise ArithmeticError('Conditional primitive is complex')
            row.append(ratio(float(hh.real), float(pp.real), float(raw_error[i, h, k]), float(raw_error[i, p, k])))
        conditional.append(dict(time=float(ti), sham=row[0], cut=row[1]))
    peak = int(np.argmax(abs(delta)))
    sham_drift = float(np.max(abs(fine['flux'][:, 0]-baseline_flux)))
    reference_sham_drift = float(np.max(abs(reference['flux'][:,0]-reference_flux)))
    coarse_sham_drift = float(np.max(abs(coarse['flux'][:,0]-baseline_flux)))
    if max(sham_drift, reference_sham_drift, coarse_sham_drift) > policy['maximum_sham_drift']:
        raise ArithmeticError('Sham stationary drift exceeds fixed cap')
    return dict(primary=verdict, area_absolute=area, area_uncertainty=u_area,
                signed_area=float(trapezoid(delta, t)), peak_relative=float(abs(delta[peak])/baseline_flux),
                time_peak=float(t[peak]), final_delta_flux=float(delta[-1]), sham_drift=sham_drift,
                reference_sham_drift=reference_sham_drift, coarse_sham_drift=coarse_sham_drift,
                refinement=comparisons,
                uncertainty_kind='ENGINEERING_DT_AND_INITIAL_CONDITION_SOLVER_SENSITIVITY_NOT_RIGOROUS_TOTAL_BOUND',
                tail_status='FINITE_WINDOW_ONLY', conditional=conditional, raw_uncertainty=raw_error)

"""Charge-covariant q=0 Liouvillian, without a dense Liouville matrix."""
from dataclasses import dataclass
import numpy as np
from scipy import sparse as sp
from e002_exp.model import clean, maxabs


@dataclass
class Space:
    charges: np.ndarray

    def __post_init__(self):
        self.charges = np.asarray(self.charges, dtype=int)
        self.d = len(self.charges)
        self.groups = [np.flatnonzero(self.charges == n) for n in np.unique(self.charges)]
        self.sizes = [len(g) ** 2 for g in self.groups]
        self.offsets = np.r_[0, np.cumsum(self.sizes)]
        self.indices = np.concatenate([(g[:, None] + self.d*g[None, :]).ravel(order='F') for g in self.groups])
        self.trace_indices = np.concatenate([off + np.arange(len(g))*(len(g)+1)
                                            for off, g in zip(self.offsets, self.groups)])
        self.size = len(self.indices)
        self.trace_row = sp.csr_matrix((np.ones(self.d), (np.zeros(self.d, int), self.trace_indices)), shape=(1, self.size))

    def pack(self, matrix, tolerance=1e-12):
        a = matrix.toarray() if sp.issparse(matrix) else np.asarray(matrix)
        if a.shape != (self.d, self.d):
            raise ValueError('Hilbert dimensions disagree')
        if maxabs(np.where(self.charges[:, None] != self.charges[None, :], a, 0)) > tolerance:
            raise ValueError('Input has components outside q=0')
        return a.ravel(order='F')[self.indices].copy()

    def unpack(self, vector):
        v = np.asarray(vector)
        if v.shape != (self.size,):
            raise ValueError('Reduced vector shape mismatch')
        a = np.zeros(self.d*self.d, complex)
        a[self.indices] = v
        return a.reshape(self.d, self.d, order='F')

    def row(self, operator):
        # trace(O rho), without conjugation of O: vec(O.T)^T vec(rho).
        a = operator.toarray() if sp.issparse(operator) else np.asarray(operator)
        return a.T.ravel(order='F')[self.indices]

    def trace(self, vector):
        return np.asarray(vector)[self.trace_indices].sum(axis=0)


def charge_checks(H, jumps, space, tolerance=1e-12):
    h = sp.coo_matrix(H)
    hbad = maxabs(h.data[space.charges[h.row] != space.charges[h.col]])
    deltas = {}
    for name, C in jumps:
        c = sp.coo_matrix(C)
        nz = abs(c.data) > tolerance
        ds = np.unique(space.charges[c.row[nz]] - space.charges[c.col[nz]])
        if len(ds) > 1:
            raise ValueError('Jump lacks definite charge: ' + name)
        deltas[name] = int(ds[0]) if len(ds) else None
    if hbad > tolerance:
        raise ValueError('Hamiltonian violates charge covariance')
    return dict(H_charge_residual=hbad, jump_charge_changes=deltas)


def liouvillian(H, jumps, space):
    """Exact block construction; every within-charge coherence is retained."""
    charge_checks(H, jumps, space)
    H = sp.csr_matrix(H)
    count = len(space.groups)
    blocks = [[sp.csr_matrix((space.sizes[a], space.sizes[b]), dtype=complex)
               for b in range(count)] for a in range(count)]
    for a, g in enumerate(space.groups):
        h = H[g][:, g]; eye = sp.eye(len(g), format='csr')
        blocks[a][a] += -1j*(sp.kron(eye, h) - sp.kron(h.T, eye))
    for _, C in jumps:
        C = sp.csr_matrix(C); loss = clean(C.getH() @ C)
        for a, ga in enumerate(space.groups):
            eye = sp.eye(len(ga), format='csr'); m = loss[ga][:, ga]
            blocks[a][a] -= .5*(sp.kron(eye, m) + sp.kron(m.T, eye))
            for b, gb in enumerate(space.groups):
                c = C[ga][:, gb]
                if c.nnz:
                    blocks[a][b] += sp.kron(c.conjugate(), c)
    L = clean(sp.bmat(blocks, format='csr'))
    if maxabs(space.trace_row @ L) > 1e-11:
        raise ValueError('Reduced generator is not trace preserving')
    return L


def dissipator_action(C, rho):
    C = sp.csr_matrix(C); m = C.getH() @ C
    right = lambda a, b: (b.T @ a.T).T
    return right(C @ rho, C.getH()) - .5*(m @ rho + right(rho, m))
