# E002d: локальная проверка перед калибровкой ВМ

Время: прогноз 30 с, диапазон 5–120 с; факт последнего полного набора
9.405 с; PASS. Предварительный набор 10.752 с также уложился в диапазон;
повтор вызван добавлением проверки знака Q и отчётных диагностик.

Пять групп unittest прошли:

1. 36 различных производственных случаев, 22 fine/14 coarse,
   1 160 000 шагов; ветвь T400 — 2 320 000; калибровка — 9000.
2. Полная карта T/C для A,B,AB: различие только на заявленном семействе
   когерентностей. Неправильная замена суммы диссипаторов одним скачком
   даёт обнаружимое расхождение.
3. Для обеих моделей baseline совпадает с прежним генератором и
   наблюдаемыми. Для A/B/AB × T/C при gamma=.2 новый генератор сверяется
   с независимой общей сборкой Линдблада и прямым действием на случайную
   положительную матрицу. H неизменен. Когерентности сверены с partial trace.
4. Сквозной smoke: QS/RR, AB_T, оба dt, T=2; 4 траектории, 1200 шагов,
   4800 RHS. Физичность, сходимость, создание и независимое чтение отчёта
   прошли. Намеренное повреждение NPZ отклоняется по хешу.
5. На аналитически заданном наборе Q=-.2 получает отрицательный знак;
   испорченный coarse-контроль блокирует вывод статусом REFINEMENT_FAILED.

Команда: `OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 MKL_NUM_THREADS=1 python -m unittest discover -s tests -p 'test_e002d.py' -v`.

Это локальная проверка, не калибровка ВМ, не стационарная эволюция и не
научная приёмка. Production пока не отправлялся. Copilot не вызывался.
Базовые модули взяты из `29fe4496485c17e935b2e2ffa9c88b7d75ba6efe`;
в старом engine добавлен только необязательный параметр builder для
подключения E002d без изменения прежнего вызова E002c.
