# Первый полный представитель E002e

Время ENV: неоткалиброванный ориентир 2 с [0,5;10], процесс 0,250618 с,
внутри Python 0,086833 с. Все заявленные проверки выполнены. Прежний ориентир
переоценил только загрузку/паспорт; отсутствующих решений в объёме не было.
Учёт worker имеет дискретность около 0,25 с. NOT_EVALUABLE сохраняется.
GitHub результат: 6b18ff398cc987db8c8e68c636958db26394493c, E002e_ENV_v001_r001.

Среда: AMD EPYC-Genoa, 8 CPU/affinity, Linux 6.8.0-110, Python 3.12.3,
NumPy 1.26.4, SciPy 1.11.4. До расчёта проверяются действующие BLAS-пулы.
Cgroup-файлы не смонтированы в изолированном worker; это неизвестное явно
сохраняется. RLIMIT_AS исходно unlimited. Для калибровки вводится собственный
жёсткий потолок адресного пространства 8 ГиБ; проверяется фактическое применение
и доступная память хоста не менее 9 ГиБ. Это не измерение cgroup-лимита и не
автоматическое разрешение production memory gate. Диск: 4,59 ГиБ, новых файлов
калибровки ожидается менее 20 МиБ; ничего старого не удаляется.

Обнаруженные несовместимости: scipy.gmres 1.11 принимает tol вместо rtol;
numpy 1.26 имеет trapz вместо trapezoid. Добавлен адаптер одинаковых явно
заданных допусков/трапецеидального интеграла. Модель, параметры и точность
не меняются. Для измерения потоков перенесён неизменённый threadpoolctl 3.6.0
из первичной среды с лицензией BSD-3-Clause; установки пакетов на ВМ нет.
Новый bootstrap и адаптеры не объявляются просмотренными Copilot; прежнее
ревью остаётся источником для неизменённой модели, дополнительная проверка
изменений записывается отдельно. До production нужен актуальный полный аудит.

216 состояний, 14580 зарядово-сохранных координат; sparse nnz измеряется.

Оценка обусловленности LU: 1. Статические RHS: M1,M2 каждым методом (4).
Частотный RHS omega=1 каждым методом (2). Короткий QRT H=1, 3 входа,
9 функций; dt=.01/.005, 100/200 RK4 шагов, 1200 блочных применений L,
11 общих отсчётов. Ненулевые частотные LU/ILU измеряются отдельно.
Сохранить фазы, итерации, nnz/fill-in, память факторов и пик RSS; полные
векторы в full, все примитивы/узловые блоки/корреляционные отсчёты в report.

Ориентир полного процесса 120 с [10;900]. Это первый замер нового sparse
решателя на ВМ, NOT_EVALUABLE, не калиброванный прогноз. Разбивка ориентира:

измеренными фазами в новом плане. 900 с — граница разбора времени, не тайм-аут.
