## Что проверено

Цель — проверить исполнение согласованного CONCEPT_v003 на целевой ВМ,
сопоставление с опубликованным E002d, сходимость временных корреляций и стоимость
этапов. Постановка полной модели и состав производственной серии не расширены.
Полная задача использует сектор q=0 размерности 14 580; плотная обратная
матрица не строится. Основной решатель — sparse LU, независимая проверка —
GMRES с ILU; rtol=1e−12, atol=1e−14, допуск состояния 1e−10.

В финальном запуске E002e_FINAL_CAL_v001_r001:

| Работа | Объявлено и выполнено |
|---|---:|
| Регрессионные и интеграционные тесты | 42 из 42; 4,002113 с на ВМ |
| Представители полной модели | 6: QS/RR_QS/IC1_QS × φ=0,π/2 |
| Представители малых контролей | 10 из неизменного inventory G |
| Решения NESS полной модели | 12, по два метода на случай |
| Статические правые части | 18, каждая двумя методами: 36 решений |
| Частотные правые части | 2 при ω=1, каждая двумя методами: 4 решения |
| Блоковые шаги RK4 для QRT | 71 500; 286 000 вычислений правой части |

Полные представители имеют ε=0, шум узла 0,05, v/J=1; held-out F2 с v/J=0,0,5
не использовался. Малые индексы: 2,12,20,30,38,48,56,66,76,91; охвачены
размерности 4/8, маски m6/m7, v=0/1, слабая ветвь и peer-контроль.

Все проверки состояния, независимого решения и QRT прошли. Максимальное
расхождение векторов NESS между решателями — 2,494e−13; максимальное расхождение
сохранённых скалярных наблюдаемых — 1,650e−12. Порог сравнения вектора 1e−9,
наблюдаемых — абсолютная часть 1e−9 и относительная 1e−7.

QRT для QS, φ=π/2 проверен на H=100 с шагами 0,01 / 0,005 / 0,0025:
70 000 шагов, три входа, девять комплексных функций, 1001 общий отсчёт на сетку.
Для пары 0,005/0,0025 максимум расхождения относительно заданного допуска —
0,001058 (<1); абсолютный максимум около 4,65e−11. Допуски: 1e−8 + 1e−5×масштаб.
Остальные пять полных случаев проверены на H=1 двумя сетками 0,01/0,005
(ещё 1500 шагов). Их H=100 не объявляется измеренным в этой калибровке.

## Среда, память и необходимые изменения

ВМ: AMD EPYC-Genoa, доступные CPU 0–7, Python 3.12.3, NumPy 1.26.4,
SciPy 1.11.4, системные reference BLAS/LAPACK 3.12.0. Закреплены пути и SHA256
шести загруженных библиотек; вычислительный поток во всех измеренных фазах —
один (опрос каждые 50 мс, поток наблюдения исключён). Пустой threadpoolctl
здесь не означает отсутствие BLAS. Паспорт —
[calibration_verification_final.json](calibration_verification_final.json).

Пик RSS — 361 611 264 байта (344,9 МиБ), максимум наблюдаемого VmSize —
532 471 808 байт (507,8 МиБ); одновременно живые факторы — 135 901 172 байта.
Для каждого этапа заложены 1 ГиБ дополнительного пика и 1 ГиБ резерва.
Процесс работает с проверенными равными soft/hard RLIMIT_AS=8 ГиБ;
доступная память хоста тоже проверяется перед запуском. Доступный ресурс
пересчитывается в момент запуска, а не берётся из старого паспорта.

В namespace задания cgroup не смонтирован: фактические ancestor memory limit
и CPU quota неизвестны. RLIMIT_AS ограничивает адресное пространство процесса
и не подменяет знание cgroup. Неизмеренная нагрузка хоста остаётся источником
расхождения времени/доступной памяти; при отклонении нужен разбор. Дискретный
VmSize также не является непрерывным максимумом.

В ходе калибровки исправлены реальные проблемы исполнения:

- привязка source_commit к SHA из проверяющего лаунчера вместо невозможной
  ссылки конфигурации на хеш содержащего её же коммита;
- совместимость GMRES (`tol`/`rtol`) и интегрирования NumPy без изменения
  численных допусков;
- распознавание reference BLAS и обязательная проверка памяти при скрытом
  cgroup через измеренный, реально установленный hard RLIMIT_AS;
- сохранены независимые проверки worker, происхождения отчётов и F2.

Лаунчер проверен по установленному исходнику: получает закреплённый commit,
сверяет FETCH_HEAD и все blobs, затем задаёт VM_SOURCE_COMMIT. Git HEAD внутри
песочницы не имитируется. Финальное ядро:
`733307d239ec67deae17b9e6e2631be8a73d963229491b27ae9a9ba4a6416494`.

Предыдущее завершённое ревью Copilot относится к реализации
`98cb6b0a7d8c60036308307e9ef1c3005f1d6dc8` и прежнему ядру. Дополнительные
изменения совместимости/ресурсов проверены ассистентом и 42 тестами локально
и на ВМ; новое ревью Copilot этих изменений не заявляется. Точная граница
ревью записана в [implementation_review_final.json](implementation_review_final.json).
