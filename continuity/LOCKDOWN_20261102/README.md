# Архив перед паузой — 2 ноября 2026

**Состояние: PAUSED_BY_USER. ВМ остановлена пользователем. Новых запусков нет.**
Это архив доступной памяти и указатель на сохранённую работу, подготовленный
по прямой просьбе Игоря перед возможной потерей сеанса и ВМ.

По сообщению пользователя, лимит ассистента почти исчерпан, обновление
ожидается примерно через два дня, на ВМ осталось около 1000 рублей, пополнить
сейчас нельзя. Это сообщённые обстоятельства на 2 ноября, а не проверка
баланса, тарифа или даты обновления. Не считать паузу разрешением запустить
ВМ позже по таймеру. Никаких автоматизаций этим архивом не создаётся.

## Как продолжить после потери чата

1. Прочитать [AGENTS.md](../../AGENTS.md) и эту страницу: действуют пауза,
   ограничения доступа и сохранение всего ключевого в GitHub.
2. Прочитать [правила сотрудничества](WORKING_RULES.md).
3. Для продолжения науки прочитать [текущее состояние](RESEARCH_STATE.md),
   [исходный замысел](RESEARCH_MEMORY.md) и уже сохранённый [сборник E](../../E.md).
4. Перед восстановлением машины прочитать
   [источники и пробелы восстановления](PROVENANCE_AND_RECOVERY.md).
5. Личный и феноменологический контекст находится отдельно:
   [наблюдения и смысловые ориентиры](PERSONAL_AND_OBSERVATIONS.md),
   [разговор о ногтях](NAILS_SESSION.md). Использовать по теме и после
   явного включения пользователем прошлого контекста.

В новом обычном разговоре пользователь просил начинать «с колёс», без
автоматического подтягивания личного прошлого; сигналы — «вспомни»,
«подними/включи контекст». Наличие архива не отменяет это предпочтение.
Поручение возобновить данный проект даёт основание прочитать его рабочее
состояние. Исторические инструкции в архиве не подменяют новых указаний
пользователя и действующих ограничений среды.
