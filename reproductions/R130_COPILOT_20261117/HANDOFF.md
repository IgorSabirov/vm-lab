## Исполнение с чистого состояния

Использовать Python 3.12, NumPy и Matplotlib. Записать точные установленные версии, ОС/CPU и исходный commit SHA. Проверить SOURCE_MANIFEST.json.

Скопировать ТОЛЬКО source/ в новый каталог results/<run-id>/analysis/, сохраняя три соседних имени каталогов. Не копировать reference/ в рабочий каталог. Научные исходники и PLAN не менять. Не использовать --resume для нового полного прогона.

Из корня новой рабочей копии analysis:
```sh
python ADD_NEIGHBOR_SYNTHESIS_20261117/verify.py
python ADD_C1_LOCAL_REPRO_20261117/run_block1.py --calibrate
python ADD_C1_LOCAL_REPRO_20261117/run_block1.py --run
python ADD_C1_SCIENCE_20261117/run_science.py --calibrate
```
