# R141. Измеренные резонансы, конечное окно и выходы BBN

Прямой прогон GitHub Actions. Время вычислительных стадий 66.2 с.

## Проверка закона Портера–Томаса

Первые две трети уровней по энергии задают масштаб. Положительная разность средних логарифмических оценок на отложенных уровнях благоприятствует Портеру–Томасу относительно экспоненты. Интервал условен на обучении и относится только к отобранным уровням.

|---|---:|---:|---:|---:|---:|---:|
| 21803002 | 24 | 16 / 8 | -0.035 | [-0.214, +0.150] | 0.425 | +0.085 / 0.705 |
| 10172047 | 8 | 5 / 3 | -0.286 | [-0.334, -0.238] | 0.060 | +0.857 / 0.026 |

При точных полных независимых выборках сбалансированная доля правильных решений для ПТ и экспоненты равна 67.4% при N=8, 78.1% при N=24, 90.7% при N=64, 99.6% при N=256. Отбор по обнаружению и ошибки присвоения в эксперименте могут изменить эти величины.
