# R141. Измеренные спектры и отклик BBN

Продолжение [R141](../../analysis/R141_RIEMANN_CORPUS/README.md) на научной ревизии `faad3c1`. Площадка по поручению владельца от 22 ноября 2026 г. — GitHub Actions. Прогноз вычислительных стадий 10–180 с, ориентиром служит прежний быстрый replay при готовых нулях. Получение зависимостей, очередь и публикация учитываются отдельно. Время фиксирует RECEIPT.json. Научный результат допускает отсутствие различимости даже при успешном исполнении.

## Данные и первичная проверка

Основной донор — измерения Cornelis, Mewissen и Poortmans в Геле, EXFOR 21803002, 188 строк. Отбор до анализа задаёт положительную энергию, явные L=0, J=1/2 и отсутствие флага сомнительного назначения. У мишени ⁵⁶Fe основное состояние 0⁺. Отбирается один сектор составного ⁵⁷Fe, Jᵖ=1/2⁺. Используется столбец 3 REACTION (нейтронная ширина Райха–Мура, эВ). Это параметры подгонки по данным нейтронной спектроскопии. Ошибки широких резонансов и присвоение L могут быть связаны с обнаружением. EXFOR указывает частное сообщение как источник таблицы. Второй донор — Garg, Rainwater, Havens, EXFOR 10172047, общий L=0. Из девяти строк исключается связанное состояние при отрицательной энергии. Для восьми положительных уровней используется обычная ширина, переведённая из кэВ. Разные диапазоны энергий и параметры экспериментов анализируются раздельно.

Для обоих источников применяется одна конвенция приведённой ширины, Γ⁰=Γₙ/√(E/1 эВ). Никакие γ-ширины по пропускам не восстанавливаются. Поля источника, номера исходных строк, ошибки и учёт отбора сохраняются. [Гель, первичная запись](https://github.com/IAEA-NDS/exfor_master/blob/2efecedd83bd22133350a3e1b15bf74839a1c0c7/exforall/218/21803.x4) · [Garg и соавт.](https://doi.org/10.1103/PhysRevC.3.2447) · [Таблица низких энергий](https://github.com/IAEA-NDS/exfor_master/blob/2efecedd83bd22133350a3e1b15bf74839a1c0c7/exforall/101/10172.x4) · [Конвенция МАГАТЭ](https://www-nds.iaea.org/nrdc/nrdc_doc/iaea-nds-0208-202505.pdf) · [Проблема отбора в ядерных данных](https://doi.org/10.1103/PhysRevC.84.034312).

1. Первые ⌊2N/3⌋ уровней по энергии задают масштаб Gamma с формой 1/2 (Портер–Томас) либо 1 (экспонента). Первичный результат — средняя разность логарифмов предсказательной плотности ПТ минус экспонента на последних уровнях. Дополнительно применяется условное правдоподобие при фиксированных порогах, определённых 10-м и 25-м процентилями обучающей выборки. Неизвестная эффективность обнаружения остаётся источником смещения. При трёх отложенных уровнях бутстреп особенно груб.
2. Тест KS калибруется 9999 независимыми выборками ПТ с переоценкой среднего. Он условен на полной выборке и общей шкале. Для связи ширины с зазором закреплён следующий за уровнем интервал по энергии. Метки случайно переставляются внутри смежных блоков по энергии, 3999 перестановок. Положительный контроль присваивает метке ранг зазора. Дополнительно варьируются ширины по положительной логнормальной модели с указанными относительными ошибками. Это сценарий при неизвестной ковариации измерения. Все дополнительные сравнения разведочные.
3. Для N=8,24,64,256 измерена различимость ПТ и экспоненты на десяти тысячах независимых спектров на закон. Средний масштаб обучается заново. Эта доля верных предсказаний характеризует идеальный эксперимент. Слабая мощность или большое p оставляют класс открытым.
4. Все 657 ординат из Actions 45038065048 проверяются по SHA-256. Ординаты 61–657 используются для окон 4,12,36 зазоров после гладкой развёртки Римана–фон Мангольдта. Окна внутри одной последовательности могут быть зависимы. Опорные распределения — 600 пар COE/CUE порядка 48. Межклассовый AUC относится к моделям. Окна низколежащих нулей дают конечную статистику. Вопрос ГР и существование оператора Гильберта–Пойа остаются самостоятельными.
5. Унитарное отображение в базис Фурье переносит циклический сдвиг S в exp(2πik/N), маску P в U*PU и B=P(S−I)P в соответствующее сжатие. Проверяется невязка K=BB* на двух семействах слов, N=6,12,24,48. Это точный свободный периодический сектор. Для арифметического возмущения Конна и его предела операторный перенос открыт. В R140 p задаёт вероятность выполнить физическую промежуточную запись с последующим забыванием результата. Матрица эффектов — выпуклая смесь двух физических протоколов. Проверяются точный определитель, ранг и сингулярные значения при пяти p. [Генеалогия ГП и конечных операторов](../../analysis/R141_RIEMANN_CORPUS/HILBERT_POLYA.md).
6. Полностью повторяется опубликованный [аудит усреднения](../../analysis/R141_RIEMANN_CORPUS/bbn/AVERAGING.md). Поверх него восемь компонент BBN интегрируются нелинейно на сохранённой тепловой истории, начиная при T₉=2 с интерполяцией архивного состояния. Для всех микроскопических скоростей и обратной скорости часов используется один множитель 1/f, при f=3 и f(T₉)=1+2T₉/(1+T₉). Селективный контроль меняет оба направления d(p,γ)³He на ±1% при исходном фоне. Сохраняются сдвиги выходов, уточнение допуска решателя и отклонение восстановленной траектории от исходной. Запуск условен на общей плазменной истории, барионной плотности и начальном состоянии. Он не предсказывает величину неуниверсального дрейфа CCC+TL или N_eff.
7. Для иллюстрации потери различимости один и тот же CV² ширин из обучения в Геле применяется как параметр независимых сил двух математических ансамблей при фиксированном фильтре BBN. Получается чувствительность при указанных допущениях. Для вывода о лёгком ядре понадобятся его собственные уровни, обе канальные ширины и независимые данные о сечении.

## Воспроизведение

[Workflow](../../.github/workflows/r141-integrated.yml) закрепляет коммиты всех входов, версии библиотек и пути. При наличии четырёх checkout и массива ординат команда из корня репозитория имеет вид

```sh
OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 python reproductions/R141_INTEGRATED_20261122/run.py \
  --exfor inputs/exfor --primat inputs/primat --history inputs/history \
  --zeros inputs/zeta/reproductions/R141_ZETA_657_20261122/results/45038065048/zeros657.json \
  --out /tmp/r141-results
(cd /tmp/r141-results && sha256sum -c MANIFEST.sha256)
```

Успех требует проверки закреплённых входов, полноты строк, положительного контроля, точного воспроизведения конечных эффектов, совпадения прошлого численного аудита в его допусках, сохранения барионного числа, численного нуля общих часов и противоположных знаков контролируемых сдвигов D/H. Направление предпочтения ПТ заранее не задано. Итог фиксируется в отдельной ветке с номером запуска и попытки, таблицах JSON и отчёте.
