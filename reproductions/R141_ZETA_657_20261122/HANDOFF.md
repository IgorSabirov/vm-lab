# R141: полный вычислительный повтор первых 657 нулей дзета-функции

Владелец поручил выполнить полный повтор на GitHub через тот же проверенный канал, что и R130 (#85, PR #88, Actions run 44082471150): GitHub Actions устанавливает закреплённый Copilot CLI 1.0.103, native Auto вызывает один узкий MCP-инструмент `zeta.execute`, затем опрашивает `zeta.status`. Инструмент не принимает произвольные команды/пути и не предоставляет shell. Исполнитель запускает неизменяемый скрипт `reproduce.py`.

## Научный объём

- Первые 60 положительных ординат берутся через `mpmath.zetazero(n)`.
- Следующие 597 находятся сканированием Siegel Z с шагом 0.1, только по истинным сменам знака `mpmath.siegelz`; уточнение выполняется бисекцией той же функции при повышенной точности.
- Spot checks через индексированный `mpmath.zetazero(n)`: 1, 2, 10, 60, 100, 300, 500, 596, 617, 650, 651, 657.
- Проверяются порядок, уникальность, знаки скобок, остатки в корнях и ровно 657 значений.
- Пересчитывается парное произведение `Xi(z)/Xi(0)` при z=1, сравнение абсолютной/относительной ошибки при N=10,30,100,595,596,616,617,650,657 и первые пересечения 1e-3.
- Гауссовы суммы для a=0.01,0.1,1.0 вычисляются на первых 60 и на всех 657 нулях.
- CCC+TL clock integral s(1000) вычисляется отдельно при 50 десятичных знаках.

## Ограничения интерпретации

Это численное воспроизведение, не доказательство RH, простоты всех нулей или полноты поиска среди возможных кратных/не меняющих знак нулей. Шаг сетки и spot checks документируются. mpmath не является интервальным proof checker. Результат сравнения с произведением Адамара условен в рамках принятого спектрального представления Xi; научный статус R141 не меняется.

## Запуск

Push коммита пакета в ветку `work/r141-zeta-657-copilot-20261122` автоматически запускает `.github/workflows/r141-zeta-657-copilot.yml`. Это тот же способ запуска, что и успешный R130: workflow вызывает native Copilot CLI с MCP-сервером фиксированных операций, Copilot запускает execute и опрашивает status. Результат сохраняется в Actions artifact, затем доверенный publish job коммитит его и открывает draft PR.
