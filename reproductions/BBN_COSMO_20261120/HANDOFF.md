# Полные прямые расчёты BBN и CMB на GitHub

Задание [#140](https://github.com/IgorSabirov/vm-lab/issues/140). Нативный Copilot CLI вызывает одну фиксированную команду `bbn.execute` на GitHub Actions. После вызова раннер ждёт завершения расчётов. Отдельное задание проверяет SHA-256 и публикует исходные выходы и квитанции в ветке результата.

| Блок | Замороженный объём |
|---|---|
| Две нативные проверки | Стандартная малая сеть PRIMAT Python против upstream-эталона. LINX key_PRIMAT_2023 против базовой точки S3 при прежних допусках. |
| Общая задача | 17 историй/реализаций, каждая в LINX и малой сети PRIMAT. Обе системы получают одни плазменные величины, часы, начальные содержания, прямые, обратные и слабые скорости. PRIMAT использует штатные стехиометрические операторы RHS и якобиана со SciPy BDF. LINX интегрирует сеть штатным Kvaerno3. |
| Чувствительность D+D | Оба канала при q=±0.25 и ±0.125, центральные разности логарифмов Yp и D/H. Дополнительное ужесточение точности для базы и d+d→t+p при q=±0.125. |
| Две истории H(T) | +0.30% при 0.2–2 МэВ, +0.55% при 0.02–0.2 МэВ и половинные амплитуды при фиксированных микрофизике и плотности барионов как функциях температуры. |
| Две эпохи | Свободно распространяющееся дополнительное излучение до конца BBN. Калибровка запаса энергии на позднюю передачу, эквивалентную 4% энергии фотонов и 4% исходного нефотонного излучения. При полном расходовании запаса и термализации фотонов сохраняется число барионов. Вторая история переносит полученную барионную плотность и отношение энергий в CLASS. |
| Шесть запусков CLASS | Нативный PRIMAT, общая база LINX, раннее и позднее окна, дополнительное свободное излучение и его позднее перераспределение. Нелензированные скалярные TT, EE, TE до ℓ=2500, численный фон и входные параметры для каждой истории. |

Используется плоская ΛCDM с безмассовым свободно распространяющимся релятивистским сектором. Для CMB используется массовая конвенция гелия PRIMAT. При поздней передаче предполагается завершение термализации задолго до входа учитываемых мод в горизонт и адиабатическое начальное состояние возмущений CLASS. Переход представлен согласованием двух эпох. Профиль передачи во времени и возмущения самого X остаются открытыми. Окна H(T) задают только часы BBN. Их влияние на CMB передано через гелий.

Научная граница проходит по входам. У BH1 отсутствует заданный физический источник, у графа ADD нет калиброванного отображения в плотности и часы. Эти расчёты дают контрольные предсказания при явных входах. Подгонка по данным CMB, оценка правдоподобия и происхождение экспериментальной ковариации D+D в пакет не входят. Сравнение с атласом Burns сохраняет собственную нормировку табличных неопределённостей.

В каждой общей задаче сохраняются канонический JSON, дополнительные слабые/обратные скорости, две траектории восьми видов и конечные наблюдаемые. Файл SUMMARY.json объединяет результаты. EXECUTION_RECEIPT.json фиксирует отдельно фактическое время и ошибки. Порог сравнения базовых выходов по двум интеграторам равен 0.01% для Yp и 0.1% для D/H. Доверие к малым производным оценивается по обоим шагам и уточнению численной точности. Различие в контрольных значениях сохраняется в данных.
