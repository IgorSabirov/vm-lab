# NOW_INTEGRATED_CONTINUATION_V1 — патч 0.4 для ревизии

[План доработки](../../analysis/INTEGRATED_EXPERIMENT_20261107/PATCH_20261108.md)
и [пакет технической ревизии с командами](FOUR_CANDIDATE_REVIEW.md).

Это прежний опыт, расширенный на базе проверенного исходника 0.3 `ea49ebc`.
123 прежних случая сохранены; 87 добавленных дают 210 случаев, 160 контрастов,
413 задач основного состава (включая прежние 192 MC и 11 контролей).
Научная цель — способность организации хранить содержание, передавать аппарат
и восстанавливать действие на изменяющемся носителе в модели «сейчас».

Работают в коде: прежние память/W-R/производство/передача; C2 FULL Q/QI2 с реальными
пакетами; подготовленные причинные порядки и CDT-слои; платная XOR-проба в слоте B;
ON/OFF/SHAM после повреждения; полный snapshot; импорт взвешенных геометрий;
optional Serbian C++ диагностика через `--signature-library`.

Часы, инфраструктура и метрика контрольных геометрий заданы. Они не являются
равновесными ансамблями авторов. C3-D, физический reverse и обратное действие
организации на Q/I2 ещё не реализованы. Мера и j* не выдумываются.
Основные показатели задачи и цена разделены; health остаётся прежней наблюдаемой.

Статус: код написан; синтаксис/JSON/связи проверены статически. 17 новых unit-тестов
подготовлены, но автором до ревизии не исполнялись. Сохранён порядок: ревизия →
исправления → ограниченные дымовые → новая VM-калибровка → решение о main.
Диагностика Copilot: CLI и сохранённый вход в этой среде отсутствуют.

Прежние 54 теста, 18 проверок, дымовые 15,59 с и прогноз 19,45 с относятся к 0.3
на его SHA. Этот патч требует собственной проверки и калибровки. Прежние supervisor,
hard limits, контроль хешей, сохранение/возобновление и конечные бюджеты сохранены.
`PROTOCOL.json` не заморожен для main. Новая квитанция не подделывается.
