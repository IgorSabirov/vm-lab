# Связи моделей, отображений и методов

Это инкрементальные карточки, не полная матрица пар. Число связей заранее не
замораживается. Типы ModelVariant, Mapping, Method, PhysicalContext различаются.
Карточка хранит `context_family` и `context_instance`; неизвестное — null, а не
придуманная физика. Одностороннее вложение контекстов не означает эквивалентность.

ADD_F2 — независимая реконструкция `sqrt_tau(I2(g))`. R129_CONTACT_CAPACITY —
отдельная линия конечной ёмкости контактов, не автоматически вариант ADD.
ANTHROPIC_HP и ещё не определённый BH1_COSMOLOGICAL_SECTOR не отождествляются.

Укрупнение требует strong lumpability только при заявлении точного марковского
закона для всех начальных распределений. Память, расширение состояния или явно
заданный класс начальных распределений — другие допустимые контракты.

Диагностика порядка/контакта заранее различает совпадение, контактную зависимость
и смешанную зависимость по подмножеству вмешательств. Различие содержательно лишь
после исключения конвенций и при указании механизма, который его предсказывает.
Ни одна карточка здесь не устанавливает общий физический инвариант.
