# Первый пакет независимых исполнителей

`infra/package_runner.py` получает замороженный execution plan и подтверждённую
копию единственной записи RESERVED из общего ledger. Диспетчер использует
`admit.decision/reserve` с CAS; local/Actions/VM не получают отдельные суточные квоты.
CLI не резервирует повторно, не возобновляет существующий output и не ремонтирует
код. Для этого установленного runner допускаются только local и parallel_sections=1.
Другие маршруты отклоняются до исполнения; архитектурный валидатор PR #61 сохраняет
проверку параллельной памяти и делимости для специализированных исполнителей.

Каждая независимая секция содержит свой v1 run_plan, конфигурацию, фиксированный
entrypoint `infra/adapters/worker.py`, процессный бюджет и отдельные артефакты.
Целый пакет ≤600 с, а не каждая секция отдельно. Общая память и совокупные выходы
ограничены; процессы и потомки завершаются перед освобождением reservation.

Три уровня доказательств:

1. `run_contract.verify_receipt` проверяет идентичность и хеши каждой секции.
2. `adapters/domain_verify.py` не вызывает адаптеры/оператор F2: отдельно считает
   начальные частицы и проверяет сохранение; для Gram использует точный определитель
   по Герону. Это ограниченные проверки, не независимая реализация всей динамики.
3. Карточки `infra/relationships` задают физическое отображение и его предпосылки.
   Совместное исполнение не удостоверяет физическую связь.

ADD: одна короткая траектория реконструированного F2, не полный ансамбль и не
аттестация авторского закона. Serbian: существующий build_and_check без
несуществующего --kernel-only, восемь наборов ядра + штатные проверки сборки,
затем четыре отдельные Gram-фикстуры. Exact-degenerate и negative signature
различаются; reliable/ambiguity/cutoff — отдельные наблюдаемые поля ядра.

Технический FAIL сохраняется; независимая следующая секция может выполниться,
зависимые научные этапы не запускаются. Публикация готовых результатов может быть
восстановлена без повторного расчёта. Завершение ledger фиксирует только факт
выхода процессов; научная приёмка остаётся false.

Манифест публикации содержит RAW/DOMAIN/PROCESS/SECTION, BUILD.json и stdout.
Восстановимые компиляторные build-каталоги остаются локальными scratch; они
явно исключены из манифеста, а исходный архив и рецепты закреплены SHA-256.
