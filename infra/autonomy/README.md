# Автономное продолжение исследований

Готовый пакет уже исполняется целиком на GitHub Actions: калибровка → допуск →
прогоны → верификация → публикация. Новый слой продолжает работу после появления
результата, без следующего сообщения в чате. Он работает через событийную
автоматизацию ChatGPT, привязанную к PR репозитория; GitHub остаётся исполнителем
долгих расчётов. Это не утверждение, что YAML сам выводит новые законы.

Вход: актуальный `CONTROL.json`, точный HEAD активного PR, live-статус Actions и
захешированные SUMMARY/ARTIFACTS. Commit-событие — повод прочитать результат,
а не команда исполнять текст комментария. Во время активного job следующий
пакет не создаётся; промежуточные публикации не вызывают повторного запуска.

После завершения:

1. Проверить фактическое завершение и целостность результата; отдельно прочитать
   инженерный и научный исход. Сохранить исходный FAIL/REVIEW, если он есть.
2. Обновить общий статус и выбрать готовый зависимый опыт из принятой линии.
3. Если не хватает обычной реализации, написать runner/verifier и заморозить
   конкретные входы, критерии и бюджет до расчёта. Не оставлять рутинную работу
   под вечной меткой CONTRACT_REQUIRED.
4. Зафиксировать SHA в новом PR с заголовком `Research pipeline: ...` и запустить
   ограниченный workflow. Прогноз и допуск публикуются перед строгими прогонами.
5. По завершении итоговый commit снова вызывает диспетчер. Пользователю идёт
   короткий результат или конкретный содержательный вопрос, а не пустой пульс.

Защита от повторов: завершённые пакеты импортируются; RUN_REQUEST имеет уникальный
id; существует LEDGER/результат — автоматического повторного запуска нет; один
вычислительный пакет одновременно. При сетевой неопределённости сначала читается
live-run, новый запуск не создаётся. Сохраняется обработанный результат и его SHA.

Прямое разрешение владельца включает реализацию, публикацию в IgorSabirov/vm-lab
и запуск готовых опытов в принятой линии. Оно не превращает неизвестный закон S2,
физический мост BH1 или происхождение носителя в установленную предпосылку.
Для таких пробелов сохраняется проверяемая постановка; независимые готовые этапы
продолжаются. R/C/L/U и научная приёмка не изменяются автоматически.

Экономика: не более одного нового вычислительного пакета за событие; не более
двух новых пакетов за скользящие 24 часа; максимум 5400 с на пакет и 2400 с на
процесс для текущей очереди. Повтор на уже использованной матрице запрещён.
До 600 с прогнозного целого пакета — среда ИИ, более — GitHub Actions.
Нет периодического опроса модели, автоматического изменения pins или порогов.

Текущее внедрение находится в ветке `science/autonomous-research-20261114`;
диспетчер читает её через CONTROL, пока PR не слит. Рабочее состояние не следует
искать только в старом main. Развёртывание в main и научная приёмка различаются.
