# Отзыв соседа: что внедрено и почему

Источник: [полный исходный отзыв](NEIGHBOR.txt). База проверки репозитория:
`7770ce940c398199e1ffd5d0888a6dc925be3ac6`. Прямое последующее поручение владельца:
Copilot управляет реестрами, ищет публичные модели и готовит интеграции через GitHub;
ВМ на паузе в резерве. Это расширяет прежнюю роль исключительно рецензента кода.

| Предложение | Проверка и решение |
|---|---|
| Сохранить изолированный bridge | Принято: текстовая рецензия остаётся отдельным каналом. Это не независимое научное воспроизведение |
| Нативные instructions и profiles | Принято: общая инструкция, три области и три роли вместо пяти постоянно вызываемых рецензентов |
| Управление реестром через MCP | Цель принята: используем уже встроенный GitHub MCP и небольшой read-only context CLI поверх существующего INDEX. Новый постоянно работающий MCP-сервис пока не нужен |
| Cloud Agent как исполнитель | На Free реализуем штатный Agentic Workflow с Copilot CLI на Actions. Pro/Pro+ добавляют нативное назначение Issue облачному агенту без замены данных |
| Автоматическое Code Review каждого PR | Сейчас отложено: GitHub PR review не включён в Free; ревью каждого push расходует квоту. После upgrade — выборочно, с фактическим учётом пользы |
| Skills и hooks | Не создаём параллельный процедурный слой: уже есть проверяемые скрипты, allowlist публикации, native safe outputs и CI. Инструкция модели не является защитой прав |
| Обновить CLI до 1.0.109 | Не включено в этот пакет: не смешиваем смену CLI с вводом нового контура. Проверенная история — 1.0.105; compiler и CLI закреплены, откат прозрачен |
| Отдельная validation VM | Не принята сейчас: против текущего поручения работать на GitHub и держать ВМ резервом |
| Несколько внешних агентов на задачу | Не включено: общий источник кода не делает мнения независимыми, затратная польза не измерена |
| Сначала купить Pro+ | Исправлено: CLI и Agentic Workflow возможны на Free; для личного репозитория нужна отдельная авторизация, не обязательная покупка |
| Кредиты/Actions | Проверено: Pro+ $39, 7000 credits на дату проверки, flex изменяем; стандартные runners публичного репозитория бесплатны, другие среды и хранение учитываются отдельно |

Цены Lite/Balanced/Max в отзыве действительно встречаются в официальной документации
как средние ориентиры, не гарантированная стоимость. Они не входят в бюджет нашего
Free-профиля. Положение «Copilot лучше знает GitHub» преобразовано в обязанность
проверять реальные commits, лицензии и файлы: специального всеведения у модели нет.

Из прошлых опытов берём проверку предложений, точные хеши, сохранение ответа и
исключение слепых повторов. Не заявляем переносимость производительности прежних
численных опытов на новую нагрузку. Нового научного результата или эксперимента
это внедрение не создаёт; карточки R/C/L/U/N и 66 предпосылок сохраняют свои статусы.

Техническая оговорка компилятора: gh-aw 1.2.2 принимал YAML allowed-tools с
объектами `max-calls`, но предупреждал о невозможности разобрать конфигурацию.
Использован корректно компилируемый список имён. Лимит поисков/файлов в prompt —
инструкция, не обещание отдельного enforced счётчика. Жёсткие пределы — budget,
turns, время, permissions и пути публикации. Сборка проходит без предупреждений.

Статус активации брать из последнего Copilot integration preflight и реального
операторского run. Файл конфигурации и зелёные offline-тесты не доказывают ответ
Copilot. Если секрета/квоты нет — AUTH_REQUIRED/ошибка сервиса, а не успешный пилот.
