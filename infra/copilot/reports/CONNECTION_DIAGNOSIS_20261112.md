## Локализация

Действующий токен и прямой native inference работают. Сбой локализован в маршруте
gh-aw/AWF с явным выбором модели; успешное чтение каталога не аттестует право
аккаунта на такой выбор. Возвращённый 502 не доказывает недоступность сервиса Copilot.

В проверенном AWF v0.29.11 (`d9272015d8523b4c9cf3b00ce26b507046cbf1a3`),
`containers/api-proxy/upstream-http.js`, `model_fallback_exhausted` может
генерироваться самим прокси после `model_not_supported`. Исходное тело отказа
в сохранённых журналах нашего запуска не найдено: конкретный исходный HTTP 400
для нашего запроса не объявляем непосредственно наблюдённым.

Известная несовместимость подтверждена первичными upstream-источниками:
- [gh-aw #46531](https://github.com/github/gh-aw/issues/46531): Free допускает
  native Auto, каталог не фильтрует право на явный выбор модели.
- [gh-aw #74970](https://github.com/github/gh-aw/issues/74970): разработчик
  подтверждает, что gh-aw запускает CLI в offline/BYOK, заранее разрешая auto
  в конкретную модель и фиксируя wire API. Простого сохранения строки auto недостаточно.
- [AWF #11269](https://github.com/github/gh-aw-firewall/issues/11269): native Auto
  через credential-isolating proxy требует отдельного согласованного режима.

Сочетание нашего прямого контроля, неудачного проксированного маршрута и этих
источников объясняет отказ текущей конфигурации. Не выдаём это за испытание всех
версий AWF или за гарантию, что покупка подписки исправит систему.

## Исправление маршрута в ограниченном объёме

Добавлен `Copilot native report pilot` для уже поставленной задачи #16:
доверенный сбор источников и проверки → native Auto без инструментов → проверка
формата/границ → отдельный publisher с двумя фиксированными Markdown/JSON-путями
→ draft PR → независимая проверка фактического SHA. Модель не получает write-token,
не выполняет команды, не видит секретов в запросе и не меняет научные статусы.
Исходный gh-aw sandbox не ослабляется; native pilot — отдельный ограниченный путь.

Первый pilot касается существующего IsingCauset, R127, F02, N02; произвольные
задачи, самостоятельный поиск и редактура реестров этим ещё не реализованы.
30 AI Credits — минимальный допустимый потолок CLI, не измеренная стоимость.
Одна сессия, 120 секунд, без повторов по расписанию. Истинный итог пилота — его
run/PR и сохранённая квитанция, не наличие этого кода или зелёный CI.
