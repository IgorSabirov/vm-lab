# XB_SU3_EOS_PAIR_v0.1 — две устойчивые фазы чистой SU(3)

Поставка #161/#167 для исследования источника GW в #174, R135 / C037 / U006. Основание — PR #185 на 8e3ce884, исполнитель #159 на c3bc771d, проект #160 на cfbf4cbc. [Аудит доноров](../PHYSICAL_INPUT_DONORS_174.md) · [Присланное описание](SOURCE_REVIEW.txt) · [Паспорт постановки XB](XB_SU3_MODEL_PASSPORT.json) · [Результат](eos_pair_su3.json).

## Какой результат получен

Собраны опубликованные равновесные ветви чистой SU(3) по разные стороны температуры сосуществования. Для каждой температуры сохранены x=T/Tc, s/Tc³, p/Tc⁴, e/Tc⁴, w/Tc⁴, остаток опубликованной аппроксимации давления и две оценки производной, где им хватает данных. В точке сосуществования фазы имеют разные энтропии и общее давление. Для вычисления Δp при переохлаждении обе фазы нужны **при одной температуре**. В текущем пакете их проверенные интервалы пересекаются только при Tc.

Горячая ветвь доступна на [1,3.433], холодная на [0.8,1]. Источник энтропии — формулы §5 и континуальные значения табл. 3; при x=1 используем раздельные фазовые измерения §4. В контрольной таблице зафиксирована версия arXiv v1, включая холодную точку 0.98. Файлы [donor_inputs.json](donor_inputs.json) и [replay_eos.py](replay_eos.py) содержат входы и команды построения. Хеш первичного архива Giusti взят из закреплённого манифеста #159; SHA-256 точных байтов локального среза входов вычисляется при каждой сборке. Три числа для скрытой теплоты представляют два определения и их объединение; в совместной статистике это зависимые величины. [Giusti и соавт., §§4–5, табл. 3](https://arxiv.org/html/2501.10284v1) · [Версия журнала](https://doi.org/10.1016/j.physletb.2025.139775).

## Нормировка и ошибки

Авторы строят начальное давление по газу глюболов до 0.8Tc, далее интегрируют энтропию по температуре с интерполяцией log(s/T³). Здесь реализован явно заданный вариант этой процедуры. На холодных узлах линейно интерполируем log(s/T³) по x и интегрируем x³s/T³ от 0.8 до 1. Нижний вклад равен давлению четырёх бозонных состояний при 0.8Tc. После определения общего якоря продолжаем давление в каждую устойчивую фазу интегралом её опубликованной энтропийной аппроксимации; e=Ts−p, w=Ts. Параметризация давления из статьи служит отдельной сверкой. Это реконструкция по открытым центральным данным. [Giusti, §5](https://arxiv.org/html/2501.10284v1) · [Фиксированный срез #159](https://github.com/IgorSabirov/vm-lab/blob/c3bc771d1daa292d5d9fd3e1d17bf4d3d6d01c92/analysis/R135_PHYSICAL_SECTOR_X_20261120/full_run/software/donors/validation.json).

| Опора для Tc/√σ струны | s/T³ газа при 0.8Tc | s/T³ газа при Tc | Общий p(Tc)/Tc⁴ |
|---|---:|---:|---:|
| 0.6462, опора #159 | 0.03080 | 0.10221 | 0.017775 |
| 0.629, Boyd и соавт. | 0.02621 | 0.08951 | 0.017580 |

Четыре основных состояния и вырождения взяты из работы **2021 г.**, табл. 34, к которой отсылает Giusti. При Tc они дают около 31–35% наблюдаемого s/T³=0.2928(38); ближе к переходу существенны более тяжёлые состояния. Струнное натяжение в конверсии масс имеет размерность энергии², межфазное — энергии³. [Athenodorou–Teper, табл. 34](https://arxiv.org/abs/2106.00364) · [Альтернативная шкала Boyd](https://doi.org/10.1103/PhysRevLett.75.4169).

Подъём и снижение всех холодных точек на их опубликованные маргинальные ошибки при фиксированной шкале дают интервал чувствительности якоря 0.016802–0.018722. Он учитывает монотонность логарифмической интерполяции по её положительным узлам и не имеет назначенной вероятности покрытия. Полная ковариация фаз, калибровки масс и производных остаётся OPEN_INPUT. Для замены этой оценки нужны совместные выборки авторов либо отдельно обоснованная модель ошибок. Значения двух масштабов образуют отдельную проверку выбора шкалы.

**Поправка к приложению.** Аддитивное изменение общего p(Tc)/Tc⁴ на C меняет оба давления на C, обе энергии на −C; энтальпии и Δp при одинаковой температуре сохраняются. Смещение только одной ветви на 0.00016 создаёт ошибку относительной нормировки. Это отдельная систематика, её нельзя считать ошибкой общего якоря или физическим разбросом скорости нуклеации. Корреляции ошибок формы ветвей существенны даже при точном совпадении давлений на Tc.

## Допуск к гидродинамической интерпретации

- Формула q_s горячей фазы имеет ближайший нуль при x=0.99487548 и полюс при 0.99259637. Оба лежат вне опубликованной области. Вторая таблица из приложения при ε≤0.005 не пересекает этот полюс. Её значения остаются экстраполяцией, включая x=0.99931. Более глубокое интегрирование через полюс дополнительно математически некорректно. Скрипт отклоняет любой запрос горячей фазы при x<1.
- При Tc дифференцирование независимых приближений давления даёт s/T³=1.60679 и 0.26358. Входные приближения энтропии дают 1.471 и 0.2927. Давление в пакете строится интегрированием энтропии. Собственная производная аппроксимации s/T³ на горячем стыке при 1.1 даёт односторонние c_s²=0.17054 и 0.17235.
- Для устойчивой холодной фазы при x=0.99931 получены c_s²=0.02429 по дробно-степенному фиту и 0.04397 по PCHIP величины s/Tc³ на измеренных узлах. Точка выбрана по модельному примеру HPR; численное сравнение относится к холодной стороне. В пределе x→1⁻ аналитическая производная фита по x уходит в −∞, что нарушает устойчивость при достаточно малом 1−x. В JSON значение фита в самой граничной точке равно null; оценка PCHIP сохраняется как односторонняя диагностика. Промежуток между оценками характеризует выбор интерполяции. Для допуска скорости нужны производная с подтверждённой областью, разрешением по температуре и неопределённостью.
- Для газа при использовании q_s=s/T³ формула c_s²=1/(3+d ln q_s/d ln T). Выражение q_s/(T dq_s/dT) из промежуточного блока вложения пропускает множитель T³ в размерной энтропии.

## Воспроизведение контроля

Из этого каталога с Python 3, NumPy и SciPy:

```sh
python replay_eos.py --output /tmp/xb-eos-review.json
python -m unittest -v test_replay_eos
```

Тесты покрывают скаляры/массивы и выход за область, отдельные опубликованные измерения, контроль четырёх бозонных состояний, размерности, независимую квадратуру давления, общую константу и маску производной. Для побайтовой сверки в той же среде используйте `cmp /tmp/xb-eos-review.json eos_pair_su3.json`. Внешний авторский код не исполнялся. Среда контрольного повтора — Python 3.12.14, NumPy 2.3.5, SciPy 1.17.0. Состояние пакета — донорский контроль устойчивых фаз. Физический запуск, присвоение статуса physical_candidate и научная приёмка не входят в эту поставку.
